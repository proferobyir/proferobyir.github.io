📦 1. Variables y tipos fundamentos

En Luau usamos local para ámbito. Tipos dinámicos: nil, boolean, number, string, table, function, thread, userdata.

-- Variables básicas local nombre = "Ana" local edad = 28 local activo = true local lista = { "Luau", 2025, false } -- interpolación con .. (concatenación) local mensaje = "Hola, " .. nombre .. " tienes " .. edad print(mensaje) -- Hola, Ana tienes 28
▶ Hola, Ana tienes 28  |  lista[1] = Luau

⚙️ 2. Funciones & tablas estructuras

Las funciones son ciudadanas de primera clase. Las tablas son el pilar de Luau: arrays, diccionarios y objetos.

-- función que retorna múltiples valores local function saludar(nombre, edad) return "Hola " .. nombre, edad + 1 end local persona = { nombre = "Carlos", edad = 32, saludar = function(self) return "Soy " .. self.nombre end } local msg, nuevaEdad = saludar(persona.nombre, persona.edad) print(msg, nuevaEdad) -- Hola Carlos 33
▶ Hola Carlos 33  |  persona:saludar() → "Soy Carlos"

🧊 3. Cuerpos (Body) y colisiones física

En entornos como Roblox, un Body representa un objeto físico con masa, velocidad, posición. Las colisiones ocurren cuando dos cuerpos se intersectan.

-- Simulación de un cuerpo simple local Body = {} Body.__index = Body function Body:new(x, y, vx, vy) local self = setmetatable({}, Body) self.x = x or 0 self.y = y or 0 self.vx = vx or 0 self.vy = vy or 0 self.masa = 1 return self end function Body:actualizar(dt) self.x = self.x + self.vx * dt self.y = self.y + self.vy * dt end function Body:colisionaCon(otro) -- distancia simple (círculos) local dx = self.x - otro.x local dy = self.y - otro.y local dist = math.sqrt(dx*dx + dy*dy) return dist < 2.0 -- umbral de colisión end local cuerpoA = Body:new(0, 0, 0.5, 0.3) local cuerpoB = Body:new(1.2, 0.8, -0.2, 0.1) cuerpoA:actualizar(0.5) -- avanza local choque = cuerpoA:colisionaCon(cuerpoB) print("¿Colisión? " .. tostring(choque))
▶ ¿Colisión? false   (cuerpoA en (0.25, 0.15) , cuerpoB en (1.2,0.8) → distancia > 2)

🌳 4. Nodos (Nodes) jerarquía

Un nodo es un elemento en un árbol o escena. Puede tener hijos y propiedades como posición, rotación, etc. Usamos tablas para simularlo.

-- Definición de Nodo con herencia local Node = {} Node.__index = Node function Node:new(nombre, parent) local self = setmetatable({}, Node) self.nombre = nombre or "nodo" self.hijos = {} self.parent = parent or nil if parent then parent:addHijo(self) end return self end function Node:addHijo(hijo) table.insert(self.hijos, hijo) hijo.parent = self end function Node:obtenerRuta() if self.parent then return self.parent:obtenerRuta() .. "/" .. self.nombre else return self.nombre end end local raiz = Node:new("raiz") local hijo1 = Node:new("nivel1", raiz) local hijo2 = Node:new("nivel2", hijo1) print(hijo2:obtenerRuta()) -- raiz/nivel1/nivel2
▶ raiz/nivel1/nivel2   (jerarquía de nodos)

📡 5. Señales (Signals) eventos

Las señales permiten comunicación desacoplada. Un objeto emite una señal y otros se suscriben (patrón observer).

-- Implementación mínima de Signal local Signal = {} Signal.__index = Signal function Signal:new() local self = setmetatable({}, Signal) self._escuchas = {} return self end function Signal:conectar(callback) table.insert(self._escuchas, callback) end function Signal:emitir(...) for _, cb in ipairs(self._escuchas) do cb(...) end end local evento = Signal:new() evento:conectar(function(msg) print("📨 " .. msg) end) evento:conectar(function() print("⚡ señal recibida") end) evento:emitir("Hola desde Luau")
▶ 📨 Hola desde Luau
▶ ⚡ señal recibida

🔗 6. Todo junto: cuerpo, nodo, señal colisión con evento

Un cuerpo se convierte en un nodo y emite una señal cuando colisiona. Demostración de conceptos integrados.

-- CuerpoNodo que hereda de Body y Node (mixin) local BodyNode = {} BodyNode.__index = function(t, k) return Body[k] or Node[k] or BodyNode[k] end function BodyNode:new(nombre, x, y) local self = setmetatable({}, BodyNode) -- inicializar partes for k,v in pairs(Body:new(x, y, 0, 0)) do self[k] = v end for k,v in pairs(Node:new(nombre)) do self[k] = v end self.onColision = Signal:new() -- señal propia return self end -- sobrescribir colisionaCon para emitir señal function BodyNode:colisionaCon(otro) local dx = self.x - otro.x local dy = self.y - otro.y local dist = math.sqrt(dx*dx + dy*dy) if dist < 1.8 then self.onColision:emitir(self, otro) return true end return false end local a = BodyNode:new("A", 0, 0) local b = BodyNode:new("B", 1.5, 1.5) a.onColision:conectar(function(self, otro) print("💥 Colisión entre " .. self.nombre .. " y " .. otro.nombre) end) local chocan = a:colisionaCon(b) print("¿Chocan? " .. tostring(chocan))
▶ 💥 Colisión entre A y B
▶ ¿Chocan? true   (distancia ~2.12, umbral 1.8 → true)
