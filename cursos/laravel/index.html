Fase 1: Preparación Básica del Entorno

1. Configuración Detallada de XAMPP y PHP

Para que Laravel 13 funcione de manera óptima sobre XAMPP, debemos asegurar que el motor de PHP y sus extensiones cumplan con los requisitos estrictos del framework.

1.1. Activación de Extensiones Críticas en php.ini

Abre el archivo de configuración ubicado por defecto en C:\xampp\php\php.ini utilizando un editor de texto. Asegúrate de que las siguientes líneas no tengan punto y coma (;) al inicio:

extension=curl
extension=fileinfo
extension=mbstring
extension=openssl
extension=pdo_mysql
extension=pdo_pgsql
extension=pgsql
extension=sqlite3
extension=xml

1.2. Configuración de Variables de Entorno del Sistema (PATH)

Para poder invocar comandos de PHP y Composer desde cualquier terminal sin errores:

  1. Presiona la tecla Windows, escribe Variables de entorno y selecciona "Editar las variables de entorno del sistema".
  2. Haz clic en el botón Variables de entorno....
  3. En "Variables del sistema", busca la variable llamada Path y haz clic en Editar.
  4. Añade las siguientes dos rutas exactas:
    • C:\xampp\php
    • C:\Users\TU_USUARIO\AppData\Roaming\Composer\vendor\bin (Directorio global de Composer)
💡 Acotación didáctica
Reinicia cualquier terminal o consola abierta (CMD, PowerShell o VS Code) después de modificar el PATH para que los comandos php y composer se reconozcan correctamente de inmediato.
Fase 2: Preparación Avanzada

2. VS Code y Extensiones Recomendadas

Un entorno de desarrollo profesional requiere herramientas de apoyo cognitivo y autocompletado avanzado para evitar errores de sintaxis.

Extensiones Esenciales para el Stack Laravel

  1. PHP Intelephense (bmewburn): Ofrece autocompletado rápido, análisis estático y navegación de clases.
  2. Laravel Extra Intellisense (Amir Vahedi): Autocompleta nombres de rutas, vistas Blade, migraciones y traducciones.
  3. Laravel Blade Snippets (Mahmoud Ali): Sintaxis y atajos rápidos para directivas Blade (@if, @foreach, etc.).
  4. DotENV (Chuckali): Colores y resaltado de sintaxis para archivos de configuración .env.
  5. Prettier - Code formatter: Mantiene la limpieza y el formateo estándar del código HTML y JavaScript.
⚠️ Nota técnica sobre VS Code
Desactiva temporalmente el formateador nativo de PHP de VS Code si usas Intelephense para evitar conflictos de indentación en clases y métodos extensos.
Fase 3: Creación del Proyecto

3. Instalación de Laravel 13 paso a paso

Abrimos la terminal integrada de Visual Studio Code (Ctrl + `) y procedemos a descargar el núcleo de Laravel mediante Composer.

# Crear un nuevo proyecto Laravel 13 en el directorio actual
composer create-project laravel/laravel proyecto-laravel-master

# Entrar a la carpeta del proyecto
cd proyecto-laravel-master

# Levantar el servidor de desarrollo integrado
php artisan serve
📌 Nota sobre el servidor local
El comando php artisan serve iniciará un servidor local en http://127.0.0.1:8000. Mantén esta terminal abierta mientras desarrollas.
Parte 1: Integración Avanzada con MySQL

4. Gestión de Base de Datos relacional en MySQL (XAMPP)

Con el módulo MySQL activo desde el panel de control de XAMPP, conectaremos nuestra aplicación Laravel y desarrollaremos un esquema transaccional.

4.1. Configuración del archivo .env

Abre el archivo .env en la raíz del proyecto y ajusta las credenciales por defecto de XAMPP (usuario root sin contraseña):

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sistema_xampp_db
DB_USERNAME=root
DB_PASSWORD=

4.2. Creación de Migraciones y Modelos Avanzados

Generaremos el modelo y su respectivo archivo de migración para una tabla de transacciones de inventario: 

php artisan make:model TransaccionInventario -m

Define la estructura detallada en el archivo de migración generado dentro de database/migrations/:

public function up(): void
{
    Schema::create('transacciones_inventario', function (Blueprint $table) {
        $table->id();
        $table->string('referencia', 30)->unique();
        $table->enum('tipo', ['entrada', 'salida']);
        $table->decimal('monto_total', 12, 2);
        $table->unsignedBigInteger('usuario_id');
        $table->timestamps();
    });
}

4.3. Ejecución y Controlador con Eloquent

# Ejecutar migraciones pendientes
php artisan migrate

# Crear el controlador de recursos
php artisan make:controller TransaccionController --resource
💡 Acotación MySQL
Utilizar tipos decimal(12,2) en MySQL previene desbordamientos de punto flotante en cálculos contables complejos dentro de entornos empresariales locales.
Parte 2: Integración Avanzada con PostgreSQL

5. Arquitectura de Alta Complejidad con PostgreSQL

En esta segunda parte, migramos el contexto técnico hacia PostgreSQL para explotar tipos de datos avanzados y consultas optimizadas sobre estructuras NoSQL integradas (jsonb).

5.1. Conexión y Configuración de PostgreSQL

Modifica el archivo .env para apuntar al servidor de PostgreSQL:

DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=sistema_postgres_db
DB_USERNAME=postgres
DB_PASSWORD=clave_segura
⚠️ Nota sobre extensiones PHP / XAMPP
Verifica que la línea extension=pdo_pgsql esté activa en tu archivo php.ini y reinicia Apache o tu servidor para permitir la comunicación con el motor PostgreSQL.

5.2. Migración con Campos JSONB Nativos

Creamos una entidad de logs analíticos con soporte nativo para metadatos estructurados en formato JSON: 

php artisan make:model LogAnalitico -m

Estructura de la migración para PostgreSQL:

public function up(): void
{
    Schema::create('logs_analiticos', function (Blueprint $table) {
        $table->id();
        $table->string('evento');
        $table->jsonb('payload_datos'); // Campo nativo de alta velocidad en Postgres
        $table->timestamps();
    });
}

5.3. Consulta Avanzada de Eloquent sobre JSONB

Ejemplo de consulta transaccional avanzada filtrando propiedades internas del documento JSON en PostgreSQL:

use App\Models\LogAnalitico;

// Filtrar registros donde el nivel dentro del payload sea 'critical'
$logsCriticos = LogAnalitico::where('payload_datos->nivel', 'critical')
    ->orderBy('created_at', 'desc')
    ->get();
💡 Acotación didáctica final
Dominar tanto MySQL (ideal para esquemas relacionales directos con XAMPP) como PostgreSQL (potente para analítica y estructuras semi-estructuradas) proporciona al desarrollador una versatilidad profesional sobresaliente en Laravel 13.
