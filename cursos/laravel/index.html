Introducción

Guía Didáctica de Laravel 13

Bienvenido/a a este tutor estructurado paso a paso para dominar Laravel 13. Esta guía está diseñada para llevarte gradualmente desde la configuración del entorno hasta el desarrollo interactivo con dos de los motores de bases de datos más extendidos en la industria: MySQL y PostgreSQL.

Fase Preparatoria

1. Preparación del Entorno de Trabajo y VS Code

Antes de iniciar con el framework, debemos asegurar que nuestro sistema local posea las herramientas clave correctamente configuradas.

Requisitos Previos del Sistema

  • PHP >= 8.2: Con extensiones activas como pdo, mbstring, openssl, xml, curl.
  • Composer: Manejador de dependencias global de PHP.
  • Node.js & npm: Para la compilación de assets de frontend mediante Vite.

Extensiones Recomendadas para Visual Studio Code

Para acelerar tu flujo de trabajo, abre VS Code e instala las siguientes extensiones desde el Marketplace:

  1. Laravel Extra Intellisense: Autocompletado inteligente de rutas, vistas y configuraciones.
  2. PHP Intelephense: Indexado de código PHP de alto rendimiento y análisis estático.
  3. Laravel Blade Snippets: Resaltado de sintaxis y atajos para plantillas Blade.
  4. DotENV: Soporte de coloración y sintaxis para archivos de configuración .env.
  5. Prettier / PHP CS Fixer: Mantener el formato de código estandarizado bajo PSR-12.
💡 Acotación didáctica
Configurar correctamente las extensiones desde el primer día evita errores tipográficos comunes en las vistas de Blade y acelera la importación automática de espacios de nombres (namespaces).
Inicio del Proyecto

2. Instalación y Estructura del Proyecto

Procederemos a crear una nueva aplicación mediante Composer en la terminal integrada de VS Code (Ctrl + `).

# Crear proyecto Laravel 13
composer create-project laravel/laravel mi-proyecto-laravel

# Acceder al directorio
cd mi-proyecto-laravel

# Iniciar el servidor local de desarrollo
php artisan serve
📌 Nota sobre Laravel 13
En las versiones modernas de Laravel, la estructura de archivos es sumamente limpia. Las rutas principales residen en routes/web.php y las configuraciones de servicios se estructuran mediante bootstrap/app.php en lugar del antiguo kernel tradicional.
Parte 1: Integración MySQL

3. Desarrollo Avanzado orientando a MySQL

En esta sección configuraremos Laravel 13 para conectarse a un servidor MySQL/MariaDB y construiremos una estructura de datos transaccional.

3.1. Configuración del Archivo .env

Edita las variables de entorno en la raíz de tu proyecto para establecer el driver de MySQL:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sistema_gestion_db
DB_USERNAME=root
DB_PASSWORD=secret

3.2. Creación de Migración y Modelo

Crearemos una tabla de Productos con campos estructurados para MySQL:

php artisan make:model Producto -m

            
Modifica el archivo de migración generado en database/migrations/xxxx_create_productos_table.php:

            
public function up(): void
{
    Schema::create('productos', function (Blueprint $table) {
        $table->id();
        $table->string('codigo', 50)->unique();
        $table->string('nombre');
        $table->decimal('precio', 10, 2);
        $table->integer('stock')->default(0);
        $table->timestamps();
    });
}

            
3.3. Ejecución de Migraciones y Controlador

            
php artisan migrate

            
Creamos el controlador para administrar los productos mediante Eloquent ORM:

            
php artisan make:controller ProductoController --resource

            

                
💡 Acotación MySQL

                MySQL maneja de manera óptima el tipo decimal(10,2) para valores monetarios. Evita utilizar float o double al almacenar precios para prevenir imprecisiones de redondeo en cálculos financieros.
            

        

        
        

            Parte 2: Integración PostgreSQL
            

                
4. Desarrollo Avanzado orientando a PostgreSQL

            

            
PostgreSQL destaca por sus capacidades avanzadas con datos no estructurados (JSONB) y búsquedas complejas. En esta segunda parte, migraremos el contexto hacia un motor PostgreSQL.


            
4.1. Configuración de la Conexión PostgreSQL

            
Modifica la configuración en el archivo .env:

            
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=sistema_avanzado_db
DB_USERNAME=postgres
DB_PASSWORD=postgres


            

                
⚠️ Nota de Extensión PHP

                Asegúrate de tener activa la extensión extension=pdo_pgsql en tu archivo php.ini para evitar errores de conexión con PostgreSQL.
            


            
4.2. Uso de Campos Nativos JSONB en Migraciones

            
Aprovecharemos las características nativas de PostgreSQL creando un modelo de Bitacora o historial técnico:

            
php artisan make:model EventoAuditoria -m

            
En la migración correspondiente:

            
public function up(): void
{
    Schema::create('eventos_auditoria', function (Blueprint $table) {
        $table->uuid('id')->primary();
        $table->string('accion');
        $table->jsonb('metadatos'); // Columna JSONB nativa de PG
        $table->timestamps();
    });
}

            
4.3. Consulta ORM Avanzada sobre Datos JSONB

            
En Laravel 13 puedes realizar consultas directas sobre propiedades dentro del objeto JSON de Postgres de forma transparente:

            
use App\Models\EventoAuditoria;

// Buscar eventos donde el rol dentro del metadato sea 'Administrador'
$eventos = EventoAuditoria::where('metadatos->usuario->rol', 'Administrador')
    ->orderBy('created_at', 'desc')
    ->get();

            

                
💡 Acotación PostgreSQL

                A diferencia de MySQL tradicional, el uso de jsonb en PostgreSQL permite indexar directamente atributos dentro del documento JSON, optimizando exponencialmente la velocidad de búsqueda en grandes volúmenes de registros auditables.
