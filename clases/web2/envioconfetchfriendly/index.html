Envío de Datos en Web con fetch()

Guía de referencia rápida: de lo nativo directo a la construcción manual en JSON.

Paso 1 FormData Directo

El objeto FormData empaqueta todos los campos del formulario automáticamente basándose en el atributo name de cada campo HTML.

¿Cuándo usarlo?
  • Cuando el formulario incluye archivos, imágenes o documentos.
  • Cuando envías datos directamente a un backend que acepta multipart/form-data.
const formulario = document.getElementById('miForm'); formulario.addEventListener('submit', (e) => { e.preventDefault(); // Empaqueta texto y archivos automáticamente const datos = new FormData(e.target); fetch('procesar.php', { method: 'POST', body: datos // No requiere JSON.stringify ni cabeceras manuales }); });

Paso 2 Conversión Automática con Object.fromEntries

Convierte de forma limpia el paquete FormData en un objeto JavaScript estándar en una sola línea para enviarlo como JSON.

¿Cuándo usarlo?
  • Para formularios extensos de solo texto donde quieres evitar escribir campo por campo.
  • Requiere que todos los inputs tengan su atributo name definido.
const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // 1. Lectura de inputs vía atributo 'name' const formData = new FormData(e.target); // 2. Transformación automática a Objeto JS const usuario = Object.fromEntries(formData.entries()); // 3. Conversión a JSON plano const jsonPlano = JSON.stringify(usuario); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });

Paso 3 Creación de JSON Manual

Construye el objeto manualmente extrayendo los valores directamente antes de convertirlos a JSON. Tienes dos variantes según el origen de los datos:

Opción 3-A: Por ID (DOM Explícito)

Selecciona valor por valor usando los IDs del documento.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // Objeto construido manualmente vía ID const usuario = { nombre: document.getElementById('nombre').value, correo: document.getElementById('correo').value }; fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(usuario) }); });
Detalles:
  • Lectura directa por ID.
  • Paso a paso fácil de rastrear.
Opción 3-B: In-Situ con e.target

Extrae del evento del formulario e inyecta directo a JSON.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // Construcción in-situ sin variable intermedia const jsonPlano = JSON.stringify({ nombre: e.target.elements.nombre.value, correo: e.target.elements.correo.value }); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });
Detalles:
  • Usa e.target.elements.
  • Sin necesidad de crear variables intermedias.
Resumen de Elección:

1. Usa FormData directo si hay archivos.
2. Usa Object.fromEntries para automatizar el objeto si el formulario es grande.
3. Usa la Creación manual cuando necesites validar, renombrar o formatear claves específicas antes de enviar.
