Envío de Datos en Web con fetch()

Guía de referencia rápida: cuándo y cómo usar FormData y JSON.

Previo 1. El Método Directo: FormData

El objeto FormData empaqueta los campos del formulario automáticamente basándose en el atributo name de cada elemento HTML.

¿Cuándo usarlo?
  • Cuando el formulario incluye archivos, imágenes o documentos.
  • Cuando quieres enviar los datos directamente a un servidor PHP sin transformarlos a JSON.
const formulario = document.getElementById('miForm'); formulario.addEventListener('submit', (e) => { e.preventDefault(); // Empaqueta texto y archivos automáticamente const datos = new FormData(e.target); fetch('procesar.php', { method: 'POST', body: datos // No requiere JSON.stringify ni cabeceras manuales }); });

Enfoque Principal 2. Envío de Datos en Formato JSON

Cuando el backend requiere un JSON plano, puedes preparar el objeto de datos de tres formas distintas antes de pasarlo por JSON.stringify().

Ejemplo A: DOM Explícito

Obtiene valor por valor directo desde los IDs del HTML.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // 1. Selección por ID const usuario = { nombre: document.getElementById('nombre').value, correo: document.getElementById('correo').value }; // 2. Conversión a JSON const jsonPlano = JSON.stringify(usuario); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });
Detalles:
  • Lectura directa mediante IDs.
  • Paso a paso fácil de rastrear.
Ejemplo B-1: Conversión Automática

Convierte el FormData completo a un objeto en una sola línea.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // 1. Lectura de inputs 'name' const formData = new FormData(e.target); // 2. Transformación a Objeto const usuario = Object.fromEntries(formData.entries()); // 3. Conversión a JSON const jsonPlano = JSON.stringify(usuario); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });
Detalles:
  • Muy corto de escribir.
  • Requiere atributo name en HTML.
Ejemplo B-2: Objeto Manual In-Situ

Construye el objeto manualmente extrayendo datos directo al stringificar.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // Construcción explícita del objeto // y conversión directa a JSON const jsonPlano = JSON.stringify({ nombre: e.target.elements.nombre.value, correo: e.target.elements.correo.value }); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });
Detalles:
  • Usa e.target.elements.
  • Mantiene control manual sin variables extra.
Resumen de Elección:

Usa FormData directo para subir archivos. Usa la Opción A o B-2 para entender el origen de los datos paso a paso. Usa la Opción B-1 para formularios extensos de solo texto.
