Envío de Datos en Web con fetch()

Guía de referencia rápida: cuándo y cómo usar FormData y JSON.

Previo 1. El Método Directo: FormData

El objeto FormData empaqueta los campos del formulario automáticamente basándose en el atributo name de cada elemento HTML.

¿Cuándo usarlo?
  • Cuando el formulario incluye archivos, imágenes o documentos.
  • Cuando quieres enviar los datos directamente a un servidor PHP sin transformarlos a JSON.
const formulario = document.getElementById('miForm'); formulario.addEventListener('submit', (e) => { e.preventDefault(); // Empaqueta texto y archivos automáticamente const datos = new FormData(e.target); fetch('procesar.php', { method: 'POST', body: datos // No requiere JSON.stringify ni cabeceras manuales }); });

Enfoque Principal 2. Envío de Datos en Formato JSON

Cuando el backend requiere recibir un objeto JSON plano (frecuente en APIs REST o peticiones de solo texto), existen dos formas principales de preparar los datos antes del envío.

Ejemplo A: Construcción Manual

Obtiene valor por valor de forma explícita directamente desde el DOM.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // 1. Selección explícita const usuario = { nombre: document.getElementById('nombre').value, correo: document.getElementById('correo').value }; // 2. Conversión a texto JSON const jsonPlano = JSON.stringify(usuario); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });
Características:
  • Paso a paso visible: Muestra exactamente qué variable se asigna a qué propiedad.
  • Fácil depuración: Ideal para aislar errores en campos específicos.
Ejemplo B: Conversión Automática

Utiliza métodos nativos de JS para convertir el formulario completo en un objeto.

const form = document.getElementById('miForm'); form.addEventListener('submit', (e) => { e.preventDefault(); // 1. Captura de entradas const formData = new FormData(e.target); // 2. Conversión automática const usuario = Object.fromEntries(formData.entries()); // 3. Conversión a texto JSON const jsonPlano = JSON.stringify(usuario); fetch('api.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: jsonPlano }); });
Características:
  • Menos código: Procesa automáticamente formularios con múltiples campos.
  • Requisito clave: Todos los elementos HTML deben tener el atributo name.
Resumen de Elección:

Usa FormData directo para subir archivos. Usa la Construcción Manual (A) para control total de datos sencillos. Usa la Conversión Automática (B) para formularios extensos de solo texto.
