¿Qué es el Box Model?

El Box Model (modelo de caja) es la forma en que CSS representa cada elemento HTML como una caja rectangular. Esa caja está formada por cuatro capas concéntricas que van de dentro hacia fuera: contenido → padding → borde → margen.

Entenderlo es fundamental porque todo lo que maquetas —un botón, una tarjeta, un menú— no es más que una suma de estas capas. Si no controlas el box model, los anchos y alturas "no cuadran" y los layouts se rompen.

Las 4 capas del Box Model

La propiedad clave: box-sizing (explicación a fondo)

Cuando escribes width: 200px, la pregunta clave es: ¿200px de qué? La respuesta depende de box-sizing. Hay dos valores posibles:

  • content-box (valor por defecto): el width es solo del contenido. El padding y el borde se suman por fuera.
  • border-box: el width es del contenido + padding + borde juntos. Todo cabe dentro.

Parece un detalle, pero cambia por completo cómo se calculan los tamaños. Vamos a verlo con números exactos.

Las dos fórmulas (memorízalas)

content-box

Ancho total = width + padding-left + padding-right + border-left + border-right

Alto total = height + padding-top + padding-bottom + border-top + border-bottom

El width que declaras NO incluye nada más.

border-box

Ancho total = width (ya incluye padding y borde)

Alto total = height (ya incluye padding y borde)

El contenido se encoge para dejar sitio al padding y al borde.

Ejemplo numérico paso a paso

Aplicamos exactamente los mismos estilos a dos cajas. Solo cambia box-sizing:

.caja { width: 200px; height: 100px; padding: 20px; /* 20px por los 4 lados */ border: 5px solid #4a6cf7; } .content { box-sizing: content-box; } .border { box-sizing: border-box; }

Caso práctico: por qué border-box salva tu layout

Quieres dos columnas al 50% dentro de un contenedor, con padding y borde.

🅰️ Sin border-box (content-box) → se rompe

Columna A
50% + 20 + 20 + 2 + 2 = 50% + 44px
Columna B
50% + 20 + 20 + 2 + 2 = 50% + 44px

Suma: (50% + 44px) × 2 = 100% + 88px → se pasa del contenedor → la columna B cae a la línea siguiente.

🅱️ Con border-box → funciona

Columna A
50% incluye todo
Columna B
50% incluye todo

Suma: 50% + 50% = 100% → caben perfectamente en una línea.

🏆 La regla de oro

Casi todos los proyectos modernos empiezan con este reset global:

*, *::before, *::after { box-sizing: border-box; }

Así, todo lo que midas con width y height incluirá padding y borde, y tu layout siempre será predecible. Es la primera línea que suele escribirse en cualquier hoja de estilos seria.

Las 3 vías para aplicar CSS

Inline En línea

Se escribe en el atributo style del propio elemento. Solo afecta a ese elemento.

<p style="color:red">Hola</p>

Insertado Interno

Dentro de <style> en el <head>. Afecta a todo el documento.

<style> p { color: red; } </style>

Externo

Archivo .css aparte enlazado con <link>. Reutilizable en muchas páginas.

<link rel="stylesheet" href="estilos.css">

Ver solución (las 3 vías)

① Inline — el estilo va en el propio elemento:

Ver solución (las 3 vías)

① Inline — envolver cada párrafo en un div con overflow:hidden:

<div style="overflow:hidden;"> <p style="margin:20px 0;">Párrafo 1</p> </div> <div style="overflow:hidden;"> <p style="margin:20px 0;">Párrafo 2</p> </div>

② Insertado

<style> .contenedor-margen { overflow: hidden; /* crea un BFC */ } .contenedor-margen p { margin: 20px 0; } </style>

③ Externo

/* estilos.css */ .contenedor-margen { overflow: hidden; } .contenedor-margen p { margin: 20px 0; }

Alternativa: usar solo padding en lugar de margin, o aplicar padding al contenedor padre.
