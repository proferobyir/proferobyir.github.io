¿Qué es el Box Model?

Es el modelo de caja de CSS mediante el cual todo elemento HTML se representa como una caja rectangular formada por capas concéntricas que controlan el diseño y la separación de los elementos en la página.

Las 4 Capas del Box Model

Contenido
CapaPropiedad CSSDescripción
Contenidowidth, heightEl área donde se aloja el texto, imágenes u otros elementos.
PaddingpaddingEspacio de relleno interior entre el contenido y el borde.
BordeborderLínea perimetral que rodea el padding y el contenido.
MargenmarginEspacio exterior que separa la caja de otros elementos colindantes.

La propiedad clave: box-sizing

Define cómo se computan el ancho y alto total de un elemento:

  • content-box (Por defecto): El width es exclusivo del contenido. El padding y el borde se suman por fuera, incrementando el tamaño real de la caja.
  • border-box: El width incluye el contenido, el padding y el borde en una sola medida fija.
content-box

Ancho total = width + padding + border

border-box

Ancho total = width (incluye todo)

Reset universal recomendado:

*, *::before, *::after { box-sizing: border-box; }

Las 3 Vías para Aplicar CSS

Inline

En el atributo style del elemento HTML.

<p style="color:red;">Texto</p>
Insertado

Dentro de <style> en el <head>.

<style> p { color: red; } </style>
Externo

Archivo .css vinculado mediante <link>.

<link rel="stylesheet" href="estilos.css">
