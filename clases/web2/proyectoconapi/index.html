Electiva III • Módulo 3

Creación y Consumo de APIs RESTful

Arquitectura Cliente-Servidor con Node.js, Express, MySQL y Fetch API

💻 Descripción de la Clase

En esta sesión práctica integraremos los conocimientos de desarrollo web Frontend y Backend. Implementaremos una arquitectura desacoplada real utilizando Apache para servir el cliente, Node.js con Express para construir el servicio API RESTful y MySQL como motor de persistencia relacional.

🎯 Objetivos de Aprendizaje

  • Comprender los fundamentos de la arquitectura RESTful (Verbos HTTP, códigos de estado y formato JSON).
  • Resolver el intercambio de recursos de origen cruzado (CORS) entre Apache (Puerto 80) y Node.js (Puerto 3000).
  • Capturar datos mediante un formulario web e interactuar de forma asíncrona con la Fetch API (async/await).
  • Conectar Node.js con la base de datos ejemplodb e insertar registros mediante consultas preparadas en SQL.

🏗️ Arquitectura del Sistema

Diagrama del flujo de comunicación entre el cliente web, el servidor de aplicaciones y la base de datos:

[ Navegador del Alumno ] │ ├── 1. Pide la interfaz web ────► [ Apache (Puerto 80 / htdocs) ] │◄── 2. Devuelve index.html ───┘ │ ├── 3. Petición POST (fetch) ──► [ Node.js (Puerto 3000) ] │ │ │ 4. INSERT SQL │ ▼ │ [ Base de Datos MySQL ] │ │ │◄── 5. Respuesta JSON (200 OK) ────────┘
⚠️ Nota sobre Seguridad / CORS

Asegúrate de acceder al Frontend siempre a través de la URL de Apache o http://localhost:3000. No abras el archivo HTML mediante doble clic directo desde el explorador para evitar bloqueos del navegador.
