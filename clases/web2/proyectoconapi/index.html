Estructura del Proyecto y Despliegue Local

Separación de capas: Servidor Apache (Frontend) y Node.js (API REST Backend)

📁 Ubicación de las Carpetas

El proyecto está organizado en dos componentes independientes. Debes ubicar cada carpeta en su entorno correspondiente:

🌐 Carpeta /frontend
Debe copiarse dentro del directorio web de Apache:
C:\xampp\htdocs\frontend

Acceso web:
http://localhost/frontend/index.html
⚙️ Carpeta /backend
Puede ir en cualquier ruta fuera de htdocs (ej. Escritorio o Documentos):
C:\Users\Alumno\Desktop\backend

API Escuchando en:
http://localhost:3000

🚀 Cómo Levantar el Backend (API REST)

Sigue estos pasos para iniciar el servidor de servicios con Node.js:

  1. Abre el panel de XAMPP e inicia únicamente el servicio de MySQL (puerto 3306).
  2. Abre una ventana de la terminal (CMD o PowerShell) y navega hasta tu carpeta backend: 
    cd C:\Users\TuUsuario\Desktop\backend
  3. Ejecuta el comando para iniciar la API REST: 
    node server.js
  4. Verifica los mensajes de confirmación en consola: 
    ¡Conectado exitosamente a la base de datos MySQL!
Servidor API REST corriendo en http://localhost:3000

🏗️ Estructura del Repositorio en GitHub

Así está organizado este repositorio para la práctica del laboratorio:

mi-repositorio-api/ ├── frontend/ <-- COPIAR A: C:\xampp\htdocs\frontend │ └── index.html <-- Vista + Fetch API (apunta a puerto 3000) │ └── backend/ <-- COPIAR A: C:\Escritorio\backend (o cualquier ruta) ├── node_modules/ <-- Dependencias offline preinstaladas ├── package.json <-- Configuración de paquetes Node └── server.js <-- Express + Conexión MySQL + CORS habilitado
💡 Recordatorio de CORS y Peticiones

El código JavaScript en frontend/index.html hace peticiones mediante fetch('http://localhost:3000/api/usuarios'). El backend tiene configurado el middleware de CORS para permitir la comunicación entre Apache (Puerto 80) y Node.js (Puerto 3000) sin bloqueos.
