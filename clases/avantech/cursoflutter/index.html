02. Fase 1: Dominio del Lenguaje Dart (Días 1 al 3)

Día 1: Sintaxis Fundamental, Tipado Estricto y Sound Null Safety
Dart es un lenguaje fuertemente tipado. Hoy aprenderás a declarar variables de forma segura y evitar errores en tiempo de ejecución mediante Null Safety.

Explicación Detallada:

  • var infiere el tipo implícitamente en la asignación.
  • final se asigna una sola vez en tiempo de ejecución.
  • const es una constante estricta evaluada en tiempo de compilación.
  • Sound Null Safety: Por defecto, una variable no puede ser null. Se usa ? para indicar que un valor puede ser nulo, y ! para forzar un valor no nulo. 
void main() {
  // Declaración explícita e implícita
  String nombre = 'Carlos';
  var edad = 28;
  final String ciudad = 'Valencia';
  const double pi = 3.14159;

  // Null Safety
  String? clienteId; // Puede contener null
  
  // Operador de asignación con comprobación de nulos (??=)
  clienteId ??= 'CLI-0001';

  print('Desarrollador: $nombre ($edad años) - ID: $clienteId');
}
Día 2: Programación Orientada a Objetos (POO) y Constructores Nombrados
En Flutter, absolutamente todo es un objeto. Dominar clases y constructores en Dart es fundamental para crear componentes reutilizables.

Explicación Detallada:

  • Las clases definen el molde para instanciar objetos con atributos y comportamientos.
  • Los constructores con parámetros nombrados ({ }) son el estándar en Flutter para configurar opciones con claridad.
  • El uso de required garantiza que los parámetros obligatorios no sean omitidos.
class Producto {
  final String id;
  final String nombre;
  final double precio;
  final bool enStock;

  // Constructor moderno de Dart con parámetros nombrados
  Producto({
    required this.id,
    required this.nombre,
    required this.precio,
    this.enStock = true, // Parámetro opcional con valor por defecto
  });

  void aplicarDescuento(double porcentaje) {
    print('Precio original: \$${precio}');
  }
}

void main() {
  final prod = Producto(id: 'P1', nombre: 'Teclado Mecánico', precio: 85.0);
  print('Producto cargado: ${prod.nombre} - \$${prod.precio}');
}
Día 3: Asincronía con Futures, Async/Await y Manejo de Excepciones
Las aplicaciones modernas consultan datos de servidores remotos. Aprende a ejecutar tareas en segundo plano sin congelar la interfaz de usuario.

Explicación Detallada:

  • Un Future<T> representa una promesa de un valor que se resolverá más adelante.
  • La palabra clave async convierte una función en asíncrona.
  • await detiene la ejecución dentro de la función asíncrona hasta que el Future se complete.
  • Los bloques try-catch-finally capturan fallos de red o errores de formato.
Future<Map<String, dynamic>> obtenerDatosUsuario(String uid) async {
  try {
    print('Consultando API remota...');
    await Future.delayed(Duration(seconds: 2)); // Simula latencia de red
    return {'id': uid, 'nombre': 'Ana María', 'status': 'Activo'};
  } catch (e) {
    throw Exception('Error al conectar con el servidor: $e');
  }
}

void main() async {
  print('Inicio del programa');
  final usuario = await obtenerDatosUsuario('USR-99');
  print('Respuesta recibida: ${usuario['nombre']}');
  print('Fin del programa');
}

Día 6: Gestión de Estado Básico con StatefulWidget y setState
El estado es cualquier dato que puede cambiar en la aplicación y requiere actualizar lo que el usuario ve en pantalla.
class ContadorApp extends StatefulWidget {
  const ContadorApp({super.key});

  @override
  State<ContadorApp> createState() => _ContadorAppState();
}

class _ContadorAppState extends State<ContadorApp> {
  int _contador = 0;

  void _incrementar() {
    setState(() {
      _contador++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: _incrementar,
      style: ElevatedButton.styleFrom(backgroundColor: const Color(0xFF0F62FE)),
      child: Text('Contador de Clics: $_contador'),
    );
  }
}

import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'dart:convert';

void main() => runApp(const EcoWeatherApp());

class EcoWeatherApp extends StatelessWidget {
  const EcoWeatherApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData.dark().copyWith(
        scaffoldBackgroundColor: const Color(0xFF161616),
      ),
      home: const PantallaClima(),
    );
  }
}

class PantallaClima extends StatefulWidget {
  const PantallaClima({super.key});

  @override
  State<PantallaClima> createState() => _PantallaClimaState();
}

class _PantallaClimaState extends State<PantallaClima> {
  final _controller = TextEditingController();
  String _ciudad = 'Madrid';
  String _temp = '--';
  String _descripcion = 'Escribe una ciudad';
  bool _cargando = false;

  Future<void> consultarClima(String ciudad) async {
    setState(() { _cargando = true; });
    
    final url = Uri.parse('https://api.openweathermap.org/data/2.5/weather?q=$ciudad&units=metric&appid=TU_API_KEY');
    
    try {
      final response = await http.get(url);
      if (response.statusCode == 200) {
        final data = jsonDecode(response.body);
        setState(() {
          _temp = '${data['main']['temp'].round()}°C';
          _descripcion = data['weather'][0]['description'].toString().toUpperCase();
        });
      } else {
        setState(() { _descripcion = 'Ciudad no encontrada'; });
      }
    } catch (e) {
      setState(() { _descripcion = 'Error de conexión'; });
    } finally {
      setState(() { _cargando = false; });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('EcoWeather - Carbon Style'),
        backgroundColor: const Color(0xFF262626),
      ),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          children: [
            TextField(
              controller: _controller,
              style: const TextStyle(color: Colors.white),
              decoration: InputDecoration(
                labelText: 'Ingrese una ciudad',
                labelStyle: const TextStyle(color: Color(0xFF78A9FF)),
                filled: true,
                fillColor: const Color(0xFF262626),
                border: const OutlineInputBorder(),
                suffixIcon: IconButton(
                  icon: const Icon(Icons.search, color: Color(0xFF78A9FF)),
                  onPressed: () => consultarClima(_controller.text),
                ),
              ),
            ),
            const SizedBox(height: 30),
            _cargando 
              ? const CircularProgressIndicator(color: Color(0xFF0F62FE))
              : Container(
                  width: double.infinity,
                  padding: const EdgeInsets.all(20),
                  decoration: BoxDecoration(
                    color: const Color(0xFF262626),
                    border: Border.all(color: const Color(0xFF393939)),
                  ),
                  child: Column(
                    children: [
                      Text(_controller.text.isEmpty ? 'Ciudad' : _controller.text, 
                           style: const TextStyle(fontSize: 22, color: Colors.white, fontWeight: FontWeight.bold)),
                      const SizedBox(height: 10),
                      Text(_temp, style: const TextStyle(fontSize: 48, color: Color(0xFF78A9FF), fontWeight: FontWeight.bold)),
                      const SizedBox(height: 5),
                      Text(_descripcion, style: const TextStyle(fontSize: 14, color: Colors.grey)),
                    ],
                  ),
                ),
          ],
        ),
      ),
    );
  }
}
