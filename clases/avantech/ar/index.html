Bienvenido al Laboratorio de WebAR

Hoy vamos a aprender a traer objetos 3D al mundo real usando Realidad Aumentada (AR).

¿Cómo es posible esto? (El poder de las librerías)

Usamos librerías especializadas que resuelven las matemáticas por nosotros:

  • A-Frame: Crea el entorno 3D donde vive el modelo.
  • AR.js: Rastrea el marcador usando la cámara de tu teléfono.

¿Qué es el Marcador Hiro?

Es nuestro punto de referencia visual (el "GPS"). Cuando la cámara reconoce el patrón visual del marcador Hiro, proyecta el archivo 3D en ese punto exacto.

Puedes abrir el marcador para probar aquí: Ver Marcador Hiro.

Recursos para la clase

Descarga modelos 3D en formato .glb en:

  • Sketchfab
  • Poly.pizza

Código de la Clase

Copia este código en un archivo index.html para ejecutar tu laboratorio:


<!DOCTYPE html>
<html>
<head>
    <meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
    <!-- Importamos las librerías necesarias -->
    <script src="https://aframe.io/releases/1.3.0/aframe.min.js"></script>
    <script src="https://raw.githack.com/AR-js-org/AR.js/master/aframe/build/aframe-ar.js"></script>
</head>
<body style="margin: 0px; overflow: hidden;">

    <!-- arjs con detección optimizada y resoluciones dinámicas -->
    <a-scene 
        embedded 
        arjs="sourceType: webcam; debugUIEnabled: false; detectionMode: mono; matrixCodeType: 3x3;">
        
        <!-- Marcador "Hiro" -->
        <a-marker preset="hiro" smooth="true" smoothCount="5">
            
            <!-- Modelo 3D del zapato -->
            <a-entity 
                gltf-model="https://raw.githack.com/KhronosGroup/glTF-Sample-Models/master/2.0/MaterialsVariantsShoe/glTF-Binary/MaterialsVariantsShoe.glb"
                scale="1.5 1.5 1.5"
                position="0 0 0"
                rotation="0 0 0">
            </a-entity>

        </a-marker>

        <a-entity camera></a-entity>
    </a-scene>

</body>
</html>
