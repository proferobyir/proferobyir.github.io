KinematicBody2D movimiento controlado

propiedades velocity, up_direction, motion (solo lectura)

move_and_slide(velocity, up_direction, stop_on_slope, max_slides, floor_max_angle)
Desplaza el cuerpo aplicando velocity y actualiza automáticamente velocity tras colisiones. Devuelve Vector2 con la velocidad final.
move_and_collide(velocity, test_only, safe_margin)
Mueve el cuerpo y devuelve un objeto KinematicCollision2D si hay colisión, o null si no.
is_on_floor() → bool
Devuelve true si el cuerpo está en contacto con el suelo (según up_direction).
is_on_wall() → bool
Devuelve true si hay colisión con una pared (lateral).
is_on_ceiling() → bool
Devuelve true si hay colisión con el techo.
get_slide_count() → int
Número de colisiones detectadas en el último move_and_slide().
get_slide_collision(slide_idx) → KinematicCollision2D
Devuelve información detallada de una colisión específica.
# Ejemplo completo en _physics_process
var vel = velocity
# Input.get_axis(negative, positive) devuelve -1, 0 o 1 según las teclas
vel.x = Input.get_axis("ui_left", "ui_right") * 200
vel.y += 9.8 # gravedad
velocity = move_and_slide(vel, Vector2.UP)
if is_on_floor():
  if Input.is_action_just_pressed("ui_accept"):
    vel.y = -300
Señales: KinematicBody2D no emite señales de colisión por sí mismo. Para detectar colisiones se usa un Area2D hijo.
ejemplo $Area2D.connect("body_entered", self, "_on_area_entered")
Sonido en colisión: Conectar body_entered del Area2D y llamar a $AudioStreamPlayer2D.play().

StaticBody2D estático / obstáculo

No se mueve. Ideal para suelos, paredes, plataformas fijas.

  • set_collision_layer(layer) — establecer capa de colisión
  • set_collision_mask(mask) — establecer máscara de colisión
  • No tiene métodos de movimiento ni detección de suelo.
Señales: No emite señales directamente. Se usa un Area2D hijo para detectar entrada/salida de cuerpos.
ejemplo $Area2D.connect("body_entered", self, "_on_body_entered")

CollisionShape2D forma de colisión

Define la geometría de colisión. Se usa como hijo de KinematicBody2D, RigidBody2D, StaticBody2D o Area2D.

set_shape(shape: Shape2D)
Asigna una forma (RectangleShape2D, CircleShape2D, CapsuleShape2D, etc.)
get_shape() → Shape2D
Devuelve la forma actual.
disabled (propiedad) — si es true, la colisión se desactiva temporalmente.
# Crear un círculo desde código
var circle = CircleShape2D.new()
circle.radius = 16
$CollisionShape2D.shape = circle

CollisionPolygon2D polígono personalizado

Permite dibujar formas de colisión con polígonos convexos.

set_polygon(polygon: Array)
Establece un array de Vector2 que define el polígono.
get_polygon() → Array
Devuelve el polígono actual.
build_mode (propiedad) — BuildMode.SOLIDS o BuildMode.SEGMENTS.
# Triángulo
var pts = [

$CollisionPolygon2D.polygon = pts

KinematicBody2D · ejemplo completo con señales y sonido

Propiedades comunes: velocity, speed (custom), jump_strength (custom), gravity (custom)

Métodos clave:

  • move_and_slide(velocity, up_direction) — mueve y detecta colisiones.
  • is_on_floor() → bool — detecta suelo.
  • is_on_wall() → bool — detecta pared.
  • get_floor_velocity() → Vector2 — velocidad del suelo (útil para plataformas móviles).
# _physics_process
var vel = velocity
# get_axis(negative_key, positive_key) → -1, 0, 1
vel.x = Input.get_axis("ui_left", "ui_right") * speed
vel.y += gravity # gravedad
if Input.is_action_just_pressed("ui_accept") and is_on_floor():
  vel.y = -jump_strength
velocity = move_and_slide(vel, Vector2.UP)
Explicación de get_axis():
Input.get_axis("ui_left", "ui_right") devuelve -1 si se pulsa ←, 1 si se pulsa →, y 0 si no se pulsa ninguna o ambas. Esto permite un control analógico suave. Se multiplica por la velocidad para obtener el movimiento.
Señales con Area2D hijo
  • body_entered → detecta colisión
  • body_exited → fin de colisión
# Conectar en _ready()
$Area2D.connect("body_entered", self, "_on_body_entered")
# Función de callback
func _on_body_entered(body):
  if body.is_in_group("suelo"):
    $AudioStreamPlayer2D.play()
Nodos de sonido
AudioStreamPlayer2D sonido posicional (atenúa con distancia)
AudioStreamPlayer sonido global (sin posición)
Procedimiento completo para colisión + sonido:
  1. Agregar Area2D como hijo del KinematicBody2D.
  2. Agregar CollisionShape2D o CollisionPolygon2D como hijo del Area2D.
  3. Conectar la señal body_entered del Area2D a un método.
  4. En el método, verificar si el cuerpo es suelo o enemigo (usando grupos o tipos).
  5. Llamar a $AudioStreamPlayer2D.play() para reproducir el sonido.
  6. Opcional: usar is_on_floor() en _physics_process para sonidos de aterrizaje.

Nodos de sonido en Godot 3.x 2D

AudioStreamPlayer
Sonido global, sin posición. Ideal para música, efectos generales.
métodos play(), stop(), set_stream(stream)
AudioStreamPlayer2D
Sonido posicional. Atenúa según la distancia al oyente.
propiedades max_distance, attenuation, panning_strength
Señal útil: finished — se emite cuando termina la reproducción. Útil para encadenar sonidos.
Ejemplo típico:
$AudioStreamPlayer2D.play() dentro de body_entered o is_on_floor().

Recomendación: Para sonidos de pasos o saltos, usar is_on_floor() en _physics_process y reproducir el sonido solo cuando cambia el estado (ej. al aterrizar).
