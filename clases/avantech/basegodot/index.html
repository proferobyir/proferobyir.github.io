⚡ KinematicBody2D movimiento controlado

propiedades velocity, motion, up_direction

  • move_and_slide() — desplaza y detecta colisiones
  • is_on_floor() → bool (suelo)
  • is_on_wall() , is_on_ceiling()
  • get_slide_count() + get_slide_collision()
# Ejemplo _physics_process
velocity.y += 9.8 # gravedad
velocity = move_and_slide(velocity, Vector2.UP)
if is_on_floor(): jump()
📡 Señales típicas: no posee señales de colisión nativas; se usan áreas o raycasts.
ejemplo body_entered desde un Area2D hijo.

🌀 RigidBody2D física completa

propiedades mass, gravity_scale, linear_velocity, angular_velocity

  • apply_central_impulse() — golpe
  • apply_force() — fuerza continua
  • set_axis_velocity()
  • is_on_floor() (solo si contact_monitor true)
# desde _integrate_forces(state)
if Input.is_action_just_pressed("jump"):
  apply_central_impulse(Vector2(0, -200))
📡 Señales: body_entered, body_exited, body_shape_entered
ejemplo conectar body_entered para detectar suelo u objetos.

🧱 StaticBody2D estático / obstáculo

No se mueve, ideal para suelos, paredes, plataformas.

  • set_collision_layer() / set_collision_mask()
  • No tiene métodos de movimiento.
  • Puede emitir señales si se usa con Area2D hijo.
📡 Señales: (a través de Area2D hijo) body_entered, area_entered
ejemplo activar sonido al pisar una plataforma.

🔵 Area2D detección & superposición

Detecta cuerpos y áreas sin colisión física.

  • overlaps_body() → bool
  • get_overlapping_bodies() → Array
  • get_overlapping_areas()
  • set_collision_mask()
📡 Señales: body_entered, body_exited, area_entered, area_exited
ejemplo body_entered → reproducir sonido de impacto.

⬡ CollisionShape2D forma de colisión

Define la geometría: RectangleShape2D, CircleShape2D, CapsuleShape2D, etc.

  • set_shape() — asignar forma
  • get_shape()
  • Propiedad disabled para desactivar temporalmente.
  • Se usa como hijo de KinematicBody2D, RigidBody2D, StaticBody2D, Area2D.
# Asignar círculo desde código
var shape = CircleShape2D.new()
shape.radius = 16
$CollisionShape2D.shape = shape

⬡ CollisionPolygon2D polígono a medida

Permite dibujar formas de colisión personalizadas (polígonos convexos).

  • set_polygon() — array de Vector2
  • get_polygon()
  • Propiedad build_mode (solids / segments).
# polígono triangular
var pts = [ Vector2(0,-20), Vector2(20,20), Vector2(-20,20) ]
$CollisionPolygon2D.polygon = pts

🎞️ AnimatedSprite animaciones 2D

Reproduce spritesheet con SpriteFrames.

  • play() — inicia animación
  • stop() / pause()
  • set_frame(), get_frame()
  • is_playing() → bool
  • connect("animation_finished") — señal
$AnimatedSprite.play("correr")
if $AnimatedSprite.is_playing(): hacer_algo()

🧩 KinematicBody2D · ejemplo completo + señales + sonido

Propiedades: velocity, speed, jump_strength, gravity

Métodos clave:

  • move_and_slide(velocity, up_direction)
  • is_on_floor() → bool
  • is_on_wall()
  • get_floor_velocity()
# _physics_process
var vel = velocity
vel.x = Input.get_axis("left", "right") * speed
if Input.is_action_just_pressed("jump") and is_on_floor():
  vel.y = -jump_strength
velocity = move_and_slide(vel, Vector2.UP)
📡 Señales (con Area2D hijo)
  • body_entered → detecta colisión
  • body_exited → fin de colisión
# Conectar en _ready()
$Area2D.connect("body_entered", self, "_on_body_entered")

Dentro de _on_body_entered(body) se puede comprobar si es suelo o enemigo.

🔊 Nodos de sonido
AudioStreamPlayer2D sonido posicional (2D)
AudioStreamPlayer sonido global
🎵 Ejemplo: reproducir sonido al entrar en colisión
func _on_body_entered(body):
  if body.is_in_group("suelo"):
    $AudioStreamPlayer2D.play() # reproduce el sonido asignado

También se puede usar play() desde is_on_floor() en _physics_process.

🔊 Nodos de sonido en Godot 3.x 2D

AudioStreamPlayer — sonido sin posición, ideal para música o efectos globales.
métodos play(), stop(), set_stream()
AudioStreamPlayer2D — sonido posicional (atenúa con distancia).
propiedades max_distance, attenuation
AudioStreamPlayer3D — (aunque es 3D, puede usarse con ciertos trucos, pero en 2D se usa el 2D)
Ejemplo típico: $AudioStreamPlayer2D.play() dentro de body_entered o is_on_floor().
Señal útil: finished — se emite cuando termina la reproducción.

🎯 Procedimiento para colisiones + sonido:

  1. Agregar Area2D como hijo del KinematicBody2D (o RigidBody).
  2. Conectar señal body_entered a un método personalizado.
  3. Dentro del método, verificar etiqueta (grupo) o tipo del cuerpo.
  4. Ejecutar $AudioStreamPlayer2D.play() para reproducir sonido.
  5. Opcional: usar is_on_floor() para sonidos de aterrizaje en _physics_process.
