Registro de Estudiantes

Envía datos al Webhook de n8n y manipula la respuesta devuelta en el Frontend

Nota de entorno / CORS: Si la aplicación cliente corre en un puerto distinto al de n8n (ej. Live Server en :5500 o GitHub Pages) hacia localhost:5678, asegúrate de habilitar la variable de entorno N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true o los encabezados HTTP CORS correspondientes en n8n para permitir peticiones de orígenes cruzados.
