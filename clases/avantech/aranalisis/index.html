Bienvenido al Laboratorio de WebAR

Hoy vamos a aprender a traer objetos 3D al mundo real usando Realidad Aumentada (AR). Para lograrlo, necesitamos entender cómo "engañamos" al teléfono para que sepa dónde dibujar los objetos.

¿Qué es el Marcador Hiro?

Seguro te preguntas: ¿Por qué apuntamos a un cuadrado negro con un símbolo blanco?

El Marcador Hiro es el "GPS" de nuestra experiencia AR. Imagínalo como la "X" en un mapa de tesoro. No contiene información, no tiene chip, ni magia. Es simplemente un patrón visual que el software de Realidad Aumentada (AR.js) ha sido programado para reconocer instantáneamente.

  • Cuando la cámara "ve" este cuadrado, el software dice: "¡Ya sé dónde estoy! Aquí es donde debo dibujar".
  • Si quitas el marcador, el teléfono pierde la referencia y el objeto 3D desaparece.

Puedes abrir el marcador original aquí: Ver Marcador Hiro.

Recursos para la clase

Necesitarás un Modelo 3D (.glb), que es el "Actor" que aparecerá sobre el marcador. Puedes descargar modelos gratuitos en:

  • Sketchfab (Busca formato .GLB).
  • Poly.pizza (Modelos ligeros, ideales para celulares).

Código de la Clase

Copia este código y guárdalo en un archivo index.html:


<!DOCTYPE html>
<html>
<head>
    <script src="https://aframe.io/releases/1.3.0/aframe.min.js"></script>
    <script src="https://raw.githack.com/AR-js-org/AR.js/master/aframe/build/aframe-ar.js"></script>
</head>
<body style="margin: 0px; overflow: hidden;">

    <a-scene embedded arjs="sourceType: webcam; debugUIEnabled: false;">
        
        <!-- El marcador "Hiro" es nuestro punto de anclaje -->
        <a-marker preset="hiro">
            
            <!-- El modelo .glb es el objeto 3D que aparecerá -->
            <a-entity 
                gltf-model="https://raw.githack.com/KhronosGroup/glTF-Sample-Models/master/2.0/MaterialsVariantsShoe/glTF-Binary/MaterialsVariantsShoe.glb"
                scale="2 2 2"
                rotation="0 0 0">
            </a-entity>

        </a-marker>

        <a-entity camera></a-entity>
    </a-scene>

</body>
</html>
