01. Recorrido Básico `forEach` (Arreglo Plano)

Nivel: Básico

Iteramos un arreglo de objetos simple con forEach y extraemos la propiedad directa de imagen para construir tarjetas de producto.

const data1 = [
    { id: 1, title: 'Servidor Blade X1', img: 'https://picsum.photos/id/10/200/120' },
    { id: 2, title: 'Switch Óptico 24P', img: 'https://picsum.photos/id/20/200/120' }
];

let html1 = '';
data1.forEach(item => {
    html1 += `
        <div class="carbon-card">
            <img src="${item.img}" alt="${item.title}">
            <div class="title">${item.title}</div>
            <div class="subtitle">ID: ${item.id}</div>
        </div>
    `;
});
document.getElementById('out-1').innerHTML = html1;

20. Función de Recorrido Recursivo para Img Keys Arbitrarias

Nivel: Experto

Una función recursiva explora cualquier objeto JSON sin importar su profundidad y detecta claves que contengan enlaces a imágenes para renderizarlas.

const data20 = {
    a: 'Texto ignorable',
    b: { deepImg: 'https://picsum.photos/id/210/200/120' },
    c: [{ anotherImg: 'https://picsum.photos/id/211/200/120' }],
    d: { e: { f: { image: 'https://picsum.photos/id/212/200/120' } } }
};

function findImagesRecursive(obj, found = []) {
    if (!obj || typeof obj !== 'object') return found;
    
    for (const key in obj) {
        if (typeof obj[key] === 'string' && obj[key].startsWith('http')) {
            found.push({ url: obj[key], key: key });
        } else if (typeof obj[key] === 'object') {
            findImagesRecursive(obj[key], found);
        }
    }
    return found;
}

const extracted = findImagesRecursive(data20);
document.getElementById('out-20').innerHTML = extracted.map(({ url, key }) => `
    <div class="carbon-card">
        <img src="${url}">
        <div class="subtitle">Clave: ${key} (Extraído por Recursividad)</div>
    </div>
`).join('');
