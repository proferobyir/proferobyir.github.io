Referencia Rápida de Métodos y Funciones

1. Conversión JSON (`JSON.parse` / `JSON.stringify`)

Permiten convertir cadenas de texto en formato JSON a objetos de JavaScript y viceversa.

// Convertir texto JSON a Objeto JS
const obj = JSON.parse('{"id": 1, "nombre": "Ana"}');

// Convertir Objeto JS a texto JSON
const jsonTexto = JSON.stringify(obj);

2. Recorrido (`forEach`)

Ejecuta una función sobre cada elemento del arreglo sin retornar un nuevo valor.

const datos = [1, 2, 3];
datos.forEach(n => console.log(n * 2));

3. Transformación (`map`)

Crea un nuevo arreglo transformando cada uno de los elementos originales.

const nums = [1, 2, 3];
const dobles = nums.map(n => n * 2); // [2, 4, 6]

4. Filtrado (`filter`)

Retorna un nuevo arreglo con los elementos que cumplan una condición lógica.

const nums = [10, 15, 20];
const mayores = nums.filter(n => n > 12); // [15, 20]

5. Acumulación (`reduce`)

Reduce los elementos del arreglo a un único valor (ejemplo: suma total).

const precios = [10, 20, 30];
const total = precios.reduce((acc, p) => acc + p, 0); // 60

6. Búsqueda (`find`)

Devuelve el primer elemento que cumpla con la condición dada.

const lista = [{ id: 1 }, { id: 2 }];
const encontrado = lista.find(item => item.id === 2); // { id: 2 }

7. Validaciones (`some` / `every`)

`some` verifica si al menos un elemento cumple la condición. `every` verifica si todos la cumplen. 

const nums = [2, 4, 5];
const hayImpar = nums.some(n => n % 2 !== 0); // true
const todosPares = nums.every(n => n % 2 === 0); // false

8. Aplanamiento (`flatMap`)

Mapea los elementos y aplana el resultado en un arreglo unidimensional.

const listas = [[1], [2, 3]];
const plano = listas.flatMap(x => x); // [1, 2, 3]
