Guía Práctica: API RESTful con Flask y MySQL

Construcción paso a paso de una API RESTful con Python, Flask, soporte CORS y binding para acceso remoto.

Python 3 Flask Flask-CORS MySQL Connector

1. Configuración del Entorno Virtual e Instalación

Abre la terminal y ejecuta los siguientes comandos para preparar el entorno de Python e instalar las dependencias:

# Crear carpeta del proyecto
mkdir api-flask-mysql
cd api-flask-mysql

# Crear e instalar entorno virtual (recomendado)
python -m venv venv

# Activar entorno virtual (Linux/Mac)
source venv/bin/activate
# Activar entorno virtual (Windows)
# venv\Scripts\activate

# Instalación de paquetes requeridos
pip install flask flask-cors mysql-connector-python

2. Esquema de la Base de Datos

Ejecuta este script SQL en tu cliente de base de datos MySQL (phpMyAdmin, Workbench o CLI):

CREATE DATABASE IF NOT EXISTS tienda;
USE tienda;

CREATE TABLE IF NOT EXISTS productos (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nombre VARCHAR(100) NOT NULL,
  precio DECIMAL(10, 2) NOT NULL
);

3. Código Principal del Servidor (app.py)

Crea el archivo app.py y copia este código completo ejecutable:

import os
from flask import Flask, request, jsonify
from flask_cors import CORS
import mysql.connector
from mysql.connector import pooling

app = Flask(__name__)

# ==========================================
# MIDDLEWARE Y CONFIGURACIÓN DE CORS
# ==========================================
# Habilita peticiones entre orígenes (Cross-Origin) sin bloqueos en el navegador
CORS(app)

# ==========================================
# CONEXIÓN A BASE DE DATOS (Connection Pool)
# ==========================================
db_config = {
    "host": os.environ.get("DB_HOST", "localhost"),
    "user": os.environ.get("DB_USER", "root"),
    "password": os.environ.get("DB_PASSWORD", ""),
    "database": os.environ.get("DB_NAME", "tienda"),
    "port": int(os.environ.get("DB_PORT", 3306))
}

db_pool = pooling.MySQLConnectionPool(
    pool_name="mypool",
    pool_size=10,
    **db_config
)

def get_db_connection():
    return db_pool.get_connection()

# ==========================================
# ENDPOINTS GET
# ==========================================

# 1. GET No parametrizado: Obtener todos los productos
@app.route('/productos', methods=['GET'])
def get_productos():
    try:
        conn = get_db_connection()
        cursor = conn.cursor(dictionary=True) # Devuelve filas como diccionarios
        cursor.execute('SELECT * FROM productos')
        rows = cursor.fetchall()
        cursor.close()
        conn.close()
        return jsonify(rows), 200
    except Exception as e:
        return jsonify({"error": str(e)}), 500

# 2. GET Parametrizado (Path param): Obtener producto por ID
@app.route('/productos/', methods=['GET'])
def get_producto_by_id(id):
    try:
        conn = get_db_connection()
        cursor = conn.cursor(dictionary=True)
        cursor.execute('SELECT * FROM productos WHERE id = %s', (id,))
        row = cursor.fetchone()
        cursor.close()
        conn.close()

        if not row:
            return jsonify({"mensaje": "Producto no encontrado"}), 404
        return jsonify(row), 200
    except Exception as e:
        return jsonify({"error": str(e)}), 500

# 3. GET Parametrizado (Query param): Filtrar por nombre (?nombre=laptop)
@app.route('/productos/buscar/filtro', methods=['GET'])
def search_productos():
    try:
        nombre = request.args.get('nombre', '')
        conn = get_db_connection()
        cursor = conn.cursor(dictionary=True)
        cursor.execute('SELECT * FROM productos WHERE nombre LIKE %s', (f"%{nombre}%",))
        rows = cursor.fetchall()
        cursor.close()
        conn.close()
        return jsonify(rows), 200
    except Exception as e:
        return jsonify({"error": str(e)}), 500

# ==========================================
# ENDPOINTS POST
# ==========================================

# 1. POST No parametrizado: Crear nuevo registro (datos en Body JSON)
@app.route('/productos', methods=['POST'])
def create_producto():
    try:
        data = request.get_json()
        nombre = data.get('nombre')
        precio = data.get('precio')

        if not nombre or not precio:
            return jsonify({"error": "Faltan datos requeridos (nombre, precio)"}), 400

        conn = get_db_connection()
        cursor = conn.cursor()
        cursor.execute(
            'INSERT INTO productos (nombre, precio) VALUES (%s, %s)',
            (nombre, precio)
        )
        conn.commit() # Guarda los cambios en MySQL
        new_id = cursor.lastrowid
        cursor.close()
        conn.close()

        return jsonify({"id": new_id, "nombre": nombre, "precio": precio}), 201
    except Exception as e:
        return jsonify({"error": str(e)}), 500

# 2. POST Parametrizado (Path + Body): Crear enlazando un ID por URL
@app.route('/categorias//productos', methods=['POST'])
def create_producto_con_categoria(categoria_id):
    try:
        data = request.get_json()
        nombre = data.get('nombre')
        precio = data.get('precio')

        conn = get_db_connection()
        cursor = conn.cursor()
        cursor.execute(
            'INSERT INTO productos (nombre, precio) VALUES (%s, %s)',
            (nombre, precio)
        )
        conn.commit()
        new_id = cursor.lastrowid
        cursor.close()
        conn.close()

        return jsonify({
            "id": new_id,
            "categoriaId": categoria_id,
            "nombre": nombre,
            "precio": precio
        }), 201
    except Exception as e:
        return jsonify({"error": str(e)}), 500

# ==========================================
# ARRANQUE DEL SERVIDOR
# ==========================================
if __name__ == '__main__':
    port = int(os.environ.get("PORT", 3000))
    # host='0.0.0.0' permite escuchar en red local y conexiones remotas
    app.run(host='0.0.0.0', port=port, debug=True)

4. Resumen de Endpoints de la API

Método Ruta / Endpoint Parámetro Descripción
GET /productos Ninguno Retorna la lista completa de productos.
GET /productos/<int:id> Path (URL) Busca un producto especificando su ID.
GET /productos/buscar/filtro Query (request.args) Filtra por nombre (ej. ?nombre=laptop).
POST /productos Body JSON (request.get_json()) Crea un nuevo producto en la base de datos.
POST /categorias/<int:categoria_id>/productos Path + Body JSON Crea un registro asociando un valor de la URL.
Puntos clave para explicar en clase:
  • Placeholder MySQL (%s): En Python con MySQL Connector se utiliza %s como comodín de parametrización para prevenir inyecciones SQL.
  • Cursor Dictionary (dictionary=True): Convierte automáticamente las tuplas de MySQL en diccionarios Python clave-valor para ser serializados a JSON fácilmente.
  • Commit explícito (conn.commit()): Las operaciones de escritura (POST, PUT, DELETE) requieren invocar .commit() para aplicar los cambios permanentemente en la base de datos.
  • CORS y Enlace Local (0.0.0.0): CORS(app) elimina las restricciones de origen en las peticiones web, y 0.0.0.0 asegura la visibilidad de la API a través de la red local o servidores de pruebas en el laboratorio.
