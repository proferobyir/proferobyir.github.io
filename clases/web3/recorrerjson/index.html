📚 Guía de Recorrido de JSON y Anidamientos

20 ejercicios progresivos para dominar la iteración, filtrado y renderizado dinámico de datos JSON anidados.

● Básico ● Intermedio ● Avanzado ● Experto

📦 Bloque 1: Fundamentos de JSON y Primeros Pasos

01. Recorrido Básico con forEach Básico

Arreglo Plano
📖 ¿Qué es JSON? JSON (JavaScript Object Notation) es un formato ligero para intercambiar datos. Se compone de dos estructuras principales: objetos { } (pares clave/valor) y arreglos [ ] (listas ordenadas).

🎯 Aprendizaje: Aquí usamos forEach, el método más básico para recorrer un arreglo y extraer propiedades directas (item.title, item.img) para construir tarjetas. 
const data1 = [
    { id: 1, title: 'Servidor Blade X1', img: 'https://picsum.photos/id/10/200/120' },
    { id: 2, title: 'Switch Óptico 24P', img: 'https://picsum.photos/id/20/200/120' }
];

let html1 = '';
data1.forEach(item => {
    html1 += `
        <div class="carbon-card">
            <img src="${item.img}" alt="${item.title}">
            <div class="title">${item.title}</div>
            <div class="subtitle">ID: ${item.id}</div>
        </div>
    `;
});
document.getElementById('out-1').innerHTML = html1;

02. Transformación con map Básico

Anidamiento Nivel 1
📖 ¿Qué es map? A diferencia de forEach (que solo itera), map transforma cada elemento y devuelve un nuevo arreglo del mismo tamaño. Es ideal para convertir datos en HTML.

🎯 Aprendizaje: Accedemos a propiedades dentro de un sub-objeto (user.profile.avatar) y usamos join('') para convertir el arreglo resultante en un solo string HTML. 
const data2 = [
    { name: 'Ana Silva', profile: { avatar: 'https://picsum.photos/id/64/100/100', role: 'DevOps Lead' } },
    { name: 'Luis Ramos', profile: { avatar: 'https://picsum.photos/id/65/100/100', role: 'Frontend Spec' } }
];

document.getElementById('out-2').innerHTML = data2.map(u => `
    <div class="carbon-card" style="align-items: center; text-align: center;">
        <img class="avatar" src="${u.profile.avatar}" alt="${u.name}">
        <div class="title">${u.name}</div>
        <div class="subtitle">${u.profile.role}</div>
    </div>
`).join('');

🔗 Bloque 2: Anidamiento Básico y Sub-estructuras

03. Sub-arreglo de Imágenes (Galería) Intermedio

Arreglo Anidado
📖 ¿Qué es un anidamiento? En JSON, un objeto puede contener otros objetos o arreglos dentro de sí. Esto permite estructurar datos jerárquicos como categorías, comentarios o galerías.

🎯 Aprendizaje: Aquí cada ítem tiene un gallery que es un arreglo de URLs. Usamos map dentro de otro map para mostrar múltiples imágenes en una tarjeta. 
const data3 = [
    { title: 'Cluster DB Alpha', gallery: [
        'https://picsum.photos/id/30/80/50',
        'https://picsum.photos/id/31/80/50',
        'https://picsum.photos/id/32/80/50'
    ] }
];

document.getElementById('out-3').innerHTML = data3.map(item => `
    <div class="carbon-card">
        <div class="title">${item.title}</div>
        <div style="display: flex; gap: 0.5rem; margin-top: 0.5rem;">
            ${item.gallery.map(url => `<img src="${url}" style="height: 50px; width: auto;">`).join('')}
        </div>
    </div>
`).join('');

04. Desestructuración de Parámetros Básico

Extracción Elegante
📖 ¿Qué es la desestructuración? Es una forma concisa de extraer propiedades de objetos y arreglos. En lugar de escribir item.name, podemos extraer { name } directamente.

🎯 Aprendizaje: Usamos for...of con desestructuración anidada ({ name, media: { poster } }) para acceder limpiamente a propiedades profundas. 
const data4 = [
    { name: 'Módulo IoT', media: { poster: 'https://picsum.photos/id/40/200/120' } },
    { name: 'Sensor Riego', media: { poster: 'https://picsum.photos/id/42/200/120' } }
];

let html4 = '';
for (const { name, media: { poster } } of data4) {
    html4 += `
        <div class="carbon-card">
            <img src="${poster}" alt="${name}">
            <div class="title">${name}</div>
        </div>
    `;
}
document.getElementById('out-4').innerHTML = html4;

05. Renderizado Condicional con Fallback Intermedio

Operador ||
📖 ¿Qué es un fallback? Es un valor por defecto que se usa cuando el dato esperado no existe. En JS usamos el operador || (OR) para esto.

🎯 Aprendizaje: Evaluamos si item.image es null o vacío usando item.image || 'url-por-defecto'. También mostramos un texto condicional (item.image ? 'Foto real' : 'Placeholder'). 
const data5 = [
    { title: 'Cámara IP', image: 'https://picsum.photos/id/50/200/120' },
    { title: 'Gateway Sin Foto', image: null }
];

document.getElementById('out-5').innerHTML = data5.map(item => `
    <div class="carbon-card">
        <img src="${item.image || 'https://picsum.photos/id/100/200/120'}" alt="${item.title}">
        <div class="title">${item.title}</div>
        <div class="subtitle">${item.image ? 'Foto real' : 'Placeholder fallback'}</div>
    </div>
`).join('');

🔍 Bloque 3: Filtrado y Transformación de Datos

06. Filtrado Previo con filter Intermedio

Selección Condicional
📖 ¿Qué es filter? Crea un nuevo arreglo con todos los elementos que cumplan una condición (true). No modifica el arreglo original.

🎯 Aprendizaje: Filtramos solo los elementos con active: true antes de mapear, reduciendo los datos a renderizar. 
const data6 = [
    { name: 'Nodo A', active: true, pic: 'https://picsum.photos/id/60/200/120' },
    { name: 'Nodo B', active: false, pic: 'https://picsum.photos/id/61/200/120' },
    { name: 'Nodo C', active: true, pic: 'https://picsum.photos/id/62/200/120' }
];

document.getElementById('out-6').innerHTML = data6
    .filter(i => i.active)
    .map(i => `
        <div class="carbon-card">
            <img src="${i.pic}">
            <div class="title">${i.name}</div>
            <span class="mini-tag">Activo</span>
        </div>
    `).join('');

🏗️ Bloque 4: Anidamiento Profundo (3+ Niveles)

07. Anidamiento Profundo (Categoría → Subcategoría → Producto) Avanzado

3 Niveles
📖 ¿Qué es un anidamiento profundo? Cuando tenemos 3 o más niveles de profundidad (ej: cat.subs[].items[]). Esto es común en datos jerárquicos como categorías de productos.

🎯 Aprendizaje: Usamos tres bucles anidados (forEach dentro de forEach dentro de forEach) para llegar hasta los ítems finales. La clave está en entender el orden de acceso. 
const data7 = [
    { cat: 'Hardware', subs: [
        { name: 'RAM', items: [
            { model: 'DDR5 16GB', img: 'https://picsum.photos/id/70/200/120' },
            { model: 'DDR4 8GB', img: 'https://picsum.photos/id/71/200/120' }
        ]},
        { name: 'Storage', items: [
            { model: 'SSD 1TB', img: 'https://picsum.photos/id/72/200/120' }
        ]}
    ]}
];

let html7 = '';
data7.forEach(c => {
    c.subs.forEach(s => {
        s.items.forEach(p => {
            html7 += `
                <div class="carbon-card">
                    <img src="${p.img}">
                    <div class="title">${p.model}</div>
                    <div class="subtitle">${c.cat} > ${s.name}</div>
                </div>`;
        });
    });
});
document.getElementById('out-7').innerHTML = html7;

08. Publicación con Autor y Comentarios Avanzado

Relaciones Anidadas
📖 ¿Qué son las relaciones anidadas? En datos sociales, una publicación tiene un autor y una lista de comentarios, cada uno con su propio autor. Esto refleja estructuras de datos del mundo real.

🎯 Aprendizaje: Combinamos dos niveles de anidamiento: la publicación principal (con author y avatar) y sus comentarios (cada uno con user.name y user.avatar). 
const data8 = [{
    author: 'Carlos',
    avatar: 'https://picsum.photos/id/88/50/50',
    content: 'Lanzamiento de versión v2.0 completado.',
    comments: [
        { user: { name: 'Elena', avatar: 'https://picsum.photos/id/91/30/30' }, text: '¡Excelente!' },
        { user: { name: 'Miguel', avatar: 'https://picsum.photos/id/92/30/30' }, text: 'Buen trabajo' }
    ]
}];

document.getElementById('out-8').innerHTML = data8.map(p => `
    <div class="carbon-card">
        <div style="display:flex; align-items:center; gap:0.5rem;">
            <img class="avatar" src="${p.avatar}">
            <div><strong>${p.author}</strong></div>
        </div>
        <p style="margin: 0.5rem 0;">${p.content}</p>
        <div style="border-top: 1px solid var(--cds-border-subtle); padding-top: 0.5rem;">
            ${p.comments.map(c => `
                <div style="display:flex; align-items:center; gap:0.5rem; font-size: 0.813rem;">
                    <img class="avatar-sm" src="${c.user.avatar}">
                    <span><strong>${c.user.name}:</strong> ${c.text}</span>
                </div>
            `).join('')}
        </div>
    </div>
`).join('');

⚙️ Bloque 5: Manipulación Avanzada de Datos

09. Transformación de Rutas Relativas a Absolutas Intermedio

Concatenación de Strings
📖 ¿Qué es la transformación de datos? A veces los datos vienen en un formato que no es directamente usable (ej: rutas relativas). Podemos transformarlos durante el recorrido.

🎯 Aprendizaje: Usamos map para concatenar un servidor CDN base (CDN_BASE) con la ruta relativa (item.relPath) antes de insertarla en el HTML. 
const CDN_BASE = 'https://picsum.photos/id/';
const data9 = [
    { name: 'Router CNC', relPath: '101' },
    { name: 'Impresora 3D', relPath: '102' }
];

document.getElementById('out-9').innerHTML = data9.map(item => `
    <div class="carbon-card">
        <img src="${CDN_BASE}${item.relPath}/200/120">
        <div class="title">${item.name}</div>
    </div>
`).join('');

10. Iteración con Object.entries() Avanzado

Objetos como Diccionarios
📖 ¿Qué es Object.entries()? Convierte un objeto en un arreglo de pares [clave, valor]. Útil cuando los datos vienen como un diccionario en lugar de un arreglo.

🎯 Aprendizaje: En lugar de un arreglo estándar, tenemos un objeto data10 donde cada clave (item_A, item_B) contiene un producto. Usamos Object.entries() para iterar sobre las claves y valores. 
const data10 = {
    item_A: { title: 'Rack 42U', img: 'https://picsum.photos/id/110/200/120' },
    item_B: { title: 'UPS 3000VA', img: 'https://picsum.photos/id/111/200/120' }
};

document.getElementById('out-10').innerHTML = Object.entries(data10).map(([key, val]) => `
    <div class="carbon-card">
        <img src="${val.img}">
        <div class="title">${val.title}</div>
        <div class="subtitle">Key: ${key}</div>
    </div>
`).join('');

📊 Bloque 6: Reducción y Agrupamiento

11. Agrupamiento con reduce Avanzado

Acumulación de Datos
📖 ¿Qué es reduce? El método más poderoso para transformar arreglos. Acumula todos los elementos en un único valor (puede ser un número, string u objeto).

🎯 Aprendizaje: Agrupamos fotos por categoría (group) usando reduce. El acumulador (acc) es un objeto donde cada clave es un grupo y cada valor es un arreglo de ítems de ese grupo. 
const data11 = [
    { name: 'Cam1', group: 'Exterior', img: 'https://picsum.photos/id/120/150/90' },
    { name: 'Cam2', group: 'Interior', img: 'https://picsum.photos/id/121/150/90' },
    { name: 'Cam3', group: 'Exterior', img: 'https://picsum.photos/id/122/150/90' }
];

const grouped = data11.reduce((acc, item) => {
    (acc[item.group] = acc[item.group] || []).push(item);
    return acc;
}, {});

document.getElementById('out-11').innerHTML = Object.entries(grouped).map(([grp, items]) => `
    <div style="margin-bottom: 1rem;">
        <h3 style="font-size:0.875rem; margin-bottom:0.5rem; color:var(--cds-link-01);">${grp}</h3>
        <div class="card-grid">
            ${items.map(i => `<div class="carbon-card"><img src="${i.img}"><div class="title">${i.name}</div></div>`).join('')}
        </div>
    </div>
`).join('');

🧩 Bloque 7: Estructuras Complejas y Polimorfismo

16. Arreglos Heterogéneos (Polimórficos) Avanzado

Múltiples Tipos
📖 ¿Qué es un arreglo heterogéneo? Un arreglo que contiene objetos de diferentes estructuras. En JSON es válido, pero debemos manejar cada tipo de objeto de manera diferente.

🎯 Aprendizaje: Usamos un if/else dentro del map para renderizar componentes diferentes según el type del ítem ('card' o 'banner'). 
const data16 = [
    { type: 'card', name: 'Tarjeta A', img: 'https://picsum.photos/id/170/200/120' },
    { type: 'banner', text: 'Anuncio Promocional Especial' },
    { type: 'card', name: 'Tarjeta B', img: 'https://picsum.photos/id/171/200/120' }
];

document.getElementById('out-16').innerHTML = data16.map(item => {
    if (item.type === 'card') {
        return `<div class="carbon-card"><img src="${item.img}"><div class="title">${item.name}</div></div>`;
    } else {
        return `<div style="background:var(--cds-bg-200); padding:1rem; border-left:3px solid var(--cds-link-01);">${item.text}</div>`;
    }
}).join('');

🌀 Bloque 8: Aplanado y Recursividad

19. Aplanado de Datos con flatMap Avanzado

Aplanar Anidamiento
📖 ¿Qué es flatMap? Es la combinación de map + flat (aplanar un nivel). Útil cuando tenemos arreglos dentro de arreglos y queremos un solo arreglo plano.

🎯 Aprendizaje: Cada depósito tiene un inventory (arreglo de items). Usamos flatMap para extraer todos los items de todos los depósitos en un solo arreglo plano. 
const data19 = [
    { store: 'Depósito A', inventory: [{ img: 'https://picsum.photos/id/200/200/120', name: 'Item X' }] },
    { store: 'Depósito B', inventory: [{ img: 'https://picsum.photos/id/201/200/120', name: 'Item Y' }] },
    { store: 'Depósito C', inventory: [{ img: 'https://picsum.photos/id/202/200/120', name: 'Item Z' }] }
];

const flattened = data19.flatMap(s => s.inventory);
document.getElementById('out-19').innerHTML = flattened.map(item => `
    <div class="carbon-card">
        <img src="${item.img}">
        <div class="title">${item.name}</div>
    </div>
`).join('');

20. Recorrido Recursivo para Encontrar Imágenes Experto

Profundidad Variable
📖 ¿Qué es la recursividad? Es una técnica donde una función se llama a sí misma para recorrer estructuras de profundidad variable (cuando no sabemos cuántos niveles tiene el JSON).

🎯 Aprendizaje: La función findImagesRecursive explora cualquier objeto JSON, sin importar su profundidad, y detecta todas las claves que contienen URLs de imágenes. Es la solución más flexible y poderosa para JSONs desconocidos. 
const data20 = {
    a: 'Texto ignorable',
    b: { deepImg: 'https://picsum.photos/id/210/200/120' },
    c: [{ anotherImg: 'https://picsum.photos/id/211/200/120' }],
    d: { e: { f: { image: 'https://picsum.photos/id/212/200/120' } } }
};

function findImagesRecursive(obj, found = []) {
    if (!obj || typeof obj !== 'object') return found;
    
    for (const key in obj) {
        if (typeof obj[key] === 'string' && obj[key].startsWith('http')) {
            found.push({ url: obj[key], key: key });
        } else if (typeof obj[key] === 'object') {
            findImagesRecursive(obj[key], found);
        }
    }
    return found;
}

const extracted = findImagesRecursive(data20);
document.getElementById('out-20').innerHTML = extracted.map(({ url, key }) => `
    <div class="carbon-card">
        <img src="${url}">
        <div class="subtitle">Clave: ${key} (Extraído por Recursividad)</div>
    </div>
`).join('');
