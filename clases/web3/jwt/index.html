📘 Aprende API REST Fácil

Explicación simple de Express, JWT, MySQL y CORS

⚡ Node.js 🛤️ Express 🔐 JWT 🐬 MySQL 🌐 CORS

1 🤔 ¿Qué es una API REST?

Imagina que es un menú de restaurante 🍽️. Tú pides (cliente) y la cocina (servidor) te prepara lo que quieres.

📌 Sin estado

Cada pedido es independiente. El chef no recuerda lo que pediste antes.

📌 Verbos HTTP

GET (leer), POST (crear), PUT (actualizar todo), PATCH (actualizar parte), DELETE (borrar).

📌 Recursos (URLs)

Cada cosa tiene su dirección: /productos, /usuarios/5.

📌 Cliente ↔ Servidor

El frontend (tu navegador) y el backend (servidor) están separados.

💡 En resumen: Tú pides algo (URL + verbo), el servidor te responde. ¡No necesitas saber cómo lo hace!

2 🛠️ Verbos HTTP (las acciones)

Verbo Acción Ejemplo
GET Leer datos /productos
POST Crear nuevo /productos
PUT Actualizar todo /productos/1
PATCH Actualizar parte /productos/1
DELETE Eliminar /productos/1

// Así se crea un endpoint

  // /productos?categoria=electronica

🔹 Body (datos)

app.post('/productos', (req, res) => {
  const { nombre, precio } = req.body;
});

4 🌐 CORS: el portero

🚨 El problema: Los navegadores bloquean peticiones entre diferentes dominios por seguridad. Ejemplo: tu frontend en localhost:5500 no puede hablar con tu API en localhost:3000.
🌐 Frontend (localhost:5500)
⬇️
🚫 BLOQUEADO ❌
⬇️
🖥️ API (localhost:3000)
✅ La solución: CORS El servidor debe permitir explícitamente las peticiones desde otros orígenes.
🌐 Frontend (localhost:5500)
⬇️
✅ PERMITIDO ✓
⬇️
🖥️ API (localhost:3000)

🛠️ Cómo habilitar CORS en Express

✅ Con el middleware cors

// Instalar
npm install cors

// Usar (permitir todo)
const cors = require('cors');
app.use(cors());

// Más seguro
app.use(cors({
  origin: 'http://localhost:5500'
}));

✅ Manual (sin dependencias)

app.use((req, res, next) => {
  res.setHeader('Access-Control-Allow-Origin', '*');
  next();
});

5 🎟️ JWT (JSON Web Token): La pulsera del evento

Imagínate que vas a un festival de música 🎪:

1. Identificación

Llegas a la taquilla, muestras tu cédula/DNI y pagas tu entrada.

2. Entrega de Pulsera

Te dan una pulsera sellada (JWT) que dice tu nombre, tipo de pase y fecha de vencimiento.

3. Acceso Libre

Para entrar a la zona VIP o pedir comida, solo muestras la pulsera. ¡Ya no tienes que mostrar la cédula cada 5 minutos!

🔍 Las 3 partes de un JWT

Un JWT es un texto largo separado por dos puntos (.) que representan tres secciones:

eyJhbGciOiJIUzI1NiJ9.eyJpZCI6MSwicm9sIjoiZG9jZW50ZSJ9.d9F8sA_xK91Lz2M...

1. Encabezado (Header)

¿Qué es? La etiqueta de la pulsera.

Indica qué algoritmo se usó para la firma.

{
  "alg": "HS256",
  "typ": "JWT"
}

2. Datos (Payload)

¿Qué es? La información impresa.

Aquí van los datos del usuario (id, rol, expiración).

{
  "id": 1,
  "rol": "docente",
  "exp": 1700000000
}

3. Firma (Signature)

¿Qué es? El sello de agua o holograma anti-falsificación.

Permite al servidor verificar que la pulsera no fue alterada. 

HMACSHA256(
  header + payload,
  clave_secreta
)
⚠️ Regla de Oro: El JWT está firmado y visible (Base64), pero NO está encriptado. Cualquiera puede leer su contenido en jwt.io. ¡Jamás guardes contraseñas ni datos bancarios dentro del Payload!

6 📦 Código básico del servidor

Instala las dependencias:

npm init -y
npm install express jsonwebtoken mysql2 bcrypt cors

Archivo server.js (simplificado):

const express = require('express');
const jwt = require('jsonwebtoken');
const bcrypt = require('bcrypt');
const mysql = require('mysql2/promise');
const cors = require('cors');

const app = express();
app.use(cors()); // ⬅️ Habilita CORS
app.use(express.json());

// Conexión a MySQL
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: '',
  database: 'electiva3_db'
});

const JWT_SECRET = 'mi_clave_secreta';

// Middleware para verificar la pulsera (JWT)
function autenticar(req, res, next) {
  const token = req.headers['authorization']?.split(' ')[1];
  if (!token) return res.status(401).json({ error: 'Token requerido' });
  try {
    const decoded = jwt.verify(token, JWT_SECRET);
    req.user = decoded;
    next();
  } catch {
    res.status(403).json({ error: 'Token inválido o expirado' });
  }
}

// 1. LOGIN (Entrega de la pulsera)
app.post('/api/login', async (req, res) => {
  const { email, password } = req.body;
  const [rows] = await pool.execute(
    'SELECT * FROM usuarios WHERE email = ?', [email]
  );
  if (rows.length === 0) return res.status(401).json({ error: 'Credenciales inválidas' });

  const user = rows[0];
  const valido = await bcrypt.compare(password, user.password_hash);
  if (!valido) return res.status(401).json({ error: 'Credenciales inválidas' });

  // Firmar y generar el JWT
  const token = jwt.sign(
    { id: user.id, email: user.email, rol: user.rol },
    JWT_SECRET,
    { expiresIn: '1h' }
  );
  res.json({ mensaje: 'Login exitoso', token });
});

// 2. LISTAR PRODUCTOS (Zona protegida)
app.get('/api/productos', autenticar, async (req, res) => {
  const [rows] = await pool.execute('SELECT * FROM productos');
  res.json(rows);
});

// 3. CREAR PRODUCTO (Zona protegida)
app.post('/api/productos', autenticar, async (req, res) => {
  const { nombre, precio, categoria } = req.body;
  const [result] = await pool.execute(
    'INSERT INTO productos (nombre, precio, categoria) VALUES (?, ?, ?)',
    [nombre, precio, categoria]
  );
  const [newProduct] = await pool.execute('SELECT * FROM productos WHERE id = ?', [result.insertId]);
  res.status(201).json(newProduct[0]);
});

app.listen(3000, () => console.log('🚀 Servidor en http://localhost:3000'));

7 📡 Consumir desde el Frontend

🌐 Nota: El cliente guarda la pulsera (JWT) en localStorage y la envía en la cabecera Authorization cada vez que realiza una petición.

🔐 Login (Pedir pulsera)

const login = async () => {
  const res = await fetch('http://localhost:3000/api/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      email: 'profe@mail.com',
      password: '123456'
    })
  });
  const data = await res.json();
  if (data.token) {
    localStorage.setItem('token', data.token);
    console.log('✅ Login exitoso, pulsera guardada');
  }
  return data;
};

📋 Obtener productos (Mostrar pulsera)

const getProductos = async () => {
  const token = localStorage.getItem('token');
  if (!token) return console.error('❌ No hay token');

  const res = await fetch('http://localhost:3000/api/productos', {
    headers: { 'Authorization': `Bearer ${token}` }
  });

  return await res.json();
};

➕ Crear producto

const crearProducto = async (producto) => {
  const token = localStorage.getItem('token');
  const res = await fetch('http://localhost:3000/api/productos', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(producto)
  });
  return await res.json();
};

✏️ Actualizar parcialmente

const actualizarParcial = async (id, datos) => {
  const token = localStorage.getItem('token');
  const res = await fetch(`http://localhost:3000/api/productos/${id}`, {
    method: 'PATCH',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(datos)
  });
  return await res.json();
};

8 🔄 Flujo completo

1️⃣ Cliente → Envía credenciales con POST /api/login.
2️⃣ Servidor → Valida datos en MySQL y genera el JWT.
3️⃣ Servidor → Responde entregando la "pulsera" (JWT).
4️⃣ Cliente → Guarda el JWT en localStorage.
5️⃣ Cliente → Pide un recurso enviando la cabecera Authorization: Bearer <token>.
6️⃣ Servidor → El middleware revisa la firma de la pulsera.
7️⃣ Servidor → Si la firma coincide y no venció, entrega la información.
🎯 Resumen: El JWT es una pulsera digital. Te identificas una sola vez al hacer login, recibes tu token y luego lo muestras en cada petición para acceder a las rutas protegidas.

9 🐬 Base de Datos MySQL

Script para crear la base de datos:

CREATE DATABASE electiva3_db;
USE electiva3_db;

CREATE TABLE usuarios (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nombre VARCHAR(100),
  email VARCHAR(100) UNIQUE,
  password_hash VARCHAR(255),
  rol ENUM('admin', 'docente', 'estudiante')
);

CREATE TABLE productos (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nombre VARCHAR(150),
  precio DECIMAL(10,2),
  categoria VARCHAR(50)
);

10 🧠 Resumen final

🔐 Seguridad

• Usa bcrypt para contraseñas
• Usa consultas preparadas (SQL injection)
• El JWT no guarda información sensible
• Configura CORS con orígenes específicos

📦 Buenas prácticas

• Usa variables de entorno (.env)
• Separa el código en rutas y controladores
• Usa middlewares para autenticación
• Valida los datos de entrada

npm start - Inicia el servidor
npm install cors - Instala CORS
