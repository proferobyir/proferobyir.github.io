1 ¿Qué es una API REST?

REST es un estilo arquitectónico para diseñar servicios web. Sus principios clave son:

📌 Sin Estado (Stateless)

Cada petición es independiente. El servidor no guarda información entre peticiones.

📌 Interfaz Uniforme

Usa verbos HTTP estándar: GET, POST, PUT, DELETE, PATCH.

📌 Recursos Identificables

Todo se accede mediante URLs: /carbon, /minas/1

📌 Cliente-Servidor

Frontend y backend están separados y evolucionan independientemente.

💡 Analogía: Una API REST es como una mina de carbón. Tú (cliente) pides del catálogo (URL + verbo HTTP), la mina (servidor) prepara tu pedido y te lo entrega (respuesta). No necesitas saber cómo extraen el carbón, solo qué pedir.

2 Verbos HTTP que debes conocer

Verbo Qué hace Ejemplo ¿Idempotente?
GET Leer datos de carbón /carbon ✅ Sí
POST Registrar nuevo lote de carbón /carbon ❌ No
PUT Actualizar TODO sobre un lote /carbon/1 ✅ Sí
PATCH Actualizar PARTE de un lote /carbon/1 ❌ No
DELETE Eliminar registro de carbón /carbon/1 ✅ Sí
⚠️ Importante: Idempotente = hacer la misma petición varias veces da el mismo resultado. GET, PUT y DELETE son idempotentes. POST no lo es (cada vez crea un nuevo recurso).

4 CORS - Cross-Origin Resource Sharing

🚨 El problema: Por seguridad, los navegadores bloquean peticiones HTTP entre diferentes dominios (orígenes). Ejemplo: tu frontend en http://localhost:5500 no puede hablar con tu API de carbón en http://localhost:3000.
🌐 Frontend (http://localhost:5500)
⬇️
🚫 BLOQUEADO por el navegador ❌
⬇️
🖥️ API de Carbón (http://localhost:3000)
¿Por qué? El navegador aplica la Same-Origin Policy (Política de mismo origen).
✅ La solución: CORS El servidor debe permitir explícitamente las peticiones desde otros orígenes mediante cabeceras HTTP.
🌐 Frontend (http://localhost:5500)
⬇️
✅ PERMITIDO por CORS ✓
⬇️
🖥️ API de Carbón (http://localhost:3000)
¿Cómo? El servidor envía la cabecera: Access-Control-Allow-Origin: *

🛠️ Cómo habilitar CORS en Express (2 formas)

Opción 1: Con el middleware cors (recomendado)

// 1. Instalar
npm install cors

// 2. Importar
const cors = require('cors');

// 3. Usar (permitir todo)
app.use(cors());

// 🔒 Configuración más segura
app.use(cors({
  origin: 'http://localhost:5500', // solo este frontend
  methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));

Opción 2: Manual (sin dependencias extra)

// Middleware manual
app.use((req, res, next) => {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 
    'GET, POST, PUT, PATCH, DELETE'
  );
  res.setHeader('Access-Control-Allow-Headers', 
    'Content-Type, Authorization'
  );
  
  // Manejar peticiones OPTIONS (preflight)
  if (req.method === 'OPTIONS') {
    return res.sendStatus(200);
  }
  
  next();
});
📌 ¿Qué es una petición OPTIONS (Preflight)?
Antes de enviar peticiones "complejas" (PUT, DELETE, o con cabeceras personalizadas), el navegador envía automáticamente una petición OPTIONS para preguntar al servidor qué métodos y cabeceras permite. Si el servidor responde correctamente, el navegador envía la petición real.

6 JWT - JSON Web Tokens

Un JWT es como un pase VIP que le das al minero después de que inicia sesión en el sistema.

Header

Algoritmo y tipo

{"alg":"HS256","typ":"JWT"}

Payload

Datos del usuario

{"id":1,"rol":"supervisor"}

Signature

Firma para verificar

HMACSHA256(...)
🔒 Importante: El JWT NO está encriptado, solo codificado en Base64. Nunca guardes contraseñas en el payload.

Instala las dependencias:

Archivo server.js completo:

const express = require('express');
const jwt = require('jsonwebtoken');
const bcrypt = require('bcrypt');
const mysql = require('mysql2/promise');
const multer = require('multer');
const cors = require('cors');
const dotenv = require('dotenv');
dotenv.config();

const app = express();

// ========== CONFIGURACIÓN DE CORS ==========
// Opción 1: Permitir todo (solo para desarrollo)
app.use(cors());

// Opción 2: Configuración específica (más segura)
// app.use(cors({
//   origin: 'http://localhost:5500', // tu frontend
//   methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'],
//   allowedHeaders: ['Content-Type', 'Authorization']
// }));

// Middlewares para parsear JSON y formularios
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// ========== CONEXIÓN A MYSQL ==========
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: 'tu_contraseña',
  database: 'carbon_db'
});

// ========== CONFIGURACIÓN JWT ==========
const JWT_SECRET = 'mi_clave_super_secreta_carbon';

// ========== MIDDLEWARE DE AUTENTICACIÓN ==========
function autenticar(req, res, next) {
  const token = req.headers['authorization']?.split(' ')[1];
  
  if (!token) {
    return res.status(401).json({ error: 'Token requerido' });
  }

  try {
    const decoded = jwt.verify(token, JWT_SECRET);
    req.user = decoded;
    next();
  } catch {
    res.status(403).json({ error: 'Token inválido o expirado' });
  }
}

// ========== 1. LOGIN (público) ==========
app.post('/api/login', async (req, res) => {
  try {
    const { email, password } = req.body;
    
    if (!email || !password) {
      return res.status(400).json({ error: 'Email y contraseña requeridos' });
    }
    
    const [rows] = await pool.execute(
      'SELECT * FROM usuarios WHERE email = ?', [email]
    );
    
    if (rows.length === 0) {
      return res.status(401).json({ error: 'Credenciales inválidas' });
    }
    
    const user = rows[0];
    const valido = await bcrypt.compare(password, user.password_hash);
    
    if (!valido) {
      return res.status(401).json({ error: 'Credenciales inválidas' });
    }
    
    const token = jwt.sign(
      { id: user.id, email: user.email, rol: user.rol },
      JWT_SECRET,
      { expiresIn: '1h' }
    );
    
    res.json({ 
      mensaje: 'Login exitoso - Bienvenido a la mina', 
      token,
      usuario: { id: user.id, nombre: user.nombre, email: user.email, rol: user.rol }
    });
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Error en el servidor' });
  }
});

// ========== 2. LISTAR REGISTROS DE CARBÓN (protegido) ==========
app.get('/api/carbon', autenticar, async (req, res) => {
  try {
    const { tipo, calidad, mina, pagina = 1, limite = 10 } = req.query;
    const offset = (pagina - 1) * limite;
    
    let sql = 'SELECT * FROM carbon WHERE 1=1';
    const params = [];
    
    if (tipo) { sql += ' AND tipo = ?'; params.push(tipo); }
    if (calidad) { sql += ' AND calidad = ?'; params.push(calidad); }
    if (mina) { sql += ' AND mina_origen LIKE ?'; params.push(`%${mina}%`); }
    
    const [totalRows] = await pool.execute(
      `SELECT COUNT(*) as total FROM (${sql}) as sub`, params
    );
    
    sql += ' ORDER BY fecha_extraccion DESC LIMIT ? OFFSET ?';
    params.push(parseInt(limite), parseInt(offset));
    
    const [rows] = await pool.execute(sql, params);
    
    res.json({ 
      carbon: rows, 
      pagina: parseInt(pagina), 
      limite: parseInt(limite),
      total: totalRows[0].total,
      totalPaginas: Math.ceil(totalRows[0].total / limite)
    });
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Error al obtener registros de carbón' });
  }
});

// ========== 3. OBTENER UN REGISTRO DE CARBÓN (protegido) ==========
app.get('/api/carbon/:id', autenticar, async (req, res) => {
  try {
    const [rows] = await pool.execute(
      'SELECT * FROM carbon WHERE id = ?', [req.params.id]
    );
    
    if (rows.length === 0) {
      return res.status(404).json({ error: 'Registro de carbón no encontrado' });
    }
    
    res.json(rows[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al obtener el registro' });
  }
});

// ========== 4. REGISTRAR NUEVO LOTE DE CARBÓN (protegido) ==========
app.post('/api/carbon', autenticar, async (req, res) => {
  try {
    const { tipo, descripcion, peso_toneladas, calidad, mina_origen, fecha_extraccion, precio_tonelada } = req.body;
    
    if (!tipo || !peso_toneladas) {
      return res.status(400).json({ error: 'Tipo y peso del carbón son requeridos' });
    }
    
    const [result] = await pool.execute(
      'INSERT INTO carbon (tipo, descripcion, peso_toneladas, calidad, mina_origen, fecha_extraccion, precio_tonelada) VALUES (?, ?, ?, ?, ?, ?, ?)',
      [tipo, descripcion || '', peso_toneladas, calidad || 'B', mina_origen || 'Mina Principal', fecha_extraccion || new Date().toISOString().split('T')[0], precio_tonelada || 0]
    );
    
    const [newRecord] = await pool.execute(
      'SELECT * FROM carbon WHERE id = ?', [result.insertId]
    );
    
    res.status(201).json(newRecord[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al registrar lote de carbón' });
  }
});

// ========== 5. ACTUALIZAR LOTE DE CARBÓN (PUT - completo) ==========
app.put('/api/carbon/:id', autenticar, async (req, res) => {
  try {
    const { tipo, descripcion, peso_toneladas, calidad, mina_origen, fecha_extraccion, precio_tonelada } = req.body;
    const { id } = req.params;
    
    await pool.execute(
      'UPDATE carbon SET tipo = ?, descripcion = ?, peso_toneladas = ?, calidad = ?, mina_origen = ?, fecha_extraccion = ?, precio_tonelada = ? WHERE id = ?',
      [tipo, descripcion, peso_toneladas, calidad, mina_origen, fecha_extraccion, precio_tonelada, id]
    );
    
    const [updated] = await pool.execute(
      'SELECT * FROM carbon WHERE id = ?', [id]
    );
    
    res.json(updated[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al actualizar lote de carbón' });
  }
});

// ========== 6. ACTUALIZAR LOTE (PATCH - parcial) ==========
app.patch('/api/carbon/:id', autenticar, async (req, res) => {
  try {
    const { id } = req.params;
    const updates = req.body;
    
    const campos = Object.keys(updates);
    if (campos.length === 0) {
      return res.status(400).json({ error: 'No se enviaron campos para actualizar' });
    }
    
    const valores = Object.values(updates);
    const setClause = campos.map(c => `${c} = ?`).join(', ');
    valores.push(id);
    
    await pool.execute(
      `UPDATE carbon SET ${setClause} WHERE id = ?`, valores
    );
    
    const [updated] = await pool.execute(
      'SELECT * FROM carbon WHERE id = ?', [id]
    );
    
    res.json(updated[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al actualizar lote de carbón' });
  }
});

// ========== 7. ELIMINAR LOTE DE CARBÓN (protegido) ==========
app.delete('/api/carbon/:id', autenticar, async (req, res) => {
  try {
    await pool.execute('DELETE FROM carbon WHERE id = ?', [req.params.id]);
    res.json({ mensaje: 'Lote de carbón eliminado correctamente' });
  } catch (error) {
    res.status(500).json({ error: 'Error al eliminar lote de carbón' });
  }
});

// ========== 8. SUBIR ARCHIVOS (protegido) ==========
const storage = multer.diskStorage({
  destination: 'uploads/',
  filename: (req, file, cb) => {
    cb(null, `carbon-${Date.now()}-${file.originalname}`);
  }
});

const upload = multer({ 
  storage,
  limits: { fileSize: 5 * 1024 * 1024 },
  fileFilter: (req, file, cb) => {
    const allowed = ['image/jpeg', 'image/png', 'image/gif', 'application/pdf'];
    if (allowed.includes(file.mimetype)) {
      cb(null, true);
    } else {
      cb(new Error('Tipo de archivo no permitido'), false);
    }
  }
});

app.post('/api/upload', autenticar, upload.single('archivo'), (req, res) => {
  if (!req.file) {
    return res.status(400).json({ error: 'No se envió ningún archivo' });
  }
  res.json({ 
    mensaje: 'Archivo de registro de carbón subido correctamente',
    archivo: req.file.originalname,
    tamaño: req.file.size,
    tipo: req.file.mimetype
  });
});

// ========== RUTA NO ENCONTRADA (404) ==========
app.use((req, res) => {
  res.status(404).json({ error: 'Ruta no encontrada en el sistema de carbón' });
});

// ========== INICIAR SERVIDOR ==========
const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`⛏️  Servidor de Carbón en http://localhost:${PORT}`);
  console.log(`📋 CORS habilitado para todos los orígenes`);
});

8 Consumir desde el Frontend (Fetch)

🌐 Nota: Gracias a CORS, tu frontend puede hacer peticiones a la API de carbón sin problemas.

Login - Acceso a la Mina

const login = async () => {
  const res = await fetch('http://localhost:3000/api/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      email: 'super@mina.com',
      password: '123456'
    })
  });
  const data = await res.json();
  if (data.token) {
    localStorage.setItem('token', data.token);
    console.log('⛏️ Acceso a la mina concedido');
  }
  return data;
};

Obtener registros de carbón

const getCarbon = async () => {
  const token = localStorage.getItem('token');
  
  if (!token) {
    console.error('❌ No hay token de acceso');
    return;
  }
  
  const res = await fetch('http://localhost:3000/api/carbon', {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  
  if (res.status === 401) {
    console.log('⏰ Token expirado, redirigiendo al login...');
    localStorage.removeItem('token');
  }
  
  const data = await res.json();
  return data;
};

Registrar nuevo lote de carbón

const registrarCarbon = async (lote) => {
  const token = localStorage.getItem('token');

      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'

    body: JSON.stringify(lote)

  return await res.json();
};

9 Flujo Completo de Autenticación - Sistema de Carbón

1️⃣ Minero → POST /api/login (email + password)
2️⃣ Servidor → Verifica credenciales en MySQL
3️⃣ Servidor → Genera JWT y lo devuelve al minero
4️⃣ Minero → Guarda JWT en localStorage
5️⃣ Minero → GET /api/carbon (con token en header)
6️⃣ Servidor → Middleware verifica el token
7️⃣ Servidor → Si es válido, devuelve los datos de carbón
8️⃣ Minero → Muestra los datos en la interfaz
🌐 Con CORS incluido:
1️⃣ Frontend (http://localhost:5500) → hace petición a la API de carbón
2️⃣ Navegador → pregunta al servidor si permite CORS (OPTIONS)
3️⃣ Servidor → responde con Access-Control-Allow-Origin: *
4️⃣ Navegador → permite la petición
5️⃣ Frontend → recibe la respuesta de la API
🎯 Resumen: El JWT es un pase temporal para la mina. El minero se autentica una vez y recibe un token que usa en cada petición. El servidor no guarda sesiones, solo verifica el token. CORS permite que tu frontend y backend hablen aunque estén en diferentes puertos.

10 Consideraciones Finales - Gestión de Carbón

🔐 Seguridad en la Mina

• Usa bcrypt para hashear contraseñas
• Usa consultas preparadas contra SQL injection
• El JWT no guarda información sensible de la mina
• Expira el token (ej: 1 hora)
• Configura CORS con orígenes específicos en producción

📦 Buenas prácticas mineras

• Usa variables de entorno (.env)
• Separa el código en rutas y controladores
• Usa middlewares para autenticación
• Valida los datos de entrada (peso, tipo, calidad)
• CORS: en desarrollo usa cors(), en producción configura orígenes

🛠️ CORS en producción

// Solo permitir tu frontend en producción

  methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'],

📚 Extras que puedes agregar

• Refresh tokens (renovar JWT sin re-login)
• Roles y permisos (admin, supervisor, minero)
• Validación con Joi o express-validator
• Logging de operaciones mineras
• Manejo de errores centralizado
