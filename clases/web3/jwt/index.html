1

Concepto Clave (La Analogía del Club VIP)

Aplica esta metáfora al iniciar tu exposición para fijar la idea central de inmediato:

🍹 La Discoteca / Club Privado

🏷️ JWT (La Pulsera VIP)

Es un carnet o pulsera que te entregan al entrar. Contiene tu ID y rol, viene con una firma digital infalsificable. No cambia en cada puerta.

🛡️ Middleware (El Guardia)

Es el personal de seguridad en la puerta de la zona VIP. Intercepta tu paso, revisa la validez de tu pulsera y decide si entras o te rechaza.

2

Anatomía de un JSON Web Token (JWT)

Un JWT es una cadena de texto dividida en 3 partes separadas por puntos (.):

Header Encabezado

Define el algoritmo de firma y tipo de token.

{"alg": "HS256", "typ": "JWT"}

Payload Carga Útil

Datos del usuario (claims). ¡Visibles, no sensibles!

{"id": 101, "role": "admin"}

Signature Firma

Garantiza la integridad. Creada con clave secreta.

HMACSHA256(header+payload, secret)
💡
Regla de Oro: El Payload es accesible en Base64. Nunca almacenes contraseñas, claves secretas o tarjetas de crédito dentro de un JWT.
3

¿Qué es un Middleware?

Es una función intermedia entre la petición recibida y la respuesta enviada por el servidor. Posee 3 parámetros fundamentales:

  • 🔹 req (Request): La petición entrante (headers, body, datos recibidos).
  • 🔹 res (Response): Objeto para responder al cliente (envía JSON, estados HTTP).
  • 🔹 next(): Función pivote que transfiere el control al siguiente middleware o ruta.
4

Flujo Completo de Autenticación

Paso 1: Cliente envía credenciales POST /login
⬇️
Paso 2: Servidor valida, genera el JWT y se lo retorna al Cliente
⬇️
Paso 3: Cliente realiza petición a ruta protegida adjuntando Header Authorization: Bearer <TOKEN>
⬇️
Paso 4: Middleware valida el token. Si es correcto llama a next(), de lo contrario devuelve 401 Unauthorized.
5

Implementación en Código (Node.js + Express)

Instalación inicial de librerías en terminal:

Terminal / Bash 
npm init -y
npm install express jsonwebtoken

Código del Servidor y Middleware (server.js):

server.js JavaScript 
const express = require('express');
const jwt = require('jsonwebtoken');

const app = express();
app.use(express.json());

const SECRET_KEY = 'clave_secreta_electiva_3';

// --- 1. RUTA PÚBLICA (LOGIN) ---
app.post('/login', (req, res) => {
  const { username, password } = req.body;

  if (username === 'profesor' && password === '123456') {
    // Payload con datos públicos del usuario
    const payload = { id: 101, username: 'profesor', role: 'docente' };
    
    // Generar token con tiempo de expiración (1 hora)
    const token = jwt.sign(payload, SECRET_KEY, { expiresIn: '1h' });
    return res.json({ mensaje: 'Autenticación Exitosa', token });
  }

  return res.status(401).json({ error: 'Credenciales incorrectas' });
});

// --- 2. MIDDLEWARE DE VERIFICACIÓN DE TOKEN ---
function authMiddleware(req, res, next) {
  const authHeader = req.headers['authorization'];
  // Extraer el token del encabezado "Bearer "
  const token = authHeader && authHeader.split(' ')[1];

  if (!token) {
    return res.status(401).json({ error: 'Acceso denegado. Token no suministrado.' });
  }

  try {
    // Verificar validez y firma del token
    const decoded = jwt.verify(token, SECRET_KEY);
    req.user = decoded; // Inyectar usuario a la petición
    next(); // Pasar a la siguiente función/ruta
  } catch (err) {
    return res.status(403).json({ error: 'Token inválido o expirado' });
  }
}

// --- 3. RUTA PROTEGIDA (USO DEL MIDDLEWARE) ---
app.get('/dashboard', authMiddleware, (req, res) => {
  res.json({
    mensaje: `Bienvenido ${req.user.username}`,
    contenidoExclusivo: 'Notas de la materia: Todos aprobados.'
  });
});

app.listen(3000, () => console.log('Servidor en ejecucion en puerto 3000'));

Puntos Clave para Destacar en Clase

  • ✔
    JWT es Stateless (Sin Estado): El servidor no necesita guardar sesiones en Base de Datos. La firma del token valida la petición instantáneamente.
  • ✔
    Estructura del Header: Recordar siempre enviar el token usando el formato estándar Authorization: Bearer <TOKEN>.
  • ✔
    Codificación vs Encriptación: Base64 es solo una codificación de formato, no oculta información. La seguridad radica exclusivamente en la Firma (Signature).
