Guía práctica para construir una API con autenticación stateless

Node.js Express JWT MySQL CORS

1 ¿Qué es una API REST?

REST es un estilo arquitectónico para diseñar servicios web. Sus principios clave son:

📌 Sin Estado (Stateless)

Cada petición es independiente. El servidor no guarda información entre peticiones.

📌 Interfaz Uniforme

Usa verbos HTTP estándar: GET, POST, PUT, DELETE, PATCH.

📌 Recursos Identificables

Todo se accede mediante URLs: /productos, /usuarios/1

📌 Cliente-Servidor

Frontend y backend están separados y evolucionan independientemente.

💡 Analogía: Una API REST es como un restaurante. Tú (cliente) pides del menú (URL + verbo HTTP), la cocina (servidor) prepara tu pedido y te lo entrega (respuesta). No necesitas saber cómo cocinan, solo qué pedir.

2 Verbos HTTP que debes conocer

Verbo Qué hace Ejemplo ¿Idempotente?
GET Leer datos /productos ✅ Sí
POST Crear un recurso /productos ❌ No
PUT Actualizar TODO /productos/1 ✅ Sí
PATCH Actualizar PARTE /productos/1 ❌ No
DELETE Eliminar /productos/1 ✅ Sí
⚠️ Importante: Idempotente = hacer la misma petición varias veces da el mismo resultado. GET, PUT y DELETE son idempotentes. POST no lo es (cada vez crea un nuevo recurso).

4 CORS - Cross-Origin Resource Sharing

🚨 El problema: Por seguridad, los navegadores bloquean peticiones HTTP entre diferentes dominios (orígenes). Ejemplo: tu frontend en http://localhost:5500 no puede hablar con tu API en http://localhost:3000.
🌐 Frontend (http://localhost:5500)
⬇️
🚫 BLOQUEADO por el navegador ❌
⬇️
🖥️ API (http://localhost:3000)
¿Por qué? El navegador aplica la Same-Origin Policy (Política de mismo origen).
✅ La solución: CORS El servidor debe permitir explícitamente las peticiones desde otros orígenes mediante cabeceras HTTP.
🌐 Frontend (http://localhost:5500)
⬇️
✅ PERMITIDO por CORS ✓
⬇️
🖥️ API (http://localhost:3000)
¿Cómo? El servidor envía la cabecera: Access-Control-Allow-Origin: *

🛠️ Cómo habilitar CORS en Express (2 formas)

Opción 1: Con el middleware cors (recomendado)

// 1. Instalar
npm install cors

// 2. Importar
const cors = require('cors');

// 3. Usar (permitir todo)
app.use(cors());

// 🔒 Configuración más segura
app.use(cors({
  origin: 'http://localhost:5500', // solo este frontend
  methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));

Opción 2: Manual (sin dependencias extra)

// Middleware manual
app.use((req, res, next) => {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 
    'GET, POST, PUT, PATCH, DELETE'
  );
  res.setHeader('Access-Control-Allow-Headers', 
    'Content-Type, Authorization'
  );
  
  // Manejar peticiones OPTIONS (preflight)
  if (req.method === 'OPTIONS') {
    return res.sendStatus(200);
  }
  
  next();
});
📌 ¿Qué es una petición OPTIONS (Preflight)?
Antes de enviar peticiones "complejas" (PUT, DELETE, o con cabeceras personalizadas), el navegador envía automáticamente una petición OPTIONS para preguntar al servidor qué métodos y cabeceras permite. Si el servidor responde correctamente, el navegador envía la petición real.

6 JWT - JSON Web Tokens

Un JWT es como un pase VIP que le das al usuario después de que inicia sesión.

Header

Algoritmo y tipo

{"alg":"HS256","typ":"JWT"}

Payload

Datos del usuario

{"id":1,"rol":"docente"}

Signature

Firma para verificar

HMACSHA256(...)
🔒 Importante: El JWT NO está encriptado, solo codificado en Base64. Nunca guardes contraseñas en el payload.

7 Código Completo del Servidor (con CORS)

Instala las dependencias:

npm init -y
npm install express jsonwebtoken mysql2 bcrypt dotenv multer cors

🔧 Nota: Ahora incluimos cors como dependencia para habilitar peticiones desde el frontend.

Archivo server.js completo:

const express = require('express');
const jwt = require('jsonwebtoken');
const bcrypt = require('bcrypt');
const mysql = require('mysql2/promise');
const multer = require('multer');
const cors = require('cors');
const dotenv = require('dotenv');
dotenv.config();

const app = express();

// ========== CONFIGURACIÓN DE CORS ==========
// Opción 1: Permitir todo (solo para desarrollo)
app.use(cors());

// Opción 2: Configuración específica (más segura)
// app.use(cors({
//   origin: 'http://localhost:5500', // tu frontend
//   methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE'],
//   allowedHeaders: ['Content-Type', 'Authorization']
// }));

// Middlewares para parsear JSON y formularios
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// ========== CONEXIÓN A MYSQL ==========
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: 'tu_contraseña',
  database: 'electiva3_db'
});

// ========== CONFIGURACIÓN JWT ==========
const JWT_SECRET = 'mi_clave_super_secreta';

// ========== MIDDLEWARE DE AUTENTICACIÓN ==========
function autenticar(req, res, next) {
  const token = req.headers['authorization']?.split(' ')[1];
  
  if (!token) {
    return res.status(401).json({ error: 'Token requerido' });
  }

  try {
    const decoded = jwt.verify(token, JWT_SECRET);
    req.user = decoded;
    next();
  } catch {
    res.status(403).json({ error: 'Token inválido o expirado' });
  }
}

// ========== 1. LOGIN (público) ==========
app.post('/api/login', async (req, res) => {
  try {
    const { email, password } = req.body;
    
    if (!email || !password) {
      return res.status(400).json({ error: 'Email y contraseña requeridos' });
    }
    
    const [rows] = await pool.execute(
      'SELECT * FROM usuarios WHERE email = ?', [email]
    );
    
    if (rows.length === 0) {
      return res.status(401).json({ error: 'Credenciales inválidas' });
    }
    
    const user = rows[0];
    const valido = await bcrypt.compare(password, user.password_hash);
    
    if (!valido) {
      return res.status(401).json({ error: 'Credenciales inválidas' });
    }
    
    const token = jwt.sign(
      { id: user.id, email: user.email, rol: user.rol },
      JWT_SECRET,
      { expiresIn: '1h' }
    );
    
    res.json({ 
      mensaje: 'Login exitoso', 
      token,
      usuario: { id: user.id, nombre: user.nombre, email: user.email, rol: user.rol }
    });
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Error en el servidor' });
  }
});

// ========== 2. LISTAR PRODUCTOS (protegido) ==========
app.get('/api/productos', autenticar, async (req, res) => {
  try {
    const { categoria, precioMin, precioMax, busqueda, pagina = 1, limite = 10 } = req.query;
    const offset = (pagina - 1) * limite;
    
    let sql = 'SELECT * FROM productos WHERE 1=1';
    const params = [];
    
    if (categoria) { sql += ' AND categoria = ?'; params.push(categoria); }
    if (precioMin) { sql += ' AND precio >= ?'; params.push(parseFloat(precioMin)); }
    if (precioMax) { sql += ' AND precio <= ?'; params.push(parseFloat(precioMax)); }
    if (busqueda) { 
      sql += ' AND (nombre LIKE ? OR descripcion LIKE ?)'; 
      params.push(`%${busqueda}%`, `%${busqueda}%`); 
    }
    
    // Contar total
    const [totalRows] = await pool.execute(
      `SELECT COUNT(*) as total FROM (${sql}) as sub`, params
    );
    
    sql += ' LIMIT ? OFFSET ?';
    params.push(parseInt(limite), parseInt(offset));
    
    const [rows] = await pool.execute(sql, params);
    
    res.json({ 
      productos: rows, 
      pagina: parseInt(pagina), 
      limite: parseInt(limite),
      total: totalRows[0].total,
      totalPaginas: Math.ceil(totalRows[0].total / limite)
    });
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Error al obtener productos' });
  }
});

// ========== 3. OBTENER UN PRODUCTO (protegido) ==========
app.get('/api/productos/:id', autenticar, async (req, res) => {
  try {
    const [rows] = await pool.execute(
      'SELECT * FROM productos WHERE id = ?', [req.params.id]
    );
    
    if (rows.length === 0) {
      return res.status(404).json({ error: 'Producto no encontrado' });
    }
    
    res.json(rows[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al obtener producto' });
  }
});

// ========== 4. CREAR PRODUCTO (protegido) ==========
app.post('/api/productos', autenticar, async (req, res) => {
  try {
    const { nombre, descripcion, precio, categoria, stock } = req.body;
    
    if (!nombre || !precio) {
      return res.status(400).json({ error: 'Nombre y precio requeridos' });
    }
    
    const [result] = await pool.execute(
      'INSERT INTO productos (nombre, descripcion, precio, categoria, stock) VALUES (?, ?, ?, ?, ?)',
      [nombre, descripcion || '', precio, categoria || 'general', stock || 0]
    );
    
    const [newProduct] = await pool.execute(
      'SELECT * FROM productos WHERE id = ?', [result.insertId]
    );
    
    res.status(201).json(newProduct[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al crear producto' });
  }
});

// ========== 5. ACTUALIZAR PRODUCTO (PUT - completo) ==========
app.put('/api/productos/:id', autenticar, async (req, res) => {
  try {
    const { nombre, descripcion, precio, categoria, stock } = req.body;
    const { id } = req.params;
    
    await pool.execute(
      'UPDATE productos SET nombre = ?, descripcion = ?, precio = ?, categoria = ?, stock = ? WHERE id = ?',
      [nombre, descripcion, precio, categoria, stock, id]
    );
    
    const [updated] = await pool.execute(
      'SELECT * FROM productos WHERE id = ?', [id]
    );
    
    res.json(updated[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al actualizar producto' });
  }
});

// ========== 6. ACTUALIZAR PRODUCTO (PATCH - parcial) ==========
app.patch('/api/productos/:id', autenticar, async (req, res) => {
  try {
    const { id } = req.params;
    const updates = req.body;
    
    const campos = Object.keys(updates);
    if (campos.length === 0) {
      return res.status(400).json({ error: 'No se enviaron campos para actualizar' });
    }
    
    const valores = Object.values(updates);
    const setClause = campos.map(c => `${c} = ?`).join(', ');
    valores.push(id);
    
    await pool.execute(
      `UPDATE productos SET ${setClause} WHERE id = ?`, valores
    );
    
    const [updated] = await pool.execute(
      'SELECT * FROM productos WHERE id = ?', [id]
    );
    
    res.json(updated[0]);
  } catch (error) {
    res.status(500).json({ error: 'Error al actualizar producto' });
  }
});

// ========== 7. ELIMINAR PRODUCTO (protegido) ==========
app.delete('/api/productos/:id', autenticar, async (req, res) => {
  try {
    await pool.execute('DELETE FROM productos WHERE id = ?', [req.params.id]);
    res.json({ mensaje: 'Producto eliminado correctamente' });
  } catch (error) {
    res.status(500).json({ error: 'Error al eliminar producto' });
  }
});

// ========== 8. SUBIR ARCHIVOS (protegido) ==========
const storage = multer.diskStorage({
  destination: 'uploads/',
  filename: (req, file, cb) => {
    cb(null, `${Date.now()}-${file.originalname}`);
  }
});

const upload = multer({ 
  storage,
  limits: { fileSize: 5 * 1024 * 1024 }, // 5MB
  fileFilter: (req, file, cb) => {
    const allowed = ['image/jpeg', 'image/png', 'image/gif', 'application/pdf'];
    if (allowed.includes(file.mimetype)) {
      cb(null, true);
    } else {
      cb(new Error('Tipo de archivo no permitido'), false);
    }
  }
});

app.post('/api/upload', autenticar, upload.single('archivo'), (req, res) => {
  if (!req.file) {
    return res.status(400).json({ error: 'No se envió ningún archivo' });
  }
  res.json({ 
    mensaje: 'Archivo subido correctamente',
    archivo: req.file.originalname,
    tamaño: req.file.size,
    tipo: req.file.mimetype
  });
});

// ========== RUTA NO ENCONTRADA (404) ==========
app.use((req, res) => {
  res.status(404).json({ error: 'Ruta no encontrada' });
});

// ========== INICIAR SERVIDOR ==========
const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`🚀 Servidor en http://localhost:${PORT}`);
  console.log(`📋 CORS habilitado para todos los orígenes`);
});

8 Consumir desde el Frontend (Fetch)

🌐 Nota: Gracias a CORS, tu frontend puede hacer peticiones a la API sin problemas.

Login

const login = async () => {
  const res = await fetch('http://localhost:3000/api/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      email: 'profe@mail.com',
      password: '123456'
    })
  });
  const data = await res.json();
  if (data.token) {
    localStorage.setItem('token', data.token);
    console.log('✅ Login exitoso');
  }
  return data;
};

Obtener productos

const getProductos = async () => {
  const token = localStorage.getItem('token');
  
  if (!token) {

    return;

    localStorage.removeItem('token');
    // window.location.href = '/login'
  }
  
  const data = await res.json();
  return data;
};

Crear producto

const crearProducto = async (producto) => {

9 Flujo Completo de Autenticación

1️⃣ Cliente → POST /api/login (email + password)
2️⃣ Servidor → Verifica credenciales en MySQL
3️⃣ Servidor → Genera JWT y lo devuelve al cliente
4️⃣ Cliente → Guarda JWT en localStorage
5️⃣ Cliente → GET /api/productos (con token en header)
6️⃣ Servidor → Middleware verifica el token
7️⃣ Servidor → Si es válido, devuelve los datos
8️⃣ Cliente → Muestra los datos en la interfaz
🌐 Con CORS incluido:
1️⃣ Frontend (http://localhost:5500) → hace petición a la API
2️⃣ Navegador → pregunta al servidor si permite CORS (OPTIONS)
3️⃣ Servidor → responde con Access-Control-Allow-Origin: *
4️⃣ Navegador → permite la petición
5️⃣ Frontend → recibe la respuesta de la API
🎯 Resumen: El JWT es un pase temporal. El usuario se autentica una vez y recibe un token que usa en cada petición. El servidor no guarda sesiones, solo verifica el token. CORS permite que tu frontend y backend hablen aunque estén en diferentes puertos.

10 Consideraciones Finales

🔐 Seguridad

• Usa bcrypt para hashear contraseñas
• Usa consultas preparadas contra SQL injection
• El JWT no guarda información sensible
• Expira el token (ej: 1 hora)
• Configura CORS con orígenes específicos en producción

📦 Buenas prácticas

• Usa variables de entorno (.env)
• Separa el código en rutas y controladores
• Usa middlewares para autenticación
• Valida los datos de entrada
• CORS: en desarrollo usa cors(), en producción configura orígenes
