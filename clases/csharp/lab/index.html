GUÍA PRÁCTICA DE LABORATORIO

Construcción de un Sistema Modular con Contenedores en Windows Forms (C# 5)

Entorno de Trabajo: Visual Studio 2012 — .NET Framework 4.5
Objetivo: Diseñar interfaces responsivas usando contenedores (TableLayoutPanel, Panel, GroupBox), implementar inicio de sesión con enmascaramiento de clave y construir un panel principal (Dashboard) con navegación modular.

PARTE 1: Manejo de Contenedores y Diseño Adaptable

Paso 1: Crear el Proyecto

  1. Abre Visual Studio 2012.
  2. Ve a Archivo → Nuevo → Proyecto...
  3. Selecciona Visual C# → Aplicación de Windows Forms.
  4. Nombra el proyecto como SistemaModuloControl y haz clic en Aceptar.

Paso 2: Formulario de Login (FormLogin.cs)

  1. Cambia el nombre de Form1.cs a FormLogin.cs en el Explorador de Soluciones.
  2. En Propiedades configura: Text = Inicio de Sesión, StartPosition = CenterScreen.
  3. Arrastra los siguientes controles y cambia sus nombres (Name):

PARTE 2: Código del Módulo de Autenticación

Haz doble clic sobre el formulario o presiona F7 para abrir el código fuente e implementa la siguiente lógica en C# 5:

using System;
using System.Windows.Forms;

namespace SistemaModuloControl
{
    public partial class FormLogin : Form
    {
        public FormLogin()
        {
            InitializeComponent();
        }

        // 1. Mostrar u ocultar la clave al marcar el CheckBox
        private void chkMostrar_CheckedChanged(object sender, EventArgs e)
        {
            if (chkMostrar.Checked)
            {
                // '\0' es el carácter nulo: revela el texto original
                txtClave.PasswordChar = '\0';
            }
            else
            {
                txtClave.PasswordChar = '*';
            }
        }

        // 2. Validar credenciales
        private void btnIngresar_Click(object sender, EventArgs e)
        {
            string usuario = txtUsuario.Text.Trim();
            string clave = txtClave.Text.Trim();

            if (string.IsNullOrEmpty(usuario) || string.IsNullOrEmpty(clave))
            {
                MessageBox.Show("Por favor, llene todos los campos.", "Atención", 
                                MessageBoxButtons.OK, MessageBoxIcon.Warning);
                return;
            }

            // Credenciales de prueba
            if (usuario == "admin" && clave == "1234")
            {
                MessageBox.Show("¡Acceso concedido!", "Bienvenido", 
                                MessageBoxButtons.OK, MessageBoxIcon.Information);

                this.Hide(); // Oculta el Login

                // Instancia y abre el Dashboard
                FormDashboard dashboard = new FormDashboard(usuario);
                dashboard.ShowDialog(); 

                this.Close(); // Cierra la app al salir del Dashboard
            }
            else
            {
                MessageBox.Show("Usuario o clave incorrectos.", "Error", 
                                MessageBoxButtons.OK, MessageBoxIcon.Error);
                txtClave.Clear();
                txtClave.Focus();
            }
        }

        private void btnCancelar_Click(object sender, EventArgs e)
        {
            this.Close();
        }
    }
}

PARTE 3: Creación del Dashboard Modular

Paso 1: Agregar el Formulario Principal

  1. Haz clic derecho en el proyecto → Agregar → Windows Form... y nómbralo FormDashboard.cs.
  2. Ajusta su tamaño a 900 x 600 y StartPosition = CenterScreen.

Paso 2: Estructurar con Paneles

  • Panel izquierdo (Name: panelMenu, Dock: Left, Width: 200).
  • Panel central (Name: panelContenedor, Dock: Fill).
  • Dentro del menú coloca un Label (lblUsuarioActivo) y tres botones para los módulos y cerrar sesión.

PARTE 4: Código de Navegación Dinámica (FormDashboard.cs)

using System;
using System.Windows.Forms;

namespace SistemaModuloControl
{
    public partial class FormDashboard : Form
    {
        public FormDashboard()
        {
            InitializeComponent();
        }

        public FormDashboard(string nombreUsuario) : this()
        {
            lblUsuarioActivo.Text = "Usuario: " + nombreUsuario;
        }

        // Método genérico para cargar subformularios en el panel
        private void AbrirFormularioEnPanel(Form formularioHijo)
        {
            if (this.panelContenedor.Controls.Count > 0)
            {
                this.panelContenedor.Controls.RemoveAt(0);
            }

            formularioHijo.TopLevel = false;
            formularioHijo.FormBorderStyle = FormBorderStyle.None;
            formularioHijo.Dock = DockStyle.Fill;

            this.panelContenedor.Controls.Add(formularioHijo);
            this.panelContenedor.Tag = formularioHijo;
            formularioHijo.Show();
        }

        private void btnUsuarios_Click(object sender, EventArgs e)
        {
            AbrirFormularioEnPanel(new FormUsuarios());
        }

        private void btnVentas_Click(object sender, EventArgs e)
        {
            AbrirFormularioEnPanel(new FormVentas());
        }

        private void btnCerrarSesion_Click(object sender, EventArgs e)
        {
            if (MessageBox.Show("¿Desea cerrar la sesión?", "Confirmar", 
                MessageBoxButtons.YesNo, MessageBoxIcon.Question) == DialogResult.Yes)
            {
                this.Close();
            }
        }
    }
}

RETO EVALUADO EN CLASE

Realiza las siguientes modificaciones antes de finalizar la sesión:

  1. Agrupación Visual (GroupBox): En FormUsuarios.cs, organiza los campos de texto dentro de un GroupBox titulado "Información de Usuario".

  3. Nuevo Módulo: Agrega un formulario FormReportes.cs e intégralo en el menú lateral del Dashboard.
