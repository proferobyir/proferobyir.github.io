Guía Técnica: Dictionary y LINQ en C# 5.0

Estructuras de almacenamiento clave y consultas declarativas orientadas al .NET Framework 4.5 / C# 5

1. El Diccionario en C# (`Dictionary<TKey, TValue>`)

Un Dictionary almacena pares de Clave-Valor. En C# 5.0, la clave debe ser única y proporciona búsquedas altamente eficientes por índice de clave gracias a su tabla hash interna.

Declaración e Inicialización básica

// Declarar e instanciar un diccionario con Clave string y Valor int
Dictionary<string, int> edades = new Dictionary<string, int>();

// Agregar elementos
edades.Add("Carlos", 25);
edades["Ana"] = 30; // Forma directa de agregar o actualizar

// Verificar existencia antes de consultar para evitar excepciones
if (edades.ContainsKey("Carlos"))
{
    int edadCarlos = edades["Carlos"];
}

// Lectura segura con TryGetValue (Muy recomendado en C# 5)
int valorEdad;
if (edades.TryGetValue("Ana", out valorEdad))
{
    // valorEdad contiene 30
}

Explicación detallada de TryGetValue:

Si intentas acceder a una clave que no existe utilizando corchetes directos (ej: edades["Desconocido"]), C# lanzará una excepción del tipo KeyNotFoundException, lo cual puede interrumpir el flujo de tu aplicación si no se maneja adecuadamente.

El método TryGetValue resuelve este problema de forma óptima combinando dos acciones en una sola operación:

  • Búsqueda segura: Comprueba de manera interna y eficiente si la clave existe en el diccionario.
  • Retorno condicional: Devuelve un booleano (true si encontró la clave, false en caso contrario) y, mediante el modificador out, asigna de inmediato el valor asociado a la variable proporcionada (valorEdad) sin necesidad de realizar una segunda búsqueda.

2. Definición del Contexto

Para ilustrar el uso de LINQ en C# 5.0, utilizaremos clases con constructores explícitos y un método que alimenta la lista de forma interactiva mediante un bucle do-while:

public class Producto
{
    public int Id { get; set; }
    public string Nombre { get; set; }
    public decimal Precio { get; set; }
    public string Categoria { get; set; }

    // Constructor público para inicializar obligatoriamente las propiedades
    public Producto(int id, string nombre, decimal precio, string categoria)
    {
        Id = id;
        Nombre = nombre;
        Precio = precio;
        Categoria = categoria;
    }
}

public class InventarioServicio
{
    public List<Producto> ObtenerProductos()
    {
        // Lista dinámica inicializada vacía
        List<Producto> listaProductos = new List<Producto>();
        string respuesta;

        Console.WriteLine("=== MÓDULO DE INVENTARIO ===");

        do
        {
            Console.Write("\nIngrese el ID del producto: ");
            int id = int.Parse(Console.ReadLine());

            Console.Write("Ingrese el Nombre del producto: ");
            string nombre = Console.ReadLine();

            Console.Write("Ingrese el Precio del producto: ");
            decimal precio = decimal.Parse(Console.ReadLine());

            Console.Write("Ingrese la Categoría: ");
            string categoria = Console.ReadLine();

            // Instanciación dinámica con constructor y adición a la lista
            Producto nuevoProducto = new Producto(id, nombre, precio, categoria);
            listaProductos.Add(nuevoProducto);

            Console.Write("¿Desea registrar otro producto? (s/n): ");
            respuesta = Console.ReadLine();

        } while (respuesta != null && respuesta.Trim().ToLower() == "s");

        /* --- EJEMPLO DE VALORES HARDCODEADOS ANTERIORES (Referencia) ---
        // Producto p1 = new Producto(1, "Laptop", 850m, "Tecnología");
        // listaProductos.Add(p1);
        ------------------------------------------------------------- */

        return listaProductos;
    }
}

3. Operadores Principales de LINQ en C# 5.0

LINQ (Language Integrated Query) permite consultar colecciones de forma declarativa usando tanto sintaxis de consultas (tipo SQL) como sintaxis de métodos (expresiones lambda).

Where (Filtrado)

Filtra una secuencia basada en una condición lógica.

// Sintaxis de Métodos
var techProducts = productos
    .Where(p => p.Categoria == "Tecnología")
    .ToList();

Select (Proyección)

Transforma los elementos de una colección en una nueva forma o estructura.

// Proyectar solo los nombres
var nombres = productos
    .Select(p => p.Nombre)
    .ToList();

OrderBy / OrderByDescending

Ordena los elementos de menor a mayor o viceversa.

// Ordenar por precio ascendente
var ordenados = productos
    .OrderBy(p => p.Precio)
    .ToList();

GroupBy (Agrupación)

Agrupa elementos compartiendo una clave común.

// Agrupar por categoría
var grupos = productos
    .GroupBy(p => p.Categoria);

foreach (var grupo in grupos)
{
    // grupo.Key = "Tecnología", etc.
}

4. Combinación Avanzada: LINQ sobre un Dictionary

En C# 5.0, un Dictionary<TKey, TValue> implementa IEnumerable<KeyValuePair<TKey, TValue>>, lo que permite aplicarle operadores LINQ directamente. 

public class ReporteInventario
{
    public void ProcesarDiccionarioConLinq()
    {
        // Inicializar Diccionario con ID de producto y su Stock
        Dictionary<int, int> stockProductos = new Dictionary<int, int>()
        {
            { 1, 12 },
            { 2, 5 },
            { 3, 0 },
            { 4, 20 }
        };

        // Usar LINQ para filtrar productos con stock menor a 10 unidades
        var stockCritico = stockProductos
            .Where(kvp => kvp.Value < 10)
            .ToDictionary(kvp => kvp.Key, kvp => kvp.Value);

        // Consultar el elemento máximo usando LINQ
        var mayorStock = stockProductos
            .OrderByDescending(kvp => kvp.Value)
            .FirstOrDefault();
            
        // mayorStock.Key contiene el ID y mayorStock.Value el stock máximo
    }
}
