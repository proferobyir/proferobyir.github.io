Evolucionando de Clases con Datos a Clases con Métodos

Guía paso a paso para repasar la tarea de notas de estudiantes y dar el salto fundamental hacia la encapsulación de comportamiento en C# 5.

1
Repaso: Resolución de la Tarea Anterior
Propiedades Públicas

En la sesión anterior construimos clases formadas únicamente por propiedades públicas (nombre, arreglo de notas y promedio). Toda la lógica matemática y los cálculos se realizaban directamente dentro del ciclo en el método Main.

Program.cs (Versión Base) 
using System;
using System.Collections.Generic;

namespace TareaEstudiantes
{
    public class Estudiante
    {
        public string Nombre;
        public double[] Notas = new double[3];
        public double Promedio;
    }

    class Program
    {
        static void Main(string[] args)
        {
            List<Estudiante> listaEstudiantes = new List<Estudiante>();
            string opcion = "s";

            while (opcion.ToLower() == "s")
            {
                Estudiante est = new Estudiante();

                Console.Write("\nIngrese el nombre del estudiante: ");
                est.Nombre = Console.ReadLine();

                double suma = 0;
                for (int i = 0; i < 3; i++)
                {
                    Console.Write("Ingrese la nota {0}: ", (i + 1));
                    est.Notas[i] = Convert.ToDouble(Console.ReadLine());
                    suma += est.Notas[i];
                }

                est.Promedio = suma / 3;
                listaEstudiantes.Add(est);

                Console.Write("\n¿Desea registrar otro estudiante? ('s' para seguir): ");
                opcion = Console.ReadLine();
            }

            Console.WriteLine("\n--- LISTADO DE ESTUDIANTES ---");
            foreach (var e in listaEstudiantes)
            {
                Console.WriteLine("Estudiante: {0} | Promedio: {1:F2}", e.Nombre, e.Promedio);
            }

            Console.WriteLine("\nPresione cualquier tecla para salir...");
            Console.ReadKey();
        }
    }
}
2
Avanzando: Añadiendo Métodos a la Clase
Comportamiento POO

Para evolucionar en nuestra clase de hoy, daremos el paso clave de la Programación Orientada a Objetos: agregar métodos dentro de la clase Estudiante para que ella misma calcule su promedio e imprima sus datos.

Incorporamos dos subrutinas o métodos públicos:

  • CalcularPromedio(): Recorre el arreglo interno y calcula la nota final.
  • MostrarDatos(): Imprime la información formateada limpiamente.
EstudianteConMetodos.cs (Versión Avanzada) 
using System;
using System.Collections.Generic;

namespace ClasesConMetodos
{
    public class Estudiante
    {
        public string Nombre;
        public double[] Notas = new double[3];
        public double Promedio;

        public void CalcularPromedio()
        {
            double suma = 0;
            for (int i = 0; i < Notas.Length; i++)
            {
                suma += Notas[i];
            }
            Promedio = suma / Notas.Length;
        }

        public void MostrarDatos()
        {
            Console.WriteLine("Estudiante: {0} - Promedio Final: {1:F2}", Nombre, Promedio);
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            List<Estudiante> listaEstudiantes = new List<Estudiante>();
            string opcion = "s";

            while (opcion.ToLower() == "s")
            {
                Estudiante est = new Estudiante();

                Console.Write("\nIngrese el nombre del estudiante: ");
                est.Nombre = Console.ReadLine();

                for (int i = 0; i < 3; i++)
                {
                    Console.Write("Ingrese la nota {0}: ", (i + 1));
                    est.Notas[i] = Convert.ToDouble(Console.ReadLine());
                }

                est.CalcularPromedio();
                listaEstudiantes.Add(est);

                Console.Write("\n¿Desea registrar otro estudiante? ('s' para seguir): ");
                opcion = Console.ReadLine();
            }

            Console.WriteLine("\n--- LISTADO OFICIAL DE ESTUDIANTES ---");
            foreach (var e in listaEstudiantes)
            {
                e.MostrarDatos();
            }

            Console.WriteLine("\nPresione cualquier tecla para salir...");
            Console.ReadKey();
        }
    }
}

Guía Paso a Paso para Publicar en GitHub Pages
Despliegue Web

Sigue estos sencillos pasos para almacenar esta guía en tu repositorio y compartirla con tus estudiantes en línea:

1. Crear Repositorio

Entra a GitHub, crea un repositorio público nuevo con el nombre clase-csharp-metodos.

2. Subir Archivo HTML

Haz clic en Add file > Upload files, arrastra este archivo guardado estrictamente como index.html y pulsa Commit changes.

3. Activar Pages

Ve a Settings > Pages, en Branch selecciona la rama main / /(root) y guarda los cambios.
