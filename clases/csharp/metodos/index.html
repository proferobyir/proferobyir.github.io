Programación Orientada a Objetos (C# 5.0)

Conceptos Básicos: Namespaces, Propiedades, Métodos y Listas

1. Conceptos Fundamentales en C#

Antes de crear clases u objetos, debemos entender cómo se organizan y estructuran en C#:

📁 Espacio de Nombres (Namespace)

¿Qué es? Es un contenedor lógico utilizado para organizar y agrupar clases relacionadas dentro de un proyecto.

¿Para qué sirve? Evita colisiones de nombres (conflictos cuando dos clases se llaman igual en distintos módulos) y permite organizar el código de manera modular e higiénica.

Analogía: Funciona exactamente igual que las carpetas de tu computadora. Puedes tener dos archivos con el mismo nombre siempre y cuando estén en distintas carpetas (namespaces).

📦 Propiedades (Atributos)

¿Qué son? Variables o miembros que almacenan la información y el estado de un objeto.

¿Para qué sirven? Para definir las características del objeto (ej. Nombre, Notas, Promedio).

⚙️ Métodos (Comportamientos)

¿Qué son? Funciones o acciones encapsuladas dentro de la clase.

¿Para qué sirven? Para procesar o manipular las propiedades (ej. CalcularPromedio(), MostrarInformacion()).

💡 Ejemplo Integrador: En SistemaEducativo.Modelos (Namespace), la clase Estudiante tiene el atributo Nombre (Propiedad) y la acción CalcularPromedio() (Método).

2. Planteamiento del Ejercicio

Requerimiento: Crear un programa que solicite la nota de n cantidad de estudiantes.

  • Usar un namespace apropiado para el proyecto.
  • Utilizar una List<Estudiante> para almacenar los registros.
  • Cada estudiante debe incluir: Nombre, Notas (arreglo de 3 notas) y Promedio.
  • Controlar el bucle solicitando al usuario si desea continuar (pulsando 's' para continuar u otra tecla para salir).

3. Definición de la Clase en C# 5.0

Estructura utilizando sintaxis compatible con C# 5.0 (.NET Framework 4.5):

using System;

namespace SistemaEducativo.Modelos
{
    public class Estudiante
    {
        // 1. PROPIEDADES (Sintaxis C# 5)
        public string Nombre { get; set; }
        public double[] Notas { get; set; }
        public double Promedio { get; private set; }

        // CONSTRUCTOR (Inicialización de arreglos en C# 5)
        public Estudiante()
        {
            Notas = new double[3];
        }

        // 2. MÉTODOS

        // Método para calcular el promedio de las 3 notas
        public void CalcularPromedio()
        {
            double suma = 0;
            for (int i = 0; i < Notas.Length; i++)
            {
                suma += Notas[i];
            }
            this.Promedio = suma / Notas.Length;
        }

        // Método para mostrar los datos en pantalla (Formateo C# 5)
        public void MostrarInformacion()
        {
            Console.WriteLine("Nombre: {0}", this.Nombre);
            Console.WriteLine("Notas: [{0}, {1}, {2}]", this.Notas[0], this.Notas[1], this.Notas[2]);
            Console.WriteLine("Promedio: {0:F2}", this.Promedio);
            Console.WriteLine("-----------------------------------");
        }
    }
}

4. Programa Principal (Program.cs)

Uso de List<Estudiante> e invocación de métodos:

using System;
using System.Collections.Generic;
using SistemaEducativo.Modelos; // Importación del Namespace

namespace SistemaEducativo
{
    class Program
    {
        static void Main(string[] args)
        {
            List<Estudiante> listaEstudiantes = new List<Estudiante>();
            string opcion;

            do
            {
                Estudiante est = new Estudiante();

                Console.Write("Ingrese el nombre del estudiante: ");
                est.Nombre = Console.ReadLine();

                // Lectura de las 3 notas
                for (int i = 0; i < 3; i++)
                {
                    Console.Write("Ingrese la nota {0}: ", i + 1);
                    est.Notas[i] = Convert.ToDouble(Console.ReadLine());
                }

                // Invocación del método encapsulado
                est.CalcularPromedio();

                // Guardar objeto en la lista
                listaEstudiantes.Add(est);

                Console.Write("¿Desea ingresar otro estudiante? (s = sí / otra tecla = salir): ");
                opcion = Console.ReadLine().ToLower();

            } while (opcion == "s");

            // RECORRIDO Y MOSTRADO DE RESULTADOS
            Console.WriteLine("\n=== LISTA DE ESTUDIANTES REGISTRADOS ===");
            foreach (Estudiante e in listaEstudiantes)
            {
                e.MostrarInformacion();
            }

            Console.ReadKey();
        }
    }
}
Nota pedagógica para C# 5: Recordar a los estudiantes que en C# 5 las propiedades auto-implementadas no admiten inicialización directa en línea (como = new double[3];) ni interpolación de cadenas con $. Por ello se utiliza el constructor para instanciar el arreglo y Console.WriteLine("{0}", val) para las salidas.
