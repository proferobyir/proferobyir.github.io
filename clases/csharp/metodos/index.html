Programación Orientada a Objetos

Estructura de una Clase: Propiedades, Métodos y Listas de Objetos

1. ¿Cuáles son las partes de una Clase?

Una clase es una plantilla o molde para crear objetos. Se compone principalmente de dos partes fundamentales:

📦 Propiedades (o Atributos)

¿Qué son? Son las características, variables o datos que definen el estado de un objeto.

¿Para qué funcionan? Sirven para almacenar la información de cada objeto generado por la clase.

Ejemplo en Estudiante: Nombre, Notas, Promedio.

⚙️ Métodos (o Funciones)

¿Qué son? Son bloques de código o funciones declaradas dentro de la clase que definen su comportamiento.

¿Para qué funcionan? Sirven para procesar, manipular o realizar cálculos sobre los datos guardados en las propiedades.

Ejemplo en Estudiante: CalcularPromedio(), MostrarInformacion().

💡 Analogía: Piensa en un teléfono celular. Sus propiedades son su marca, modelo, color y porcentaje de batería. Sus métodos son las acciones que realiza: Llamar(), TomarFoto() o CargarBateria().

2. Planteamiento del Ejercicio

Requerimiento: Crear un programa que solicite la nota de n cantidad de estudiantes.

  • Usar una Lista del tipo Estudiante.
  • Propiedades: Nombre, Notas (arreglo de 3 notas) y Promedio.
  • El programa usará un bucle donde el usuario decidirá cuándo salir (pulsando 's' para continuar u otra tecla para salir).

A diferencia de la clase anterior donde solo declaramos propiedades, hoy encapsularemos la lógica agregando los métodos necesarios.

3. Código de la Clase Estudiante

Implementación de propiedades y métodos en C#:

public class Estudiante
{
    // 1. PROPIEDADES (Datos)
    public string Nombre { get; set; }
    public double[] Notas { get; set; } = new double[3];
    public double Promedio { private set; }

    // 2. MÉTODOS (Comportamiento)

    // Método para calcular el promedio de las 3 notas
    public void CalcularPromedio()
    {
        double suma = 0;
        for (int i = 0; i < Notas.Length; i++)
        {
            suma += Notas[i];
        }
        this.Promedio = suma / Notas.Length;
    }

    // Método para mostrar los resultados en pantalla
    public void MostrarInformacion()
    {
        Console.WriteLine($"Nombre: {Nombre}");
        Console.WriteLine($"Notas: [{Notas[0]}, {Notas[1]}, {Notas[2]}]");
        Console.WriteLine($"Promedio: {Promedio:F2}");
        Console.WriteLine("-----------------------------------");
    }
}

4. Programa Principal (Manejo de la Lista)

Creación de la lista dinámica para registrar n estudiantes:

List<Estudiante> listaEstudiantes = new List<Estudiante>();
string opcion;

do
{
    Estudiante est = new Estudiante();

    Console.Write("Ingrese el nombre del estudiante: ");
    est.Nombre = Console.ReadLine();

    // Lectura de las 3 notas
    for (int i = 0; i < 3; i++)
    {
        Console.Write($"Ingrese la nota {i + 1}: ");
        est.Notas[i] = Convert.ToDouble(Console.ReadLine());
    }

    // Invocación del método para calcular el promedio
    est.CalcularPromedio();

    // Se guarda el objeto completo en la lista
    listaEstudiantes.Add(est);

    Console.Write("¿Desea ingresar otro estudiante? (s = sí / otra tecla = salir): ");
    opcion = Console.ReadLine().ToLower();

} while (opcion == "s");

// RECORRIDO Y MOSTRADO DE RESULTADOS
Console.WriteLine("\n=== LISTA DE ESTUDIANTES REGISTRADOS ===");
foreach (Estudiante e in listaEstudiantes)
{
    // Invocación del método para mostrar la información
    e.MostrarInformacion();
}
Punto clave a resaltar en clase: Observen cómo el bucle principal no realiza operaciones matemáticas directas ni múltiples concatenaciones; simplemente llama a est.CalcularPromedio() y a e.MostrarInformacion(). Esto es el principio de **encapsulamiento**.
