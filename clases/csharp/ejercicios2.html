Bloque 1: Cadenas (String) y ciclos básicos

1. Invertir una cadena

for decremental

Construye una cadena invertida usando un ciclo for decremental a partir de una variable inicial.

  • Usar bucle for con índice inicial Length - 1 hasta 0.
string original = "C# 5.0"; string invertida = ""; for (int i = original.Length - 1; i >= 0; i--) { invertida += original[i]; } Console.WriteLine(invertida); // ".5 #C"

2. Contador de vocales

foreach + switch/if

Recorre una cadena de texto para contar cuántas vocales (mayúsculas o minúsculas) contiene.

  • Usar foreach sobre string.
  • Evaluar caracteres con char.ToLower() o estructura condicional.
string texto = "Desarrollo de software"; int contadorVocales = 0; foreach (char c in texto) { char lower = char.ToLower(c); if (lower == 'a' || lower == 'e' || lower == 'i' || lower == 'o' || lower == 'u') { contadorVocales++; } } Console.WriteLine("Vocales: " + contadorVocales);

3. Validar palíndromo

while con dos índices

Determina si una palabra o frase normalizada es un palíndromo comparando extremos al centro.

  • Usar while (inicio < fin) con índices convergentes.
string s = "radar"; int inicio = 0, fin = s.Length - 1; bool esPalindromo = true; while (inicio < fin) { if (s[inicio] != s[fin]) { esPalindromo = false; break; } inicio++; fin--; } Console.WriteLine("¿Es palíndromo? " + esPalindromo);
Bloque 2: Arrays unidimensionales y bucles

4. Búsqueda de el mayor y menor

for en int[]

Dado un array de 10 enteros desordenados, recorre el arreglo para hallar máximo y mínimo.

  • Usar ciclo for estándar.
int[] numeros = { 14, 2, 89, 45, 12, 7, 63, 21, 9, 30 }; int max = numeros[0], min = numeros[0]; for (int i = 1; i < numeros.Length; i++) { if (numeros[i] > max) max = numeros[i]; if (numeros[i] < min) min = numeros[i]; } Console.WriteLine("Máx: " + max + ", Mín: " + min);

5. Promedio de elementos mayores a X

foreach double[]

Suma elementos de un array double[] mayores a 5.0 y calcula su promedio aritmético.

  • Usar foreach y contador auxiliar de elementos filtrados.
double[] valores = { 3.5, 6.0, 8.2, 4.1, 7.5, 5.0, 9.0, 2.0 }; double suma = 0; int count = 0; foreach (double val in valores) { if (val > 5.0) { suma += val; count++; } } double promedio = (count > 0) ? (suma / count) : 0; Console.WriteLine("Promedio filtrado: " + promedio);

Bloque 3: Combinación avanzada

7. Conversión a mayúsculas manual

for + char[] ASCII

Convierte texto a minúsculas en mayúsculas restando 32 a códigos ASCII entre 'a' y 'z'.

  • Usar .ToCharArray() y ciclo for.
char[] chars = "hola csharp".ToCharArray(); for (int i = 0; i < chars.Length; i++) { if (chars[i] >= 'a' && chars[i] <= 'z') { chars[i] = (char)(chars[i] - 32); } } string resultado = new string(chars); Console.WriteLine(resultado);

8. Contar repeticiones de carácter

while + Index/Length

Busca cuántas veces aparece un carácter específico usando índice numérico y while.

  • Control explícito de índice con while (i < s.Length).
string frase = "programacion en c# es excelente"; char objetivo = 'e'; int idx = 0, repetido = 0; while (idx < frase.Length) { if (frase[idx] == objetivo) repetido++; idx++; } Console.WriteLine("Apariciones de '" + objetivo + "': " + repetido);

9. Invertir palabras de una frase

Split + for inverso

Divide una frase con string.Split(' ') y reconstruye el string en orden inverso de palabras.

  • Usar array de strings resultante de Split y bucle decremental.
string[] palabras = "Hola mundo en C#".Split(' '); string invFrase = ""; for (int i = palabras.Length - 1; i >= 0; i--) { invFrase += palabras[i] + (i > 0 ? " " : ""); } Console.WriteLine(invFrase);

10. Búsqueda lineal con bandera

while + bool flag

Busca nombre en array de 10 elementos usando while y variable booleana de control de salida.

  • Usar bandera bool encontrado y control de límites del array.
string[] nombres = { "Ana", "Luis", "Carlos", "Diana", "Elena", "Fernando", "Gabriel", "Hugo", "Iris", "Jorge" }; string buscar = "Carlos"; bool encontrado = false; int i = 0; while (i < nombres.Length && !encontrado) { if (nombres[i] == buscar) { encontrado = true; Console.WriteLine("Encontrado en índice: " + i); } i++; } if (!encontrado) Console.WriteLine("No hallado.");

Nota pedagógica (C# 5.0)

No se emplean expresiones de rango moderno (^1) ni interpolación avanzada de cadenas (disponible desde C# 6.0), priorizando concatenación tradicional con + y recuento clásico por índices.
