1. Arquitectura Dashboard: Window vs. UserControl

Para construir una aplicación moderna con menú lateral izquierdo y contenido dinámico en el centro/derecha, no se abren múltiples ventanas flotantes. En su lugar se usa una única ventana base y vistas intercambiables:

  • Window (Ventana Principal): Es el contenedor maestro. Tiene el menú lateral izquierdo fijo y un contenedor central llamado ContentControl.
  • UserControl (Control de Usuario): Es una pantalla parcial (el "relleno" o módulo). Cada opción del menú (Inicio, Clientes, Productos, Reportes) es un UserControl independiente que se carga dentro del ContentControl.
  • DataGrid (La tabla de datos): El control estándar de WPF para mostrar tablas provenientes de listas o bases de datos (equivalente moderno al DataGridView de Windows Forms) se llama exactamente DataGrid.

2. ¿Qué es un ResourceDictionary (Diccionario de Recursos)?

Efectivamente, existe un archivo especial en WPF llamado Diccionario de Recursos (ResourceDictionary) con extensión .xaml. Funciona exactamente como una hoja de estilos CSS en desarrollo web: te permite definir colores, degradados y plantillas de controles en un archivo separado para reutilizarlos en toda la aplicación sin ensuciar el código de tus ventanas.

¿Cómo crearlo en Visual Studio?

  • Haz clic derecho sobre tu proyecto (o crea una carpeta llamada Styles).
  • Selecciona Agregar → Nuevo elemento...
  • Busca y elige Diccionario de recursos (WPF) y nómbralo ModernStyles.xaml.
MiProyectoWPF/
├── App.xaml                   <-- Aquí se enlaza el diccionario globalmente
├── MainWindow.xaml            <-- Ventana base con menú lateral
├── Styles/
│   └── ModernStyles.xaml    <-- Todos los estilos (Botones, TextBox, ComboBox, DataGrid)
└── Views/
    └── ProductosView.xaml   <-- UserControl que carga en el centro

Enlazar el Diccionario en App.xaml

Para que todas las ventanas y UserControl reconozcan automáticamente tus estilos modernos, registra el archivo en App.xaml:

App.xaml 
<Application x:Class="MiProyectoWPF.App"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             StartupUri="MainWindow.xaml">
    <Application.Resources>
        <ResourceDictionary>
            <ResourceDictionary.MergedDictionaries>
                <!-- Enlace a nuestro archivo externo de estilos -->
                <ResourceDictionary Source="Styles/ModernStyles.xaml"/>
            </ResourceDictionary.MergedDictionaries>
        </ResourceDictionary>
    </Application.Resources>
</Application>

3. Estilos Modernos (Glass / Degradado Corporativo)

En WPF el efecto tipo "vidrio" corporativo (glassmorphism ligero) se logra combinando degradados lineales (LinearGradientBrush), un borde fino semitransparente en la parte superior e inferior, y esquinas redondeadas (CornerRadius="8"), evitando filtros pesados que consuman demasiada memoria o tarjeta gráfica.

Truco clave: Si un Style tiene TargetType="TextBox" y NO tiene x:Key, WPF lo aplicará automáticamente a todos los TextBox del proyecto sin tener que escribir Style="..." en cada uno.

Views/ProductosView.xaml.cs 
using System.Collections.ObjectModel;
using System.Windows;
using System.Windows.Controls;

namespace MiProyectoWPF.Views
{
    public partial class ProductosView : UserControl
    {
        // ObservableCollection actualiza el DataGrid automáticamente al agregar elementos
        private ObservableCollection<Producto> listaProductos = new ObservableCollection<Producto>();

        public ProductosView()
        {
            InitializeComponent();
            dgProductos.ItemsSource = listaProductos;

            // Datos de prueba iniciales
            listaProductos.Add(new Producto { Nombre = "Monitor LED 24"", Categoria = "Hardware", Precio = "145.00" });
            listaProductos.Add(new Producto { Nombre = "Licencia Antivirus", Categoria = "Software", Precio = "35.00" });
        }

        private void BtnAgregar_Click(object sender, RoutedEventArgs e)
        {
            if (string.IsNullOrWhiteSpace(txtNombre.Text) || string.IsNullOrWhiteSpace(txtPrecio.Text))
            {
                MessageBox.Show("Complete el nombre y el precio.", "Validación", MessageBoxButton.OK, MessageBoxImage.Warning);
                return;
            }

            string cat = (cmbCategoria.SelectedItem as ComboBoxItem)?.Content.ToString();

            listaProductos.Add(new Producto
            {
                Nombre = txtNombre.Text.Trim(),
                Categoria = cat,
                Precio = txtPrecio.Text.Trim()
            });

            txtNombre.Clear();
            txtPrecio.Clear();
            txtNombre.Focus();
        }
    }

    public class Producto
    {
        public string Nombre { get; set; }
        public string Categoria { get; set; }
        public string Precio { get; set; }
    }
}

6. Consejos de Rendimiento en Equipos con Recursos Limitados

Importante para laboratorios con .NET Framework 4.5:
  • Evita DropShadowEffect y BlurEffect: Esos efectos obligan a WPF a renderizar por software si la GPU es básica, haciendo lenta la ventana. Los bordes finos (BorderThickness="1") y degradados lineales son acelerados y muy livianos.
  • Mantén los estilos en el ResourceDictionary: Evita definir ControlTemplate repetidos dentro de cada ventana; centralizarlos reduce consumo de memoria y facilita el mantenimiento.
  • Usa ObservableCollection<T> para el DataGrid: Así evitas recargar toda la tabla cada vez que insertas o eliminas un registro.
