Taller Práctico: Fundamentos de Aplicaciones de Consola

Entorno: Visual Studio 2012 | Lenguaje: C# 5.0 (.NET Framework 4.5)

1. Creación de un Proyecto de Consola en VS 2012

Pasos fundamentales para inicializar la estructura básica de la solución:

Estructura inicial generada por el IDE:

  • using System; Importa las funciones esenciales de entrada y salida de la consola.
  • namespace Agrupa las clases del proyecto para evitar conflictos de nombres.
  • class Program Clase principal que encapsula el código.
  • static void Main(string[] args) Punto de inicio donde se ejecuta la aplicación.

2. Operaciones Fundamentales en C# 5.0

  • Salida de Datos: Console.WriteLine() muestra texto con salto de línea y Console.Write() sin salto.
  • Entrada de Datos: Console.ReadLine() lee una cadena ingresada por el usuario.
  • Conversión de Tipos: Uso explícito de Convert.ToInt32(), Convert.ToDouble() o double.Parse() para operar valores numéricos.
  • Pausa de Control: Console.ReadKey() detiene la ejecución hasta presionar una tecla.

3. Ejercicios Prácticos (Para desarrollar en el laboratorio)

Resolver en pantalla utilizando únicamente sintaxis de C# 5.0 y salida por consola:

Ejercicio 1: Conversión de Temperatura y Validación

Requerimiento: Solicitar al usuario una temperatura en grados Celsius por consola.

  • Convertir el valor a Fahrenheit usando la fórmula: F = (C * 9/5) + 32.
  • Evaluar con una estructura condicional (if / else) e informar si el clima está "Caluroso" (mayor o igual a 30 °C) o "Fresco/Frío".
  • Mostrar el resultado formateado en consola.
Ejercicio 2: Calculadora de Calificaciones con Bucle

Requerimiento: Crear una aplicación que capture las notas de N estudiantes.

  • Pedir al usuario cuántos estudiantes procesará.
  • Utilizar un bucle for para solicitar la nota de cada estudiante por teclado.
  • Calcular e imprimir el promedio general del grupo.
  • Indicar la nota más alta registrada en la corrida.
Ejercicio 3: Menú Interactivo de Operaciones

Requerimiento: Construir un menú de opciones dinámico en consola utilizando la estructura switch y un bucle do-while.

  • Opción 1: Validar si un número ingresado es par o impar.
  • Opción 2: Generar la tabla de multiplicar de un número.
  • Opción 3: Salir del programa.
Ejercicio 4: Registro y Recorrido de Inventario de Productos

Requerimiento: Gestionar una lista dinámica de productos utilizando la librería System.Collections.Generic.

  • Importar el espacio de nombres using System.Collections.Generic; para utilizar List<string>.
  • Permitir al usuario ingresar nombres de productos a una lista mediante un bucle while hasta que escriba "fin".
  • Recorrer y mostrar todos los productos registrados utilizando la estructura foreach.
  • Imprimir en consola el total de productos almacenados con la propiedad .Count.
Ejercicio 5: Control de Ventas y Filtro Dinámico

Requerimiento: Procesar una lista dinámica de montos de ventas y filtrar resultados de negocio.

  • Declarar una lista de números decimales (List<double>) e ir agregando valores ingresados por el usuario mediante .Add().
  • Recorrer la lista con un bucle foreach para calcular la sumatoria total de las ventas.
  • Mostrar únicamente los montos que superen los $100 aplicando una condición interna durante la iteración.
