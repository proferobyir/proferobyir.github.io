Taller Práctico de Programación en C#

Entorno: Visual Studio 2012 | Versión de Lenguaje: C# 5.0 (.NET Framework 4.5)

1. Estructura Básica de un Proyecto en C# 5.0

Proceso de creación de una aplicación de consola estándar en Visual Studio 2012:

Elementos esenciales de la plantilla inicial de C# 5.0:

  • using System; Importación del espacio de nombres base.
  • namespace Organización lógica de las clases del proyecto.
  • class Program Clase principal contenedora.
  • static void Main(string[] args) Punto de entrada ejecutable de la aplicación.

2. Características Clave de C# 5.0

Repaso sintáctico compatible con .NET 4.5:

  • Propiedades Auto-implementadas: Requieren get; set; explícitos para lectura y escritura.
  • Inicialización de Objetos: Sintaxis limpia mediante bloques de inicialización new Persona { Nombre = "Juan" }.
  • Programación Asíncrona: Uso de las palabras clave async y await introducidas en esta versión junto con Task.

3. Ejercicios Prácticos para Resolver en Clase

Desarrollar los siguientes programas utilizando únicamente la sintaxis de C# 5.0:

Ejercicio 1: Calculadora de Promedio y Estado Académico

Requerimiento: Crear una aplicación de consola que solicite al usuario 3 notas de un estudiante (valores flotantes o decimales).

  • Calcular el promedio de las notas.
  • Determinar si el estudiante está Aprobado (promedio >= 9.5) o Reprobado.
  • Mostrar los resultados en pantalla formateados con dos decimales.
  • Pausar la consola usando Console.ReadKey() al finalizar.
Ejercicio 2: Gestión de Empleados con POO

Requerimiento: Diseñar una clase Empleado e instanciarla en el método Main.

  • La clase debe contener las propiedades auto-implementadas: Id (int), Nombre (string) y SalarioBase (double).
  • Incluir un método CalcularSalarioNeto() que descuente un 4% de seguro social y retorne el total.
  • En el Main, instanciar al menos dos objetos usando sintaxis de inicializador de objetos, calcular su salario neto y mostrar sus datos tabulados en la consola.
Ejercicio 3: Simulación de Operación Asíncrona (async/await)

Requerimiento: Implementar una simulación de descarga de datos usando la sintaxis async y await de C# 5.0.

  • Crear un método asíncrono static async Task DescargarArchivoAsync().
  • Usar await Task.Delay(3000) para simular una espera de 3 segundos sin bloquear el hilo principal.
  • Mostrar mensajes informativos en la consola antes y después de la simulación.
