Registro de Usuarios en WPF y MySQL con Arquitectura de Servicios

Organización del código en servicios especializados utilizando clases públicas, List<T> y Dictionary<TKey, TValue> sobre la base de datos EjercicioWPFDb.

En lugar de colocar toda la lógica de acceso a datos y validaciones dentro del código detrás de la ventana WPF (MainWindow.xaml.cs), el proyecto se divide en dos servicios alineados con las tablas departamento, cargo y usuarios:

  1. Servicio de Cargos (CargosService): consulta los registros de cargo relacionados con departamento, construye una List<CargoItem> para alimentar el ItemsSource del ComboBox y mantiene un Dictionary<int, CargoItem> indexado por Id para consultar o validar cargos por clave.
  2. Servicio de Usuarios (UsuariosService): valida los campos del formulario (Nickname, Password, Email y Role), verifica que el cargo exista en el catálogo de cargos, utiliza un Dictionary<string, string> para identificar campos duplicados (nickname o correo) y ejecuta el INSERT empleando SHA2(@password, 256) en MySQL.
Consideraciones de entorno (.NET Framework 4.5 / Visual Studio 2012)
  • Referencia a MySQL: el proyecto debe apuntar a .NET Framework 4.5, tener referenciada una versión compatible de MySql.Data.dll y mantener alineada la plataforma de compilación (por ejemplo, x86 o AnyCPU) con el conector instalado.
  • Control de contraseña en WPF: si el formulario utiliza un control PasswordBox (por ejemplo, pwdPassword), la contraseña se obtiene mediante pwdPassword.Password y se limpia con pwdPassword.Clear().
  • Requisitos cubiertos: se conserva el uso de MySql.Data.MySqlClient, hashing con SHA2(?, 256) en el INSERT, población dinámica del ComboBox mediante List<T>, DisplayMemberPath y SelectedValuePath, y manejo de excepciones con MessageBox.

1. Clases públicas de modelo y respuesta

Estructuras públicas utilizadas para transportar datos del catálogo de cargos, la solicitud de registro y el resultado de cada operación.

Modelos.cs 
using System;

namespace SistemaUsuarios.Modelos
{
    public class CargoItem
    {
        public int Id { get; set; }
        public string Nombre { get; set; }

        public string Nickname { get; set; }

    public class RespuestaServicio

    }

2. Servicio de Cargos (List<CargoItem> y Dictionary<int, CargoItem>)

Recupera los cargos desde MySQL junto con el nombre del departamento, devuelve una lista para el ComboBox y almacena un diccionario por Id.

CargosService.cs 
using System;
using System.Collections.Generic;
using MySql.Data.MySqlClient;
using SistemaUsuarios.Modelos;

namespace SistemaUsuarios.Servicios
{
    public class CargosService
    {
        private readonly string _cadenaConexion;
        private readonly Dictionary<int, CargoItem> _cargosPorId;

        public CargosService(string cadenaConexion)
        {
            _cadenaConexion = cadenaConexion;
            _cargosPorId = new Dictionary<int, CargoItem>();
        }

        public List<CargoItem> ObtenerListaCargos()
        {
            List<CargoItem> listaCargos = new List<CargoItem>();
            _cargosPorId.Clear();

            string sql = "SELECT c.id, c.nombre, c.id_departamento, c.id_cargo, d.nombre AS departamento_nombre " +
                         "FROM cargo c " +
                         "INNER JOIN departamento d ON c.id_departamento = d.id " +
                         "ORDER BY c.nombre ASC;";

            using (MySqlConnection conexion = new MySqlConnection(_cadenaConexion))
            {
                conexion.Open();
                using (MySqlCommand comando = new MySqlCommand(sql, conexion))
                {
                    using (MySqlDataReader reader = comando.ExecuteReader())
                    {
                        while (reader.Read())
                        {
                            CargoItem item = new CargoItem();
                            item.Id = Convert.ToInt32(reader["id"]);
                            item.Nombre = reader["nombre"].ToString();
                            item.IdDepartamento = Convert.ToInt32(reader["id_departamento"]);

                            if (reader["id_cargo"] != DBNull.Value)
                            {
                                item.IdCargoSuperior = Convert.ToInt32(reader["id_cargo"]);
                            }
                            else
                            {
                                item.IdCargoSuperior = null;
                            }

                            string nombreDepto = reader["departamento_nombre"].ToString();
                            item.EtiquetaCombo = item.Nombre + " (" + nombreDepto + ")";

                            listaCargos.Add(item);

                            if (!_cargosPorId.ContainsKey(item.Id))
                            {
                                _cargosPorId.Add(item.Id, item);
                            }
                        }
                    }
                }
            }

            return listaCargos;
        }

        public bool ExisteCargo(int idCargo)
        {
            return _cargosPorId.ContainsKey(idCargo);
        }

        public CargoItem BuscarCargoPorId(int idCargo)
        {
            if (_cargosPorId.ContainsKey(idCargo))
            {
                return _cargosPorId[idCargo];
            }
            return null;
        }
    }
}

3. Servicio de Usuarios (validación, Dictionary<string, string> y SHA2(?, 256))

Valida la entrada, comprueba la existencia del cargo, inserta el usuario cifrando la contraseña con SHA2(@password, 256) y traduce errores de duplicidad mediante un diccionario.

UsuariosService.cs 
using System;
using System.Collections.Generic;
using MySql.Data.MySqlClient;
using SistemaUsuarios.Modelos;

namespace SistemaUsuarios.Servicios
{
    public class UsuariosService
    {
        private readonly string _cadenaConexion;
        private readonly CargosService _cargosService;
        private readonly Dictionary<string, string> _mensajesDuplicados;

        public UsuariosService(string cadenaConexion, CargosService cargosService)
        {
            _cadenaConexion = cadenaConexion;
            _cargosService = cargosService;

            _mensajesDuplicados = new Dictionary<string, string>();
            _mensajesDuplicados.Add("nickname", "El Nickname ingresado ya está registrado.");
            _mensajesDuplicados.Add("correo", "El Email ingresado ya está registrado.");
        }

        public RespuestaServicio RegistrarUsuario(NuevoUsuarioRequest request)
        {
            RespuestaServicio respuesta = new RespuestaServicio();
            respuesta.Exito = false;
            respuesta.CodigoError = 0;

            if (request == null)
            {
                respuesta.Mensaje = "Los datos del usuario son obligatorios.";
                return respuesta;
            }

            string nickname = (request.Nickname ?? string.Empty).Trim();
            string password = request.Password ?? string.Empty;
            string correo = (request.Correo ?? string.Empty).Trim();

            if (nickname == string.Empty || password == string.Empty || correo == string.Empty)
            {
                respuesta.Mensaje = "Debe completar Nickname, Password y Email.";
                return respuesta;
            }

            if (!_cargosService.ExisteCargo(request.IdCargo))
            {
                respuesta.Mensaje = "Debe seleccionar un Role (cargo) válido.";
                return respuesta;
            }

            string sql = "INSERT INTO usuarios (nickname, password_hash, correo, id_cargo) " +
                         "VALUES (@nickname, SHA2(@password, 256), @correo, @id_cargo);";

            try
            {
                using (MySqlConnection conexion = new MySqlConnection(_cadenaConexion))
                {
                    conexion.Open();
                    using (MySqlCommand comando = new MySqlCommand(sql, conexion))
                    {
                        comando.Parameters.AddWithValue("@nickname", nickname);
                        comando.Parameters.AddWithValue("@password", password);
                        comando.Parameters.AddWithValue("@correo", correo);
                        comando.Parameters.AddWithValue("@id_cargo", request.IdCargo);

                        int filasAfectadas = comando.ExecuteNonQuery();

                        if (filasAfectadas > 0)
                        {
                            respuesta.Exito = true;
                            respuesta.Mensaje = "Usuario registrado correctamente en la base de datos.";
                        }
                        else
                        {
                            respuesta.Mensaje = "No se pudo registrar el usuario.";
                        }
                    }
                }
            }
            catch (MySqlException ex)
            {
                respuesta.CodigoError = ex.Number;
                respuesta.Mensaje = InterpretarErrorMySql(ex);
            }
            catch (Exception ex)
            {
                respuesta.Mensaje = "Error inesperado al registrar usuario: " + ex.Message;
            }

            return respuesta;
        }

        private string InterpretarErrorMySql(MySqlException ex)
        {
            if (ex.Number == 1062)
            {
                string detalle = ex.Message.ToLower();
                foreach (KeyValuePair<string, string> entrada in _mensajesDuplicados)
                {
                    if (detalle.Contains(entrada.Key))
                    {
                        return entrada.Value;
                    }
                }
                return "Ya existe un registro duplicado con ese Nickname o Email.";
            }

            return "Error de base de datos (" + ex.Number + "): " + ex.Message;
        }
    }
}

4. Ventana WPF (MainWindow.xaml.cs con PasswordBox en .NET Framework 4.5)

Enlaza la lista de cargos al ComboBox, lee pwdPassword.Password y delega el registro a UsuariosService.

MainWindow.xaml.cs 
using System;
using System.Collections.Generic;
using System.Windows;
using SistemaUsuarios.Modelos;
using SistemaUsuarios.Servicios;

namespace SistemaUsuarios
{
    public partial class MainWindow : Window
    {
        private readonly string _conexion = "Server=127.0.0.1;Database=EjercicioWPFDb;Uid=root;Pwd=;";
        private readonly CargosService _cargosService;
        private readonly UsuariosService _usuariosService;

        public MainWindow()
        {
            InitializeComponent();
            _cargosService = new CargosService(_conexion);
            _usuariosService = new UsuariosService(_conexion, _cargosService);
            CargarComboRole();
        }

        private void CargarComboRole()
        {
            try
            {
                List<CargoItem> cargos = _cargosService.ObtenerListaCargos();
                cmbRole.ItemsSource = cargos;
                cmbRole.DisplayMemberPath = "EtiquetaCombo";
                cmbRole.SelectedValuePath = "Id";

                if (cargos.Count > 0)
                {
                    cmbRole.SelectedIndex = 0;
                }
            }
            catch (Exception ex)
            {
                MessageBox.Show("Error al cargar roles: " + ex.Message, "Error", MessageBoxButton.OK, MessageBoxImage.Error);
            }
        }

        private void btnRegistrar_Click(object sender, RoutedEventArgs e)
        {
            int idCargoSeleccionado = 0;
            if (cmbRole.SelectedValue != null)
            {
                idCargoSeleccionado = Convert.ToInt32(cmbRole.SelectedValue);
            }

            NuevoUsuarioRequest nuevoUsuario = new NuevoUsuarioRequest();
            nuevoUsuario.Nickname = txtNickname.Text;
            nuevoUsuario.Password = pwdPassword.Password;
            nuevoUsuario.Correo = txtEmail.Text;
            nuevoUsuario.IdCargo = idCargoSeleccionado;

            RespuestaServicio resultado = _usuariosService.RegistrarUsuario(nuevoUsuario);

            if (resultado.Exito)
            {
                MessageBox.Show(resultado.Mensaje, "Éxito", MessageBoxButton.OK, MessageBoxImage.Information);
                txtNickname.Clear();
                pwdPassword.Clear();
                txtEmail.Clear();
            }
            else
            {
                MessageBox.Show(resultado.Mensaje, "Atención", MessageBoxButton.OK, MessageBoxImage.Warning);
            }
        }
    }
}
