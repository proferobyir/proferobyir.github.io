Guía docente paso a paso: Sintaxis, Árbol de Nodos, Física y TileMaps

Módulo 1: Sintaxis Básica de C# en Godot

Para trabajar con C# en Godot 4 (.NET), cada script vinculado a un nodo debe cumplir tres reglas estructurales fundamentales:

  • Heredar del tipo de nodo al que está adjunto (ej. Node2D, CharacterBody2D).
  • Utilizar el modificador partial en la declaración de la clase para la integración con Godot.
  • Usar GD.Print() para imprimir mensajes en la consola del editor.

Estructura de un Script Tipo

using Godot;
using System;

namespace TutorialJuego;

public partial class MiPrimerNodo : Node2D
{
    // Variables exportadas: visibles en el Inspector de Godot
    [Export] public float VelocidadBase { get; set; } = 200.0f;
    [Export] public string NombreJugador = "Héroe";

    // Variables privadas de control
    private int _puntosVida = 100;
    private bool _estaActivo = true;

    // Se ejecuta una vez al entrar al árbol de escenas
    public override void _Ready()
    {
        GD.Print($"Inicializando a {NombreJugador} con vida: {_puntosVida}");
    }

    // Se ejecuta en cada frame de renderizado
    public override void _Process(double delta)
    {
        if (_estaActivo)
        {
            RotarObjeto((float)delta);
        }
    }

    private void RotarObjeto(float delta)
    {
        Rotation += 1.0f * delta;
    }
}

Módulo 2: Escenas, Nodos y Manejo del Árbol

Godot organiza los elementos mediante una arquitectura de composición basada en Árboles de Nodos. Una Escena es una colección jerárquica de nodos guardada como un archivo .tscn.

EscenaPrincipal (Node2D) ├── Player (CharacterBody2D) <-- Contiene Player.cs │ ├── Sprite2D │ └── CollisionShape2D └── Enemigo (Area2D)

Instanciación Dinámica de Escenas desde C#

Permite generar objetos programáticamente durante la ejecución (como proyectiles u objetos recolectables):

using Godot;

public partial class Generador : Node2D
{
    [Export] public PackedScene EscenaProyectil;

    public void Disparar(Vector2 posicionInicial)
    {
        if (EscenaProyectil != null)
        {
            // 1. Instanciar el nodo
            Node2D nuevoProyectil = EscenaProyectil.Instantiate<Node2D>();
            
            // 2. Definir posición inicial
            nuevoProyectil.Position = posicionInicial;
            
            // 3. Agregar al árbol como hijo
            AddChild(nuevoProyectil);
        }
    }
}

Módulo 3: Objeto del Jugador y Movimiento 2D

El nodo CharacterBody2D está optimizado para entidades controladas por código que requieren física cinemática y detección precisa de colisiones.

Configuración de Input Map

Defina en Proyecto → Configuración del Proyecto → Mapa de Entradas:

  • mover_derecha (Tecla D / Flechas)
  • mover_izquierda (Tecla A / Flechas)
  • saltar (Barra espaciadora)

Código del Jugador

using Godot;

public partial class Jugador : CharacterBody2D
{
    [Export] public float Speed = 300.0f;
    [Export] public float JumpVelocity = -400.0f;

    public float Gravity = ProjectSettings.GetSetting("physics/2d/default_gravity").AsSingle();

    public override void _PhysicsProcess(double delta)
    {
        Vector2 velocity = Velocity;

        // Aplicar gravedad
        if (!IsOnFloor())
        {
            velocity.Y += Gravity * (float)delta;
        }

        // Manejo del salto
        if (Input.IsActionJustPressed("saltar") && IsOnFloor())
        {
            velocity.Y = JumpVelocity;
        }

        // Obtener dirección del input (-1 a 1)
        Vector2 direction = Input.GetVector("mover_izquierda", "mover_derecha", "ui_up", "ui_down");
        if (direction != Vector2.Zero)
        {
            velocity.X = direction.X * Speed;
        }
        else
        {
            velocity.X = Mathf.MoveToward(Velocity.X, 0, Speed);
        }

        Velocity = velocity;
        MoveAndSlide();
    }
}

Módulo 4: Detección de Colisiones y Señales

El nodo Area2D permite detectar superposiciones de objetos sin generar una respuesta física de solidez. Es ideal para coleccionables o zonas de disparo.

Moneda Recolectable (Area2D)

using Godot;

public partial class Moneda : Area2D
{
    [Export] public int ValorPuntos = 10;

    public override void _Ready()
    {
        // Suscribir método a la señal BodyEntered
        BodyEntered += OnBodyEntered;
    }

    private void OnBodyEntered(Node2D body)
    {
        // Validar si el cuerpo que entró es el Jugador
        if (body is Jugador jugador)
        {
            GD.Print($"Moneda recolectada. +{ValorPuntos} puntos.");
            
            // Eliminar el nodo de forma segura
            QueueFree();
        }
    }
}

Módulo 5: Creación de Niveles con Baldosas

En Godot 4.3+, el mapa de baldosas se gestiona mediante el nodo TileMapLayer.

Paso Configuración en el Editor
1. Crear Nodo Agregar un nodo TileMapLayer. En el inspector, asignar un nuevo recurso TileSet.
2. Textura En el panel inferior TileSet, arrastrar el sprite sheet o atlas de imágenes.
3. Físicas En el inspector del TileSet, ir a Physics Layers → Add Element.
4. Colisiones En el panel TileSet, seleccionar la herramienta Physics y dibujar el polígono sobre las baldosas sólidas.
5. Pintar Seleccionar la pestaña TileMap y pintar las baldosas en el visor 2D.

Módulo 6: Resumen y Buenas Prácticas

  • QueueFree(): Liberación de memoria asíncrona recomendada para no interrumpir el ciclo de procesamiento de física.
  • _PhysicsProcess: Usar exclusivamente para movimiento físico y manipulación de cuerpos cinemáticos o rígidos.
  • Pattern Matching: Aprovechar las comprobaciones con is en C# (ej. if (body is Jugador)) para evitar excepciones de tipo nulo.
