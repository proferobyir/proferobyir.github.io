Guía Práctica: Menú Lateral y Módulos Dinámicos en WPF

Compatible con C# 5 y Visual Studio 2012 (Uso de Clases Públicas y Listas Dinámicas)

Paso 1: Crear la clase pública del Menú

Define los campos básicos (título e identificador) para estructurar las opciones del menú lateral.

namespace MiSistemaHotel { public class OpcionMenu { public string Titulo { get; set; } public string Identificador { get; set; } } }

Paso 2: Diseñar la Ventana Principal (MainWindow.xaml)

Divide la interfaz en dos columnas: la izquierda con un ListBox para las opciones y la derecha con un ContentControl como contenedor central.

<Window x:Class="MiSistemaHotel.MainWindow" xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" Title="Sistema Hotelero" Height="700" Width="1100" WindowStartupLocation="CenterScreen"> <Grid> <Grid.ColumnDefinitions> <ColumnDefinition Width="240"/> <ColumnDefinition Width="*"/> </Grid.ColumnDefinitions> <!-- 1. MENÚ LATERAL IZQUIERDO --> <Border Grid.Column="0" Background="#1E222B"> <StackPanel Margin="15"> <TextBlock Text="Los Pastores" Foreground="White" FontSize="18" FontWeight="Bold" Margin="0,0,0,20"/> <ListBox x:Name="ListaMenu" DisplayMemberPath="Titulo" SelectionChanged="ListaMenu_SelectionChanged" Background="Transparent" BorderBrush="Transparent" Foreground="White"/> </StackPanel> </Border> <!-- 2. CONTENEDOR CENTRAL DINÁMICO --> <ContentControl x:Name="ContenedorCentral" Grid.Column="1" Margin="20"/> </Grid> </Window>

Paso 3: Lógica en el Código Detrás (MainWindow.xaml.cs)

Inicializa la lista dinámica y programa el evento de selección para intercambiar los módulos en el centro con un control switch.

using System.Collections.Generic; using System.Windows; using System.Windows.Controls; using MiSistemaHotel.Views; namespace MiSistemaHotel { public partial class MainWindow : Window { public List<OpcionMenu> OpcionesDelMenu { get; set; } public MainWindow() { InitializeComponent(); // 1. Llenamos la lista dinámica con clases públicas OpcionesDelMenu = new List<OpcionMenu> { new OpcionMenu { Titulo = "📊 Dashboard", Identificador = "Dashboard" }, new OpcionMenu { Titulo = "🛏️ Habitaciones", Identificador = "Habitaciones" }, new OpcionMenu { Titulo = "📅 Reservas", Identificador = "Reservas" } }; ListaMenu.ItemsSource = OpcionesDelMenu; // 2. Cargamos una vista por defecto al iniciar ContenedorCentral.Content = new DashboardView(); } private void ListaMenu_SelectionChanged(object sender, SelectionChangedEventArgs e) { var seleccion = ListaMenu.SelectedItem as OpcionMenu; if (seleccion == null) return; switch (seleccion.Identificador) { case "Dashboard": ContenedorCentral.Content = new DashboardView(); break; case "Habitaciones": ContenedorCentral.Content = new HabitacionesView(); break; case "Reservas": ContenedorCentral.Content = new ReservasView(); break; } } } }

Paso 4: Crear los Módulos independientes (UserControls)

Haz clic derecho en tu proyecto dentro de Visual Studio 2012, selecciona Agregar > Nuevo elemento > UserControl (WPF) para cada módulo (ej. DashboardView.xaml, HabitacionesView.xaml) y diséñalos por separado.

Entorno optimizado para Visual Studio 2012 / .NET Framework 4.5.
