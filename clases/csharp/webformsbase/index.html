1 Qué es un archivo .aspx

Un archivo .aspx es HTML con etiquetas especiales que el servidor procesa antes de enviarlo al navegador. El navegador nunca ve el .aspx: ve el HTML resultante.

Esos archivos van acompañados de un archivo .aspx.cs (C#) donde va la lógica. El .aspx es la vista; el .aspx.cs es el código.

En una frase: el .aspx es un molde con HTML y huecos; el .aspx.cs llena esos huecos antes de entregar la página.

Lo que NO es un .aspx

  • No es un HTML normal: el servidor lo transforma antes de enviarlo.
  • No es un archivo que el navegador pueda abrir directamente.
  • No lleva la lógica: esa va en el .aspx.cs.

2 Crear el proyecto (VS 2012, .NET 4.5)

  1. Abrir Visual Studio 2012.
  2. Archivo → Nuevo → Proyecto.
  3. Panel izquierdo: Visual C# → Web.
  4. Centro: Aplicación web ASP.NET.
  5. Arriba: framework .NET Framework 4.5 (si no aparece, elige 4.0; el código funciona igual).
  6. Nombre: MiPrimeraApp. Aceptar.
  7. Plantilla: Web Forms (o Vacío y luego agregas un Formulario Web Forms).
Archivo Qué es
Default.aspx La vista: HTML + etiquetas especiales.
Default.aspx.cs La lógica en C#.
Web.config Configuración del proyecto.

3 Anatomía de un .aspx: qué se le agrega al HTML

Este es un .aspx completo y mínimo:

<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="Default.aspx.cs" Inherits="MiPrimeraApp.Default" %>

<!DOCTYPE html>
<html>
<head runat="server">
    <title>Mi primera app</title>
</head>
<body>
    <form id="form1" runat="server">
        <div>
            <asp:TextBox ID="txtNombre" runat="server"></asp:TextBox>
            <asp:Button ID="btnSaludar" runat="server" Text="Saludar" OnClick="btnSaludar_Click" />
            <br /><br />
            <asp:Label ID="lblResultado" runat="server"></asp:Label>
        </div>
    </form>
</body>
</html>

Frente a un HTML normal, aquí hay cuatro cosas nuevas:

1. La directiva <%@ Page %>

Va en la primera línea. No es HTML: es una instrucción para el servidor.

Atributo Qué significa
Language="C#" El código del .aspx.cs está en C#.
AutoEventWireup="true" Conecta solo los eventos como Page_Load.
CodeBehind="..." Nombre del archivo de lógica asociado.
Inherits="..." Namespace + clase del .aspx.cs. Debe coincidir exactamente.

2. El atributo runat="server"

Es la clave de todo. Le dice al servidor: "procesa esta etiqueta antes de enviarla". Sin runat="server", la etiqueta es HTML normal y el servidor la ignora.

  • En <head runat="server">: permite modificar el título desde C#.
  • En <form runat="server">: obligatorio para que funcionen los controles. Solo puede haber un formulario con runat="server" por página.
  • En <asp:...>: todos los controles de servidor lo llevan.

3. Los controles <asp:...>

Son etiquetas que no son HTML. El servidor las convierte en HTML real antes de enviarlo. Se explican en la sección 4.

4. El atributo ID="..."

Es el nombre con el que el código C# se refiere a esa etiqueta. Como el id de HTML, pero usado desde el servidor.

Regla: si una etiqueta no tiene runat="server", el código C# no puede verla ni modificarla. Es HTML puro y muere en el navegador.

4 Los controles de servidor (asp:)

Son etiquetas que empiezan con <asp:. El servidor las transforma en HTML. Siempre llevan runat="server" y un ID.

Control Se convierte en Propiedad para leer/escribir
<asp:TextBox> <input type="text"> .Text
<asp:Button> <input type="submit"> .Text, evento OnClick
<asp:Label> <span> .Text
<asp:Panel> <div> .Visible
<asp:Repeater> Lista repetida de HTML DataSource, DataBind()

Ejemplo: leer y escribir desde C#

string nombre = txtNombre.Text;                      // leer del TextBox
lblResultado.Text = "Hola, " + nombre + "!";          // escribir en el Label

Diferencia con HTML: en HTML, un <input> solo se lee con JavaScript o al enviar el formulario. Aquí, el control tiene una propiedad .Text que el servidor lee y escribe directamente.

El evento OnClick

En el botón:

<asp:Button ID="btnSaludar" runat="server" Text="Saludar" OnClick="btnSaludar_Click" />

OnClick="btnSaludar_Click" le dice al servidor: "cuando hagan clic, ejecuta el método C# llamado btnSaludar_Click". Ese método va en el .aspx.cs.

5 El archivo .aspx.cs (la lógica)

Cada .aspx tiene su .aspx.cs. Ahí va el código C#. La estructura es siempre esta:

using System;

namespace MiPrimeraApp
{
    public partial class Default : System.Web.UI.Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
            // se ejecuta cada vez que carga la página
        }

        protected void btnSaludar_Click(object sender, EventArgs e)
        {
            // se ejecuta al hacer clic en el botón
        }
    }
}
Parte Qué es
namespace MiPrimeraApp Agrupación del proyecto. Debe coincidir con Inherits del .aspx.
public partial class Default La página es una clase. partial: está partida en dos archivos (.aspx y .aspx.cs).
: System.Web.UI.Page Hereda de la clase base de toda página Web Forms.
Page_Load Evento que corre al cargar la página.
btnSaludar_Click Método que corre al hacer clic en el botón con ese OnClick.
object sender El control que disparó el evento.
EventArgs e Datos extra del evento (casi nunca se usan).

Código funcional del botón

protected void btnSaludar_Click(object sender, EventArgs e)
{
    string nombre = txtNombre.Text;
    lblResultado.Text = "Hola, " + nombre + ". ¡Esto es ASP.NET!";
}

En .NET 4.5 (C# 5) NO uses $"Hola {nombre}". Eso es C# 6 y no compila. Usa concatenación con +.

Presiona F5, escribe un nombre, haz clic. El Label muestra el saludo.

6 Page_Load vs. Click

Page_Load se ejecuta en cada petición: al abrir la página y también en cada clic de botón. btn_Click solo corre al hacer clic.

Error típico: poner la lógica del botón en Page_Load.

protected void Page_Load(object sender, EventArgs e)
{
    // MAL: esto corre antes del clic y con datos viejos
    lblResultado.Text = "Hola, " + txtNombre.Text;
}

Regla:

Page_Load → preparar cosas la primera vez.

btn_Click → responder a un clic.

IsPostBack

IsPostBack es true cuando la página viene de una interacción del usuario (un clic). Sirve para que cierto código corra solo la primera vez:

protected void Page_Load(object sender, EventArgs e)
{
    if (!IsPostBack)
    {
        // solo la primera vez que se abre la página
    }
}

!IsPostBack se lee: "si NO es una recarga por clic".

7 Session

Session guarda datos de un usuario mientras navega entre páginas. Es una bolsa con clave y valor.

Session["UsuarioActual"] = "admin";                 // guardar
string user = Session["UsuarioActual"].ToString();  // leer
Session.Clear();                                    // borrar todo

Proteger una página

Al inicio de Page_Load:

if (Session["UsuarioActual"] == null)
{
    Response.Redirect("Login.aspx");
    return;
}
Elemento Qué hace
Session["clave"] Guarda un valor por usuario.
== null Significa que el usuario no ha iniciado sesión.
Response.Redirect("...") Envía al navegador a otra página.
return; Corta la ejecución para que no siga el resto del método.

8 List y Repeater

Para mostrar varios elementos se usa una List<T> y un Repeater. El Repeater repite un bloque de HTML por cada elemento de la lista.

En el .aspx

<asp:Repeater ID="rptProductos" runat="server">
    <ItemTemplate>
        <div>
            <h3><%# Eval("Nombre") %></h3>
            <p>Precio: $<%# Eval("Precio") %></p>
        </div>
    </ItemTemplate>
</asp:Repeater>

En el .aspx.cs

List<Producto> lista = new List<Producto>();
lista.Add(new Producto { Nombre = "Teclado", Precio = 45 });
lista.Add(new Producto { Nombre = "Mouse", Precio = 18 });

rptProductos.DataSource = lista;
rptProductos.DataBind();
Elemento Qué hace
List<Producto> Lista de objetos Producto.
<ItemTemplate> El bloque de HTML que se repite por cada elemento.
<%# Eval("Nombre") %> Toma la propiedad Nombre del elemento actual.
DataSource = lista Le dice al Repeater de dónde sacar los datos.
DataBind() Dibuja el Repeater. Sin esto no aparece nada.

Ojo: Producto es una clase que debes crear antes (con propiedades Nombre y Precio). Si no existe, el código no compila.

9 Errores comunes en 4.5

Error Causa Solución
No compila $"..." Interpolación es C# 6, no existe en 4.5 Usar "texto " + variable
"No se encuentra el tipo Default" Inherits no coincide con el namespace/clase Revisar que digan exactamente lo mismo
El botón no hace nada Falta runat="server" en el form o en el botón Agregarlo
El Label no muestra nada Falta runat="server" en el Label Agregarlo
El Repeater sale vacío Falta DataBind() Llamarlo después de asignar DataSource
Error al crear el proyecto No aparece .NET 4.5 en el desplegable Elegir .NET 4.0: el código funciona igual
