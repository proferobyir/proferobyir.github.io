One-Way vs. Two-Way Data Binding en Web Forms

En ASP.NET Web Forms, el código C# se ejecuta en el servidor y el HTML en el navegador. El Data Binding conecta ambos lados:

TipoDirecciónSintaxis (.NET 4.5)Uso habitual
One-Way (1 vía)C# → HTML<%#: Item.Propiedad %>Mostrar datos de solo lectura (ej. Label).
Two-Way (2 vías)C# ↔ HTML<%#: BindItem.Propiedad %>Cargar datos en un TextBox y recoger cambios al guardar.
Novedad de .NET 4.5 (VS 2012): A diferencia del antiguo Eval("Nombre") y Bind("Nombre"), usar Item y BindItem te da IntelliSense y validación de tipos al compilar.

Crear el proyecto en Visual Studio 2012

  1. Abre Visual Studio 2012 → Archivo → Nuevo → Proyecto...
  2. En la parte superior selecciona .NET Framework 4.5.
  3. Elige Visual C# → Web → Aplicación web vacía de ASP.NET y llámala DemoDataBinding.
  4. Clic derecho en el proyecto → Agregar → Nuevo elemento → Formulario Web Forms llamado RegistroProducto.aspx.
2

Crear la Clase Modelo en C# 5.0

En Web Forms no necesitas implementar INotifyPropertyChanged. Agrega una clase llamada Producto.cs:

Producto.cs
using System;
using System.ComponentModel.DataAnnotations;

namespace DemoDataBinding
{
    public class Producto
    {
        public int Id { get; set; }

        [Required(ErrorMessage = "El nombre es obligatorio")]
        public string Nombre { get; set; }

        public decimal Precio { get; set; }

        public bool Disponible { get; set; }
    }
}

Ejemplo 1: One-Way Data Binding (Solo Lectura)

El atributo ItemType="DemoDataBinding.Producto" activa el enlace fuertemente tipado dentro de un FormView:

Vista One-Way (.aspx)
<asp:FormView ID="fvLectura" runat="server"
    ItemType="DemoDataBinding.Producto"
    SelectMethod="ObtenerProducto">

    <ItemTemplate>
        <h3>Producto #<%#: Item.Id %></h3>
        <p>Nombre: <%#: Item.Nombre %></p>
        <p>Precio: $<%#: Item.Precio %></p>
    </ItemTemplate>

</asp:FormView>

Ejemplo 2: Two-Way Data Binding (Edición completa)

Configura DefaultMode="Edit", UpdateMethod="ActualizarProducto" y usa <%#: BindItem.Propiedad %>:

RegistroProducto.aspx
<%@ Page Language="C#" AutoEventWireup="true" CodeBehind="RegistroProducto.aspx.cs" Inherits="DemoDataBinding.RegistroProducto" %>

<!DOCTYPE html>
<html>
<body>
    <form id="form1" runat="server">
        <asp:FormView ID="fvProducto" runat="server"
            ItemType="DemoDataBinding.Producto"
            DataKeyNames="Id"
            DefaultMode="Edit"
            SelectMethod="ObtenerProducto"
            UpdateMethod="ActualizarProducto">

            <EditItemTemplate>
                <h3>Editando ID: <%#: Item.Id %></h3>
                <div>Nombre: <asp:TextBox ID="txtNombre" runat="server" Text='<%#: BindItem.Nombre %>' /></div>
                <div>Precio: <asp:TextBox ID="txtPrecio" runat="server" Text='<%#: BindItem.Precio %>' /></div>
                <div>Disponible: <asp:CheckBox ID="chkDisponible" runat="server" Checked='<%#: BindItem.Disponible %>' /></div>
                <asp:Button ID="btnGuardar" runat="server" CommandName="Update" Text="Guardar" />
            </EditItemTemplate>
        </asp:FormView>

        <br />
        <asp:Label ID="lblResultado" runat="server" ForeColor="Green" />
    </form>
</body>
</html>

Programar el Code-Behind en C# 5.0 (.aspx.cs)

No necesitas Page_Load ni llamar a DataBind(). TryUpdateModel() recoge los datos de vuelta:

RegistroProducto.aspx.cs
using System;
using System.Web.UI;

namespace DemoDataBinding
{
    public partial class RegistroProducto : Page
    {
        private static Producto _productoEnBD = new Producto
        {
            Id = 101,
            Nombre = "Teclado Mecánico",
            Precio = 75.50m,
            Disponible = true
        };

        // IDA (C# -> HTML)
        public Producto ObtenerProducto()
        {
            return _productoEnBD;
        }

        // VUELTA (HTML -> C#)
        public void ActualizarProducto(int id)
        {
            Producto itemActualizado = new Producto { Id = id };
            TryUpdateModel(itemActualizado);

            if (ModelState.IsValid)
            {
                _productoEnBD.Nombre = itemActualizado.Nombre;
                _productoEnBD.Precio = itemActualizado.Precio;
                _productoEnBD.Disponible = itemActualizado.Disponible;

                lblResultado.Text = string.Format(
                    "¡Guardado! {0} - ${1}",
                    _productoEnBD.Nombre,
                    _productoEnBD.Precio
                );
            }
        }
    }
}

Checklist de Errores Comunes en VS 2012

  • [ ] Comillas simples externas: Usa comillas simples alrededor de la expresión: Text='<%#: BindItem.Nombre %>'.
  • [ ] ItemType con Namespace: Incluye el namespace completo (ej. ItemType="DemoDataBinding.Producto").
  • [ ] CommandName exacto: El botón de guardar debe tener CommandName="Update".
  • [ ] Controles sueltos: Fuera de un FormView o GridView, Web Forms no soporta BindItem; asigna .Text manualmente dentro de if (!IsPostBack).
