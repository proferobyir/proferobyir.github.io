Material de soporte para el laboratorio en Visual Studio 2012 (.NET Framework 4.5).

¿Qué es XAML?

Extensible Application Markup Language: Lenguaje de marcado basado en XML para diseñar e inicializar interfaces de usuario de forma declarativa, separando el diseño estético de la lógica de C#.

¿Qué es WPF?

Windows Presentation Foundation: Framework gráfico basado en DirectX para Windows que permite crear interfaces modernas con gráficos vectoriales, soporte XAML y arquitectura avanzada.

Lección 1: Fundamentos de XAML

Nivel Principiante

XAML define elementos gráficos de forma declarativa mediante XML. Cada etiqueta representa una instancia de una clase .NET.

MainWindow.xamlXAML
<Window x:Class="AppWpf.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="Mi Primera Interfaz" Height=250 Width=400>
    <Grid Background="#1E1E1E">
        <Button x:Name="btnGuardar" 
                Content="Aceptar" 
                Width="120" Height="35"
                Background="#007ACC" Foreground="White"
                Click="btnGuardar_Click"/>
    </Grid>
</Window>
MainWindow.xaml.csC# Code-Behind
using System.Windows;

namespace AppWpf
{
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
        }

        private void btnGuardar_Click(object sender, RoutedEventArgs e)
        {
            MessageBox.Show("¡Hola desde XAML en WPF!");
        }
    }
}

Lección 2: Contenedores de Layout (Grid y StackPanel)

Nivel Intermedio

A diferencia de Windows Forms, WPF no usa coordenadas fijas. Se emplean paneles adaptativos como Grid (filas y columnas) y StackPanel (apilamiento).

FormularioLayout.xamlXAML Layout
<Grid Margin="15">
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto"/>
        <RowDefinition Height="Auto"/>
        <RowDefinition Height="*"/>
    </Grid.RowDefinitions>

    <!-- Fila 0: Título -->
    <TextBlock Grid.Row="0" Text="Registro de Usuario" 
               FontSize="18" FontWeight="Bold" Margin="0,0,0,10"/>

    <!-- Fila 1: Campos apilados -->
    <StackPanel Grid.Row="1" Orientation="Vertical">
        <Label Content="Nombre:"/>
        <TextBox x:Name="txtNombre" Padding="5"/>
    </StackPanel>
</Grid>

Lección 3: Data Binding (Enlace de Datos)

Nivel Avanzado

Data Binding conecta la vista XAML con objetos de C# sin manipular directamente los controles por código imperativo.

BindingView.xamlXAML
<StackPanel Margin="20">
    <TextBox Text="{Binding Nombre, UpdateSourceTrigger=PropertyChanged}" 
             Padding="5"/>
    
    <TextBlock Text="{Binding Nombre, StringFormat='Texto escrito: {0}'}" 
               Margin="0,10,0,0" Foreground="LightGreen"/>
</StackPanel>

Lección 4: Conexión MySQL + DataGrid en XAML

Avanzano / Base de Datos

Carga de datos desde una base de datos MySQL hacia un control DataGrid de WPF usando MySqlData en C#.

ConsultaView.xamlXAML
<Grid Margin="10">
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto"/>
        <RowDefinition Height="*"/>
    </Grid.RowDefinitions>

    <Button Content="Cargar Usuarios MySQL" Click="btnCargar_Click" 
            Padding="8" Margin="0,0,0,10"/>

    <DataGrid Grid.Row="1" x:Name="dgUsuarios" 
              AutoGenerateColumns="True" 
              Background="#252526"/>
</Grid>
ConsultaView.xaml.csC# + MySQL
using System.Data;
using System.Windows;
using MySql.Data.MySqlClient;

namespace AppWpf
{
    public partial class ConsultaView : Window
    {
        private string cadenaConexion = 
            "Server=localhost;Database=instituto;Uid=root;Pwd=1234;";

        public ConsultaView()
        {
            InitializeComponent();
        }

        private void btnCargar_Click(object sender, RoutedEventArgs e)
        {
            using (MySqlConnection conn = new MySqlConnection(cadenaConexion))
            {
                try
                {
                    conn.Open();
                    string query = "SELECT id, nombre, email FROM usuarios";
                    MySqlDataAdapter adapter = new MySqlDataAdapter(query, conn);
                    DataTable dt = new DataTable();
                    adapter.Fill(dt);

                    dgUsuarios.ItemsSource = dt.DefaultView;
                }
                catch (System.Exception ex)
                {
                    MessageBox.Show("Error: " + ex.Message);
                }
            }
        }
    }
}
