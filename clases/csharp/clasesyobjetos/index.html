01

¿Qué es una clase?

Una clase es una descripción o molde que define qué información y qué comportamientos tendrán los objetos que creemos.

Imagina un formulario de estudiante. Todos los estudiantes pueden tener nombre, edad y nota, aunque cada estudiante tendrá valores diferentes.

CLASE: Estudiante

Define:

Nombre · Edad · Nota
💡 Piensa así La clase describe cómo será un objeto. Todavía no estamos hablando de un estudiante específico.

Primera clase pública

C# 5 — Estudiante.cs
public class Estudiante
{
    public string Nombre;
    public int Edad;
    public double Nota;
}
✓ Observa public class Estudiante significa que estamos declarando una clase pública llamada Estudiante.
02

¿Qué es un objeto?

Un objeto es una instancia concreta de una clase. Es decir, es algo que podemos crear utilizando la clase como molde.

Clase: Estudiante
↓ new
estudiante1
estudiante2

Crear nuestro primer objeto

C# 5
Estudiante estudiante1 = new Estudiante();

Observa los nombres cuidadosamente:

Parte Significado
Estudiante El tipo / clase que estamos utilizando.
estudiante1 La variable que referencia al objeto.
new Crea una nueva instancia.
Estudiante() Construye una instancia de la clase.
⚠️ Regla visual para aprender Evitaremos llamar al objeto exactamente igual que a la clase. Usaremos Estudiante para la clase y estudiante1, estudiante2, etc. para los objetos. Así la diferencia se ve claramente.
03

Los datos del objeto: atributos

Nuestra clase tiene tres atributos: 

public string Nombre;
public int Edad;
public double Nota;

Cada objeto tendrá sus propios valores.

Asignar datos al objeto

Estudiante estudiante1 = new Estudiante();

estudiante1.Nombre = "Ana";
estudiante1.Edad = 19;
estudiante1.Nota = 16;
estudiante1

Nombre → Ana
Edad → 19
Nota → 16

Crear otro objeto

Estudiante estudiante2 = new Estudiante();

estudiante2.Nombre = "Luis";
estudiante2.Edad = 20;
estudiante2.Nota = 12;
✓ Comprueba Los dos objetos pertenecen a la misma clase, pero contienen datos diferentes.

05

Un comportamiento: los métodos

Una clase también puede tener acciones. En programación orientada a objetos, esas acciones se representan mediante métodos.

Por ejemplo, podemos pedirle al estudiante que muestre sus datos.

Clase Estudiante
public class Estudiante
{
    public string Nombre;
    public int Edad;
    public double Nota;

    public void MostrarDatos()
    {
        Console.WriteLine("Nombre: " + Nombre);
        Console.WriteLine("Edad: " + Edad);
        Console.WriteLine("Nota: " + Nota);
    }
}

Utilizar el método

Estudiante estudiante1 = new Estudiante();

estudiante1.Nombre = "Ana";
estudiante1.Edad = 19;
estudiante1.Nota = 16;

estudiante1.MostrarDatos();
💡 Observa la diferencia Atributos representan información. Métodos representan acciones o comportamientos.
⚠️ No te adelantes En esta primera aproximación no necesitamos todavía profundizar en encapsulamiento, propiedades, herencia o polimorfismo. Primero hay que dominar la relación clase → objeto.
06

Una lista de objetos

Ya conoces List. Ahora vamos a combinarlo con clases.

Antes teníamos, por ejemplo: 

List<string> nombres = new List<string>();

Ahora podemos crear una lista cuyos elementos sean objetos Estudiante: 

List<Estudiante> estudiantes =
    new List<Estudiante>();

↓

Agregar objetos a la lista

estudiantes.Add(estudiante1);
estudiantes.Add(estudiante2);
✓ Punto importante La lista no contiene solamente nombres o números. Ahora contiene objetos completos.

Programa completo hasta este punto

List<Estudiante> estudiantes =
    new List<Estudiante>();

estudiante1.Nombre = "Ana";
estudiante1.Edad = 19;
estudiante1.Nota = 16;

07

Recorrer objetos con foreach

Ahora viene una de las partes más importantes: recorrer todos los objetos almacenados en la lista. 

foreach (Estudiante estudiante in estudiantes)
{
    Console.WriteLine(estudiante.Nombre);
}

¿Qué significa cada parte?

1 foreach: indica que vamos a recorrer una colección.
2 Estudiante: indica el tipo de elemento que vamos a recibir.
3 estudiante: es la variable que representa al elemento actual durante cada vuelta.
4 in estudiantes: indica que recorreremos la lista llamada estudiantes.

Podemos acceder a todos sus atributos

foreach (Estudiante estudiante in estudiantes)
{
    Console.WriteLine("Nombre: " + estudiante.Nombre);
    Console.WriteLine("Edad: " + estudiante.Edad);
    Console.WriteLine("Nota: " + estudiante.Nota);

    Console.WriteLine("----------------");
}
estudiantes
↓ foreach

1ª vuelta → estudiante1

2ª vuelta → estudiante2

3ª vuelta → estudiante3

🧠 Una forma sencilla de leerlo “Por cada estudiante que exista dentro de estudiantes, haz lo que está entre las llaves”.

estudiantes.Add(estudiante2);

09

Acceder a un objeto por posición

Como ya sabemos que una lista tiene posiciones, también podemos obtener un objeto específico. 

Estudiante estudiante = estudiantes[0];

Console.WriteLine(estudiante.Nombre);

Si la lista contiene: 

0 → estudiante1
1 → estudiante2

entonces estudiantes[0] representa el primer objeto.

💡 Conexión con lo aprendido Esto es exactamente la misma idea de List que ya conoces. La diferencia es que ahora cada posición contiene un objeto en lugar de un dato simple.
10

Ejercicio guiado

Vamos a construir una pequeña lista de productos.

Paso 1 — Crear la clase

public class Producto
{
    public string Nombre;
    public double Precio;
}

Paso 2 — Crear dos objetos

Producto producto1 = new Producto();
producto1.Nombre = "Teclado";
producto1.Precio = 25;

Producto producto2 = new Producto();
producto2.Nombre = "Mouse";
producto2.Precio = 15;

Paso 3 — Crear la lista

List<Producto> productos =
    new List<Producto>();

Paso 4 — Agregar los objetos

productos.Add(producto1);
productos.Add(producto2);

Paso 5 — Recorrer con foreach

foreach (Producto producto in productos)
{
    Console.WriteLine(producto.Nombre);
    Console.WriteLine(producto.Precio);
}
✓ Reto Agrega un tercer producto y consigue que aparezca automáticamente al recorrer la lista. No cambies el foreach.
🔥 Reto adicional: agrega un atributo int Stock a la clase y muestra también el stock de cada producto.

Errores frecuentes

❌ Confundir clase y objeto Clase: Estudiante
Objeto: estudiante1
❌ Olvidar new Para crear una instancia: Estudiante estudiante1 = new Estudiante();
❌ Pensar que todos los objetos tienen los mismos datos estudiante1.Nombre y estudiante2.Nombre pueden tener valores diferentes.
❌ Confundir la lista con el objeto estudiantes es la colección. estudiante dentro del foreach representa el objeto actual.

Las 7 ideas que debes recordar

  1. Una clase es un molde.
  2. Un objeto es una instancia de una clase.
  3. new crea una nueva instancia.
  4. Los objetos tienen sus propios datos.
  5. Una clase puede tener atributos y métodos.
  6. List<Estudiante> puede almacenar objetos Estudiante.
  7. foreach permite recorrer cada objeto de la lista.
🧠 Fórmula mental Clase → new → Objeto → List → foreach
