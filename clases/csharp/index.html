Programación en C# (Visual Studio 2012)

Estructura, Tipos de Datos, Variables y Similitudes con Java

1. Ventajas de C# en Visual Studio 2012 y su cercanía con Java

La versión de C# utilizada en el ecosistema de Visual Studio 2012 (C# 5.0) comparte una arquitectura sintáctica y de diseño sumamente cercana a Java. Esto facilita enormemente la transición para programadores provenientes de entornos Java por las siguientes razones clave:

  • Orientación a Objetos Estricta: Al igual que Java, todo en C# gira en torno a clases, objetos y herencia. No existen las funciones globales sueltas; todo método debe pertenecer a una clase.
  • Tipado Estático Fuerte: Las variables deben declararse con un tipo explícito (o inferido de manera segura mediante var), previniendo errores en tiempo de ejecución de manera idéntica a Java.
  • Estructura de Paquetes y Espacios de Nombres: El concepto de namespaces en C# cumple exactamente el mismo rol que los packages en Java para organizar lógicamente el código.
  • Gestión de Memoria Automatizada: Cuenta con un recolector de basura (Garbage Collector) que libera al desarrollador de la gestión manual de memoria, un pilar compartido con la máquina virtual de Java (JVM).

2. Estructura Básica de un Programa en C#

Todo programa ejecutable en C# requiere una estructura organizada en espacios de nombres, clases y un punto de entrada principal (el método estático Main).

Ejemplo de Estructura General

using System;

namespace MiPrimerProyecto
{
    class Program
    {
        // Punto de entrada principal de la aplicación
        static void Main(string[] args)
        {
            Console.WriteLine("¡Hola desde C# en Visual Studio 2012!");
            
            // Mantener la consola abierta
            Console.ReadKey();
        }
    }
}

3. Tipos de Datos Primitivos

C# maneja tipos de datos muy similares a los primitivos de Java, los cuales mapean directamente a estructuras del Common Language Runtime (.NET CLR):

  • int: Enteros con signo de 32 bits.
  • double / float: Números de punto flotante de doble y simple precisión.
  • char: Caracteres Unicode individuales (delimitados por comillas simples).
  • bool: Valores booleanos (true o false).
  • string: Cadenas de caracteres (delimitadas por comillas dobles, idéntico a la clase String en Java).

4. Declaración y Uso de Variables

La declaración de variables en C# requiere especificar primero el tipo de dato seguido del identificador (nombre de la variable) y opcionalmente un valor inicial. También se puede utilizar la palabra reservada var para inferencia de tipos en tiempo de compilación.

Bloque Explicativo: Ejemplos de Variables

using System;

namespace EjemploVariables
{
    class Program
    {
        static void Main(string[] args)
        {
            // 1. Declaración explícita (Igual que en Java clásico)
            int edadEstudiante = 20;
            double promedioNotas = 18.5;
            char seccion = 'A';
            bool estaAprobado = true;
            string nombreCompleto = "Carlos Mendoza";

            // 2. Inferencia de tipo con 'var' (Disponible en VS 2012 / C# 3.0+)
            var anioIngreso = 2012; 

            // Uso de las variables en consola
            Console.WriteLine("Estudiante: " + nombreCompleto);
            Console.WriteLine("Edad: " + edadEstudiante);
            Console.WriteLine("Promedio: " + promedioNotas);
            Console.WriteLine("Sección: " + seccion);
            Console.WriteLine("¿Aprobado?: " + estaAprobado);
            Console.WriteLine("Año de ingreso: " + anioIngreso);
        }
    }
}
