1. El Origen del Lenguaje C#

C# (pronunciado C-sharp) fue desarrollado a finales de la década de 1990 y principios de los 2000 por Microsoft, bajo el liderazgo de Anders Hejlsberg y su equipo de arquitectos de software.

Nació como un lenguaje moderno, orientado a objetos, fuertemente tipado y diseñado específicamente para ejecutarse sobre la plataforma .NET Framework. Su propósito principal fue ofrecer la potencia de desarrollo de sistemas de bajo nivel combinada con la alta productividad en la construcción de aplicaciones de escritorio, empresariales y servicios web.

Aspectos Clave de su Evolución

  • Raíces y Sintaxis: Hereda las convenciones de la familia de lenguajes C, proporcionando una sintaxis limpia, intuitiva y estructurada.
  • Estandarización Internacional: Fue aprobado oficialmente como estándar por la asociación ECMA (ECMA-334) y por la organización ISO (ISO/IEC 23270).
  • Plataforma .NET: Su ejecución se apoya en el CLR (Common Language Runtime), garantizando la gestión segura de memoria mediante el recolector de basura (Garbage Collector) y la interoperabilidad de componentes.

2. Características Clave de C# 5.0 en Visual Studio 2012

C# 5.0 introdujo importantes avances orientados a la programación asíncrona (como las palabras clave async y await), consolidando un modelo de desarrollo robusto bajo las siguientes premisas estructurales:

  • Orientación a Objetos Pura: Todo tipo de dato, método y ejecutable se encapsula dentro de clases y estructuras controladas por espacios de nombres (namespace).
  • Tipado Estático y Seguro: Verificación estricta en tiempo de compilación, permitiendo al mismo tiempo la inferencia local de tipos mediante la palabra clave var.
  • Modelo de Ensamblados: Organización modular del código a través de ensamblados (.dll / .exe) gestionados por el CLR de .NET Framework 4.5.

5. Operadores Aritméticos y Operadores Lógicos

Los operadores permiten manipular los datos de las variables para realizar cálculos matemáticos y evaluaciones de condiciones:

  • Operadores Aritméticos: Utilizados para operaciones matemáticas básicas: suma (+), resta (-), multiplicación (*), división (/) y el módulo o residuo de una división (%).
  • Operadores Lógicos: Permiten combinar expresiones booleanas: la conjunción && (AND — verdadero si ambas partes se cumplen), la disyunción || (OR — verdadero si al menos una se cumple) y la negación ! (NOT — invierte el valor booleano).

Ejemplo de Operadores Aritméticos y Lógicos

// Operadores Aritméticos
int a = 10;
int b = 3;
int suma = a + b;       // Resultado: 13
int residuo = a % b;   // Resultado: 1 (el resto de 10 / 3)

// Operadores Lógicos
bool esAdulto = true;
bool tienePermiso = false;

// AND lógico (falso porque ambos no son verdaderos)
bool puedeAcceder = esAdulto && tienePermiso; 

// OR lógico (verdadero porque al menos uno es verdadero)
bool accesoAlternativo = esAdulto || tienePermiso;

6. Lectura y Escritura por Consola

Para interactuar con la consola de comandos en C#, utilizamos los métodos estáticos provistos por la clase Console del espacio de nombres System:

  • Escritura: Console.WriteLine() muestra un texto y realiza un salto de línea. Console.Write() muestra el texto manteniendo el cursor en la misma línea.
  • Lectura: Console.ReadLine() captura la cadena de texto ingresada por el usuario hasta presionar Enter (retorna un tipo string).
  • Conversión de Datos: Dado que la consola recibe texto, se requiere la conversión explícita mediante métodos como Convert.ToInt32() o int.Parse() para operar con tipos numéricos.

Ejemplo Práctico de Entrada y Salida

// Escritura básica en consola
Console.Write("Ingrese su nombre: ");
string usuario = Console.ReadLine(); // Lectura de cadena

Console.Write("Ingrese su edad: ");
// Lectura y conversión explícita de string a int
int edadUsuario = Convert.ToInt32(Console.ReadLine());

// Mostrar el resultado concatenando variables
Console.WriteLine("Hola " + usuario + ", el año que viene tendrás " + (edadUsuario + 1) + " años.");
Console.ReadKey(); // Pausa la ejecución hasta presionar una tecla

7. Estructuras Condicionales (if, else if, else)

Permiten ejecutar bloques de código específicos condicionados al resultado de expresiones booleanas:

  • if: Evalúa una condición inicial. Si es verdadera, ejecuta el bloque delimitado.
  • else if: Permite encadenar evaluaciones secuenciales adicionales.
  • else: Bloque de captura final que se ejecuta si ninguna condición previa resulta verdadera.

Ejemplo Completo de Estructura if - else if - else

int nota = 16;
bool asistenciaPerfecta = true;

if (nota >= 18 && asistenciaPerfecta)
{
    Console.WriteLine("¡Excelente! Obtentor de BECA de Honor.");
}
else if (nota >= 10 || asistenciaPerfecta)
{
    Console.WriteLine("Aprobado de manera regular o por asistencia.");
}
else
{
    Console.WriteLine("Reprobado. Debe cursar nuevamente la asignatura.");
}

8. Estructura de Selección Múltiple (switch)

Evalúa una expresión contra múltiples valores constantes discretos definidos en bloques case.

Ejemplo de Switch

int diaSemana = 3;

switch (diaSemana)
{
    case 1:
        Console.WriteLine("Lunes");
        break;
    case 2:
        Console.WriteLine("Martes");
        break;
    case 3:
        Console.WriteLine("Miércoles");
        break;
    default:
        Console.WriteLine("Otro día");
        break;
}

9. Arreglos (Arrays) y Listas Dinámicas (List<T>)

Los arreglos tradicionales poseen un tamaño estático definido al momento de su inicialización. En contraste, las listas genéricas dinamizadas (List<T>) ajustan su capacidad de manera automática según los elementos ingresados.

Uso de Espacios de Nombres y Ensamblados: Para utilizar colecciones genéricas como List<T>, es obligatorio incluir al inicio del archivo la directiva using System.Collections.Generic;. Esto le indica al compilador de .NET que resuelva las referencias de tipos y métodos genéricos alojados en los ensamblados base del framework.

Ejemplo de Arreglos y Listas

// Se requiere la directiva de ensamblado: using System.Collections.Generic;

// 1. Arreglo unidimensional de tamaño fijo
string[] tecnologias = { "C#", "Visual Studio", "ADO.NET" };
Console.WriteLine("Primer elemento del arreglo: " + tecnologias[0]);

// 2. Lista dinámica tipada
List<string> estudiantes = new List<string>();
estudiantes.Add("Ana");
estudiantes.Add("Carlos");

// Recorrer la lista con foreach
foreach (string est in estudiantes)
{
    Console.WriteLine("Estudiante: " + est);
}

10. Estructuras de Repetición (Bucles o Ciclos)

Permiten la ejecución iterativa de bloques de código bajo condiciones específicas de control:

  • Bucle for: Controla el número de iteraciones mediante una variable de inicialización, una condición límite y un paso de incremento/decremento.
  • Bucle while: Evalúa la condición booleana antes de cada ciclo; si es falsa inicialmente, el bloque se omite por completo.
  • Bucle do-while: Evalúa la condición después de ejecutar el bloque, garantizando al menos una ejecución inicial.
  • Bucle foreach: Recorre de forma directa y de sólo lectura los elementos contenidos en arreglos o colecciones tipadas sin requerir índices manuales.

Ejemplo de Bucles (for, while, do-while y foreach)

// 1. Bucle For
Console.WriteLine("--- Ciclo For ---");
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine("Iteración número: " + i);
}

// 2. Bucle While
Console.WriteLine("--- Ciclo While ---");
int contador = 2;
while (contador > 0)
{
    Console.WriteLine("Cuenta regresiva: " + contador);
    contador--;
}

// 3. Bucle Do-While
Console.WriteLine("--- Ciclo Do-While ---");
bool repetir = false;
do
{
    Console.WriteLine("Este mensaje aparece al menos una vez.");
} while (repetir);

// 4. Bucle Foreach
Console.WriteLine("--- Ciclo Foreach ---");
string[] modulos = { "Módulo A", "Módulo B", "Módulo C" };
foreach (string mod in modulos)
{
    Console.WriteLine("Componente: " + mod);
}

11. Declaración y Uso de Funciones (Métodos estáticos)

Bloques de código reutilizables encapsulados dentro de una clase. Pueden recibir parámetros tipados por valor o referencia y retornar resultados explícitos.

Ejemplo de Métodos

class Program
{
    // Método que retorna un valor entero
    static int Sumar(int a, int b)
    {
        return a + b;
    }

    // Método sin valor de retorno (void)
    static void Saludar(string nombre)
    {
        Console.WriteLine("Hola, " + nombre + "!");
    }

    static void Main(string[] args)
    {
        Saludar("Estudiante");
        int resultado = Sumar(10, 20);
        Console.WriteLine("El resultado de la suma es: " + resultado);
    }
}
