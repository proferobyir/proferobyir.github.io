Unidad 1

Fundamentos de C# y Visual Studio 2012

Primero se construye el contexto: de dónde viene C#, qué ofrece C# 5.0 y cómo se estructura un programa antes de trabajar con datos.

1.1 ¿Qué es C#? — Origen y evolución

C# (pronunciado C-sharp) fue desarrollado a finales de la década de 1990 y principios de los 2000 por Microsoft, bajo el liderazgo de Anders Hejlsberg y su equipo de arquitectos de software.

Nació como un lenguaje moderno, orientado a objetos, fuertemente tipado y diseñado específicamente para ejecutarse sobre la plataforma .NET Framework. Su propósito principal fue ofrecer la potencia de desarrollo de sistemas de bajo nivel combinada con la alta productividad en la construcción de aplicaciones de escritorio, empresariales y servicios web.

Aspectos Clave de su Evolución

  • Raíces y Sintaxis: Hereda las convenciones de la familia de lenguajes C, proporcionando una sintaxis limpia, intuitiva y estructurada.
  • Estandarización Internacional: Fue aprobado oficialmente como estándar por la asociación ECMA (ECMA-334) y por la organización ISO (ISO/IEC 23270).
  • Plataforma .NET: Su ejecución se apoya en el CLR (Common Language Runtime), garantizando la gestión segura de memoria mediante el recolector de basura (Garbage Collector) y la interoperabilidad de componentes.

1.2 Características de C# 5.0 y Visual Studio 2012

C# 5.0 introdujo importantes avances orientados a la programación asíncrona (como las palabras clave async y await), consolidando un modelo de desarrollo robusto bajo las siguientes premisas estructurales:

  • Orientación a Objetos Pura: Todo tipo de dato, método y ejecutable se encapsula dentro de clases y estructuras controladas por espacios de nombres (namespace).
  • Tipado Estático y Seguro: Verificación estricta en tiempo de compilación, permitiendo al mismo tiempo la inferencia local de tipos mediante la palabra clave var.
  • Modelo de Ensamblados: Organización modular del código a través de ensamblados (.dll / .exe) gestionados por el CLR de .NET Framework 4.5.

1.3 Estructura básica de un programa en C#

Esqueleto fundamental que incluye la directiva de espacio de nombres, la clase contenedora y el punto de entrada principal Main. Para crear un proyecto de consola en Visual Studio 2012, siga estos pasos:

  2. Seleccione Archivo > Nuevo > Proyecto.
  3. En el cuadro de diálogo, elija Visual C# en el panel izquierdo y luego Aplicación de Consola.
  4. Asigne un nombre al proyecto y haga clic en Aceptar.

2.2 El tipo de dato char y caracteres Unicode

El tipo de dato char en C# se utiliza para representar un único carácter o símbolo según la codificación Unicode (UTF-16). Ocupa exactamente 16 bits (2 bytes) de memoria y su valor se asigna delimiando el carácter estrictamente entre comillas simples (' '), a diferencia de las cadenas de texto (string) que emplean comillas dobles (" ").

La clase estructural detrás de este tipo de dato primitivo es System.Char, la cual provee métodos estáticos esenciales para analizar y categorizar caracteres (por ejemplo, verificar si un carácter es una letra, un número o un espacio en blanco).

Secuencias de Escape Frecuentes

Las secuencias de escape permiten representar caracteres especiales que no se pueden escribir directamente en el código:

  • \': Comilla simple.
  • \": Comilla doble.
  • \\: Barra invertida (backslash).
  • \n: Salto de línea (New Line).
  • \t: Tabulación horizontal.
  • \0: Carácter nulo (Null).
  • \uXXXX: Especificación de carácter Unicode usando código hexadecimal de 4 dígitos.

Ejemplo Práctico de Variables Char y Métodos de System.Char

// 1. Declaración e inicialización básica de variables char
char letraInicial = 'A';
char simboloSuma = '+';
char digito = '7';

// 2. Representación mediante secuencias de escape y código Unicode
char saltoLinea = '\n';
char simboloArroba = '\u0040'; // Representa '@' en hexadecimal

// 3. Conversión implícita entre char e int (Código ASCII / UTF-16)
int codigoAscii = letraInicial; // Obtiene el valor numérico 65
char letraDesdeCodigo = (char)66; // Conversión explícita que da 'B'

// 4. Métodos útiles de la clase System.Char
char caracterEvaluar = 'e';

bool esLetra = char.IsLetter(caracterEvaluar);       // Resultado: true
bool esNumero = char.IsDigit(digito);               // Resultado: true
bool esEspacio = char.IsWhiteSpace(' ');           // Resultado: true
bool esMayuscula = char.IsUpper(caracterEvaluar);    // Resultado: false

// 5. Transformación de caso
char mayuscula = char.ToUpper(caracterEvaluar);     // Convierte a 'E'
char minuscula = char.ToLower('M');                 // Convierte a 'm'

Console.WriteLine("Carácter: " + caracterEvaluar + " | En mayúscula: " + mayuscula);
Console.WriteLine("Código ASCII de " + letraInicial + ": " + codigoAscii);

2.3 Operadores aritméticos, relacionales y lógicos

Los operadores permiten manipular los datos de las variables para realizar cálculos matemáticos y evaluaciones de condiciones:

  • Operadores Aritméticos: Utilizados para operaciones matemáticas básicas: suma (+), resta (-), multiplicación (*), división (/) y el módulo o residuo de una división (%).
  • Operadores Lógicos: Permiten combinar expresiones booleanas: la conjunción && (AND — verdadero si ambas partes se cumplen), la disyunción || (OR — verdadero si al menos una se cumple) y la negación ! (NOT — invierte el valor booleano).

Ejemplo de Operadores Aritméticos y Lógicos

// Operadores Aritméticos
int a = 10;
int b = 3;
int suma = a + b;       // Resultado: 13
int residuo = a % b;   // Resultado: 1 (el resto de 10 / 3)

// Operadores Lógicos
bool esAdulto = true;
bool tienePermiso = false;

// AND lógico (falso porque ambos no son verdaderos)
bool puedeAcceder = esAdulto && tienePermiso; 

// OR lógico (verdadero porque al menos uno es verdadero)
bool accesoAlternativo = esAdulto || tienePermiso;

Entrada y salida por consola

Una vez que existen variables y tipos de datos, se aprende a recibir información del usuario, convertirla y mostrar resultados.

3.1 Entrada y salida por consola

Para interactuar con la consola de comandos en C#, utilizamos los métodos estáticos provistos por la clase Console del espacio de nombres System:

  • Escritura: Console.WriteLine() muestra un texto y realiza un salto de línea. Console.Write() muestra el texto manteniendo el cursor en la misma línea.
  • Lectura: Console.ReadLine() captura la cadena de texto ingresada por el usuario hasta presionar Enter (retorna un tipo string).
  • Conversión de Datos: Dado que la consola recibe texto, se requiere la conversión explícita mediante métodos como int.Parse() o int.Parse() para operar con tipos numéricos.

Ejemplo Práctico de Entrada y Salida

// Escritura básica en consola
Console.Write("Ingrese su nombre: ");
string usuario = Console.ReadLine(); // Lectura de cadena

Console.Write("Ingrese su edad: ");
// Lectura y conversión explícita de string a int
int edadUsuario = int.Parse(Console.ReadLine());

// Mostrar el resultado concatenando variables
Console.WriteLine("Hola " + usuario + ", el año que viene tendrás " + (edadUsuario + 1) + " años.");
Console.ReadKey(); // Pausa la ejecución hasta presionar una tecla
Unidad 4

Toma de decisiones

Las condiciones aparecen después de conocer datos, operadores y entrada de información. Se empieza con if y se continúa con switch.

4.1 Estructuras condicionales: if, else if, else

Permiten ejecutar bloques de código específicos condicionados al resultado de expresiones booleanas:

  • if: Evalúa una condición inicial. Si es verdadera, ejecuta el bloque delimitado.
  • else if: Permite encadenar evaluaciones secuenciales adicionales.
  • else: Bloque de captura final que se ejecuta si ninguna condición previa resulta verdadera.

Ejemplo Completo de Estructura if - else if - else

int nota = 16;
bool asistenciaPerfecta = true;

if (nota >= 18 && asistenciaPerfecta)
{
    Console.WriteLine("¡Excelente! Obtentor de BECA de Honor.");
}
else if (nota >= 10 || asistenciaPerfecta)
{
    Console.WriteLine("Aprobado de manera regular o por asistencia.");
}
else
{
    Console.WriteLine("Reprobado. Debe cursar nuevamente la asignatura.");
}

4.2 Selección múltiple con switch

Evalúa una expresión contra múltiples valores constantes discretos definidos en bloques case.

Ejemplo de Switch

int diaSemana = 3;

switch (diaSemana)
{
    case 1:
        Console.WriteLine("Lunes");
        break;
    case 2:
        Console.WriteLine("Martes");
        break;
    case 3:
        Console.WriteLine("Miércoles");
        break;
    default:
        Console.WriteLine("Otro día");
        break;
}
Unidad 5

Procesamiento de texto

Antes de trabajar con colecciones, el estudiante aprende a manipular cadenas: buscar, extraer, reemplazar, dividir y validar texto.

5.1 Manejo de cadenas de texto (string)

En C#, las cadenas son objetos de la clase System.String que representan secuencias inmutables de caracteres. Debido a su inmutabilidad, ningún método altera la cadena original; en su lugar, procesan la información y retornan una nueva instancia de string con el resultado que puede guardarse en otra variable o reasignarse.

Encadenamiento de Métodos (Method Chaining): Gracias a que los métodos de cadenas devuelven un nuevo objeto string, es posible conectar múltiples métodos en una sola línea de código. La evaluación se realiza de izquierda a derecha, aplicando cada transformación al resultado del método anterior.

Resumen de Métodos Más Útiles

  • Transformación: ToLower(), ToUpper(), Trim().
  • Búsqueda y Verificación: StartsWith(), EndsWith(), Contains(), IndexOf(), LastIndexOf().
  • Extracción y Modificación: Substring(), Replace(), Remove().
  • Segmentación y Unión: Split(), string.Join().
  • Evaluación de Vacíos: string.IsNullOrWhiteSpace(), string.IsNullOrEmpty().

Ejemplos Prácticos de Métodos y Encadenamiento

string cadenaBase = "   Código de Producto: PRD-98765-VEN.xlsx   ";

// 1. Encadenamiento de Métodos (Method Chaining en una sola línea)
string limpioYFormateado = cadenaBase.Trim().ToLower().Replace(".xlsx", ".pdf");

// 2. Limpieza de espacios y conversión de caso
string textoLimpio = cadenaBase.Trim();
string enMinusculas = textoLimpio.ToLower();
string enMayusculas = textoLimpio.ToUpper();

// 3. Verificación de contenido (Retornan bool)
bool iniciaConCodigo = textoLimpio.StartsWith("Código");
bool esExcel = textoLimpio.EndsWith(".xlsx");
bool contienePRD = textoLimpio.Contains("PRD");

// 4. Encadenamiento en evaluaciones condicionales
string entradaCorreo = "   USUARIO@DOMINIO.COM  ";
if (entradaCorreo.Trim().ToLower().EndsWith(".com"))
{
    Console.WriteLine("Correo válido con dominio comercial.");
}

// 5. Búsqueda de posiciones
int posDosPuntos = textoLimpio.IndexOf(':');
int posUltimoGuion = textoLimpio.LastIndexOf('-');

// 6. Extracción de partes del string (Substring)
if (posDosPuntos != -1)
{
    string codigoExtraido = textoLimpio.Substring(posDosPuntos + 2, 17);
    string extension = textoLimpio.Substring(posUltimoGuion + 1);
}

// 7. Reemplazo y Eliminación
string textoSinPuntos = textoLimpio.Replace(".", "_");
string textoRecortado = textoLimpio.Remove(0, 20);

// 8. División (Split) y Combinación (Join)
string listaFrutas = "Manzana,Pera,Uva,Naranja";
string[] arregloFrutas = listaFrutas.Split(',');
string unionConGuiones = string.Join(" - ", arregloFrutas);

// 9. Validación de cadenas vacías o nulas (C# 5.0)
string entradaUsuario = "   ";
if (string.IsNullOrWhiteSpace(entradaUsuario))
{
    Console.WriteLine("La entrada está vacía, es nula o solo contiene espacios.");
}

// 10. Formateo de Cadenas compatible con C# 5.0 (string.Format)
string producto = "Laptop";
double precio = 850.75;
string reporte = string.Format("Producto: {0} | Precio: ${1:F2}", producto, precio);
Console.WriteLine(reporte);
Unidad 6

Repetición y estructuras de datos

Primero se aprenden los bucles porque permiten recorrer y procesar colecciones. Después se presentan arrays, matrices, listas, pilas y colas.

6.1 Estructuras de repetición: for, while, do-while y foreach

Permiten la ejecución iterativa de bloques de código bajo condiciones específicas de control:

  • Bucle for: Controla el número de iteraciones mediante una variable de inicialización, una condición límite y un paso de incremento/decremento.
  • Bucle while: Evalúa la condición booleana antes de cada ciclo; si es falsa inicialmente, el bloque se omite por completo.
  • Bucle do-while: Evalúa la condición después de ejecutar el bloque, garantizando al menos una ejecución inicial.
  • Bucle foreach: Recorre de forma directa y de sólo lectura los elementos contenidos en arreglos o colecciones tipadas sin requerir índices manuales.

Ejemplo de Bucles (for, while, do-while y foreach)

// 1. Bucle For
Console.WriteLine("--- Ciclo For ---");
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine("Iteración número: " + i);
}

// 2. Bucle While
Console.WriteLine("--- Ciclo While ---");
int contador = 2;
while (contador > 0)
{
    Console.WriteLine("Cuenta regresiva: " + contador);
    contador--;
}

// 3. Bucle Do-While
Console.WriteLine("--- Ciclo Do-While ---");
bool repetir = false;
do
{
    Console.WriteLine("Este mensaje aparece al menos una vez.");
} while (repetir);

// 4. Bucle Foreach
Console.WriteLine("--- Ciclo Foreach ---");
string[] modulos = { "Módulo A", "Módulo B", "Módulo C" };
foreach (string mod in modulos)
{
    Console.WriteLine("Componente: " + mod);
}

6.2 Arreglos y colecciones de datos

Las estructuras de datos permiten almacenar y gestionar conjuntos de elementos en memoria. En C# contamos con arreglos estáticos de tamaño fijo y colecciones genéricas dinámicas que se adaptan automáticamente al número de elementos.

Espacio de Nombres Requerido: Para utilizar colecciones genéricas como List<T>, Stack<T> y Queue<T>, es obligatorio incluir al inicio del archivo la directiva using System.Collections.Generic;.

1. Arreglos Unidimensionales (Vectores)

Poseen una dimensión finita y un índice basado en cero.

// Declaración e inicialización directa
string[] tecnologias = { "C#", "Visual Studio", "ADO.NET" };
Console.WriteLine("Primer elemento: " + tecnologias[0]);

// Declaración reservando tamaño fijo
int[] numeros = new int[3];
numeros[0] = 10;
numeros[1] = 20;
numeros[2] = 30;

2. Arreglos Multidimensionales (Matrices) y Dentados

C# soporta matrices rectangulares bidimensionales (filas y columnas) y arreglos de arreglos (arreglos dentados o jagged arrays).

// Matriz rectangular (2 filas x 3 columnas)
int[,] matriz = new int[2, 3] { 
    { 1, 2, 3 }, 
    { 4, 5, 6 } 
};
Console.WriteLine("Elemento fila 1, col 2: " + matriz[1, 2]); // Imprime 6

// Arreglo Dentado (Jagged Array): Arreglo cuyos elementos son otros arreglos
int[][] dentado = new int[2][];
dentado[0] = new int[] { 1, 2 };
dentado[1] = new int[] { 3, 4, 5 };
Console.WriteLine("Elemento del arreglo dentado: " + dentado[1][2]); // Imprime 5

3. Listas Dinámicas (List<T>)

Permiten agregar, eliminar y buscar elementos de manera dinámica sin definir un límite predeterminado.

List<string> estudiantes = new List<string>();
estudiantes.Add("Ana");
estudiantes.Add("Carlos");
estudiantes.Add("Beatriz");

estudiantes.Remove("Carlos"); // Remueve por valor

foreach (string est in estudiantes)
{
    Console.WriteLine("Estudiante: " + est);
}

4. Pilas (Stack<T>) y Colas (Queue<T>)

Estructuras dinámicas que ordenan el procesamiento de sus elementos mediante políticas específicas:

  • Stack<T> (Pila): Estructura de tipo LIFO (Last In, First Out - Último en entrar, primero en salir). Usa Push() para agregar y Pop() para retirar.
  • Queue<T> (Cola): Estructura de tipo FIFO (First In, First Out - Primero en entrar, primero en salir). Usa Enqueue() para encolar y Dequeue() para desencolar.
// Uso de Pilas (Stack - LIFO)
Stack<string> historialNavegacion = new Stack<string>();
historialNavegacion.Push("Google.com");
historialNavegacion.Push("Github.com");
historialNavegacion.Push("StackOverflow.com");

string ultimaPagina = historialNavegacion.Pop(); // Extrae "StackOverflow.com"
Console.WriteLine("Página removida de la pila: " + ultimaPagina);

// Uso de Colas (Queue - FIFO)
Queue<string> colaImpresion = new Queue<string>();
colaImpresion.Enqueue("Documento1.pdf");
colaImpresion.Enqueue("Reporte.xlsx");
colaImpresion.Enqueue("Plano.dwg");

string primerDocumento = colaImpresion.Dequeue(); // Extrae "Documento1.pdf"
Console.WriteLine("Atendiendo en la cola: " + primerDocumento);
Unidad 7

Métodos y modularización

Con las bases del lenguaje consolidadas, el código se divide en métodos reutilizables: parámetros, retorno, ref/out, sobrecarga, alcance y recursividad.

7.1 Métodos y modularización

Un método es un bloque de código con nombre que encapsula una tarea específica, permitiendo su reutilización, modularidad y mantenimiento. En C#, todos los métodos deben declararse dentro de una clase o estructura.

12.1. Sintaxis General de un Método

[modificador_acceso] [static] tipo_retorno NombreMetodo([parámetros])
{
    // Cuerpo del método
    [return valor;]
}
  • modificador_acceso: public, private, protected, internal. Controla la visibilidad.
  • static: Indica que el método pertenece a la clase, no a una instancia.
  • tipo_retorno: Tipo de dato devuelto (int, string, void, etc.).
  • NombreMetodo: Identificador en PascalCase por convención.
  • parámetros: Lista opcional de variables tipadas que recibe el método.

12.2. Métodos static vs Métodos de Instancia

  • Método static: Se invoca directamente desde la clase sin crear objetos. No puede acceder a miembros de instancia.
  • Método de instancia: Requiere crear un objeto con new para poder invocarlo. Puede acceder a campos y propiedades del objeto.
class Calculadora
{
    // Método estático: no necesita instancia
    public static int Sumar(int a, int b)
    {
        return a + b;
    }

    // Método de instancia: necesita un objeto Calculadora
    public int Multiplicar(int a, int b)
    {
        return a * b;
    }
}

class Program
{
    static void Main(string[] args)
    {
        // Invocación estática
        int suma = Calculadora.Sumar(5, 3);

        // Invocación de instancia
        Calculadora calc = new Calculadora();
        int producto = calc.Multiplicar(5, 3);

        Console.WriteLine("Suma: " + suma + " | Producto: " + producto);
    }
}

12.3. Parámetros por Valor, por Referencia (ref) y de Salida (out)

Modificador Comportamiento
(ninguno) Por valor: se copia el valor. Cambios internos no afectan al original.
ref Por referencia: el método puede modificar la variable original. Debe inicializarse antes.
out Salida: el método debe asignarle un valor antes de retornar. No requiere inicialización previa. 
class Program
{
    // Por valor: no modifica el original
    static void DuplicarPorValor(int numero)
    {
        numero = numero * 2;
        Console.WriteLine("Dentro del método (valor): " + numero);
    }

    // Por referencia: modifica el original
    static void DuplicarPorReferencia(ref int numero)
    {
        numero = numero * 2;
    }

    // Parámetro de salida: obliga a asignar valor
    static bool TryDividir(int dividendo, int divisor, out double resultado)
    {
        if (divisor == 0)
        {
            resultado = 0;
            return false;
        }
        resultado = (double)dividendo / divisor;
        return true;
    }

    static void Main(string[] args)
    {
        int a = 10;
        DuplicarPorValor(a);
        Console.WriteLine("Después por valor: " + a); // Sigue siendo 10

        DuplicarPorReferencia(ref a);
        Console.WriteLine("Después por referencia: " + a); // Ahora es 20

        // C# 5.0: la variable out se declara ANTES de la llamada
        double cociente;
        if (TryDividir(20, 4, out cociente))
        {
            Console.WriteLine("Cociente: " + cociente);
        }
    }
}

12.4. Parámetros Opcionales y Arreglo params

Parámetros opcionales: Se definen con un valor predeterminado. Deben ubicarse al final de la lista.

static void Presentar(string nombre, string titulo = "Estudiante")
{
    Console.WriteLine("Hola, " + titulo + " " + nombre);
}

// Invocaciones válidas:
Presentar("Ana");                    // Usa "Estudiante"
Presentar("Luis", "Ingeniero");      // Usa "Ingeniero"

Arreglo params: Permite recibir un número variable de argumentos del mismo tipo.

static int SumarTodos(params int[] numeros)
{
    int total = 0;
    foreach (int n in numeros)
    {
        total += n;
    }
    return total;
}

// Invocaciones válidas:
int r1 = SumarTodos(1, 2, 3);
int r2 = SumarTodos(10, 20, 30, 40, 50);
int r3 = SumarTodos(); // Arreglo vacío

12.5. Sobrecarga de Métodos (Overloading)

C# permite definir varios métodos con el mismo nombre pero distinta firma (número o tipo de parámetros). El compilador resuelve cuál invocar según los argumentos.

class Area
{
    public static double Calcular(double lado)
    {
        return lado * lado; // Cuadrado
    }

    public static double Calcular(double baseRect, double altura)
    {
        return baseRect * altura; // Rectángulo
    }

    public static double Calcular(double radio, bool esCirculo)
    {
        if (esCirculo)
        {
            return Math.PI * radio * radio; // Círculo
        }
        return 0;
    }
}

// Uso:
Console.WriteLine(Area.Calcular(5));           // 25
Console.WriteLine(Area.Calcular(4, 6));        // 24
Console.WriteLine(Area.Calcular(3, true));     // 28.27...

12.6. Recursividad

Un método recursivo se invoca a sí mismo con un caso base que detiene la recursión. 

static long Factorial(int n)
{
    if (n <= 1) return 1;          // Caso base
    return n * Factorial(n - 1);   // Llamada recursiva
}

static int Fibonacci(int n)
{
    if (n <= 1) return n;
    return Fibonacci(n - 1) + Fibonacci(n - 2);
}

// Uso:
Console.WriteLine("Factorial de 5: " + Factorial(5));   // 120
Console.WriteLine("Fibonacci(7): " + Fibonacci(7));      // 13

12.7. Ámbito y Duración de Variables

  • Variables locales: declaradas dentro del método, existen solo durante su ejecución.
  • Parámetros: locales al método.
  • Campos estáticos: persisten durante toda la vida de la aplicación.
class Contador
{
    private static int totalLlamadas = 0; // Campo estático persistente

    public static void Registrar()

        totalLlamadas++;
        Console.WriteLine("Llamadas acumuladas: " + totalLlamadas);

12.8. Ejemplo Integrador: Calculadora con Múltiples Métodos

class CalculadoraCompleta
{
    public static double Sumar(double a, double b)
    {
        return a + b;
    }

    public static double Restar(double a, double b)
    {
        return a - b;
    }

    public static double Multiplicar(double a, double b)
    {
        return a * b;
    }

    public static bool Dividir(double a, double b, out double resultado)
    {
        if (b == 0)
        {
            resultado = 0;
            return false;
        }
        resultado = a / b;
        return true;
    }

    public static long Potencia(int baseNum, int exponente)
    {
        long resultado = 1;
        for (int i = 0; i < exponente; i++)
        {
            resultado *= baseNum;
        }
        return resultado;
    }
}

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Suma: " + CalculadoraCompleta.Sumar(10, 5));
        Console.WriteLine("Resta: " + CalculadoraCompleta.Restar(10, 5));
        Console.WriteLine("Multiplicación: " + CalculadoraCompleta.Multiplicar(10, 5));

        // C# 5.0: variable out declarada antes de la llamada
        double cociente;
        if (CalculadoraCompleta.Dividir(10, 0, out cociente))
        {
            Console.WriteLine("División: " + cociente);
        }
        else
        {
            Console.WriteLine("Error: división entre cero.");
        }

        Console.WriteLine("2^10 = " + CalculadoraCompleta.Potencia(2, 10));
    }
}

12.9. Ejemplo con Múltiples Valores de Retorno mediante out

En C# 5.0 no existen las tuplas; para devolver varios valores se usan parámetros out. 

static void CalcularEstadisticas(int[] datos, out int minimo, out int maximo, out double promedio)
{
    minimo = datos[0];
    maximo = datos[0];
    int suma = 0;

    for (int i = 0; i < datos.Length; i++)
    {
        if (datos[i] < minimo) minimo = datos[i];
        if (datos[i] > maximo) maximo = datos[i];
        suma += datos[i];
    }
    promedio = (double)suma / datos.Length;
}

// Uso:
int[] valores = { 15, 8, 21, 4, 42 };
int min, max;
double prom;
CalcularEstadisticas(valores, out min, out max, out prom);
Console.WriteLine("Mín: " + min + " | Máx: " + max + " | Prom: " + prom.ToString("F2"));
Unidad 8

LINQ: consultar y transformar colecciones

LINQ se presenta al final porque combina colecciones, métodos, expresiones lambda y procesamiento de datos.

8.1 Consultas integradas con LINQ

LINQ es un conjunto de extensiones del lenguaje C# que permite realizar consultas tipadas sobre cualquier colección que implemente IEnumerable<T> (arreglos, List<T>, Dictionary<K,V>, DataSet, XML, etc.). Fue introducido en .NET 3.5 y perfeccionado en .NET 4.5 (Visual Studio 2012).

Ventajas:

  • Sintaxis unificada para distintas fuentes de datos.
  • Verificación en tiempo de compilación (tipado fuerte).
  • IntelliSense completo en Visual Studio.
  • Composición de consultas mediante encadenamiento.

Espacio de Nombres Requerido: Para habilitar el uso de LINQ en C# 5.0, agregue al inicio del archivo la directiva using System.Linq;.

13.1. Dos Sintaxis Equivalentes

A) Sintaxis de Consulta (Query Syntax): similar a SQL, más legible para filtros complejos.

B) Sintaxis de Métodos (Method Syntax): usa métodos de extensión y expresiones lambda, más compacta y potente.

// Se requiere: using System.Linq;

int[] numeros = { 5, 12, 8, 21, 3, 17, 30, 4 };

// Query Syntax
var mayoresQuery = from n in numeros
                   where n > 10
                   orderby n descending
                   select n;

// Method Syntax (equivalente)
var mayoresMetodo = numeros.Where(n => n > 10)
                           .OrderByDescending(n => n);

// Ambas producen el mismo resultado
foreach (int n in mayoresQuery)
{
    Console.WriteLine(n);
}

13.2. Filtrado (Where)

string[] frutas = { "Manzana", "Pera", "Mango", "Melón", "Uva" };

var conM = frutas.Where(f => f.StartsWith("M"));
foreach (string f in conM)
{
    Console.WriteLine(f); // Manzana, Mango, Melón
}

13.3. Proyección (Select)

Transforma cada elemento en otro tipo o forma.

var longitudes = frutas.Select(f => f.Length);
foreach (int len in longitudes)
{
    Console.WriteLine("Longitud: " + len);
}

// Proyección a tipo anónimo (C# 3.0+)
var resumen = frutas.Select(f => new { Nombre = f, Letras = f.Length });
foreach (var item in resumen)
{
    Console.WriteLine(item.Nombre + " -> " + item.Letras);
}

13.4. Ordenamiento (OrderBy, ThenBy)

var ordenadas = frutas.OrderBy(f => f.Length)
                      .ThenBy(f => f); // Desempate alfabético

13.5. Agrupación (GroupBy)

var porLongitud = frutas.GroupBy(f => f.Length);

foreach (var grupo in porLongitud)
{
    Console.WriteLine("Longitud " + grupo.Key + ":");
    foreach (string f in grupo)
    {
        Console.WriteLine("  - " + f);
    }
}

13.6. Partición (Take, Skip)

var primerosTres = frutas.Take(3);
var saltandoDos  = frutas.Skip(2);
var rango        = frutas.Skip(1).Take(2);

13.7. Agregación (Count, Sum, Min, Max, Average) 

int[] ventas = { 120, 340, 560, 230, 780 };

Console.WriteLine("Total: "    + ventas.Sum());
Console.WriteLine("Mínimo: "   + ventas.Min());
Console.WriteLine("Máximo: "   + ventas.Max());
Console.WriteLine("Promedio: " + ventas.Average().ToString("F2"));
Console.WriteLine("Cantidad: " + ventas.Count());
Console.WriteLine("Mayores a 300: " + ventas.Count(v => v > 300));

13.8. Búsqueda de Elementos (First, FirstOrDefault, Single, Any, All) 

int primero     = ventas.First();                    // Lanza excepción si vacío
int primeroDef  = ventas.FirstOrDefault();           // Devuelve 0 si vacío
bool hayAltos   = ventas.Any(v => v > 700);          // true
bool todosPos   = ventas.All(v => v > 0);            // true

// Single: exactamente un elemento que cumpla
try
{
    int unico = ventas.Single(v => v == 560);
    Console.WriteLine("Encontrado: " + unico);
}
catch (InvalidOperationException ex)
{
    Console.WriteLine("No hay exactamente uno: " + ex.Message);
}

13.9. Operadores de Conjuntos (Distinct, Union, Intersect, Except) 

int[] A = { 1, 2, 3, 4, 5 };
int[] B = { 4, 5, 6, 7, 8 };

var union        = A.Union(B);        // 1,2,3,4,5,6,7,8
var interseccion = A.Intersect(B);    // 4,5
var diferencia   = A.Except(B);       // 1,2,3
var distintos    = new[] { 1, 1, 2, 2, 3 }.Distinct(); // 1,2,3

13.10. Expresiones Lambda en LINQ

Una expresión lambda es una función anónima compacta. Sintaxis: (parámetros) => expresión_o_bloque. 

// Lambda de expresión
Func<int, int> cuadrado = x => x * x;

// Lambda de bloque
Func<int, int, int> sumar = (a, b) =>
{
    int resultado = a + b;
    return resultado;
};

// Uso en LINQ
var pares = numeros.Where(n => n % 2 == 0);
var ordenados = numeros.OrderBy(n => n);

13.11. Evaluación Diferida (Deferred Execution)

Las consultas LINQ no se ejecutan al definirse, sino al iterarlas (foreach) o al invocar un operador de agregación. Esto permite componer consultas eficientemente.

var consulta = numeros.Where(n => n > 10); // Aún no se ejecuta

// Se ejecuta aquí:
foreach (int n in consulta)
{
    Console.WriteLine(n);
}

// También se ejecuta aquí:
int total = consulta.Count();

Forzar ejecución inmediata: ToList(), ToArray(), ToDictionary(). 

List<int> listaInmediata = numeros.Where(n => n > 10).ToList();

13.13. LINQ con Join (Combinación de Colecciones)

class Cliente
{
    public int Id { get; set; }
    public string Nombre { get; set; }
}

class Pedido
{
    public int Id { get; set; }
    public int ClienteId { get; set; }
    public double Monto { get; set; }
}

List<Cliente> clientes = new List<Cliente>();
clientes.Add(new Cliente { Id = 1, Nombre = "Ana" });
clientes.Add(new Cliente { Id = 2, Nombre = "Luis" });

List<Pedido> pedidos = new List<Pedido>();
pedidos.Add(new Pedido { Id = 101, ClienteId = 1, Monto = 150.00 });
pedidos.Add(new Pedido { Id = 102, ClienteId = 1, Monto = 89.90  });
pedidos.Add(new Pedido { Id = 103, ClienteId = 2, Monto = 320.50 });

var reporte = from c in clientes
              join p in pedidos on c.Id equals p.ClienteId
              select new
              {
                  Cliente = c.Nombre,
                  Pedido  = p.Id,
                  Monto   = p.Monto
              };

foreach (var r in reporte)
{
    Console.WriteLine(r.Cliente + " - Pedido #" + r.Pedido + " - $" + r.Monto);
}

13.14. Buenas Prácticas con LINQ

  1. Usar Any() en lugar de Count() > 0 para verificar existencia (más eficiente).
  2. Evitar múltiples enumeraciones: materializar con ToList() si se reutilizará.
  3. Preferir Method Syntax para consultas simples y encadenamientos largos.
  4. Usar Query Syntax cuando haya join, group by o múltiples from.
  5. No abusar de LINQ en bucles críticos: puede introducir sobrecarga.
  6. Nombrar variables de rango descriptivamente: from producto in inventario en lugar de from p in inv.
  7. Aprovechar la evaluación diferida para construir consultas dinámicas.
  8. Usar string.Format() para dar formato a salidas (C# 5.0 no tiene interpolación).

13.15. Ejemplo Integrador: Sistema de Reportes con LINQ

// using System;
// using System.Collections.Generic;
// using System.Linq;

class Estudiante
{
    public string Nombre { get; set; }
    public string Carrera { get; set; }
    public double Promedio { get; set; }
    public int Edad { get; set; }
}

class Program
{
    static void Main(string[] args)
    {
        List<Estudiante> estudiantes = new List<Estudiante>();
        estudiantes.Add(new Estudiante { Nombre = "Ana",    Carrera = "Sistemas",   Promedio = 18.5, Edad = 21 });
        estudiantes.Add(new Estudiante { Nombre = "Luis",   Carrera = "Sistemas",   Promedio = 15.2, Edad = 23 });
        estudiantes.Add(new Estudiante { Nombre = "María",  Carrera = "Industrial", Promedio = 17.8, Edad = 22 });
        estudiantes.Add(new Estudiante { Nombre = "Carlos", Carrera = "Industrial", Promedio = 12.4, Edad = 20 });
        estudiantes.Add(new Estudiante { Nombre = "Sofía",  Carrera = "Sistemas",   Promedio = 19.1, Edad = 21 });
        estudiantes.Add(new Estudiante { Nombre = "Pedro",  Carrera = "Civil",      Promedio = 14.0, Edad = 24 });

        // 1. Estudiantes destacados (promedio >= 17)
        var destacados = estudiantes
            .Where(e => e.Promedio >= 17)
            .OrderByDescending(e => e.Promedio)
            .Select(e => new { e.Nombre, e.Promedio });

        Console.WriteLine("--- Destacados ---");
        foreach (var e in destacados)
        {
            Console.WriteLine(e.Nombre + " (" + e.Promedio + ")");
        }

        // 2. Promedio general por carrera
        var porCarrera = estudiantes
            .GroupBy(e => e.Carrera)
            .Select(g => new
            {
                Carrera  = g.Key,
                Cantidad = g.Count(),
                Promedio = g.Average(e => e.Promedio),
                Mejor    = g.Max(e => e.Promedio)
            });

        Console.WriteLine("--- Resumen por carrera ---");
        foreach (var c in porCarrera)
        {
            Console.WriteLine(c.Carrera + ": " + c.Cantidad + " alumnos | Prom: "
                              + c.Promedio.ToString("F2") + " | Mejor: " + c.Mejor);
        }

        // 3. Top 3 por promedio
        var top3 = estudiantes.OrderByDescending(e => e.Promedio).Take(3);
        Console.WriteLine("--- Top 3 ---");
        foreach (var e in top3)
        {
            Console.WriteLine(e.Nombre + " -> " + e.Promedio);
        }

        // 4. ¿Hay algún reprobado (promedio < 13)?
        bool hayReprobados = estudiantes.Any(e => e.Promedio < 13);
        Console.WriteLine("\n¿Hay reprobados? " + (hayReprobados ? "Sí" : "No"));

        // 5. Estadísticas globales
        Console.WriteLine("\nTotal: " + estudiantes.Count()
                          + " | Promedio global: " + estudiantes.Average(e => e.Promedio).ToString("F2")
                          + " | Edad máxima: " + estudiantes.Max(e => e.Edad));
    }
}
