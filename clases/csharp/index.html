1. El Origen del Lenguaje C#

C# (pronunciado C-sharp) fue desarrollado a finales de la década de 1990 y principios de los 2000 por Microsoft, bajo el liderazgo de Anders Hejlsberg y su equipo, creadores también de lenguajes como Delphi y Turbo Pascal.

Nació como parte de la iniciativa .NET Framework con el propósito de combinar la potencia de C y C++ con la productividad y facilidad de desarrollo de lenguajes como Visual Basic y Java. Su diseño se consolidó como un lenguaje moderno, orientado a objetos, de fuerte tipado y altamente integrado con los servicios de Windows y la Web.

Aspectos Clave de su Evolución

  • Inspiración y Raíces: Hereda la sintaxis básica de la familia C (C, C++, Java), lo que facilita su aprendizaje a cualquier programador con bases previas.
  • Estandarización: Fue aprobado oficialmente como estándar por la ECMA (ECMA-334) y por la organización ISO (ISO/IEC 23270).
  • Evolución con .NET: Su plataforma centralizó un entorno seguro de ejecución mediante el CLR (Common Language Runtime), permitiendo la interoperabilidad entre diferentes lenguajes de programación.

2. Ventajas de C# en Visual Studio 2012 y su cercanía con Java

La versión de C# utilizada en Visual Studio 2012 (C# 5.0) comparte una arquitectura sintáctica sumamente cercana a Java, facilitando la transición entre ambos lenguajes:

  • Orientación a Objetos Estricta: Todo método y variable pertenece a una clase; no hay funciones globales sueltas.
  • Tipado Estático: Requiere definición explícita o inferencia segura (var).
  • Namespaces vs Packages: Los espacios de nombres en C# cumplen exactamente la misma función organizativa que los paquetes en Java.
  • Gestión de Memoria: Recolector de basura (Garbage Collector) automático idéntico conceptualmente al de la JVM.

5. Operadores Aritméticos y Operadores Lógicos

Los operadores permiten manipular los datos de las variables para realizar cálculos matemáticos y evaluaciones de condiciones:

  • Operadores Aritméticos: Utilizados para operaciones matemáticas básicas: suma (+), resta (-), multiplicación (*), división (/) y el módulo o residuo de una división (%).
  • Operadores Lógicos: Permiten combinar expresiones booleanas: la conjunción && (AND — verdadero si ambas partes se cumplen), la disyunción || (OR — verdadero si al menos una se cumple) y la negación ! (NOT — invierte el valor booleano).

Ejemplo de Operadores Aritméticos y Lógicos

// Operadores Aritméticos
int a = 10;
int b = 3;
int suma = a + b;       // Resultado: 13
int residuo = a % b;   // Resultado: 1 (el resto de 10 / 3)

// Operadores Lógicos
bool esAdulto = true;
bool tienePermiso = false;

// AND lógico (falso porque ambos no son verdaderos)
bool puedeAcceder = esAdulto && tienePermiso; 

// OR lógico (verdadero porque al menos uno es verdadero)
bool accesoAlternativo = esAdulto || tienePermiso;

6. Lectura y Escritura por Consola

Para interactuar con la consola de comandos en C#, utilizamos los métodos estáticos de la clase Console del espacio de nombres System:

  • Escritura: Console.WriteLine() muestra un texto y realiza un salto de línea. Por su parte, Console.Write() muestra el texto manteniendo el cursor en la misma línea.
  • Lectura: Console.ReadLine() captura la cadena de texto ingresada por el usuario hasta presionar Enter. Su retorno es siempre de tipo string.
  • Conversión de Datos: Dado que Console.ReadLine() devuelve texto, se requiere convertir la entrada mediante métodos como Convert.ToInt32(), int.Parse() o Convert.ToDouble() para trabajar con tipos numéricos.

Ejemplo Práctico de Entrada y Salida

// Escritura básica en consola
Console.Write("Ingrese su nombre: ");
string usuario = Console.ReadLine(); // Lectura de cadena

Console.Write("Ingrese su edad: ");
// Lectura y conversión explícita de string a int
int edadUsuario = Convert.ToInt32(Console.ReadLine());

// Mostrar el resultado concatenando variables
Console.WriteLine("Hola " + usuario + ", el año que viene tendrás " + (edadUsuario + 1) + " años.");
Console.ReadKey(); // Pausa la ejecución hasta presionar una tecla

7. Estructuras Condicionales (if, else if, else)

Las estructuras condicionales permiten ejecutar bloques de código específicos basándose en la evaluación de expresiones booleanas (true o false):

  • if: Evalúa una condición inicial. Si es verdadera, ejecuta el bloque delimitado entre llaves.
  • else if: Permite encadenar evaluaciones secuenciales si la condición previa resulta falsa.
  • else: Bloque opcional de captura final que se ejecuta únicamente cuando ninguna de las condiciones anteriores fue verdadera.

Ejemplo Completo de Estructura if - else if - else

int nota = 16;
bool asistenciaPerfecta = true;

// Evaluación utilizando operadores lógicos
if (nota >= 18 && asistenciaPerfecta)
{
    Console.WriteLine("¡Excelente! Obtentor de BECA de Honor.");
}
else if (nota >= 10 || asistenciaPerfecta)
{
    Console.WriteLine("Aprobado de manera regular o por asistencia.");
}
else
{
    Console.WriteLine("Reprobado. Debe cursar nuevamente la asignatura.");
}

8. Estructura de Selección Múltiple (switch)

Ideal para evaluar una variable contra múltiples valores discretos posibles.

Ejemplo de Switch

int diaSemana = 3;

switch (diaSemana)
{
    case 1:
        Console.WriteLine("Lunes");
        break;
    case 2:
        Console.WriteLine("Martes");
        break;
    case 3:
        Console.WriteLine("Miércoles");
        break;
    default:
        Console.WriteLine("Otro día");
        break;
}

9. Arreglos (Arrays) y Listas Dinámicas (List<T>)

Los arreglos tienen tamaño fijo definido en su creación. Las listas dinámicas (provenientes del espacio de nombres System.Collections.Generic) permiten redimensionamiento automático, equivalente a ArrayList en Java.

Ejemplo de Arreglos y Listas

// 1. Arreglo unidimensional de tamaño fijo
string[] tecnologias = { "C#", "Java", "PHP" };
Console.WriteLine("Primer elemento del arreglo: " + tecnologias[0]);

// 2. Lista dinámica (Requiere using System.Collections.Generic;)
List<string> estudiantes = new List<string>();
estudiantes.Add("Ana");
estudiantes.Add("Carlos");

// Recorrer la lista con foreach
foreach (string est in estudiantes)
{
    Console.WriteLine("Estudiante: " + est);
}

10. Estructuras de Repetición (Bucles o Ciclos)

Los bucles permiten ejecutar un bloque de código de forma repetitiva mientras se cumpla una condición o durante un número determinado de iteraciones:

  • Bucle for: Ideal cuando se conoce de antemano el número exacto de repeticiones. Controla la iteración mediante una variable de inicialización, una condición y un incremento/decremento.
  • Bucle while: Evalúa una condición booleana antes de cada ejecución. Si la condición es falsa desde el inicio, el bloque no se ejecuta nunca.
  • Bucle do-while: Similar al while, pero evalúa la condición después de ejecutar el bloque, garantizando que el código interno se ejecute al menos una vez.
  • Bucle foreach: Diseñado específicamente para recorrer elementos de arreglos o colecciones de manera sencilla y directa, sin necesidad de gestionar índices manualmente.

Ejemplo de Bucles (for, while, do-while y foreach)

// 1. Bucle For (Contar del 1 al 3)
Console.WriteLine("--- Ciclo For ---");
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine("Iteración número: " + i);
}

// 2. Bucle While (Contador descendente)
Console.WriteLine("--- Ciclo While ---");
int contador = 2;
while (contador > 0)
{
    Console.WriteLine("Cuenta regresiva: " + contador);
    contador--;
}

// 3. Bucle Do-While (Ejecuta al menos una vez)
Console.WriteLine("--- Ciclo Do-While ---");
bool repetir = false;
do
{
    Console.WriteLine("Este mensaje aparece al menos una vez.");
} while (repetir);

// 4. Bucle Foreach (Recorrer un arreglo)
Console.WriteLine("--- Ciclo Foreach ---");
string[] frutas = { "Manzana", "Pera", "Uva" };
foreach (string fruta in frutas)
{
    Console.WriteLine("Fruta: " + fruta);
}

11. Declaración y Uso de Funciones (Métodos)

Bloques de código reutilizables definidos dentro de una clase. Pueden recibir parámetros y retornar valores, de manera idéntica a los métodos estáticos en Java.

Ejemplo de Funciones

class Program
{
    // Función que retorna la suma de dos enteros
    static int Sumar(int a, int b)
    {
        return a + b;
    }

    // Función sin valor de retorno (void)
    static void Saludar(string nombre)
    {
        Console.WriteLine("Hola, " + nombre + "!");
    }

    static void Main(string[] args)
    {
        Saludar("Profesor");
        int resultado = Sumar(10, 20);
        Console.WriteLine("El resultado de la suma es: " + resultado);
    }
}
