Guía Práctica de Métodos LINQ en C# 5

Esta guía muestra el uso de LINQ aplicando sintaxis compatible con C# 5 (Visual Studio 2012) usando tipos concretos como arreglos, listas, diccionarios y objetos de clases públicas.

1. LINQ en Colecciones Simples (Arreglos y Listas)

1.1. .Where() — Filtrado

Filtra elementos que cumplen una condición especificada.

int[] numeros = new int[] { 5, 12, 8, 20, 3, 15 };

// Obtener solo los números mayores a 10 y convertirlos a lista
List<int> mayores = numeros.Where(n => n > 10).ToList();
// Resultado: { 12, 20, 15 }

1.2. .Select() — Proyección / Transformación

Transforma cada elemento de la colección en un nuevo valor o formato.

int[] numeros = new int[] { 1, 2, 3, 4 };

// Multiplicar cada número por 2 y guardar en arreglo
int[] dobles = numeros.Select(n => n * 2).ToArray();
// Resultado: { 2, 4, 6, 8 }

1.3. .Average(), .Sum(), .Min(), .Max(), .Count() — Cálculos y Agregación

Realizan operaciones matemáticas directas sobre colecciones numéricas.

float[] notas = new float[] { 14.5f, 18.0f, 10.0f, 16.5f };

float promedio = notas.Average(); // 14.75f
float sumaTotal = notas.Sum();     // 59.0f
float notaMinima = notas.Min();   // 10.0f
float notaMaxima = notas.Max();   // 18.0f
int totalNotas = notas.Count();   // 4

1.4. .OrderBy() y .OrderByDescending() — Ordenamiento

Ordenan los elementos de forma ascendente o descendente.

List<string> nombres = new List<string>() { "Carlos", "Ana", "Beatriz" };

List<string> ordenados = nombres.OrderBy(n => n).ToList();
// Resultado: { "Ana", "Beatriz", "Carlos" }

List<string> invertidos = nombres.OrderByDescending(n => n).ToList();
// Resultado: { "Carlos", "Beatriz", "Ana" }

1.5. .FirstOrDefault(), .Any(), .All() — Búsqueda y Verificación

Buscan elementos específicos o evalúan condiciones lógicas.

int[] valores = new int[] { 4, 8, 15, 16, 23, 42 };

// Devuelve el primer valor mayor a 20 o 0 si no existe
int primero = valores.FirstOrDefault(v => v > 20); // 23

// Evalúa si EXISTE al menos un elemento que cumpla la condición
bool hayPares = valores.Any(v => v % 2 == 0); // true

// Evalúa si TODOS los elementos cumplen la condición
bool todosPositivos = valores.All(v => v > 0); // true

2. LINQ en Diccionarios (Dictionary<TKey, TValue>)

2.1. Consulta sobre Claves y Valores

LINQ puede aplicarse sobre `.Keys`, `.Values` o sobre la pareja `KeyValuePair` del diccionario.

Dictionary<string, float> registroNotas = new Dictionary<string, float>();
registroNotas.Add("V-123456", 18.5f);
registroNotas.Add("V-987654", 09.0f);
registroNotas.Add("V-456789", 15.0f);

// 1. Obtener el promedio de todas las notas guardadas
float promedioGeneral = registroNotas.Values.Average(); // 14.16f

// 2. Obtener una lista con las cédulas (Keys) de estudiantes aprobados (nota >= 10)
List<string> cedulasAprobados = registroNotas
    .Where(pareja => pareja.Value >= 10.0f)
    .Select(pareja => pareja.Key)
    .ToList();
// Resultado: { "V-123456", "V-456789" }

3. LINQ con Clases y Objetos Públicos

Definición de la Clase Pública: Toda la sección siguiente utiliza la clase Estudiante definida a continuación.

3.1. Definición de la Clase Estudiante (Compatible C# 5)

public class Estudiante
{
    public string Nombre { get; set; }
    public string Cedula { get; set; }
    public float[] Notas { get; set; }
    public float Promedio { get; set; }

    public Estudiante(string nombre, string cedula, float[] notas)
    {
        this.Nombre = nombre;
        this.Cedula = cedula;
        this.Notas = notas;
        // LINQ calcula el promedio dentro del constructor
        this.Promedio = notas.Average();
    }
}

3.2. Operaciones con Lista de Objetos Públicos

// Creación de objetos públicos
List<Estudiante> grupo = new List<Estudiante>();

grupo.Add(new Estudiante("Ana Perez", "V-111", new float[] { 18f, 19f, 20f }));
grupo.Add(new Estudiante("Juan Gomez", "V-222", new float[] { 08f, 09f, 10f }));
grupo.Add(new Estudiante("Maria Silva", "V-333", new float[] { 15f, 14f, 16f }));

// 1. WHERE: Obtener solo los objetos de estudiantes aprobados (Promedio >= 10)
List<Estudiante> aprobados = grupo.Where(e => e.Promedio >= 10f).ToList();

// 2. SELECT: Extraer únicamente los nombres de todos los estudiantes
List<string> listaNombres = grupo.Select(e => e.Nombre).ToList();

// 3. ORDERBYDESCENDING: Ordenar los objetos por promedio de mayor a menor
List<Estudiante> ranking = grupo.OrderByDescending(e => e.Promedio).ToList();

// 4. FIRSTORDEFAULT: Buscar un estudiante por número de cédula
Estudiante buscado = grupo.FirstOrDefault(e => e.Cedula == "V-222");

// 5. AVERAGE: Calcular el promedio general de la sección entera
float promedioSeccion = grupo.Average(e => e.Promedio);
