1. Encapsulamiento y Fundamentos Arquitectónicos

El Encapsulamiento es uno de los pilares esenciales de la Programación Orientada a Objetos (POO). Consiste en ocultar los detalles de implementación interna de un objeto y exponer únicamente una interfaz pública limpia y segura para interactuar con él.

¿Por qué existen los Modificadores de Acceso y qué problemas resuelven?

Sin restricciones de acceso, los sistemas de software sufren rápidamente de degradación arquitectónica. Los modificadores de acceso resuelven cuatro problemas críticos en el código:

  • 1. Inconsistencia y Corrupción de Datos: Si el código externo puede modificar variables como `_saldo` o `_estado` directamente, se pueden asignar valores inválidos (como saldos negativos) ignorando las validaciones de negocio.
  • 2. Alto Acoplamiento (Efecto Dominó): Cuando los clientes de una clase dependen de sus campos internos, cambiar una estructura de datos rompe la compilación en múltiples archivos de la solución.
  • 3. Imposibilidad de Refactorización: Si todo es accesible públicamente, no es posible optimizar ni reestructurar el algoritmo interno de una clase sin temor a causar fallos colaterales imprevistos.
  • 4. Exposición de Fallos de Seguridad e Infraestructura: Exponer métodos auxiliares internos de cifrado o comandos directos a base de datos permite que usuarios o módulos no autorizados manipulen el flujo operativo.

Sentido y Propósito en el Diseño de Software

Los modificadores de acceso establecen contratos de uso claros (API Boundaries). Permiten definir con precisión la frontera entre lo que el cliente de la clase necesita utilizar y lo que la clase maneja internamente para proteger sus invariantes de estado.

2. Los 5 Modificadores de Acceso en C# 5

En C# versión 5.0 existen cinco niveles de accesibilidad para miembros y tipos:

public Sin restricciones

El elemento es visible desde cualquier lugar: dentro de la misma clase, en clases derivadas y desde cualquier ensamblado externo (`.dll`/`.exe`) que haga referencia al proyecto.

private Máxima restricción

Acceso restringido exclusivamente al cuerpo de la clase o estructura donde fue declarado. Es la accesibilidad por defecto para variables y métodos en C#.

protected Herencia

El miembro es accesible dentro de la clase contenedora y por cualquier clase que herede de ella, incluso si la clase derivada se encuentra en otro ensamblado.

internal Mismo Ensamblado

El miembro o tipo es accesible desde cualquier punto dentro del mismo archivo ejecutable o biblioteca de clases (`.dll`), pero es invisible para proyectos externos.

protected internal Ensamblado Ó Herencia

Acceso permitido a clases dentro del mismo ensamblado O a clases derivadas situadas en ensamblados externos (unión lógica OR de protected e internal).

4. Guía Práctica y Árbol de Decisión Interactivo

Situaciones de Cuándo Usar Cada Modificador

  • private: Campos de estado (`_saldo`), métodos helper de validación y constructores en patrones Singleton.
  • public: Propiedades expuestas de una clase, métodos de la API principal e interfaces de servicio.
  • protected: Métodos base de cálculo que las subclases deben personalizar o sobreescribir mediante `protected virtual`.
  • internal: Clases de conexión a BD, drivers o algoritmos de cifrado dentro de una biblioteca `.dll` para que no se expongan fuera de la biblioteca.
  • protected internal: Puntos de extensión en frameworks donde los componentes del propio ensamblado o clases hijas externas necesiten colaborar.

Ejemplo 1: Modelo de Dominio (Entidad Bancaria con Invariantes)

Muestra el uso de campos `private` para listas internas (`List`) y saldos, validación privada y getters/setters protegidos.

CuentaBancaria.cs (C# 5 - VS2012 / .NET 4.5) Ejemplo 1 
using System;
using System.Collections.Generic;

namespace DominioBancario
{
    // Clase pública que representa una transacción indivisible e inmutable
    public class Transaccion
    {
        // Propiedades públicas con set privado para garantizar inmutabilidad desde fuera
        public DateTime Fecha { get; private set; }
        public decimal Monto { get; private set; }
        public string Tipo { get; private set; }

        // Constructor público para crear transacciones válidas
        public Transaccion(string tipo, decimal monto)
        {
            this.Fecha = DateTime.Now; // Asigna la fecha del sistema en tiempo real
            this.Tipo = tipo;          // Registra el tipo (DEPOSITO / RETIRO)
            this.Monto = monto;        // Asigna la cantidad numérica
        }
    }

    // Entidad del Dominio: Representa la cuenta bancaria protegida
    public class CuentaBancaria
    {
        // CAMPO PRIVADO: Evita que código externo modifique el saldo directamente
        private decimal _saldo;

        // CAMPO PRIVADO READONLY: Protege la lista contra reemplazos o vaciado no autorizado
        private readonly List<Transaccion> _historial;

        // PROPIEDAD PÚBLICA DE SOLO LECTURA: El número de cuenta no debe cambiar tras ser creado
        public string NumeroCuenta { get; private set; }

        // PROPIEDAD PÚBLICA: Titular de la cuenta
        public string Titular { get; set; }

        // PROPIEDAD PÚBLICA DE CONSULTA DE SALDO: Expone el saldo sin dar acceso directo a '_saldo'
        public decimal Saldo
        {
            get { return this._saldo; }
        }

        // PROPIEDAD PÚBLICA DE HISTORIAL: Retorna colección de solo lectura para evitar .Clear() o .Add() externo
        public IEnumerable<Transaccion> Historial
        {
            get { return this._historial.AsReadOnly(); }
        }

        // CONSTRUCTOR PÚBLICO: Inicializa la cuenta con estado válido
        public CuentaBancaria(string numeroCuenta, string titular, decimal depositoInicial)
        {
            this.NumeroCuenta = numeroCuenta;                             // Asigna el identificador único
            this.Titular = titular;                                       // Asigna el nombre del titular
            this._historial = new List<Transaccion>();                   // Instancia la lista privada
            this._saldo = 0;                                              // Inicializa el saldo base

            if (depositoInicial > 0)
            {
                this.Depositar(depositoInicial);                          // Aplica el primer depósito validado
            }
        }

        // MÉTODO PÚBLICO: Punto de entrada controlado para depósitos
        public void Depositar(decimal monto)
        {
            if (!ValidarMontoPositivo(monto))                            // Invoca validación privada
            {
                throw new ArgumentException("El monto a depositar debe ser mayor a cero.");
            }

            this._saldo += monto;                                         // Incrementa el saldo de forma segura
            this._historial.Add(new Transaccion("DEPOSITO", monto));      // Añade el movimiento a la bitácora
        }

        // MÉTODO PÚBLICO: Punto de entrada controlado para retiros
        public bool Retirar(decimal monto)
        {
            if (!ValidarMontoPositivo(monto))                            // Verifica que sea positivo
            {
                return false;
            }

            if (this._saldo < monto)                                      // Regla de negocio: Sin sobregiros
            {
                return false;                                             // Rechaza la transacción
            }

            this._saldo -= monto;                                         // Aplica el descuento
            this._historial.Add(new Transaccion("RETIRO", monto));        // Registra el retiro
            return true;                                                  // Retiro completado
        }

        // MÉTODO PRIVADO: Helper de validación inaccesible desde el exterior
        private bool ValidarMontoPositivo(decimal monto)
        {
            return monto > 0;                                             // Retorna verdadero solo si es positivo
        }
    }
}

Ejemplo 2: Herencia y Cálculo de Nómina (`protected` y `protected virtual`)

Demuestra el uso de `protected` para que clases hijas redefinan cálculos y compartan variables base sin exponerlas fuera de la jerarquía.

SistemaNomina.cs (C# 5 - VS2012 / .NET 4.5) Ejemplo 2 
using System;

namespace SistemaNomina
{
    // Clase Base que define la estructura común de un Empleado
    public class Empleado
    {
        // Propiedad pública visible
        public string Nombre { get; set; }

        // CAMPO PROTECTED: Accesible solo en Empleado y sus clases hijas (Gerente, Director)
        protected decimal SalarioBase;

        // CAMPO PROTECTED INTERNAL: Accesible en este proyecto O en clases derivadas de otros proyectos
        protected internal string ClaveRegistroAuditoria;

        // Constructor público de la clase base
        public Empleado(string nombre, decimal salarioBase, string id)
        {
            this.Nombre = nombre;                                         // Inicializa el nombre público
            this.SalarioBase = salarioBase;                               // Inicializa el salario protegido
            this.ClaveRegistroAuditoria = "NOM-" + id + "-" + DateTime.Now.Year; // Clave de auditoría
        }

        // MÉTODO PROTECTED VIRTUAL: Permite que clases hijas modifiquen el cálculo del sueldo neto
        protected virtual decimal CalcularSueldoNeto()
        {
            return this.SalarioBase * 0.84m;                              // Aplica 16% de retención legal
        }

        // MÉTODO PÚBLICO: Genera el recibo imprimiendo los resultados
        public void GenerarReciboPago()
        {
            // Llama internamente al método protegido (que puede ser el sobreescrito por el hijo)
            decimal sueldoFinal = this.CalcularSueldoNeto();
            
            Console.WriteLine("--- RECIBO DE PAGO ---");
            Console.WriteLine("Empleado: " + this.Nombre);
            Console.WriteLine("Sueldo Neto a Cobrar: $" + sueldoFinal);
        }
    }

    // Clase Derivada que representa a un Gerente
    public class Gerente : Empleado
    {
        // Propiedad pública propia del Gerente
        public decimal BonoLiderazgo { get; set; }

        // Constructor del Gerente invocado con base(...)
        public Gerente(string nombre, decimal salarioBase, string id, decimal bono)
            : base(nombre, salarioBase, id)                               // Delega al constructor de Empleado
        {
            this.BonoLiderazgo = bono;                                    // Asigna el bono
        }

        // SOBREESCRITURA PROTEGIDA: Modifica el cálculo incluyendo el bono
        protected override decimal CalcularSueldoNeto()
        {
            // Acceso directo al campo 'SalarioBase' por ser heredado con accesibilidad 'protected'
            decimal totalBruto = this.SalarioBase + this.BonoLiderazgo;
            
            return totalBruto * 0.84m;                                    // Aplica deducciones sobre el total acumulado
        }

        // Método público propio para mostrar la ficha de auditoría
        public void MostrarFichaAuditoria()
        {
            // Acceso a 'ClaveRegistroAuditoria' por ser protected internal en el mismo ensamblado
            Console.WriteLine("Registro de Auditoría: " + this.ClaveRegistroAuditoria);
        }
    }
}

Ejemplo 3: Arquitectura en Capas / Componente DLL (`internal` y Patrón Fachada)

Muestra cómo ocultar clases auxiliares de base de datos o cifrado dentro de un ejecutable/DLL con `internal` y exponer una API pública limpia.

ComponenteAccesoDatos.cs (C# 5 - VS2012 / .NET 4.5) Ejemplo 3 
using System;
using System.Text;

namespace ComponenteAccesoDatos
{
    // CLASE INTERNAL: Inaccesible fuera de este ensamblado (.dll).
    // Oculta completamente el motor de cifrado e infraestructura técnica a los clientes.
    internal class MotorSeguridadInterno
    {
        // Método internal de cifrado criptográfico auxiliar
        internal string CifrarCadenaConexion(string cadenaBruta)
        {
            byte[] bytes = Encoding.UTF8.GetBytes(cadenaBruta);           // Convierte el texto plano a bytes
            return Convert.ToBase64String(bytes);                       // Retorna la cadena codificada
        }

        // Método internal para validación de conectividad física
        internal bool ValidarPingServidor(string servidor)
        {
            return !string.IsNullOrWhiteSpace(servidor);                 // Comprueba si el nombre del servidor es válido
        }
    }

    // CLASE PÚBLICA (FACHADA): Única interfaz visible para proyectos externos
    public class ConectorBaseDatos
    {
        // CAMPO PRIVADO: Mantiene referencia al motor interno
        private MotorSeguridadInterno _motorSeguridad;

        // PROPIEDAD PÚBLICA: Servidor destino
        public string Servidor { get; set; }

        // CONSTRUCTOR PÚBLICO
        public ConectorBaseDatos(string servidor)
        {
            this.Servidor = servidor;                                    // Asigna el servidor
            this._motorSeguridad = new MotorSeguridadInterno();            // Instancia internamente la clase internal
        }

        // MÉTODO PÚBLICO: Punto de entrada principal para abrir conexiones
        public bool Conectar(string usuario, string password)
        {
            // Llama a 'ValidarPingServidor' de la clase internal de forma transparente
            if (!this._motorSeguridad.ValidarPingServidor(this.Servidor))
            {
                Console.WriteLine("Error: El servidor especificado no responde.");
                return false;
            }

            // Construye la cadena sin cifrar
            string cadenaRaw = "Server=" + this.Servidor + ";User=" + usuario + ";Pwd=" + password;

            // Utiliza el motor internal para cifrar la cadena de conexión
            string cadenaCifrada = this._motorSeguridad.CifrarCadenaConexion(cadenaRaw);

            Console.WriteLine("Conexión establecida exitosamente.");
            Console.WriteLine("Hash de conexión seguro: " + cadenaCifrada);
            return true;
        }
    }
}
