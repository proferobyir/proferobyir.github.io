1. ¿Qué es Wireshark?

Wireshark es el analizador de protocolos de red más conocido y utilizado del mundo. Se trata de una herramienta de código abierto que permite capturar e inspeccionar en tiempo real el tráfico de datos que circula a través de una interfaz de red (Ethernet, Wi-Fi, etc.).

A nivel pedagógico y profesional, funciona como un "rayos X" para las redes de comunicación, ya que intercepta las Unidades de Datos de Protocolo (PDUs) y permite descomponerlas capar por capa según el modelo OSI / TCP-IP.

2. Flujo Básico de Trabajo

1
Seleccionar la Interfaz de Red

Al abrir Wireshark, verás una lista de tarjetas de red disponibles (Wi-Fi, Ethernet, Loopback). Observa la gráfica de actividad junto al nombre de la interfaz y selecciona la que tenga tráfico activo.

2
Iniciar la Captura

Haz doble clic en la interfaz seleccionada o presiona el botón del aleta de tiburón azul situado en la esquina superior izquierda.

3
Detener y Analizar

Una vez capturado el evento deseado, presiona el botón rojo de detener . Utiliza el panel superior para ver la lista de paquetes, el panel medio para los detalles por capa y el panel inferior para ver el volcado Hexadecimal.

3. Filtros de Visualización Imprescindibles

Wireshark captura miles de paquetes por segundo. Para aislar la información relevante se utilizan expresiones en la barra de búsqueda de filtros:

Filtro Propósito Ejemplo de Aplicación
ip.addr == X.X.X.X Muestra tráfico entrante y saliente de una IP específica. ip.addr == 192.168.1.10
tcp.port == X Filtra la comunicación por un puerto TCP específico. tcp.port == 80
http o dns Muestra únicamente paquetes del protocolo indicado. dns
http.request.method == "POST" Muestra peticiones web donde se envían datos (ej. formularios). http.request.method == "POST"

4. Casos de Uso Comunes y Ejemplos

A. Inspección de Resoluciones DNS

Averigua cómo tu equipo resuelve nombres de dominio a direcciones IP.

Escribe el siguiente filtro en la barra de búsqueda superior de Wireshark:

dns.flags.response == 0

Esto filtrará solo las peticiones (Queries) enviadas a tu servidor DNS configurado.

B. Análisis del Saludo de 3 Vías de TCP (3-Way Handshake)

Verificación del establecimiento de sesión entre cliente y servidor.

Filtra la comunicación de una conexión específica para observar la secuencia SYN, SYN-ACK, ACK:

tcp.flags.syn == 1 || tcp.flags.ack == 1
C. Reconstrucción de Streams TCP (Seguridad)

Permite reconstruir conversaciones completas que viajan en texto plano (como HTTP unencrypted o FTP).

  1. Haz clic derecho sobre cualquier paquete TCP o HTTP de la lista.
  2. Selecciona la opción Follow > TCP Stream.
  3. Se abrirá una ventana mostrando la conversación completa en texto legible (petición en rojo, respuesta en azul).
