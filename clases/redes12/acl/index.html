🔐 ACL · Router Cisco Packet Tracer

📋 ¿Qué es una Lista de Control de Acceso?

Una ACL (Access Control List) es un conjunto de reglas que el router aplica sobre el tráfico que atraviesa sus interfaces. Cada regla permite o deniega paquetes según criterios como:

  • Dirección IP de origen / destino
  • Protocolo (TCP, UDP, ICMP, etc.)
  • Puerto origen / destino
  • Interfaz de entrada o salida
! Ejemplo de ACL extendida
access-list 101 permit tcp 192.168.1.0 0.0.0.255 any eq 80
access-list 101 deny ip any any

Las ACL se aplican en la interfaz con ip access-group y se evalúan secuencialmente (de arriba hacia abajo).

⚖️ Lista Blanca vs. Lista Negra

WHITELIST Lista blanca — Solo se permite el tráfico explícitamente autorizado. Todo lo demás se deniega por defecto.

! Lista blanca: solo permite HTTP/HTTPS
access-list 100 permit tcp any any eq 80
access-list 100 permit tcp any any eq 443
access-list 100 deny ip any any

BLACKLIST Lista negra — Se deniega explícitamente el tráfico no deseado. Todo lo demás se permite por defecto.

! Lista negra: bloquea solo ICMP (ping)
access-list 102 deny icmp any any
access-list 102 permit ip any any

🔹 Recomendación: usar listas blancas para mayor seguridad, ya que el deny implícito al final protege ante tráfico no deseado.

📱 Práctica: Bloquear celulares de estudiantes ACL extendida · Salida a Internet

Topología: Router Cisco 4321 · LAN 192.168.10.0/24 · VLAN estudiantes

  • 💻 PC Profesor 192.168.10.10
  • 📱 Celular Estudiante 1 192.168.10.101
  • 📱 Celular Estudiante 2 192.168.10.102
  • 📱 Celular Estudiante 3 192.168.10.103
  • 🖨️ Impresora 192.168.10.20
🎯 Objetivo: Permitir que los profesores y equipos administrativos naveguen, pero denegar todo el tráfico proveniente de los celulares de estudiantes (rango .101–.103) hacia la WAN.

🔧 Configuración en el router:

! Crear ACL extendida 110 (lista negra)
access-list 110 deny ip host 192.168.10.101 any
access-list 110 deny ip host 192.168.10.102 any
access-list 110 deny ip host 192.168.10.103 any
! Permitir el resto del tráfico
access-list 110 permit ip any any

! Aplicar a la interfaz GigabitEthernet0/1 (salida a Internet)
interface GigabitEthernet0/1
ip access-group 110 out
  • 📱 Celular 1 · BLOQUEADO DENY
  • 📱 Celular 2 · BLOQUEADO DENY
  • 📱 Celular 3 · BLOQUEADO DENY
  • 💻 PC Profesor · PERMITIDO PERMIT
  • 🖨️ Impresora · PERMITIDO PERMIT

✅ Verificación

Desde un celular estudiante, al hacer ping 8.8.8.8 o abrir un navegador, el router descarta los paquetes. El comando show access-lists muestra los contadores de coincidencias.

⚠️ Consideraciones

Si los celulares usan DHCP, se pueden reservar direcciones IP fijas o bloquear por dirección MAC (con ACL de capa 2 en switches). También se puede aplicar una ACL de entrada en la interfaz LAN.
