Guía Introductoria: Cisco IOS

¿Qué es Cisco IOS?

Cisco IOS es el sistema operativo que ejecutan dispositivos Cisco como routers y switches, basado en una Línea de Comandos (CLI).

  • Modo Usuario (Router> / Switch>): Solo lectura.
  • Modo Privilegiado (Router# / Switch#): Diagnósticos (enable).
  • Modo de Configuración Global (Router(config)# / Switch(config)#): Cambios (configure terminal).

Pasos Previos a la Configuración (Router o Switch)

¡Atención! Tanto en routers como en switches, antes de ejecutar cualquier comando de configuración, debes pasar por los modos de seguridad de la CLI:

  1. Al abrir la consola verás el prompt de usuario: Router> (o Switch>)
  2. Escribe enable para pasar al modo privilegiado (el prompt cambia a Router# o Switch#).
  3. Escribe configure terminal para entrar al modo de configuración global (el prompt cambia a Router(config)# o Switch(config)#).

Solo estando en config# podrás configurar interfaces, IPs o crear VLANs.

Configuración de Routers

! Asegúrate de haber hecho 'enable' y 'configure terminal' antes:
Router# configure terminal
Router(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

VLANs en Switches: Concepto de Acceso

¿Cómo "sabe" el switch a qué VLAN pertenece un puerto?

  • switchport mode access: Prepara el puerto para dispositivos finales.
  • switchport access vlan X: Etiqueta el puerto con la VLAN específica.

Configuración de 3 VLANs y Asignación de Puertos

! 1. Crear las VLANs (Estando en Switch(config)#)
Switch(config)# vlan 10
Switch(config-vlan)# name VENTAS
Switch(config-vlan)# exit
Switch(config)# vlan 20
Switch(config-vlan)# name RRHH
Switch(config-vlan)# exit
Switch(config)# vlan 30
Switch(config-vlan)# name IT
Switch(config-vlan)# exit

! 2. Asignar los rangos de puertos
Switch(config)# interface range fastEthernet 0/1 - 8
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

Switch(config)# interface range fastEthernet 0/9 - 16
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
Switch(config-if-range)# exit

Switch(config)# interface range fastEthernet 0/17 - 24
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 30
Switch(config-if-range)# exit

Resumen de Comandos Frecuentes

Comando Descripción
enable Accede al modo privilegiado.
configure terminal Entra al modo de configuración global.
show ip interface brief Muestra el estado de las interfaces.
show vlan brief Lista las VLANs creadas y sus puertos asignados.
copy running-config startup-config Guarda la configuración actual en la memoria NVRAM (evita pérdida al reiniciar).
no shutdown Activa una interfaz que está apagada.
