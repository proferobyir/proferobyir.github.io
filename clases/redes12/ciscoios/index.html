Guía Introductoria: Cisco IOS

¿Qué es Cisco IOS?

Cisco IOS es el sistema operativo que ejecutan dispositivos Cisco como routers y switches, basado en una Línea de Comandos (CLI).

  • Modo Usuario (Router> / Switch>): Solo lectura.
  • Modo Privilegiado (Router# / Switch#): Diagnósticos (enable).
  • Modo de Configuración Global (Router(config)# / Switch(config)#): Cambios (configure terminal).

Pasos Previos y Verificación Inicial

¡Atención! Tanto en routers como en switches, antes de ejecutar cualquier comando de configuración, debes pasar por los modos de seguridad de la CLI:

  1. Al abrir la consola verás el prompt de usuario: Router> (o Switch>)
  2. Escribe enable para pasar al modo privilegiado (el prompt cambia a Router# o Switch#).
  3. Escribe configure terminal para entrar al modo de configuración global (el prompt cambia a Router(config)# o Switch(config)#).

Para verificar el estado de las interfaces y sus nombres antes de configurar, ejecuta este comando en modo privilegiado (#):

show ip interface brief

Para salir de forma segura de la sesión de administración y volver al modo de usuario sin que el equipo intente traducir comandos erróneos como DNS, utiliza:

disable

Configuración Básica de Routers (Dirección IP y Estado)

! 1. Entrar a configuración global y configurar interfaz
Router> enable
Router# configure terminal
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# exit

! 2. Guardar cambios y cerrar sesión de forma segura
Router(config)# end
Router# copy running-config startup-config
Router# disable

Configuración de Servidor DHCP en un Router Cisco

¿Cómo activar un servidor DHCP en el router? En lugar de configurar IPs estáticas en cada PC, el router puede asignarlas automáticamente siguiendo estos pasos:

  1. Excluir las IPs reservadas (como el Gateway) para que no las asigne a equipos.
  2. Crear y nombrar el bloque o pool de DHCP.
  3. Definir la red y su máscara.
  4. Asignar la puerta de enlace predeterminada y el DNS.
            ! 0. Entrar al modo de configuración global
Router> enable
Router# configure terminal

! 1. Excluir el rango de direcciones IP reservadas (del .1 al .10)
Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10

! 2. Crear el pool de DHCP y definir red, gateway y DNS
Router(config)# ip dhcp pool RED_LAN
Router(config-dhcp)# network 192.168.1.0 255.255.255.0
Router(config-dhcp)# default-router 192.168.1.1
Router(config-dhcp)# dns-server 8.8.8.8
Router(config-dhcp)# exit

! 3. Configurar y encender la interfaz del router (Gateway)
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# exit

! 4. Guardar cambios y salir de forma segura
Router(config)# end
Router# copy running-config startup-config
Router# disable

VLANs en Switches: Concepto de Acceso

¿Cómo "sabe" el switch a qué VLAN pertenece un puerto?

  • switchport mode access: Prepara el puerto para dispositivos finales.
  • switchport access vlan X: Etiqueta el puerto con la VLAN específica.

Configuración de VLANs y Asignación de Puertos en Switches

! 1. Crear las VLANs
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name VENTAS
Switch(config-vlan)# exit
Switch(config)# vlan 20
Switch(config-vlan)# name RRHH
Switch(config-vlan)# exit
Switch(config)# vlan 30
Switch(config-vlan)# name IT
Switch(config-vlan)# exit

! 2. Asignar los rangos de puertos a cada VLAN
Switch(config)# interface range fastEthernet 0/1-8
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

Switch(config)# interface range fastEthernet 0/9-16
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
Switch(config-if-range)# exit

Switch(config)# interface range fastEthernet 0/17-24
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 30
Switch(config-if-range)# exit

! 3. Guardar cambios y cerrar sesión de forma segura
Switch(config)# end
Switch# copy running-config startup-config
Switch# disable

Persistencia: Guardar los cambios

¡No olvides guardar! En Cisco IOS, los cambios se almacenan en la memoria RAM (running-config), la cual es volátil. Si reinicias en Packet Tracer, perderás todo.

Pasos de salida y guardado definitivo:

  • Salir de configuración global: end[cite: 2]
  • Guardar en NVRAM: copy running-config startup-config[cite: 2]
  • Cerrar sesión de administrador de forma segura: disable[cite: 2]

Resumen de Comandos Frecuentes

Comando Descripción
enable Accede al modo privilegiado.
disable Regresa del modo privilegiado al modo de usuario (cierra sesión de administración de forma segura evitado bloqueos DNS).
configure terminal Entra al modo de configuración global.
show ip interface brief Muestra el estado de las interfaces.
show vlan brief Lista las VLANs creadas y sus puertos asignados.
copy running-config startup-config Guarda la configuración actual en la memoria NVRAM (evita pérdida al reiniciar).
no shutdown Activa una interfaz que está apagada.
ip dhcp excluded-address Excluye direcciones IP del rango que se asignará por DHCP.
ip dhcp pool Crea y accede al menú de configuración del servidor DHCP.
network Define la red principal y máscara de subred para el pool DHCP.
default-router Establece la puerta de enlace predeterminada para los clientes DHCP.
