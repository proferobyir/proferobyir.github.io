Modelo TCP/IP: Arquitectura y Protocolos

Guía de aprendizaje interactiva sobre la pila de comunicación, el viaje de los datos y diagnósticos de red

🌐 1. Origen y Necesidad del Modelo TCP/IP

A finales de la década de 1960, la agencia DARPA (Departamento de Defensa de EE. UU.) financió la creación de ARPANET para resolver dos grandes problemas de la época:

  • Incompatibilidad de fabricantes: Los computadores de distintas marcas no podían intercambiar datos porque usaban arquitecturas cerradas y propietarias.
  • Vulnerabilidad de redes centralizadas: La conmutación de circuitos antigua requería un canal de comunicación fijo; si un nodo caía, toda la red colapsaba.

La solución: Conmutación de paquetes. La información se fragmenta en trozos independientes (paquetes). Cada uno viaja de forma dinámica por la red buscando la mejor ruta y se reensamblan al llegar al destino.

Capa 4 — Unidad de Datos: Datos Puros

Capa de Aplicación

Proporciona la interfaz de acceso a la red directamente a los programas de software que utiliza el usuario final.

HTTP (80) HTTPS (443) DNS (53) SSH (22) MySQL (3306)
💡 Analogía Postal: Es el contenido de la carta que escribes (el mensaje que quieres enviar).
Capa 3 — Unidad de Datos: Segmento (TCP) / Datagrama (UDP)

Capa de Transporte

Gestiona la comunicación extremo a extremo entre procesos de software mediante puertos lógicos (ej. puerto 80 para web, 22 para terminal).

TCP (Orientado a conexión / Confiable) UDP (Sin conexión / Ultra rápido)
💡 Analogía Postal: Meter la carta dentro de un sobre etiquetado con el número de departamento exacto (Puerto).
Capa 2 — Unidad de Datos: Paquete

Capa de Internet

Asigna las direcciones lógicas origen y destino (IP) y determina la mejor ruta para atravesar distintas redes intermedias (Enrutamiento).

IPv4 IPv6 ICMP (Diagnóstico) ARP (Traducción IP a MAC)
💡 Analogía Postal: Escribir la dirección postal de origen y destino global en el sobre (Dirección IP).
Capa 1 — Unidad de Datos: Trama / Impulsos Binarios (Bits)

Capa de Acceso a la Red

Controla el hardware físico (tarjetas de red, cables, Wi-Fi) y gestiona la entrega local mediante direccionamiento físico MAC.

Ethernet (IEEE 802.3) Wi-Fi (IEEE 802.11) Dirección Física MAC
💡 Analogía Postal: El camión de correo físico o el avión que transporta físicamente el sobre de una oficina a otra.

🔍 Desglose Técnico de Estándares de Transmisión:

  • IEEE 802.3 (Ethernet): Regula la comunicación mediante cables (UTP, Par trenzado, Fibra Óptica). Emplea el método CSMA/CD (Detección de colisiones) para administrar el uso compartido del canal.
  • IEEE 802.11 (Wi-Fi): Define la comunicación inalámbrica por radiofrecuencia (2.4 GHz, 5 GHz, 6 GHz). Utiliza el algoritmo CSMA/CA (Evitación de colisiones) antes de emitir ondas en el aire.
  • Direcciones MAC: Identificador hexadecimal único de 48 bits (ejemplo: 00:1A:2B:3C:4D:5E) grabado de fábrica en la tarjeta de red (NIC). Un router la usa para entregar la trama al equipo exacto en la red local.

📦 3. El Viaje de los Datos: Encapsulamiento

A medida que la información desciende por las capas del emisor, cada capa agrega su propia cabecera de control (Header). Al llegar al receptor, el proceso se invierte (Desencapsulamiento):

4. Aplicación
[ Datos de la Aplicación ]
3. Transporte
[ Header TCP/UDP | Datos ] → Segmento
2. Internet
[ Header IP | Header TCP | Datos ] → Paquete
1. Acceso a Red
[ Header Ethernet | Header IP | Header TCP | Datos | Trailer FCS ] → Trama / Bits (01101)
