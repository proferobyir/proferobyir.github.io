Direcciones IP, CGNAT y Protocolo DHCP

1

¿Qué es una Dirección IP?

Una dirección IP (Internet Protocol) es una etiqueta numérica lógica que identifica de forma única a una interfaz de red dentro de un dispositivo para permitir el direccionamiento y transporte de datos en redes TCP/IP.

En la actualidad convivimos principalmente con el estándar IPv4, expresado en notación decimal punteada de 32 bits estructurados en cuatro octetos (ejemplo: 192.168.1.10).

192Octeto 1
168Octeto 2
1Octeto 3
10Octeto 4
2

Direcciones IP Públicas vs. Privadas (RFC 1918)

Las direcciones se clasifican funcionalmente en dos ámbitos:

IP Pública

Única y globalmente enrutable en Internet. La asigna el ISP a la interfaz WAN del router de borde.

IP Privada

Utilizada para la comunicación interna dentro de una LAN. No son enrutables en Internet y se reutilizan en redes locales.

Rangos Reservados para Redes Privadas (RFC 1918):

  • Clase A:10.0.0.0 a 10.255.255.255 (/8)
  • Clase B:172.16.0.0 a 172.31.255.255 (/12)
  • Clase C:192.168.0.0 a 192.168.255.255 (/16)
Esquema Tradicional: Red Local con NAT de Borde
Host LAN (192.168.1.5) → Router Res. (NAT) → IP Pública WAN (200.44.10.5) → Internet
3

Tipos de IP Pública y Concepto de NAT

¿Qué es NAT (Network Address Translation)?

Es un mecanismo fundamental en redes que consiste en traducir las direcciones IP privadas de una red local a una o varias direcciones IP públicas, permitiendo que múltiples dispositivos compartan una única conexión a Internet de forma transparente.

Las direcciones IP públicas asignadas por los proveedores varían según su comportamiento:

IP Pública Dinámica

Cambia de forma periódica o al reiniciar el router. Asignada automáticamente mediante DHCP corporativo del ISP.

IP Pública Estática (Fija)

Dirección invariable configurada de manera fija. Utilizada para servidores web, VPNs o VoIP.

4

Carrier-Grade NAT (CGNAT - RFC 6598)

Ante el agotamiento de direcciones IPv4, los proveedores implementan CGNAT, insertando un nivel adicional de traducción donde cientos de hogares comparten una única IP pública externa.

Impacto del CGNAT:

El router recibe una IP privada del rango 100.64.0.0/10. El Port Forwarding y los servicios DDNS dejan de funcionar al no tener control sobre las tablas de traducción del ISP.

5

Protocolo DHCP (Dynamic Host Configuration Protocol)

El protocolo DHCP (RFC 2131) opera en la capa de aplicación automatizando la gestión centralizada del direccionamiento IP mediante el proceso DORA:

D - Discover:

El cliente busca un servidor DHCP activo en la subred.

O - Offer:

El servidor responde reservando una IP libre y tiempo de concesión.

R - Request:

El cliente acepta formalmente la oferta propuesta.

A - Acknowledge:

El servidor confirma el arrendamiento y parámetros de red.
