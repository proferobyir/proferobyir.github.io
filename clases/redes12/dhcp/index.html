Clase 1

Direcciones IP y Protocolo DHCP

1

¿Qué es una Dirección IP?

Una dirección IP (Internet Protocol) es un número único e irrepetible que identifica a un dispositivo (computadora, teléfono, impresora, router) conectado a una red que utilice el protocolo IP.

Actualmente convivimos principalmente con IPv4, compuesta por 32 bits divididos en cuatro octetos separados por puntos (ejemplo: 192.168.1.15). Cada octeto puede valer entre 0 y 255.

192 Octeto 1
168 Octeto 2
1 Octeto 3
10 Octeto 4
2

Direcciones IP Públicas vs. Privadas

No todas las direcciones IP cumplen la misma función dentro de internet:

IP Pública

Es visible en todo internet. Es asignada por tu Proveedor de Servicios de Internet (ISP) y permite que tu red sea encontrada desde el exterior.

IP Privada

Se utiliza exclusivamente dentro de redes locales (hogares, oficinas, universidades). No son enrutables en internet y se pueden repetir en diferentes redes del mundo sin conflicto.

Rangos estándar definidos para redes privadas:

  • Clase A: 10.0.0.0 a 10.255.255.255
  • Clase B: 172.16.0.0 a 172.31.255.255
  • Clase C: 192.168.0.0 a 192.168.255.255
Esquema Red Local vs Internet (NAT)
Red Local (LAN) → PC (192.168.1.5) → Router (NAT) → Internet (IP Pública: 201.240.10.5)
3

Protocolo DHCP (Dynamic Host Configuration Protocol)

Configurar manualmente una dirección IP, máscara y puerta de enlace en cada equipo de una red grande es inviable. El protocolo DHCP automatiza este proceso.

El intercambio clásico de mensajes se conoce como el proceso DORA:

D - Discover (Descubrimiento):

El equipo recién conectado grita en la red buscando un servidor DHCP.

O - Offer (Oferta):

El servidor DHCP responde ofreciendo una dirección IP disponible.

R - Request (Petición):

El equipo solicita formalmente esa IP ofrecida.

A - Acknowledge (Confirmación):

El servidor confirma la asignación y entrega los parámetros de red definitivos.

Flujo de Comunicación DHCP
Cliente (PC)   ⇄   Servidor DHCP
1. D - Discover  |  2. O - Offer (IP disponible)
3. R - Request  |  4. A - ACK (Configuración completada)
