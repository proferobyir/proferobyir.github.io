1. Concepto Fundamental y Valor de Posición de los Octetos

El subneteo es el proceso lógico para dividir una red IPv4 grande en segmentos más pequeños (subredes), tomando prestados bits de la porción de host[cite: 1].

Tabla de Posición de los Octetos

Valor de Posición ($2^7$ al $2^0$)[cite: 1] Decimal Equivalente
$2^7$ (128)[cite: 1] $2^6$ (64)[cite: 1] $2^5$ (32)[cite: 1] $2^4$ (16)[cite: 1] $2^3$ (8)[cite: 1] $2^2$ (4)[cite: 1] $2^1$ (2)[cite: 1] $2^0$ (1)[cite: 1]
1 1 1 1 1 1 1 1 255[cite: 1]
1 1 0 0 0 0 0 0 192[cite: 1]

Las 3 Fórmulas Clave

  • Número de Subredes creadas: $2^n$ (donde $n$ es la cantidad de bits prestados)[cite: 1].
  • Hosts por Subred (Totales): $2^h$ (donde $h$ es la cantidad de bits que quedan para Host)[cite: 1].
  • Hosts Útiles por Subred: $2^h - 2$ (se restan 2 porque la primera IP es la dirección de red y la última es el broadcast)[cite: 1].

2. Clases de Redes IPv4 y Rangos Privados (RFC 1918)

Las direcciones IPv4 se dividen en públicas (ruteables en Internet) y privadas (utilizadas exclusivamente en redes locales LAN)[cite: 2].

Clase Rango IP Privada Máscara / CIDR Bloques / Subredes Disponibles
Clase A 10.0.0.0 – 10.255.255.255[cite: 4] 255.0.0.0 /8[cite: 4] 1 red /8 grande (16.7M de hosts)[cite: 4]
Clase B 172.16.0.0 – 172.31.255.255[cite: 4] 255.240.0.0 /12[cite: 4] 16 redes /16 continuas (65,534 hosts c/u)[cite: 4]
Clase C 192.168.0.0 – 192.168.255.255[cite: 4] 255.255.255.0 /16[cite: 4] 256 redes /24 continuas (254 hosts c/u)[cite: 4]

3. Ejemplo Práctico: Dividir 192.168.1.0/24 en 4 Subredes

  1. Paso A: Calcular bits necesarios ($n$): Queremos 4 subredes. Usamos la fórmula de subredes: $2^n \ge 4 \rightarrow n = 2$ bits. Tomamos 2 bits prestados del último octeto[cite: 1].
  2. Paso B: Calcular capacidad por host ($h$): Quedan 6 bits para host ($8 - 2 = 6$). Hosts útiles: $2^6 - 2 = 62$ direcciones por subred[cite: 1].
  3. Paso C: Calcular el Tamaño del Bloque (Salto): Se calcula restando el valor decimal de la máscara a 256. $Salto = 256 - 192 = 64$[cite: 1].

5. Consideraciones de Seguridad: Subneteo vs. VLANs

Nota de Arquitectura de Red: Un subneteo organiza el espacio de direcciones IP en Capa 3, pero no reemplaza la segmentación de Capa 2 (VLANs) en los switches físicos para mitigar ataques de descubrimiento y envenenamiento ARP[cite: 3].
