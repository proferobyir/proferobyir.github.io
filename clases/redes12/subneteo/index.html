¿Qué es el Subneteo y por qué se usa?

El subneteo (subnetworking) consiste en dividir una red grande de computadoras en subredes más pequeñas y lógicas. Esto mejora drásticamente el rendimiento de la red y optimiza la seguridad.

Imagina una empresa con departamentos de Administración, Ventas y Sistemas. Meter a todos en la misma red masiva genera saturación por tráfico de difusión (broadcast). Dividirla en subredes aísla el tráfico innecesario.

2

La Máscara de Subred y el Prefijo /CIDR

Toda dirección IP trabaja junto a una máscara de subred. Su función es actuar como un filtro para separar la IP en dos partes:

Porción de Red

Identifica a qué red pertenece el dispositivo.

Porción de Host

Identifica al dispositivo o equipo en específico dentro de esa red.

Por ejemplo, la máscara estándar de clase C 255.255.255.0 también se puede escribir con notación CIDR como /24 (indicando que los primeros 24 bits son de red).

Bits de RED (Ej: 192.168.1.) | HOST
3

Reglas Básicas de Conteo en Subredes

Al diseñar una subred, debemos tener claros tres elementos fundamentales que se calculan a partir de los bits prestados para hosts:

1. Dirección de Red:

Es la primera dirección del bloque (el identificador de la subred, los bits de host en 0). No se le puede asignar a ningún equipo.

2. Dirección de Broadcast (Difusión):

Es la última dirección del bloque (todos los bits de host en 1). Se usa para enviar mensajes a todos los equipos de la subred.

3. Direcciones de Hosts Utilizables:

Son todas las direcciones que van entre la dirección de red y la de broadcast. Su fórmula fija es siempre 2ⁿ - 2 (donde n es la cantidad de bits asignados a hosts).
