1. Concepto Fundamental y Valor de Posición de los Octetos

El subneteo es el proceso lógico para dividir una red IPv4 grande en segmentos más pequeños (subredes), tomando prestados bits de la porción de host.

Tabla de Posición de los Octetos

Valor de Posición (27 al 20) Decimal Equivalente
27 (128) 26 (64) 25 (32) 24 (16) 23 (8) 22 (4) 21 (2) 20 (1)
1 1 1 1 1 1 1 1 255
1 1 0 0 0 0 0 0 192

Las 3 Fórmulas Clave

  • Número de Subredes creadas: 2n (donde n es la cantidad de bits prestados).
  • Hosts por Subred (Totales): 2h (donde h es la cantidad de bits que quedan para Host).
  • Hosts Útiles por Subred: 2h - 2 (se restan 2 porque la primera IP es la dirección de red y la última es el broadcast).

2. Clases de Redes IPv4 y Rangos Privados (RFC 1918)

Las direcciones IPv4 se dividen en públicas (ruteables en Internet) y privadas (utilizadas exclusivamente en redes locales LAN).

Clase Rango IP Privada Máscara / CIDR Bloques / Subredes Disponibles
Clase A 10.0.0.0 – 10.255.255.255 255.0.0.0 /8 1 red /8 grande (16.7M de hosts)
Clase B 172.16.0.0 – 172.31.255.255 255.240.0.0 /12 16 redes /16 continuas (65,534 hosts c/u)
Clase C 192.168.0.0 – 192.168.255.255 255.255.255.0 /16 256 redes /24 continuas (254 hosts c/u)

3. Ejemplo Práctico: Dividir 192.168.1.0/24 en 4 Subredes

  1. Paso A: Calcular bits necesarios (n): Queremos 4 subredes. Usamos la fórmula de subredes: 2n ≥ 4 n = 2 bits. Tomamos 2 bits prestados del último octeto.
  2. Paso B: Calcular capacidad por host (h): Quedan 6 bits para host (8 - 2 = 6). Hosts útiles: 26 - 2 = 62 direcciones por subred.
  3. Paso C: Calcular el Tamaño del Bloque (Salto): Se calcula restando el valor decimal de la máscara a 256. Salto = 256 - 192 = 64.

Subred 1 192.168.1.64 192.168.1.65 – 192.168.1.126 192.168.1.127
Subred 2 192.168.1.128 192.168.1.129 – 192.168.1.190 192.168.1.191
Subred 3 192.168.1.192 192.168.1.193 – 192.168.1.254 192.168.1.255

4. Problema Propuesto: Resolución Paso a Paso

Problema: Una empresa tiene la red 192.168.10.0/24 y necesita dividirla en 4 subredes iguales para sus distintas áreas administrativas.

Debemos encontrar:

  1. La nueva máscara de red en decimal y CIDR.
  2. La cantidad de hosts útiles por subred.
  3. La dirección de red, rango útil y broadcast de la tercera subred.
Idea clave: no debemos intentar adivinar las direcciones. Vamos a obtener cada dato mediante una secuencia fija: subredes → bits prestados → nueva máscara → hosts → salto → tercera subred.

1Identificar la red original

Partimos de:

192.168.10.0/24

El prefijo /24 significa que tenemos:

  • 24 bits de red.
  • 8 bits de host, porque IPv4 tiene 32 bits.
11111111.11111111.11111111.00000000

En el último octeto tenemos 8 bits disponibles para host.

2Calcular cuántos bits debemos pedir prestados

Necesitamos 4 subredes. Utilizamos:

2n ≥ número de subredes

2n ≥ 4
22 = 4

n = 2 bits prestados

Por lo tanto, tomamos 2 bits de los 8 bits que originalmente eran de host.

11111111.11111111.11111111.11000000

3Obtener la nueva máscara

El prefijo original era /24. Al tomar 3 bits:

/24 + 2 = /26

El último octeto de la máscara es 11000000.

Convertimos sus bits a decimal:

128 + 64 + 0 + 0 + 0 + 0 + 0 + 0 = 192

Por tanto:

Nueva máscara: 255.255.255.192
CIDR: /26

Respuesta 1: 255.255.255.192 (/26)

4Calcular los hosts disponibles

Si prestamos 3 bits de los 8 originales, quedan:

h = 8 - 2 = 6 bits para host

Direcciones totales por subred:

26 = 64 direcciones

Como la primera dirección identifica la red y la última es el broadcast:

26 - 2 = 62 hosts útiles

Respuesta 2: 62 hosts útiles por subred.

5Calcular el tamaño del salto

El salto se obtiene restando el último octeto de la máscara a 256:

256 - 192 = 64

Eso significa que las redes comenzarán cada 64 posiciones:

Subred Inicio Fin del bloque
1 192.168.10.0 63
2 192.168.10.64 127
3 192.168.10.128 191
4 192.168.10.192 255

6Encontrar la tercera subred

La tercera subred comienza después de sumar el salto dos veces desde la primera red:

Primera red: 192.168.10.0
Segunda red: 0 + 64 = 64
Tercera red: 64 + 64 = 128

Por tanto, la dirección de red de la tercera subred es:

192.168.10.128

7Encontrar el rango de hosts útiles

La dirección de red es 192.168.10.128.

La primera IP utilizable es la siguiente:

192.168.10.128 + 1 = 192.168.10.129

La última IP utilizable está justo antes del broadcast.

Como el bloque termina en .191, el broadcast será 192.168.10.191.

Broadcast - 1 = 192.168.10.190

Por tanto, el rango útil es:

192.168.10.129 – 192.168.10.190

8Encontrar el broadcast

El broadcast es la última dirección del bloque de 32 direcciones:

192.168.10.191

La relación completa queda:

Dato Resultado
Nueva máscara 255.255.255.192 (/26)
Hosts útiles 62
3.ª dirección de red 192.168.10.128
Rango útil 192.168.10.129 – 192.168.10.190
Broadcast 192.168.10.191
🧠 Regla mental para resolver ejercicios similares
  1. ¿Cuántas subredes necesito? → calcula 2n.
  2. Suma los bits prestados al prefijo original.
  3. Calcula los bits que quedan para host.
  4. Usa 2h - 2 para los hosts útiles.
  5. Calcula el salto con 256 - octeto de máscara.
  6. Cuenta los bloques hasta llegar a la subred solicitada.
  7. Red = inicio del bloque; broadcast = final del bloque; hosts = lo que queda entre ambos.

Ahora intenta resolverlo tú

Antes de mirar nuevamente la solución, intenta responder mentalmente:

  • ¿Por qué se tomaron exactamente 2 bits?
  • ¿Por qué la máscara terminó en 192?
  • ¿Por qué el salto es 64?
  • ¿Por qué la tercera red comienza en .128?
Comprobación:
4 subredes × 64 direcciones = 256 direcciones.
192.168.10.0 hasta 192.168.10.255 = 256 direcciones.
Por tanto, las 8 subredes ocupan exactamente toda la red /24.

5. Consideraciones de Seguridad: Subneteo vs. VLANs

Nota de Arquitectura de Red: Un subneteo organiza el espacio de direcciones IP en Capa 3, pero no reemplaza la segmentación de Capa 2 (VLANs) en los switches físicos para mitigar ataques de descubrimiento y envenenamiento ARP.
