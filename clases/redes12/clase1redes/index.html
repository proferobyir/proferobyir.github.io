Nodo y dispositivos de red

  • Nodo: cualquier equipo conectado a la red que pueda enviar, recibir o procesar datos (PC, servidor, teléfono, impresora).
  • Router: encamina el tráfico entre redes distintas; conecta la red local con Internet.
  • Switch: interconecta los equipos dentro de una misma red local (LAN) a alta velocidad.
Router → Switch → dispositivos finales (nodos)
Infraestructura básica de red

Redes LAN y WAN

  • LAN (Local Area Network): red de alcance local, dentro de un espacio físico delimitado (laboratorio, oficina, vivienda).
  • WAN (Wide Area Network): red de gran cobertura geográfica que interconecta múltiples LAN a nivel regional o mundial. Internet es la WAN por excelencia.
LAN ↔ Router ↔ WAN (Internet)

Redes inalámbricas y dirección MAC

  • Del medio físico (cables) a las ondas de radio electromagnéticas (Wi-Fi).

Bloque 3 · Las Reglas del Tránsito Digital (Parte 1)

Direccionamiento lógico: IP y octeto

Dirección IP: identificación lógica (Capa 3) asignada a cada dispositivo para enrutar entre redes.

Estructura IPv4

32 bits divididos en 4 bloques de 8 bits (octetos) separados por puntos.
Ejemplo: 192.168.1.10

El octeto

Grupo de 8 bits que representa un valor decimal entre 0 y 255 (28 = 256 combinaciones).

192.168.1.10 → octeto1=192 octeto2=168 octeto3=1 octeto4=10

DHCP: el repartidor automático de IPs

El servidor DHCP asigna automáticamente dirección IP, máscara de red y gateway a los dispositivos, sin intervención manual.

Cliente → DHCP Discover → DHCP Offer → DHCP Request → DHCP Ack

Métricas de red: ancho de banda y latencia

Ancho de banda

Capacidad máxima de transferencia de datos por unidad de tiempo (Mbps / Gbps). Es el ancho de la autopista.

Latencia (ping)

Tiempo que tarda un paquete en ir y volver (milisegundos, ms). Es el tiempo de respuesta.

Ancho de banda = 100 Mbps  ·  Latencia = 12 ms

Redes seguras, VPN y modelo OSI

  • Red interna vs. externa: perímetro privado protegido frente a red pública (Internet).
  • VPN (Red Privada Virtual): túnel cifrado para conectar de forma segura la red interna desde el exterior.
  • Conclusión: todos estos conceptos se integran en el marco de 7 capas del Modelo OSI.
