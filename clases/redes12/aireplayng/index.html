Tutorial de Aireplay-ng: Inyección de Paquetes

Aireplay-ng es una herramienta incluida en la suite Aircrack-ng, utilizada principalmente para inyectar paquetes en redes inalámbricas. Esto es fundamental para ataques de desautenticación o para acelerar la captura de IVs (vectores de inicialización) para romper cifrados WEP o forzar el handshake WPA.

Prerrequisitos

  • Tener instalada la suite aircrack-ng.
  • Una tarjeta de red inalámbrica que soporte modo monitor e inyección.
  • Poner la interfaz en modo monitor.

Paso 1: Activar Modo Monitor

Primero, identifica tu interfaz (ej. wlan0) y ponla en modo monitor:

sudo airmon-ng start wlan0

Esto creará una interfaz virtual llamada wlan0mon.

Paso 2: Capturar paquetes (Necesario para atacar)

Para inyectar, necesitas conocer el BSSID del objetivo y el canal. Usa airodump-ng:

sudo airodump-ng wlan0mon

Paso 3: Realizar un ataque de desautenticación

Este ataque desconecta a los clientes del punto de acceso para forzar una reconexión, permitiendo capturar el handshake:

sudo aireplay-ng --deauth 5 -a [BSSID_DEL_ROUTER] wlan0mon

Donde 5 es el número de paquetes de desautenticación enviados.

Paso 4: Inyección de paquetes (ARP Request Replay)

Para redes WEP, este ataque inyecta paquetes para generar tráfico y obtener IVs rápidamente:

sudo aireplay-ng -3 -b [BSSID_DEL_ROUTER] -h [MAC_DEL_CLIENTE_ASOCIADO] wlan0mon

Nota: Es necesario que haya un cliente asociado a la red para este ataque.
