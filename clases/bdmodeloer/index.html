1. Sistema de Gestión de Bases de Datos (SGBD)

Un SGBD (o DBMS en inglés) es el software que actúa como interfaz entre la base de datos, los usuarios y las aplicaciones. Permite almacenar, modificar y extraer información de forma estructurada, segura y eficiente.

Funciones Clave de un SGBD:

  • Gestión del almacenamiento: Organiza los datos en disco de forma óptima.
  • Control de concurrencia: Permite que varios usuarios accedan simultáneamente sin corromper la información.
  • Integridad y seguridad: Aplica reglas de acceso y restricciones de datos.
  • Recuperación ante fallos: Permite restaurar datos tras un error del sistema.

2. Componentes del Modelo Entidad-Relación

El **Modelo Entidad-Relación (MER)** es una herramienta conceptual utilizada para diseñar la estructura de una base de datos antes de programarla.

Entidad

Representa un objeto, persona, lugar o concepto del mundo real sobre el cual se desea almacenar información. En el diagrama se representa con un rectángulo.

Ejemplo: Estudiante, Curso, Factura.

Atributo

Es una propiedad o característica que describe a una entidad. Se representan mediante óvalos.

Ejemplo: Cédula, Nombre, Correo. El atributo principal se subraya (Clave Primaria).

Relación

Es la asociación o vínculo que existe entre dos o más entidades. Se representa con un rombo.

Ejemplo: Un Estudiante Inscribe una Asignatura.

3. Cardinalidades y Simbología

La cardinalidad define cuántas instancias de una entidad pueden asociarse con instancias de otra entidad.

  • 1:1 (Uno a Uno): Una entidad A se relaciona con una sola entidad B.
  • 1:N (Uno a Muchos): Una entidad A se relaciona con varias entidades B, pero B solo con una A.
  • N:M (Muchos a Muchos): Varias entidades A se relacionan con varias entidades B.
