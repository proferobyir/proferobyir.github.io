1. Teoría Fundamental de CSS

CSS (Cascading Style Sheets) es el estándar formal que define la presentación visual de documentos estructurados escritos en HTML o XML. Su propósito primario es separar de manera tajante el contenido semántico de la capa de diseño gráfico.

1.1 Historia y Nacimiento (1994 - 1996)

10 de Octubre, 1994

Propuesta Inicial

Håkon Wium Lie propone CSS mientras trabajaba con Tim Berners-Lee en el CERN. El objetivo era frenar el descontrol de etiquetas visuales propietarias en HTML.

17 de Diciembre, 1996

Recomendación Oficial W3C

El consorcio W3C publica la especificación oficial CSS Level 1, estableciendo las bases del diseño web moderno con selectores, fuentes y colores.

1.2 El Algoritmo de la Cascada y la Especificidad

La "C" de Cascada se refiere a cómo el navegador determina qué estilo aplicar cuando existen reglas en conflicto para un mismo elemento:

Jerarquía de Prioridad (De Mayor a Menor Importancia):

1. Estilos en Línea (Inline) style="..." (Especificidad Máxima)
2. Estilos Internos y Externos Selectores (#ID, .Clase, Etiqueta)
3. Estilos por Defecto del Navegador User Agent Stylesheet

2. Diagrama e Interacción de las 3 Formas de Agregar CSS

Explora interactivamente cada uno de los tres métodos normalizados para aplicar hojas de estilo a un documento HTML:

Método 1: Estilos en Línea (Inline)

Se aplican directamente en el elemento mediante el atributo style="...". Modifica los controles para ver el cambio instantáneo en el elemento y en el código generado.

¡Elemento Estilizado en Línea! 

<p style="color: #002b49; background-color: #ffffff; padding: 20px; border-radius: 10px;">¡Elemento Estilizado en Línea!</p>

Método 2: Estilos Internos (Internal)

Se escriben dentro del bloque <head> usando la etiqueta <style>. Este diagrama ilustra cómo las reglas de la cabecera aplican su estilo sobre los elementos del <body>.

<!DOCTYPE html>
<html>
<head>
  <style>
    .tarjeta-academica {
      color: #002b49;
      border-left: 5px solid;
    }
  </style>
</head>
<body>
  <div class="tarjeta-academica">
    Contenido afectado
  </div>
</body>
</html>
Soy una caja estilizada mediante la regla interna de la cabecera <head>.

Método 3: Estilos Externos (External)

Es la máxima buena práctica. El archivo HTML se conecta mediante la etiqueta <link> a un archivo .css totalmente independiente.

index.html <head>
  <link rel="stylesheet"
        href="estilos.css">
</head>
<body>
  <h1 class="titulo">
</body>
VÍNCULO HTTP
<link>
estilos.css .titulo {
  color: #002b49;
  font-family: serif;
  border-bottom: 2px solid;
}

Ventajas Clave de este Método:

  • Reutilización: Una sola hoja .css puede estilizar cientos de páginas HTML.
  • Carga Rápida: El navegador almacena en caché el archivo CSS externo.
  • Mantenibilidad: Cambias el diseño de todo un sitio web modificando un solo archivo.

3. ¿A qué elementos se aplican los estilos CSS?

Además de elegir dónde escribir CSS (en línea, dentro de <style> o en un archivo externo), debemos decidir qué elementos HTML queremos seleccionar. Para eso usamos selectores.

Los tres selectores básicos de esta lección son: etiqueta o elemento, clase e ID. Las reglas CSS siguen la forma selector { propiedad: valor; }.

p { ... }

1. Selector por elemento

Selecciona todas las etiquetas del tipo indicado. Por ejemplo, p afecta a todos los párrafos alcanzados por esa regla.

p {
  color: #075985;
  font-size: 18px;
}

Primer párrafo de ejemplo.

Segundo párrafo: recibe la misma regla.

Úsalo cuando: quieras una apariencia común para todas las etiquetas de ese tipo.

.mensaje-importante { ... }

2. Selector por clase

Una clase se escribe en HTML con el atributo class y en CSS se selecciona con un punto (.). Puedes reutilizarla en muchos elementos.

.mensaje-importante {
  background: #fef3c7;
  color: #92400e;
}

Este párrafo tiene la clase mensaje-importante.

Esta caja reutiliza la misma clase.

Este otro párrafo no tiene esa clase.

Úsala cuando: varios elementos deban compartir un mismo estilo.

#mensaje-unico { ... }

3. Selector por ID

Un ID se escribe en HTML con id y en CSS se selecciona con el símbolo numeral (#). Debe identificar de forma única un elemento de la página.

#mensaje-unico {
  background: #dcfce7;
  color: #166534;
}

Este es el elemento identificado como mensaje-unico.

Úsalo cuando: quieras seleccionar un elemento específico, por ejemplo, un aviso principal.

Cómo recordar los símbolos: p = etiqueta, .nombre-clase = clase, #nombre-id = ID. El punto y el numeral se escriben en CSS, no en el valor de class ni de id en HTML.

3.1 Comparación directa en HTML y CSS

Observa cómo el HTML identifica los elementos y cómo cada selector los encuentra en la hoja de estilos.

Archivo HTML

<p>Párrafo general</p>

<p class="aviso">
  Aviso que puede repetirse
</p>

<div class="aviso">
  Otro elemento con la misma clase
</div>

<p id="aviso-principal">
  Aviso único de la página
</p>

Reglas CSS

p {
  font-family: Arial, sans-serif;
}

.aviso {
  background-color: #fef3c7;
  padding: 10px;
}

#aviso-principal {
  color: #166534;
  border: 2px solid #22c55e;
}
  • La regla p selecciona los párrafos, pero no el div.
  • La regla .aviso selecciona tanto el párrafo como el div que tengan esa clase.
  • La regla #aviso-principal selecciona el elemento cuyo atributo id sea exactamente aviso-principal.

3.2 ¿Qué ocurre si varios selectores intentan cambiar la misma propiedad?

Cuando varias reglas normales se aplican al mismo elemento y declaran la misma propiedad, la especificidad ayuda a decidir cuál gana. En condiciones equivalentes, un ID tiene más especificidad que una clase, y una clase tiene más que una etiqueta.

p { color: navy; }       /* selector de elemento */
.nota { color: orange; } /* selector de clase */
#nota-uno { color: green; } /* selector de ID */

Si un párrafo tiene class="nota" e id="nota-uno", el texto será verde por la regla del ID, siempre que no intervenga otra regla de mayor prioridad, como una declaración importante o un estilo en línea aplicable.

Importante: clase e ID no son métodos distintos de insertar CSS; son formas de seleccionar los elementos a los que una regla CSS se aplica. Puedes usar selectores de etiqueta, clase e ID dentro de CSS interno o externo.
