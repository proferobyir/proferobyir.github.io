💻 1. Introducción al Desarrollo Web

El desarrollo web abarca la creación y mantenimiento de sitios y aplicaciones que operan en internet o redes privadas. Se sustenta sobre tres tecnologías fundamentales ejecutadas o interpretadas en el ecosistema digital:

HTML5

El esqueleto y estructura semántica de la información (etiquetas, textos, formularios, multimedia).

CSS3

La capa de presentación visual, diseño responsive, colores, tipografías y animaciones.

JavaScript

La capa de comportamiento y lógica interactiva del lado del cliente.

🎨 2. Relación entre Diseño Gráfico y Desarrollo Web

El diseño gráfico y el desarrollo web son disciplinas simbióticas. Mientras el diseño define el lenguaje visual y la estrategia de comunicación, el desarrollo construye la viabilidad técnica para que dicho mensaje sea accesible, funcional y rápido en cualquier dispositivo.

  • UX (Experiencia de Usuario): Estudia la interacción humana con el sistema, buscando que sea intuitiva y eficiente.
  • UI (Interfaz de Usuario): Se enfoca en la disposición visual de los elementos, controles y estética general.
  • Traducción técnica: El desarrollador interpreta los lineamientos estéticos (espacios, escalas, paletas) y los traduce a código optimizado.

🌐 3. Estructura Cliente - Servidor

La web funciona bajo un modelo distribuido donde dos actores principales interactúan a través de protocolos de red (como HTTP/HTTPS):

CLIENTE
Navegador Web (Frontend)
➔ Petición (Request)
⬅️ Respuesta (Response)
SERVIDOR
Hosting / Base de datos (Backend)

El Cliente: Es el dispositivo del usuario (smartphone, PC) y su navegador (Chrome, Firefox, Safari). Ejecuta el HTML, CSS y JS.

El Servidor: Es una computadora remota optimizada que almacena los archivos del sitio, procesa bases de datos y gestiona la lógica pesada.

📐 4. Principios de Diseño Gráfico Aplicados

Para construir interfaces web atractivas y funcionales, es indispensable dominar los pilares del diseño visual:

Tipografía

Elección de fuentes legibles (familias Serif, Sans-Serif), jerarquía de tamaños mediante escalas modulares y correcta longitud de línea para lectura fluida.

Color

Uso de psicología del color para transmitir emociones, guiar la atención con contrastes adecuados (accesibilidad WCAG) y mantener consistencia de marca.

Composición

Organización espacial de los elementos usando leyes de la Gestalt, alineación precisa y el uso estratégico del espacio negativo (respiración visual).

Jerarquía Visual

Guía el ojo del usuario de manera natural desde lo más importante (títulos, llamados a la acción) hasta los detalles secundarios mediante tamaño, peso y color.
