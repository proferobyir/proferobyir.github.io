Clase Magistral: Manejo de JSON y el Método .map()

De cadenas de texto plano a objetos manipulables en memoria y transformación funcional de arreglos.

1. ¿Qué es JSON y por qué debemos "parsearlo"?

JSON (JavaScript Object Notation) es un formato estándar de intercambio de datos basado en texto plano. Cuando recibimos datos desde una API REST, un archivo o localStorage, JavaScript no recibe un objeto, sino una cadena de texto (string).

Si intentas acceder directamente a una propiedad de un string JSON sin convertirlo primero, obtendrás undefined:

problema-string.js 
// Esto es una cadena de texto (string), NO un objeto JavaScript
const respuestaAPI = '{"producto": "Monitor 24", "precio": 180}';

console.log(typeof respuestaAPI); // "string"
console.log(respuestaAPI.producto); // undefined (Error lógico)
Reglas estrictas de sintaxis JSON:
1. Las claves y los textos deben usar obligatoriamente comillas dobles ("clave"). Las comillas simples son inválidas.
2. No se permiten comas finales (trailing commas) después del último elemento.
3. Solo admite tipos: string, number, boolean, null, object y array.

2. Parseo y Serialización: JSON.parse() y JSON.stringify()

JavaScript integra el objeto nativo JSON con dos métodos fundamentales para transformar datos:

Método Conversión Uso Principal
JSON.parse(texto) String → Objeto / Array Convierte una cadena JSON válida en una estructura nativa de JS para leer o modificar propiedades.
JSON.stringify(dato) Objeto / Array → String Convierte un objeto o arreglo de JS en texto JSON listo para enviarse por red o guardarse en localStorage.

Flujo completo: Parsear, Manipular y Serializar

ciclo-json.js 
// 1. String JSON recibido
const jsonCrudo = `{
  "id": 101,
  "usuario": "ana_dev",
  "activo": true,
  "habilidades": ["HTML", "CSS"]
}`;

// 2. PARSEO: Convertir string a objeto manipulable
const perfil = JSON.parse(jsonCrudo);

// 3. MANIPULACIÓN: Leer, modificar, agregar y eliminar
console.log(perfil.usuario);            // "ana_dev"
perfil.usuario = "ana_fullstack";     // Modificar valor
perfil.habilidades.push("JavaScript"); // Agregar elemento al arreglo
perfil.rol = "Programadora";          // Crear nueva propiedad
delete perfil.activo;                 // Eliminar propiedad

// 4. SERIALIZACIÓN: Volver a convertir en string JSON formateado (2 espacios)
const jsonFinal = JSON.stringify(perfil, null, 2);
console.log(jsonFinal);

3. Recorrer y Transformar Arreglos JSON con .map()

En aplicaciones reales, los datos JSON suelen llegar como un arreglo de objetos (por ejemplo, una lista de estudiantes o un catálogo de productos). Una vez aplicado JSON.parse(), el método .map() es la herramienta ideal para recorrer cada objeto y generar un nuevo arreglo transformado.

Características clave de .map()

  • Recorre todos los elementos del arreglo en orden.
  • Ejecuta una función callback por cada objeto y retorna un nuevo arreglo con la misma longitud.
  • No muta (no altera) el arreglo original, lo que previene errores inesperados.
uso-map-json.js 
// String JSON que contiene un arreglo de productos
const jsonInventario = `[
  {"id": 1, "nombre": "Teclado", "precio": 40},
  {"id": 2, "nombre": "Mouse", "precio": 20},
  {"id": 3, "nombre": "Laptop", "precio": 600}
]`;

// Paso 1: Parsear el string JSON a un Array de Objetos JS
const productos = JSON.parse(jsonInventario);

// Caso A: Extraer solo una lista de nombres (Array de strings)
const soloNombres = productos.map((item) => item.nombre);
console.log(soloNombres); // ["Teclado", "Mouse", "Laptop"]

// Caso B: Transformar cada objeto calculando el IVA (16%)
const productosConIVA = productos.map((item) => {
  return {
    id: item.id,
    producto: item.nombre.toUpperCase(),
    precioBase: item.precio,
    precioFinal: +(item.precio * 1.16).toFixed(2)
  };
});

console.log(productosConIVA);

// Caso C: Generar etiquetas HTML dinámicas para renderizar en el DOM
const tarjetasHTML = productos.map((item) => {
  return `<li>${item.nombre} - $${item.precio}</li>`;
}).join("");

4. Manejo Seguro de Errores con try...catch

Si JSON.parse() recibe un texto mal formado (por ejemplo, comillas simples o una respuesta HTML de error del servidor), lanzará una excepción SyntaxError y detendrá todo el programa. Siempre encapsula el parseo en un bloque try...catch:

seguridad-parse.js 
const jsonInvalido = "{'nombre': 'Carlos'}"; // Error: usa comillas simples

try {
  const datos = JSON.parse(jsonInvalido);
  console.log(datos.nombre);
} catch (error) {
  console.error("El formato JSON es inválido:", error.message);
}
