1. Aclaratoria Pedagógica: Semántica HTML

Las tablas en HTML5 deben utilizarse únicamente para datos tabulares (información estructurada en filas y columnas). Nunca deben usarse para la maquetación de la interfaz o la estructura del sitio web.

⚠️ Regla de Oro en Desarrollo Web

Utilizar <table> para crear el diseño o maquetación general destruye la accesibilidad para lectores de pantalla y empeora el rendimiento. La estructura general se maqueta con Flexbox o CSS Grid.

3. ¿Cómo hacer la Tabla Responsiva con CSS?

El truco profesional para mantener tablas accesibles y responsivas en cualquier pantalla consiste en envolver la tabla en un elemento contenedor y aplicar:

/* 1. Envolver la tabla en un div responsivo */
                        .table-responsive {
                            width: 100%;
                            overflow-x: auto; /* Permite scroll horizontal en móviles */
                            -webkit-overflow-scrolling: touch;
                        }

                        /* 2. Mantener las celdas firmes */
                        .carbon-table th, .carbon-table td {
                            white-space: nowrap; /* Evita deformación de texto */
                        }
