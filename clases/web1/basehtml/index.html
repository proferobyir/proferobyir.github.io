Módulo 01

Fundamentos: prepara tu primer proyecto

HTML es el lenguaje que describe la estructura de una página web. Comienza creando una carpeta de trabajo, un archivo index.html y ábrelo en tu navegador.

Concepto

¿Qué es HTML?

Es el lenguaje de marcado que permite organizar títulos, textos, enlaces, imágenes, formularios y otros elementos de una web.

Base del curso Listo para iniciar
Preparación

Editor y carpeta

Usa un editor como Visual Studio Code, crea una carpeta para el proyecto y guarda ahí todos los archivos relacionados.

Organización Paso esencial
Primer archivo

El archivo index.html

Crea index.html como punto de entrada del proyecto y actualiza el navegador cada vez que guardes cambios.

Práctica rápida 5 minutos

Tu objetivo en este módulo

  • Crear una carpeta llamada mi-primer-sitio.
  • Abrir esa carpeta desde tu editor de código.
  • Crear y guardar el archivo index.html.
  • Abrir el archivo en el navegador para ver tus cambios.

Primer archivo HTML

Escribe esta estructura para comenzar.

<!DOCTYPE html>
<html lang="es">
  <head>
    <title>Mi primer sitio</title>
  </head>
  <body>
    <h1>Hola, mundo</h1>
  </body>
</html>

Módulo 02

Construye la estructura y el contenido de tu página

Aprende para qué sirven DOCTYPE, html, head, body, títulos, párrafos, comentarios y etiquetas de apoyo como span y br.

Etiquetas que debes reconocer

  • <!DOCTYPE html>: indica que el documento usa HTML5.
  • <head>: incluye información de configuración.
  • <title>: define el título de la pestaña.
  • <body>: contiene lo que verá la persona visitante.
  • <h1> a <h6>: organizan la jerarquía de títulos.
  • <p>: crea un párrafo de texto.

Jerarquía de contenido

Usa los títulos para ordenar ideas, no solo para cambiar el tamaño del texto.

<h1>Curso de HTML</h1>

<h2>¿Qué aprenderás?</h2>
<p>
  Crearás páginas web con una estructura clara.
</p>

<hr>

<p>
  Este texto tiene un <span>detalle importante</span>.
  <br>
  Esta frase aparece en otra línea.
</p>

<!-- Este comentario no se muestra en pantalla -->

Checklist de práctica

  • Cambia el contenido de <title> por un título descriptivo.
  • Escribe un <h1> para el tema principal de tu página.
  • Agrega dos secciones usando <h2> y párrafos.
  • Incluye una línea horizontal con <hr>.
  • Agrega un comentario para explicar una parte del código.

Módulo 03

Conecta páginas y muestra imágenes

Los enlaces permiten navegar hacia otras páginas o secciones. Las imágenes enriquecen el contenido cuando se usan con rutas claras y texto alternativo útil.

Enlaces

La etiqueta anchor

Usa <a> junto con el atributo href para definir a dónde debe ir una persona al hacer clic.

href Navegación
Nueva pestaña

El atributo target

Utiliza target="_blank" cuando el enlace deba abrirse en una nueva pestaña del navegador.

target Opcional
Imágenes

La etiqueta img

Usa src para la ruta de la imagen y alt para describirla cuando no pueda visualizarse.

src + alt Esencial

Ejemplo de enlace

<a
  href="https://www.ejemplo.com"
  target="_blank"
>
  Visitar recurso
</a>

Ejemplo de imagen

<img
  src="img/mi-imagen.jpg"
  alt="Descripción breve de la imagen"
  width="400"
>

Módulo 04

Recibe información con formularios

Un formulario reúne datos de una persona usuaria mediante label, input, textarea y botones. Relaciona cada etiqueta con su campo usando for e id.

Elementos principales

  • <form>: agrupa los campos de captura.
  • <label>: explica qué se solicita en un campo.
  • <input>: captura datos de una sola línea.
  • <textarea>: permite escribir mensajes más extensos.
  • name: identifica el dato al enviarlo.
  • placeholder: ofrece un ejemplo o pista dentro del campo.

Módulo 05

Organiza información con listas y tablas

Usa listas cuando el contenido se entiende mejor como una secuencia o colección. Emplea tablas cuando necesites comparar datos en filas y columnas.

Lista ordenada

<ol>
  <li>Crear la carpeta</li>
  <li>Abrir index.html</li>
  <li>Escribir contenido</li>
</ol>

<ul>
  <li>Títulos</li>
  <li>Párrafos</li>
  <li>Enlaces</li>
</ul>

Cuándo usar cada una

  • Usa <ol> cuando el orden sí importa.
  • Usa <ul> para grupos de elementos sin secuencia.
  • Usa <table> para datos comparables por columna.
  • Incluye <th> para encabezados y <td> para celdas de datos.
Etiqueta Función Ejemplo de uso
<ul> Lista sin orden Temas que aprenderás
<ol> Lista ordenada Pasos para publicar una página
<table> Tabla de datos Horario de clases o comparación de recursos
<tr> Fila de la tabla Una nueva línea de información

Proyecto final

Integra lo aprendido creando una página con encabezado, artículos, títulos, imágenes, enlaces y secciones organizadas mediante div, id y class.

1

Define la estructura

Crea el encabezado del blog y separa el contenido principal en artículos o secciones.

2

Agrega contenido

Incluye títulos, párrafos, imágenes y enlaces que permitan recorrer tu publicación.

3

Organiza con atributos

Usa class para agrupar elementos similares e id para identificar secciones concretas.
