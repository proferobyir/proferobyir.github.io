1 Introducción informal

Python puede usarse como calculadora, manejar texto y ejecutar código de forma interactiva. Los ejemplos muestran operaciones básicas, cadenas y listas.

🔹 Operaciones aritméticas y asignación múltiple

>>> 2 + 2 4 >>> 50 - 5 * 6 20 >>> (50 - 5 * 6) / 4 5.0 >>> # Asignación múltiple >>> a, b = 0, 1 >>> a 0 >>> b 1

🔹 Cadenas: índices, rebanadas e inmutabilidad

>>> word = 'Python' >>> word[0] # primer carácter 'P' >>> word[-1] # último carácter 'n' >>> word[0:2] # rebanada: desde 0 hasta 2 (sin incluir) 'Py' >>> word[2:5] 'tho' >>> # Las cadenas son inmutables >>> word[0] = 'J' # Error: TypeError Traceback (most recent call last): ... TypeError: 'str' object does not support item assignment

🔹 Listas: mutables y flexibles

>>> squares = [1, 4, 9, 16, 25] >>> squares [1, 4, 9, 16, 25] >>> squares[0] = 100 # las listas sí son mutables >>> squares [100, 4, 9, 16, 25] >>> squares.append(36) >>> squares [100, 4, 9, 16, 25, 36]

2 Más herramientas para control de flujo

Bucles while, for, condicionales, y las funciones range(), enumerate() y break/continue.

🔹 Bucle while con serie de Fibonacci

>>> a, b = 0, 1 >>> while a < 10: ... print(a, end=' ') ... a, b = b, a+b ... 0 1 1 2 3 5 8

🔹 for con range() y enumerate()

>>> for i in range(3): ... print(i) ... 0 1 2 >>> frutas = ['manzana', 'banana', 'cereza'] >>> for idx, fruta in enumerate(frutas): ... print(idx, fruta) ... 0 manzana 1 banana 2 cereza

🔹 break, continue y cláusula else en bucles

>>> for n in range(2, 10): ... for x in range(2, n): ... if n % x == 0: ... print(n, 'es igual a', x, '*', n//x) ... break ... else: ... print(n, 'es un número primo') ... 2 es un número primo 3 es un número primo 4 es igual a 2 * 2 5 es un número primo 6 es igual a 2 * 3 7 es un número primo 8 es igual a 2 * 4 9 es igual a 3 * 3

3 Funciones

Definición con def, argumentos posicionales, por nombre, valores por defecto, *args, **kwargs y funciones lambda.

🔹 Función con valor por defecto y argumentos variables

>>> def saludar(nombre, saludo='Hola'): ... return f'{saludo}, {nombre}!' ... >>> saludar('Ana') 'Hola, Ana!' >>> saludar('Luis', 'Buen día') 'Buen día, Luis!'

🔹 *args y **kwargs

>>> def mostrar(*args, **kwargs): ... print('Posicionales:', args) ... print('Nombrados:', kwargs) ... >>> mostrar(1, 2, 3, nombre='Ana', edad=30) Posicionales: (1, 2, 3) Nombrados: {'nombre': 'Ana', 'edad': 30}

🔹 Expresión lambda y ordenamiento con clave

>>> pares = [(1, 'uno'), (2, 'dos'), (3, 'tres')] >>> pares.sort(key=lambda par: par[1]) >>> pares [(2, 'dos'), (3, 'tres'), (1, 'uno')]

4 Estructuras de datos

Listas, tuplas, conjuntos y diccionarios. Operaciones comunes y comprensiones.

🔹 Listas: métodos y comprensión

>>> letras = ['a', 'b', 'c', 'd'] >>> letras.append('e') >>> letras ['a', 'b', 'c', 'd', 'e'] >>> [x.upper() for x in letras if x != 'c'] ['A', 'B', 'D', 'E']

🔹 Tuplas: inmutables y desempaquetado

>>> punto = (3, 4) >>> x, y = punto >>> x, y (3, 4) >>> # Las tuplas no se pueden modificar >>> punto[0] = 5 Traceback (most recent call last): ... TypeError: 'tuple' object does not support item assignment

🔹 Conjuntos: operaciones de unión e intersección

>>> a = {1, 2, 3, 4} >>> b = {3, 4, 5, 6} >>> a | b # unión {1, 2, 3, 4, 5, 6} >>> a & b # intersección {3, 4}

🔹 Diccionarios: claves, valores y comprensión

>>> edades = {'Ana': 30, 'Luis': 25} >>> edades['Ana'] 30 >>> edades['Carlos'] = 40 >>> edades {'Ana': 30, 'Luis': 25, 'Carlos': 40} >>> {nombre: edad for nombre, edad in edades.items() if edad > 28} {'Ana': 30, 'Carlos': 40}

5 Módulos

Importación de módulos, uso de la biblioteca estándar y creación de módulos propios (simulado).

🔹 Importar y usar el módulo math

>>> import math >>> math.sqrt(16) 4.0 >>> math.pi 3.141592653589793 >>> from math import factorial >>> factorial(5) 120

🔹 Módulo propio (ejemplo conceptual)

Archivo mi_modulo.py:

# mi_modulo.py def sumar(a, b): return a + b

Uso desde otro archivo:

>>> import mi_modulo >>> mi_modulo.sumar(3, 4) 7

6 Entrada y salida

Formateo de cadenas (f-strings, formato), lectura y escritura de archivos con open() y el gestor de contexto with.

🔹 Formateo con f-strings y str.format()

>>> nombre = 'Ana' >>> edad = 30 >>> f'{nombre} tiene {edad} años.' 'Ana tiene 30 años.' >>> '{} tiene {} años.'.format(nombre, edad) 'Ana tiene 30 años.'

🔹 Escribir y leer un archivo de texto

>>> with open('ejemplo.txt', 'w', encoding='utf-8') as f: ... f.write('Hola, mundo!\nSegunda línea.') ... >>> with open('ejemplo.txt', 'r', encoding='utf-8') as f: ... contenido = f.read() ... >>> print(contenido) Hola, mundo! Segunda línea.

7 Errores y excepciones

Manejo con try, except, else y finally. Lanzamiento de excepciones con raise.

🔹 Capturar una excepción específica

>>> try: ... x = int('abc') ... except ValueError: ... print('No se pudo convertir a entero') ... No se pudo convertir a entero

🔹 else y finally

>>> try: ... resultado = 10 / 2 ... except ZeroDivisionError: ... print('División por cero') ... else: ... print('Resultado:', resultado) ... finally: ... print('Bloque finally siempre se ejecuta') ... Resultado: 5.0 Bloque finally siempre se ejecuta

🔹 Lanzar una excepción con raise

>>> def validar_edad(edad): ... if edad < 0: ... raise ValueError('La edad no puede ser negativa') ... return edad ... >>> validar_edad(-5) Traceback (most recent call last): ... ValueError: La edad no puede ser negativa

8 Clases

Definición de clases, métodos, atributos, herencia y métodos especiales como __init__.

🔹 Clase básica con método y atributo

>>> class Perro: ... def __init__(self, nombre): ... self.nombre = nombre ... def ladrar(self): ... return f'{self.nombre} dice: ¡Guau!' ... >>> mi_perro = Perro('Rex') >>> mi_perro.ladrar() 'Rex dice: ¡Guau!'

🔹 Herencia y sobrescritura de métodos

>>> class Animal: ... def hablar(self): ... return 'Sonido genérico' ... >>> class Gato(Animal): ... def hablar(self): ... return 'Miau' ... >>> Animal().hablar() 'Sonido genérico' >>> Gato().hablar() 'Miau'

🔹 Método especial __str__

>>> class Punto: ... def __init__(self, x, y): ... self.x = x ... self.y = y ... def __str__(self): ... return f'({self.x}, {self.y})' ... >>> print(Punto(3, 4)) (3, 4)

9 Biblioteca estándar

Python incluye una amplia biblioteca estándar. Algunos módulos útiles: os, sys, datetime, json, random.

🔹 os y sys

>>> import os >>> os.getcwd() # directorio actual (ejemplo) '/home/usuario' >>> import sys >>> sys.version.split()[0] # versión de Python '3.12.0'

🔹 datetime y json

>>> from datetime import date >>> date.today() datetime.date(2026, 11, 11) >>> import json >>> json.dumps({'nombre': 'Ana', 'edad': 30}) '{"nombre": "Ana", "edad": 30}'

🔹 random: elección aleatoria

>>> import random >>> random.choice(['rock', 'papel', 'tijera']) 'papel' >>> random.randint(1, 10) 7
💡 Consejo: La biblioteca estándar de Python es muy extensa. Puedes explorarla en la documentación oficial. Algunos módulos muy útiles son collections, itertools, pathlib y re.
