Entrada y Salida en Consola: WriteLine, ReadLine y Convert.ToInt32

En aplicaciones de consola en C#, la clase Console (perteneciente al espacio de nombres System) nos permite comunicarnos con el usuario mediante texto en pantalla y lectura desde el teclado.

📤 Console.WriteLine()

Imprime un mensaje o valor en la consola y agrega automáticamente un salto de línea al final. Si deseas que el cursor se quede en la misma línea (ideal antes de pedir un dato), puedes usar Console.Write().

📥 Console.ReadLine()

Detiene la ejecución del programa hasta que el usuario escribe algo y presiona Enter. Siempre devuelve un dato de tipo string (cadena de texto), incluso si el usuario escribió números.

Lectura de cadenas (string) vs. Lectura de enteros (int)

Como Console.ReadLine() devuelve texto (string), podemos guardarlo directamente en una variable string. Sin embargo, si necesitamos realizar cálculos matemáticos con ese dato, debemos convertirlo explícitamente a entero usando Convert.ToInt32().

// ¿Cómo funciona Convert.ToInt32(valor)? Toma la cadena de texto capturada por Console.ReadLine(), analiza sus caracteres numéricos y los transforma en un entero de 32 bits (int) que ya puede asignarse a una variable entera.
Program.cs · Captura de string e int
using System;

class Program
{
    static void Main()
    {
        // 1. Solicitud de un dato tipo string (texto)
        Console.Write("Ingrese su nombre completo: ");
        string nombre = Console.ReadLine(); // Se asigna directo porque ReadLine devuelve string

        // 2. Solicitud de un dato tipo int (entero) usando Convert.ToInt32
        Console.Write("Ingrese su edad: ");
        string entradaEdad = Console.ReadLine();       // Paso A: Leemos como texto
        int edad = Convert.ToInt32(entradaEdad);        // Paso B: Convertimos a int y asignamos

        // También se puede hacer en una sola línea anidada:
        Console.Write("Ingrese su año de ingreso a la universidad: ");
        int anioIngreso = Convert.ToInt32(Console.ReadLine());

        // Salida formateada con interpolación de cadenas ($)
        Console.WriteLine($"\nHola, {nombre}. Tienes {edad} años y entraste en {anioIngreso}.");
        Console.WriteLine($"En 5 años tendrás {edad + 5} años.");
    }
}
02

Manejo de Excepciones al Leer Enteros

¿Qué ocurre si nuestro código ejecuta Convert.ToInt32(Console.ReadLine()) esperando un número, pero el usuario escribe la letra "A" o la palabra "hola"?

⚠ Error en tiempo de ejecución: System.FormatException El programa se detendrá abruptamente ("crasheará") lanzando una excepción FormatException ("La cadena de entrada no tiene el formato correcto"), porque letras como "abc" no tienen representación numérica entera. Si escribe un número gigantesco, lanzará OverflowException.

Método 1: Bloque try - catch (Captura de Excepciones)

Para evitar que el programa colapse, envolvemos el código riesgoso dentro de un bloque try. Si ocurre un error, C# salta inmediatamente al bloque catch correspondiente para mostrar un mensaje amigable al usuario.

ManejoExcepciones.cs · try-catch
int numero = 0;

try
{
    Console.Write("Por favor, ingrese un número entero: ");
    numero = Convert.ToInt32(Console.ReadLine());
    Console.WriteLine($"¡Excelente! Ingresaste el número {numero}.");
}
catch (FormatException)
{
    // Se ejecuta si el usuario escribió letras, símbolos o dejó vacío
    Console.WriteLine("Error: Debes ingresar únicamente dígitos numéricos, no letras.");
}
catch (OverflowException)
{
    // Se ejecuta si el número supera el límite de int (-2,147,483,648 a 2,147,483,647)
    Console.WriteLine("Error: El número ingresado es demasiado grande o demasiado pequeño.");
}
catch (Exception ex)
{
    // Captura cualquier otro error inesperado
    Console.WriteLine($"Ocurrió un error inesperado: {ex.Message}");
}

Método 2: Validación Preventiva con int.TryParse() (Buena Práctica)

En C# moderno, además de try-catch, se recomienda int.TryParse() cuando validamos entradas frecuentes del usuario. Este método intenta convertir el texto y devuelve true si tuvo éxito (guardando el valor en una variable out) o false si el usuario ingresó letras, sin generar excepciones.

ValidacionSegura.cs · int.TryParse
Console.Write("Ingrese su nota (0 - 20): ");
string textoUsuario = Console.ReadLine();

if (int.TryParse(textoUsuario, out int nota))
{
    Console.WriteLine($"Nota válida registrada: {nota} pts.");
}
else
{
    Console.WriteLine($"'{textoUsuario}' no es un número entero válido.");
}

03

Operadores Aritméticos, Relacionales y Lógicos en C#

Los operadores son símbolos especiales que le indican al compilador de C# que realice operaciones matemáticas, comparaciones o evaluaciones lógicas sobre variables y valores.

A. Operadores Aritméticos

Operador Nombre Descripción Ejemplo (a = 10, b = 3)
+ Suma Suma dos operandos (o concatena si son string). a + b → 13
- Resta Resta el segundo operando del primero. a - b → 7
* Multiplicación Multiplica ambos operandos. a * b → 30
/ División Divide el primero entre el segundo. Nota: Entre dos int trunca decimales. 10 / 3 → 3 (10.0 / 3 → 3.33)
% Módulo (Residuo) Devuelve el resto de una división entera. Muy útil para saber si un número es par (n % 2 == 0). 10 % 3 → 1
++ / -- Incremento / Decremento Aumenta o disminuye en 1 el valor de una variable entera. a++ → 11

B. Operadores Relacionales (de Comparación)

Comparan dos valores y siempre devuelven un resultado booleano (true o false).

Operador Significado Ejemplo en C# Resultado
== Igual a (¡cuidado! No confundir con = de asignación) 5 == 5 true
!= Diferente de / Distinto a 5 != 3 true
> y < Mayor que / Menor que 10 < 4 false
>= y <= Mayor o igual que / Menor o igual que 18 >= 18 true

C. Operadores Lógicos (Booleanos)

Permiten combinar o invertir expresiones booleanas. En C# usan evaluación de cortocircuito (si el primer operando ya define el resultado, no evalúa el segundo).

Operador Nombre Regla de Evaluación Ejemplo
&& AND Lógico (Y) Devuelve true únicamente si ambas condiciones son verdaderas. (5 > 2) && (10 == 10) → true
|| OR Lógico (O) Devuelve true si al menos una de las condiciones es verdadera. (5 < 2) || (10 == 10) → true
! NOT Lógico (Negación) Invierte el valor lógico: convierte true en false y viceversa. !(5 == 5) → false
04

Estructuras Condicionales: if, else, else if y Anidamiento

Las estructuras condicionales permiten que nuestro programa tome decisiones y ejecute distintos bloques de código dependiendo de si una expresión lógica se evalúa como true o false.

1. Condicional Simple (if) y Doble (if - else)

CondicionalSimpleDoble.cs
int temperatura = 32;

// IF SIMPLE: Solo actúa si la condición es verdadera
if (temperatura > 30)
{
    Console.WriteLine("Advertencia: Temperatura elevada.");
}

// IF - ELSE: Define un camino alternativo si la condición es falsa
int numero = 7;
if (numero % 2 == 0)
{
    Console.WriteLine("El número es PAR.");
}
else
{
    Console.WriteLine("El número es IMPAR.");
}

2. Condicionales Encadenados (if - else if - else) y Anidados (if dentro de if)

Usamos else if cuando tenemos múltiples rangos mutuamente excluyentes (por ejemplo, escalas de calificación). Por otro lado, los condicionales anidados ocurren cuando colocamos una estructura if dentro del bloque de otro if o else para verificar requisitos secundarios.

ElseIfYAnidados.cs
int nota = 18;
bool proyectoEntregado = true;

// ESCALERA IF - ELSE IF - ELSE
if (nota < 0 || nota > 20)
{
    Console.WriteLine("Nota fuera de rango.");
}
else if (nota >= 10)
{
    Console.WriteLine("Estado: APROBADO.");

    // CONDICIONAL ANIDADO: Solo se evalúa si el estudiante ya aprobó (nota >= 10)
    if (nota >= 18 && proyectoEntregado)
    {
        Console.WriteLine("Mención Honorífica: Excelencia Académica.");
    }
    else
    {
        Console.WriteLine("Aprobado sin mención honorífica.");
    }
}
else
{
    Console.WriteLine("Estado: REPROBADO.");
}

3. Condiciones Compuestas con &&, || y Combinadas

Podemos unir varias condiciones en un solo if utilizando && y ||. Cuando se combinan ambos en una misma expresión, el operador && tiene mayor precedencia que || (similar a la multiplicación frente a la suma en matemáticas). Por ello, siempre usa paréntesis ( ) para dejar clara tu intención lógica.

CondicionesCombinadas.cs
int edad = 16;
bool tieneEntrada = false;
bool esVip = true;

// Ejemplo 1: Uso de && (Ambas deben cumplirse)
if (edad >= 18 && tieneEntrada)
{
    Console.WriteLine("Acceso estándar concedido.");
}

// Ejemplo 2: Uso de || (Basta con que una sea verdadera)
if (tieneEntrada || esVip)
{
    Console.WriteLine("Puede pasar por taquilla.");
}

// Ejemplo 3: Combinación de && y || con paréntesis
// Regla: Entra si (es mayor de edad Y tiene entrada) O si (es invitado VIP)
if ((edad >= 18 && tieneEntrada) || esVip)
{
    Console.WriteLine("¡Bienvenido al evento!");
}
else
{
    Console.WriteLine("Acceso denegado.");
}

Contraste con la Tabla de la Verdad

La Tabla de la Verdad es la base matemática de la lógica proposicional que gobierna las decisiones de C#. Nos permite predecir exactamente qué camino tomará un if ante todas las combinaciones posibles de valores true (V) y false (F).

A B A && B (AND)
true true true
true false false
false true false
false false false
A B A || B (OR)
true true true
true false true
false true true
false false false
