Fundamentos de Sistemas Operativos

Guía de conceptos esenciales, arquitecturas y sistemas de archivos

1. Conceptos Clave de un Sistema Operativo

Un Sistema Operativo (SO) es el software principal que gestiona el hardware de una computadora y proporciona servicios a los programas de aplicación.

Procesos vs. Hilos (Threads)

  • Proceso: Es un programa en ejecución. Tiene su propio espacio de memoria independiente, asignación de recursos y contexto de seguridad.
  • Hilo (Thread): Es la unidad más pequeña de ejecución dentro de un proceso. Múltiples hilos dentro del mismo proceso comparten la misma memoria y recursos, lo que permite la concurrencia y la multitarea eficiente.

Servicios y Demonios (Daemons)

Son programas que se ejecutan en segundo plano sin una interfaz de usuario directa para realizar tareas continuas o responder a eventos del sistema:

  • Servicios (Windows): Procesos gestionados por el Administrador de Control de Servicios (por ejemplo, el servicio de actualización o cola de impresión).
  • Demonios / Daemons (Linux y macOS): Procesos en segundo plano que usualmente terminan en "d" (ej. sshd, httpd, launchd).

Kernel o Núcleo

Es el corazón del SO. Controla el acceso directo al hardware (CPU, memoria, dispositivos I/O) y gestiona la transición entre el espacio de usuario y el espacio de kernel.

2. Microsoft Windows (10 y 11)

Windows es un sistema operativo de código cerrado orientado al usuario final y entornos empresariales, basado en el núcleo Windows NT.

Sistema de Archivos: NTFS y ReFS

  • NTFS (New Technology File System): El sistema de archivos predeterminado desde Windows NT. Soporta permisos de acceso ACL (Listas de Control de Acceso), cifrado (EFS), compresión, listas de control de auditoría y archivos de gran tamaño.
  • ReFS (Resilient File System): Diseñado para maximizar la disponibilidad de datos, tolerancia a fallos y manejo de grandes volúmenes de almacenamiento (usado principalmente en Windows Server y versiones Pro/Enterprise).

Características Destacadas

  • Uso intensivo del Registro de Windows, una base de datos centralizada para configuraciones del sistema y aplicaciones.
  • Soporte para ejecutar subsistemas como WSL (Windows Subsystem for Linux).

Administrador de Tareas y Gestión de Procesos

El Administrador de Tareas (taskmgr.exe) es la herramienta nativa de diagnóstico en Windows que permite supervisar el uso de CPU, memoria, disco y red, además de gestionar el ciclo de vida de los procesos activos.

  • Finalización Directa: Solicita al proceso el cierre ordenado liberando recursos.
  • Matar Procesos (Terminación Forzada): Invoca la llamada a la API TerminateProcess() para detener inmediatamente la ejecución en la CPU y liberar la RAM asignada sin guardar datos en búfer.
  • Comandos CLI equivalentes:
    • tasklist: Lista todos los procesos con su ID numérico (PID).
    • taskkill /IM nombre_proceso.exe /F: Fuerza la terminación de un proceso por su nombre ejecutable.

Resolución de Problemas: Caso Atasco en la Cola de Impresión

El servicio Print Spooler (spoolsv.exe) almacena temporalmente los trabajos de impresión en disco. Si un archivo se corrompe, retiene el archivo de spool e inhabilita las llamadas posteriores. Para resolverlo se sigue este procedimiento paso a paso:

Paso 1: Detener el Servicio de Cola de Impresión

Abre la consola de Servicios (services.msc), busca el servicio Cola de impresión y detén su ejecución para liberar los bloqueos sobre los archivos temporales.

Figura 2.1: Detención manual del servicio Print Spooler desde Services.msc.

Paso 2: Eliminar los Archivos del Directorio PRINTERS

Navega a la ruta C:\Windows\System32\spool\PRINTERS y elimina todos los archivos con extensión .SHD y .SPL retenidos en la carpeta.

Figura 2.2: Limpieza de archivos de spool retenidos dentro del directorio de impresión.

Paso 3: Reiniciar el Servicio de Cola de Impresión

Regresa a la consola de Servicios y haz clic en Iniciar sobre el servicio Cola de impresión para restablecer el spooler de forma limpia.

Figura 2.3: Reanudación del servicio de impresión en el sistema operativo.

Alternativa por consola administrativa (CMD):

C:\> net stop spooler
C:\> del /Q /F /S "%systemroot%\System32\Spool\PRINTERS\*.*"
C:\> net start spooler

3. Apple macOS

macOS es el sistema operativo exclusivo de los equipos Mac, basado en Unix (núcleo XNU / arquitectura Darwin). Cumple con las especificaciones POSIX.

Sistema de Archivos: APFS

  • APFS (Apple File System): Optimizado para almacenamiento SSD y Flash. Ofrece un cifrado fuerte de varias claves, clonación instantánea de archivos, "snapshots" (capturas de estado del sistema para respaldos con Time Machine) y asignación dinámica de espacio.
  • HFS+ (Hierarchical File System Plus): El sistema heredado sustituido por APFS a partir de macOS High Sierra.

Gestión de Servicios

Usa launchd como sistema de inicialización y gestión de demonios en segundo plano, reemplazando a los tradicionales scripts init.d o cron.

4. Linux y sus Principales Vertientes

Linux es un núcleo (Kernel) de código abierto inspirado en Unix. Al combinarse con software de GNU y repositorios, conforma una Distribución Linux (Distro).

Las dos grandes familias/vertientes:

  • Vertiente Debian:
    • Se enfoca en la estabilidad, la filosofía del software libre y una inmensa comunidad.
    • Gestión de paquetes mediante .deb con herramientas como apt y dpkg.
    • Ejemplos destacados: Debian, Ubuntu, Linux Mint, Pop!_OS, Kali Linux.
  • Vertiente Red Hat:
    • Orientada a entornos empresariales, servidores corporativos, rendimiento y certificación de seguridad.
    • Gestión de paquetes mediante .rpm con herramientas como dnf y yum.
    • Ejemplos destacados: RHEL (Red Hat Enterprise Linux), Fedora, CentOS Stream, Rocky Linux, AlmaLinux.

Sistemas de Archivos en Linux

  • ext4 (Fourth Extended Filesystem): Es el estándar más utilizado. Soporta journaling (diario para evitar corrupción de datos en cortes de energía), desfragmentación en línea y excelente rendimiento general.
  • Btrfs / XFS: Sistemas modernos utilizados frecuentemente en servidores y distribuidores como Fedora o RHEL por su soporte de volúmenes lógicos, snapshots y tolerancia a fallos.

5. Estructura de Directorios (FHS en Linux)

A diferencia de Windows (que usa letras de unidad como C:\ o D:\), Linux y macOS organizan todo desde una única raíz representada por una barra diagonal /:

  • / : La raíz del sistema de archivos (Root).
  • /bin y /usr/bin : Binarios y comandos esenciales del sistema.
  • /etc : Archivos de configuración del sistema y servicios.
  • /home (o /Users en macOS) : Directorios personales de cada usuario.
  • /var : Archivos variables (logs, bases de datos temporales, colas de correo).
  • /proc : Sistema de archivos virtual que expone información sobre el kernel y los procesos en ejecución.
