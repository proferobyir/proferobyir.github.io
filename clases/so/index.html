Fundamentos de Sistemas Operativos

Guía de conceptos esenciales, arquitecturas y sistemas de archivos

1. Conceptos Clave de un Sistema Operativo

Un Sistema Operativo (SO) es el software principal que actúa como intermediario entre el hardware de una computadora y las aplicaciones del usuario, administrando los recursos de procesamiento, memoria y almacenamiento.

1.1 El Núcleo (Kernel): El Corazón del Sistema

Para cumplir con esta función de intermediación, todo sistema operativo posee un Kernel o Núcleo. Es el componente central que controla el acceso directo al hardware (CPU, memoria, dispositivos I/O) y gestiona la transición segura entre el espacio de usuario y el espacio de kernel.

1.2 Unidades de Ejecución: Procesos e Hilos

Para ejecutar las aplicaciones sobre el Kernel, el sistema organiza el trabajo en diferentes niveles de procesamiento:

  • Proceso: Es un programa en ejecución que cuenta con su propio espacio de memoria independiente, asignación de recursos y contexto de seguridad aislado.
  • Hilo (Thread): Es la unidad más pequeña de ejecución dentro de un proceso. Múltiples hilos dentro de un mismo proceso comparten la misma memoria y recursos, permitiendo la concurrencia y la multitarea eficiente sin sobrecargar al sistema.

1.3 Tareas en Segundo Plano: Servicios y Demonios

Además de los programas interactivos que el usuario observa en pantalla, el Kernel coordina procesos continuos que operan de forma invisible:

  • Servicios (Windows): Procesos background gestionados por el Administrador de Control de Servicios (por ejemplo, el servicio de actualización o la cola de impresión).
  • Demonios / Daemons (Linux y macOS): Procesos en segundo plano guiados por el sistema de inicialización que usualmente terminan en la letra "d" (ej. sshd, httpd, launchd).

2. Microsoft Windows (10 y 11)

Microsoft Windows es un sistema operativo de código cerrado basado en el núcleo Windows NT, orientado principalmente a interfaces gráficas para usuarios finales y entornos corporativos.

2.1 Sistemas de Archivos

Para organizar la información en el disco, Windows implementa estructuras específicas según el entorno de trabajo:

  • NTFS (New Technology File System): El estándar predeterminado en clientes. Soporta permisos ACL (Listas de Control de Acceso), cifrado (EFS), compresión y registros de auditoría.
  • ReFS (Resilient File System): Diseñado para entornos de alta disponibilidad y servidores, con tolerancia a fallos ante corrupción de datos y soporte para volúmenes masivos.

2.2 Arquitectura y Administración del Sistema

Windows centraliza su configuración en el Registro de Windows (una base de datos jerárquica clave-valor) y ofrece compatibilidad con subsistemas modernos como WSL (Windows Subsystem for Linux).

Para supervisar la ejecución en tiempo real, el sistema incluye el Administrador de Tareas (taskmgr.exe), el cual maneja el cierre de aplicaciones mediante dos mecanismos principales:

  • Finalización Directa: Notifica al proceso que debe cerrar de forma ordenada liberando sus recursos.
  • Terminación Forzada (Matar Proceso): Invoca directamente la llamada a la API TerminateProcess() para detener el proceso en la CPU y liberar la RAM de inmediato.
  • Gestión por Línea de Comandos (CLI):
    • tasklist: Muestra los procesos activos junto a su PID (Process ID).
    • taskkill /IM nombre_proceso.exe /F: Fuerza la detención de un proceso por su ejecutable.

2.3 Caso Práctico de Diagnóstico: Atasco en el Spooler de Impresión

El servicio Print Spooler (spoolsv.exe) almacena temporalmente los documentos en disco antes de enviarlos a la impresora. Si un archivo se corrompe, la cola se bloquea. A continuación se detalla el procedimiento para restablecerlo:

Paso 1: Detener el Servicio

Accede a la consola de Servicios (services.msc) y detén el servicio Cola de impresión para liberar el bloqueo sobre los archivos temporales.

Navega a la ruta del sistema C:\Windows\System32\spool\PRINTERS y elimina todos los archivos con extensión .SHD y .SPL.

3. Apple macOS

macOS es el sistema operativo de Apple para computadoras Mac. Está construido sobre una base Unix (núcleo XNU / arquitectura Darwin) y cumple oficialmente con las especificaciones POSIX.

3.1 Sistema de Archivos: APFS

Diseñado para aprovechar el almacenamiento en estado sólido (SSD y Flash), el sistema de archivos predeterminado es APFS (Apple File System), el cual reemplazó al histórico HFS+. APFS integra cifrado nativo de clave múltiple, clonación instantánea de archivos y instantáneas (snapshots) optimizadas para respaldos con Time Machine.

3.2 Gestión de Servicios y Demonios

A diferencia de los sistemas Unix tradicionales, macOS utiliza launchd como el demonio maestro para la inicialización y administración centralizada de procesos en segundo plano.

4. Linux y sus Principales Vertientes

Linux es un núcleo (Kernel) libre y de código abierto. Cuando el núcleo se integra con utilidades del proyecto GNU, sistemas de gestión de paquetes y software complementario, se conforma una Distribución Linux (Distro).

4.1 Principales Familias de Distribuciones

  • Vertiente Debian: Orientada a la estabilidad y al software libre.
    • Gestión de paquetes: Formato .deb mediante herramientas como apt y dpkg.
    • Ejemplos: Debian, Ubuntu, Linux Mint, Pop!_OS, Kali Linux.
  • Vertiente Red Hat: Enfocada en entornos corporativos, servidores y certificación de seguridad.
    • Gestión de paquetes: Formato .rpm mediante herramientas como dnf y yum.
    • Ejemplos: RHEL, Fedora, CentOS Stream, Rocky Linux, AlmaLinux.

4.2 Sistemas de Archivos en Linux

  • ext4 (Fourth Extended Filesystem): Es el estándar más extendido. Incorpora journaling (registro de transacciones) para prevenir la corrupción de datos ante cortes de energía.
  • Btrfs / XFS: Utilizados en servidores y distribuciones modernas (como Fedora) por sus capacidades de gestión de volúmenes lógicos, snapshots y tolerancia a fallos.

5. Estructura de Directorios (FHS en Unix/Linux)

A diferencia de Windows (que asigna letras a cada unidad como C:\ o D:\), los sistemas basados en Unix (Linux y macOS) organizan toda la jerarquía de almacenamiento a partir de una única raíz representada por la barra diagonal / (Root):

  • / : La raíz del sistema de archivos.
  • /bin y /usr/bin : Contienen los ejecutables y comandos esenciales del sistema.
  • /etc : Archivos de configuración del sistema operativo y sus servicios.
  • /home (o /Users en macOS) : Directorios personales de los usuarios.
  • /var : Archivos de datos variables (logs del sistema, colas de impresión/correo, bases de datos).
  • /proc : Sistema de archivos virtual que expone en tiempo real información del kernel y procesos activos.
