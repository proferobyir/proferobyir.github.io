1. Introducción a PSeInt

PSeInt (Pseudocódigo Intérprete) es una herramienta educativa diseñada para enseñar la lógica de programación mediante un lenguaje en español claro e intuitivo. Todo programa estructurado en PSeInt sigue un esquema básico:

Algoritmo NombreDelAlgoritmo
    // Declaración e inicialización de variables
    Definir variable Como Entero;
    
    // Instrucciones
    Escribir "Ingrese un dato:";
    Leer variable;
FinAlgoritmo

2. Estructuras Condicionales

Las estructuras condicionales permiten evaluar una expresión lógica (Verdadera o Falsa) y bifurcar el flujo de ejecución según el resultado.

Condicional Simple y Compuesto (Si-Entonces / Sino)

Evalúa una expresión lógica. Si se cumple, ejecuta el bloque correspondiente; de lo contrario, salta al bloque alternativo si existe.

Si condicion Entonces
    // Instrucciones si la condición es Verdadera
Sino
    // Instrucciones si la condición es Falsa
FinSi

Condicional Múltiple (Según)

Permite evaluar una variable discreta frente a múltiples casos posibles evitando estructuras anidadas complejas.

Segun variable_numerica Hacer
    1:
        // Instrucciones para caso 1
    2:
        // Instrucciones para caso 2
    De Otro Modo:
        // Instrucciones si no coincide con ningún caso
FinSegun

3. Operadores Lógicos (Y / O), Tablas de Verdad y Estructuras Condicionales

Cuando necesitamos evaluar múltiples condiciones al mismo tiempo dentro de una estructura Si-Entonces, utilizamos operadores lógicos:

  • Y (ó &&): Devuelve Verdadero únicamente si AMBAS condiciones son verdaderas.
  • O (ó ||): Devuelve Verdadero si AL MENOS UNA de las condiciones es verdadera.

Tipos de Estructuras Condicionales y Evaluación Paso a Paso

A continuación se detallan los 3 tipos de condiciones existentes. En todos los casos se declaran e inicializan las variables antes de evaluarlas y se explica lo que ocurre si el resultado es VERDADERO o FALSO:

3.1. Condición Sencilla o Simple (Sólo Si-Entonces)

Evalúa una expresión. Si el resultado es VERDADERO, se ejecuta el bloque interno. Si el resultado es FALSO, el programa simplemente omite las instrucciones internas y continúa su camino.

// 1. Declaración de variables
Definir temperatura Como Entero;

// 2. Inicialización / Asignación previa del valor
temperatura <- 38;

// 3. Evaluación de la condición: (temperatura > 35) -> (38 > 35) -> VERDADERO
Si temperatura > 35 Entonces
    // --- SI EL RESULTADO ES VERDADERO: ---
    // Se ingresa a este bloque y se ejecutan las siguientes instrucciones:
    Escribir "Alerta: Hace demasiado calor.";
FinSi
// --- SI EL RESULTADO ES FALSO: ---
// Si temperatura fuera p. ej. 20 (20 > 35 es FALSO), el programa salta
// directamente aquí abajo sin mostrar ningún mensaje de alerta.

3.2. Condición Compuesta (Si-Entonces / Sino [Else]) con Operadores Lógicos

Permite tomar dos caminos mutuamente excluyentes: un bloque si la condición evalúa a VERDADERO y otro bloque alternativo (Sino) si evalúa a FALSO.

// 1. Declaración de variables
Definir edad Como Entero;
Definir tieneLicencia Como Logico;

// 2. Inicialización de valores para la prueba
edad <- 20;
tieneLicencia <- Verdadero;

// 3. Evaluación paso a paso con Operador Lógico Y (AND):
//    - Condición A: (edad >= 18)        -> (20 >= 18)        -> VERDADERO (V)
//    - Condición B: (tieneLicencia = Verdadero)                -> VERDADERO (V)
//    - Según Tabla de Verdad del Y (Fila 1: V Y V = V): El resultado global es VERDADERO.

Si edad >= 18 Y tieneLicencia = Verdadero Entonces
    // --- SI EL RESULTADO ES VERDADERO: ---
    // Se ejecuta este bloque porque AMBAS condiciones resultaron verdaderas.
    Escribir "Acceso concedido: Cumple con la edad y posee licencia.";
Sino
    // --- SI EL RESULTADO ES FALSO: ---
    // Si cualquiera de las dos condiciones fuera Falsa (ej. Fila 2, 3 o 4 de la Tabla Y),
    // el flujo saltaría a esta sección e ignoraría el bloque de arriba.
    Escribir "Acceso denegado: No cumple la edad mínima o no tiene licencia.";
FinSi

3.3. Condición Anidada (Si dentro de otro Si)

Ocurre cuando colocamos una estructura condicional dentro de otra. El condicional interno sólo se evaluará si el condicional externo resulta VERDADERO.

// 1. Declaración de variables
Definir nota Como Entero;
Definir asistencia Como Entero;

// 2. Inicialización / Asignación de valores
nota <- 15;
asistencia <- 85;

// 3. Evaluación del Condicional Exterior (Nivel 1):
//    - Condición Externa: (asistencia >= 75) -> (85 >= 75) -> VERDADERO

Si asistencia >= 75 Entonces
    // --- SI EL NIVEL 1 ES VERDADERO: ---
    // Como la asistencia es adecuada, ingresamos al bloque y evaluamos el nivel interno (Nivel 2).
    
    // Evaluación del Condicional Anidado (Nivel 2):
    // - Condición Interna: (nota >= 10) -> (15 >= 10) -> VERDADERO
    Si nota >= 10 Entonces
        // RESULTADO FINAL: Asistencia V y Nota V -> APROBADO
        Escribir "Estado: APROBADO (Cumple con asistencia y nota mínima).";
    Sino
        // SI EL NIVEL 2 ES FALSO: (Asistencia V pero Nota F)
        Escribir "Estado: REPROBADO (Asistencia suficiente, pero nota insuficiente).";
    FinSi

Sino
    // --- SI EL NIVEL 1 ES FALSO: ---
    // Si la asistencia hubiera sido menor a 75 (FALSO), el programa salta directamente
    // a este Sino sin ni siquiera evaluar la nota académica (Nivel 2).
    Escribir "Estado: REPROBADO (Inasistencia grave, independientemente de la nota).";
FinSi

4. Estructuras Repetitivas (Bucles)

Los bucles permiten ejecutar de forma reiterada un conjunto de instrucciones basándose en condiciones de parada o en contadores explícitos.

4.1. Bucle "Mientras" (Pre-prueba)

Evalúa la condición antes de ejecutar el bloque. Continúa iterando mientras la condición resulte verdadera. Si la condición inicial es falsa, el bloque jamás se ejecuta.

Mientras condicion Hacer
    // Instrucciones a repetir
FinMientras

Ejemplo 1: Contador regresivo

Algoritmo ContadorRegresivo
    Definir contador Como Entero;
    contador <- 10;
    Mientras contador >= 1 Hacer
        Escribir "Cuenta: ", contador;
        contador <- contador - 1;
    FinMientras;
    Escribir "¡Despegue!";
FinAlgoritmo

Ejemplo 2: Suma indeterminada hasta ingresar cero

Algoritmo SumarHastaCero
    Definir num, suma Como Entero;
    suma <- 0;
    Escribir "Ingrese un numero (0 para terminar):";
    Leer num;
    Mientras num <> 0 Hacer
        suma <- suma + num;
        Escribir "Ingrese otro numero (0 para salir):";
        Leer num;
    FinMientras;
    Escribir "La suma total acumulada es: ", suma;
FinAlgoritmo

Ejemplo 3: Simulación de ahorro hasta alcanzar la meta

Algoritmo MetaDeAhorro
    Definir meta, ahorrado, deposito Como Real;
    meta <- 100;
    ahorrado <- 0;
    Mientras ahorrado < meta Hacer
        Escribir "Llevas $", ahorrado, " de $", meta, ". ¿Cuánto deseas ingresar?";
        Leer deposito;
        ahorrado <- ahorrado + deposito;
    FinMientras;
    Escribir "¡Felicidades! Alcanzaste tu meta con un total de $", ahorrado;
FinAlgoritmo

4.2. Bucle "Repetir-Hasta Que" (Post-prueba)

Garantiza al menos una ejecución del bloque interno antes de evaluar la condición. Finaliza cuando la condición evaluada resulta verdadera.

Repetir
    // Instrucciones a repetir
Hasta Que condicion

Ejemplo 1: Validación de clave de acceso

Algoritmo ValidarClave
    Definir clave Como Cadena;
    Repetir
        Escribir "Ingrese la clave secreta:";
        Leer clave;
        Si clave <> "1234" Entonces
            Escribir "Clave incorrecta. Intente de nuevo.";
        FinSi
    Hasta Que clave = "1234";
    Escribir "¡Acceso concedido!";
FinAlgoritmo

Ejemplo 2: Menú interactivo con opción de salida

Algoritmo MenuOpciones
    Definir opcion Como Entero;
    Repetir
        Escribir "--- MENÚ PRINCIPAL ---";
        Escribir "1. Saludar";
        Escribir "2. Ver hora";
        Escribir "3. Salir";
        Leer opcion;
        Segun opcion Hacer
            1: Escribir "¡Hola! Bienvenid@.";
            2: Escribir "La sesión continúa activa.";
            3: Escribir "Saliendo del programa...";
            De Otro Modo: Escribir "Opción no válida.";
        FinSegun
    Hasta Que opcion = 3;
FinAlgoritmo

Ejemplo 3: Solicitar un número strictly positivo

Algoritmo ValidarPositivo
    Definir num Como Real;
    Repetir
        Escribir "Ingrese un valor positivo (> 0):";
        Leer num;
        Si num <= 0 Entonces
            Escribir "Error: El numero debe ser mayor que cero.";
        FinSi
    Hasta Que num > 0;
    Escribir "Numero valido registrado: ", num;
FinAlgoritmo

4.3. Bucle "Para" (Controlado por Contador)

Ideal para cuando se conoce de antemano la cantidad exacta de iteraciones. Maneja automáticamente la inicialización, la condición de parada y el incremento de la variable de control.

Para i <- 1 Hasta 10 Con Paso 1 Hacer
    // Instrucciones ejecutadas con i variando de 1 a 10
FinPara

Ejemplo 1: Tabla de multiplicar de un número

Algoritmo TablaMultiplicar
    Definir num, i Como Entero;
    Escribir "¿De qué número deseas ver la tabla?";
    Leer num;
    Para i <- 1 Hasta 10 Con Paso 1 Hacer
        Escribir num, " x ", i, " = ", (num * i);
    FinPara
FinAlgoritmo

Ejemplo 2: Generación de números pares del 2 al 20

Algoritmo NumerosPares
    Definir i Como Entero;
    Escribir "Números pares entre 2 y 20:";
    Para i <- 2 Hasta 20 Con Paso 2 Hacer
        Escribir i;
    FinPara
FinAlgoritmo

Ejemplo 3: Promedio de N calificaciones

Algoritmo PromedioNotas
    Definir n, i Como Entero;
    Definir nota, suma, promedio Como Real;
    suma <- 0;
    Escribir "¿Cuántas notas vas a promediar?";
    Leer n;
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir "Ingrese la nota ", i, ":";
        Leer nota;
        suma <- suma + nota;
    FinPara;
    promedio <- suma / n;
    Escribir "El promedio general es: ", promedio;
FinAlgoritmo

5. Ejercicio 1: Determinación de Par o Impar

Problema: Determinar si un número entero ingresado por el usuario es par o impar utilizando el operador módulo (% o MOD).

Análisis Matemático
Un número entero $n$ es par si es divisible por 2, es decir, si $n \bmod 2 = 0$. En caso contrario, el residuo es 1 y el número es impar. 
Algoritmo DeterminarParImpar
    Definir num Como Entero;
    
    Escribir "Ingrese un numero entero:";
    Leer num;
    
    Si num % 2 = 0 Entonces
        Escribir "El numero ", num, " es PAR.";
    Sino
        Escribir "El numero ", num, " es IMPAR.";
    FinSi
FinAlgoritmo

6. Ejercicio 2: Validación de Rangos con Operadores Lógicos (Y / O)

Problema: Solicitar al usuario una nota académica (0 a 20) o un código especial de exoneración (-1). Determinar si la entrada es válida y si aprueba.

Uso de Operadores Lógicos
Se usa el operador Y para comprobar si una nota está dentro del rango válido ($nota \ge 0 \land nota \le 20$), y el operador O para verificar condiciones alternativas. 
Algoritmo ValidarNotaYExoneracion
    Definir nota Como Entero;
    
    Escribir "Ingrese la nota del estudiante (0 a 20) o -1 para exoneración:";
    Leer nota;
    
    // Evaluamos rango válido usando Y, u opción especial usando O
    Si (nota >= 0 Y nota <= 20) O nota = -1 Entonces
        Si nota = -1 O nota >= 10 Entonces
            Escribir "Estado: APROBADO / EXONERADO.";
        Sino
            Escribir "Estado: REPROBADO.";
        FinSi
    Sino
        Escribir "Error: La nota ingresada no es válida.";
    FinSi
FinAlgoritmo

7. Ejercicio 3: Verificación de Número Primo

Problema: Validar si un número entero mayor que 1 es primo (divisible únicamente entre 1 y sí mismo).

Análisis Lógico
Contaremos cuántos divisores exactos tiene el número desde $1$ hasta $n$. Si la suma total de divisores es igual a 2, el número es primo. 
Algoritmo VerificarNumeroPrimo
    Definir num, i, contDivisores Como Entero;
    contDivisores <- 0;
    
    Escribir "Ingrese un numero entero mayor a 1:";
    Leer num;
    
    Si num <= 1 Entonces
        Escribir "El numero debe ser mayor a 1.";
    Sino
        Para i <- 1 Hasta num Con Paso 1 Hacer
            Si num % i = 0 Entonces
                contDivisores <- contDivisores + 1;
            FinSi
        FinPara
        
        Si contDivisores = 2 Entonces
            Escribir "El numero ", num, " es PRIMO.";
        Sino
            Escribir "El numero ", num, " NO es primo.";
        FinSi
    FinSi
FinAlgoritmo

8. Ejercicio 4: Cálculo del Factorial

Problema: Calcule el factorial de un número $n$ no negativo ($n!$).

Definición Matemática
$n! = 1 \times 2 \times 3 \times \dots \times n$. Por definición, $0! = 1$. 
Algoritmo CalcularFactorial
    Definir n, i Como Entero;
    Definir factorial Como Real; // Usamos Real por el rápido crecimiento del valor
    
    Repetir
        Escribir "Ingrese un numero entero no negativo:";
        Leer n;
    Hasta Que n >= 0;
    
    factorial <- 1;
    
    Para i <- 1 Hasta n Con Paso 1 Hacer
        factorial <- factorial * i;
    FinPara
    
    Escribir "El factorial de ", n, " es: ", factorial;
FinAlgoritmo

9. Ejercicio 5: Generación de la Serie de Fibonacci

Problema: Generar e imprimir los primeros $N$ términos de la sucesión de Fibonacci.

Regla de Recurrencia
$F_0 = 0$, $F_1 = 1$, y para $n \ge 2$: $F_n = F_{n-1} + F_{n-2}$. 
Algoritmo GenerarFibonacci
    Definir n, i, a, b, c Como Entero;
    
    Escribir "Ingrese la cantidad de terminos a generar (N >= 1):";
    Leer n;
    
    Mientras n < 1 Hacer
        Escribir "Por favor, ingrese un numero mayor o igual a 1:";
        Leer n;
    FinMientras
    
    a <- 0;
    b <- 1;
    
    Escribir "Los primeros ", n, " terminos de Fibonacci son:";
    
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir a;
        c <- a + b;
        a <- b;
        b <- c;
    FinPara
FinAlgoritmo
