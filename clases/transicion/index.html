Transición: C++ a C# 5.0

Guía rápida de sintaxis para Visual Studio 2012 (.NET Framework 4.5)

1. Estructura Básica del Programa

Comparación entre la estructura tradicional de C++ y la requerida obligatoriamente en C#.

C++:

#include <iostream>
using namespace std;

int main() {
    cout << "Hola Mundo";
    return 0;
}

C# 5.0 (VS 2012):

using System;

class Program {
    static void Main(string[] args) {
        Console.WriteLine("Hola Mundo");
    }
}

2. Entrada y Salida de Datos (¡Atención aquí!)

En C#, Console.ReadLine() siempre captura texto, por lo que las conversiones numéricas deben hacerse de forma explícita.

C++:

int edad;
cout << "Ingresa tu edad: ";
cin >> edad; // El compilador deduce el tipo

C# 5.0 (VS 2012):

Console.Write("Ingresa tu edad: ");
string entrada = Console.ReadLine(); // ¡Siempre lee string!
int edad = int.Parse(entrada);      // Conversión obligatoria

3. Tipos de Datos y Cadenas

El manejo de cadenas de texto nativas y tipos primitivos elementales.

C++:

#include <string>
string nombre = "Carlos"; // Requiere librería <string>
char inicial = 'C';
bool activo = true;

C# 5.0 (VS 2012):

string nombre = "Carlos"; // Tipo nativo primitivo
char inicial = 'C';
bool activo = true;

4. Mostrar Variables en Pantalla

Nota importante: En C# 5.0 (VS 2012) no existe la interpolación con signos de dólar ($).

C++:

int edad = 20;
cout << "Tengo " << edad << " años." << endl;

C# 5.0 (VS 2012):

int edad = 20;
// Opción A: Concatenación tradicional
Console.WriteLine("Tengo " + edad + " años.");

// Opción B: Marcadores de posición
Console.WriteLine("Tengo {0} años.", edad);

5. Control de la Ventana de Consola

Evita que la ventana negra se cierre automáticamente al terminar la ejecución.

C# 5.0 (VS 2012):

Console.WriteLine("Presiona una tecla para salir...");
Console.ReadKey();

Reglas de Oro para recordar en clase

  • Sensibilidad a mayúsculas (Case Sensitive): Console va siempre con 'C' mayúscula.
  • Punto y coma (;): Se mantiene exactamente igual que en C++ al final de cada instrucción.
  • Espacios de nombres: Se utiliza using System; al inicio para acceder directamente a las funciones de la consola.
