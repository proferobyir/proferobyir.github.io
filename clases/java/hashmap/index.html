Map y Scanner en Java Moderno

Guía rápida para desarrolladores y estudiantes con experiencia previa en C#

De C# a Java:

En Java no instanciamos Dictionary como en C#. En su lugar, usamos la interfaz Map<K,V> implementada habitualmente con la clase HashMap<>.

¿Por qué NO usar Dictionary en Java?

Aunque en C# Dictionary<TKey, TValue> es el estándar diario, en Java la clase Dictionary es obsoleta (Java 1.0) y abstracta.

Concepto En C# En Java Moderno
Estructura de Datos Dictionary<K, V> Map<K, V> = new HashMap<>();
Agregar Elemento dic.Add(clave, valor); map.put(clave, valor);
Obtener Elemento var u = dic[clave]; Usuario u = map.get(clave);
Lectura Consola Console.ReadLine(); scanner.nextLine();
Código Completo Corregido

A continuación tienes la forma estándar y limpia para estructurar un Map y leer desde la consola en Java:

Main.java 
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // 1. Declarar e inicializar el Map (Equivalente al Dictionary de C#)
        Map<String, Usuario> dicUsers = new HashMap<>();

        // 2. Instanciar objetos
        Usuario u = new Usuario("Robyir Loreto", "15248304", 45);
        Usuario u1 = new Usuario("Wladimir Loreto", "36011671", 13);

        // 3. Insertar datos con .put() (Similar a .Add() en C#)
        dicUsers.put("15248304", u);
        dicUsers.put("36011671", u1);

        // 4. Preparar lectura por consola (Similar a Console.ReadLine())
        Scanner scanner = new Scanner(System.in);

        System.out.println("Ingrese la cédula a buscar:");
        String code = scanner.nextLine();

        // 5. Buscar valor mediante .get() (Similar a dic[key])
        Usuario estudiante = dicUsers.get(code);

        // 6. Validar resultado
        if (estudiante != null) {
            System.out.println("¡Estudiante encontrado!: " + estudiante);
        } else {
            System.out.println("No existe estudiante registrado con la cédula: " + code);
        }

        scanner.close();
    }
}
Paso a Paso Explicado
1

Uso de la Interfaz Map y Diamante

Se recomienda tipar la variable como la interfaz Map<K,V> y crear la instancia con HashMap<>. El operador diamante <> evita repetir tipos en el constructor.

2

Inserción con el método .put()

En lugar de usar .Add(), Java utiliza .put(clave, valor). Si la clave ya existía en el mapa, el valor anterior será reemplazado automáticamente.

3

Lectura con Scanner (Evita System.in.read)

System.in.read() solo lee un solo byte ASCII. Para leer líneas completas de texto ingresadas por el usuario, utilizamos la clase Scanner y su método scanner.nextLine().

4

Búsqueda Directa con .get()

En Java no usamos corchetes dic[key] para leer. Usamos dicUsers.get(code). Si la clave no está presente en el mapa, nos devolverá un valor null.
