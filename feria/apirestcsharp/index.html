Guía Práctica: API REST en C# 5 y MySQL

Diseñado para Visual Studio 2012 (.NET Framework 4.5) con explicaciones detalladas en código

Recurso esencial: Para conectar tu proyecto con MySQL en este entorno offline, puedes descargar el conector oficial MySql.Data.dll desde este enlace de Google Drive y agregarlo a tus referencias.

Paso 0: Creación y Configuración Inicial en Visual Studio 2012

Sigue estos pasos para crear el proyecto base desde cero en el entorno de laboratorio:

  1. Abre Visual Studio 2012.
  2. Ve al menú superior y selecciona File > New > Project... (Archivo > Nuevo > Proyecto).
  3. En la ventana emergente, selecciona Visual C# > Web y elige la plantilla ASP.NET MVC 4 Web Application.
  4. Abajo en el selector de versión, asegúrate de que esté seleccionado .NET Framework 4.5. Asígnale un nombre (ej. FeriaIutepiAPI) y haz clic en OK.
  5. En el asistente que aparece a continuación, selecciona la plantilla Web API y presiona OK.
  6. Agregar el conector: En el Explorador de soluciones (derecha), haz clic derecho sobre References > Add Reference..., busca y selecciona el archivo MySql.Data.dll que descargaste previamente para habilitar la conexión con MySQL.

Paso 1: Configurar Conexión y CORS (Web.config)

Agrega la cadena de conexión a tu base de datos feria_iutepi y habilita los encabezados CORS en el archivo Web.config para permitir peticiones externas.

<configuration>
  <!-- Sección donde definimos las cadenas de conexión a bases de datos -->
  <connectionStrings>
    <add name="ConexionMySQL" 
         connectionString="Server=127.0.0.1;Database=feria_iutepi;Uid=root;Pwd=;" 
         providerName="MySql.Data.MySqlClient" />
  </connectionStrings>

  <!-- Configuración del servidor web IIS Express para la API -->
  <system.webServer>
    <httpProtocol>
      <customHeaders>
        <!-- CORS: Permite que aplicaciones o páginas web externas consuman esta API -->
        <add name="Access-Control-Allow-Origin" value="*" />
        <add name="Access-Control-Allow-Methods" value="GET, POST, PUT, DELETE, OPTIONS" />
        <add name="Access-Control-Allow-Headers" value="Content-Type, Token" />
      </customHeaders>
    </httpProtocol>
  </system.webServer>
</configuration>

Paso 3: Controlador de Autenticación (Controllers/AuthController.cs)

Crea este controlador en la carpeta Controllers. Valida las credenciales contra la tabla usuarios y emite un token temporal guardado en una lista estática.

using System;
using System.Collections.Generic;
using System.Configuration;
using System.Net;
using System.Net.Http;
using System.Web.Http;
using MySql.Data.MySqlClient;
using FeriaIutepiAPI.Models;

namespace FeriaIutepiAPI.Controllers
{
    public class AuthController : ApiController
    {
        // Obtenemos la cadena de conexión definida en el archivo Web.config
        private readonly string conexionDB = ConfigurationManager.ConnectionStrings["ConexionMySQL"].ConnectionString;
        
        // Diccionario estático en memoria para almacenar las sesiones activas (Token -> Usuario)
        public static Dictionary<string, string> Sesiones = new Dictionary<string, string>();

        // Método POST para iniciar sesión: api/Auth/Login
        [HttpPost]
        public HttpResponseMessage Login([FromBody] LoginModel credenciales)
        {
            // Validamos que el cliente haya enviado los datos obligatorios
            if (credenciales == null || string.IsNullOrEmpty(credenciales.usuario) || string.IsNullOrEmpty(credenciales.password))
                return Request.CreateErrorResponse(HttpStatusCode.BadRequest, "Debe enviar usuario y contraseña.");

            bool usuarioValido = false;

            // Conexión y consulta a MySQL usando ADO.NET clásico
            using (var conexion = new MySqlConnection(conexionDB))
            {
                string query = "SELECT COUNT(*) FROM usuarios WHERE usuario = @usu AND password = @pass AND estado = 1";
                using (var cmd = new MySqlCommand(query, conexion))
                {
                    // Añadimos parámetros para prevenir ataques de Inyección SQL
                    cmd.Parameters.AddWithValue("@usu", credenciales.usuario);
                    cmd.Parameters.AddWithValue("@pass", credenciales.password);
                    
                    conexion.Open();
                    int resultado = Convert.ToInt32(cmd.ExecuteScalar());
                    if (resultado > 0) usuarioValido = true;
                }
            }

            // Si las credenciales son incorrectas, devolvemos error 401 (No autorizado)
            if (!usuarioValido)
                return Request.CreateErrorResponse(HttpStatusCode.Unauthorized, "Credenciales incorrectas.");

            // Si es correcto, generamos un Token único utilizando un GUID
            string token = Guid.NewGuid().ToString();
            
            // Usamos lock para sincronizar hilos concurrentes en el diccionario compartido
            lock (Sesiones)
            {
                Sesiones[token] = credenciales.usuario;
            }

            // Devolvemos una respuesta HTTP 200 con el token generado en formato JSON
            return Request.CreateResponse(HttpStatusCode.OK, new { Token = token, Mensaje = "¡Login exitoso!" });
        }
    }
}

Paso 4: Controlador Protegido con Método Privado (Controllers/ProductosController.cs)

Crea este controlador en la carpeta Controllers. Aquí aplicamos el concepto de método privado para encapsular la validación del Token antes de entregar los datos de la base de datos.

using System.Collections.Generic;
using System.Configuration;
using System.Linq;
using System.Net;
using System.Net.Http;
using System.Web.Http;
using MySql.Data.MySqlClient;

namespace FeriaIutepiAPI.Controllers
{
    public class ProductosController : ApiController
    {
        private readonly string conexionDB = ConfigurationManager.ConnectionStrings["ConexionMySQL"].ConnectionString;

        // =========================================================================
        // MÉTODO PRIVADO DE SEGURIDAD (Concepto clave de visibilidad)
        // Es 'private' porque solo este controlador necesita ejecutar esta validación 
        // internamente y no debe ser expuesto como una ruta web pública para clientes.
        // =========================================================================
        private bool ValidarToken()
        {
            // Verificamos si en los headers (cabeceras HTTP) de la petición viene el campo "Token"
            if (Request.Headers.Contains("Token"))
            {
                string tokenEnviado = Request.Headers.GetValues("Token").FirstOrDefault();

                // Comprobamos si el token existe dentro de las sesiones activas del AuthController
                if (!string.IsNullOrEmpty(tokenEnviado) && AuthController.Sesiones.ContainsKey(tokenEnviado))
                {
                    return true; // ¡Token legítimo y válido!
                }
            }
            return false; // ¡Token ausente o incorrecto!
        }

        // GET: api/Productos (Método público protegido)
        [HttpGet]
        public HttpResponseMessage Get()
        {
            // Llamamos al método privado de seguridad antes de consultar la base de datos
            if (!ValidarToken())
            {
                return Request.CreateErrorResponse(HttpStatusCode.Unauthorized, "Acceso denegado. Falta el Token o es inválido.");
            }

            var lista = new List<object>();

            // Realizamos la consulta a la tabla productos con ADO.NET
            using (var conexion = new MySqlConnection(conexionDB))
            {
                string query = "SELECT id, nombre, precio, stock FROM productos";
                using (var cmd = new MySqlCommand(query, conexion))
                {
                    conexion.Open();
                    using (var reader = cmd.ExecuteReader())
                    {
                        // Recorremos fila por fila los registros obtenidos de MySQL
                        while (reader.Read())
                        {
                            lista.Add(new {
                                Id = reader.GetInt32("id"),
                                Nombre = reader.GetString("nombre"),
                                Precio = reader.GetDecimal("precio"),
                                Stock = reader.GetInt32("stock")
                            });
                        }
                    }
                }
            }

            // Web API convierte automáticamente la lista de objetos anónimos a formato JSON
            return Request.CreateResponse(HttpStatusCode.OK, lista);
        }
    }
}
