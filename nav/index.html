Barra de Navegación Superior con CSS Flexbox

Guía de implementación rápida usando HTML5 semántico y CSS Vanilla.

1. Estructura HTML5 Semántica

El elemento <nav> define la sección de navegación. Para alinear el logo a la izquierda y los enlaces a la derecha, agrupamos las opciones dentro de una lista desordenada (<ul>).

<nav class="navbar"> <a href="#" class="nav-brand">MiSitioWeb</a> <ul class="nav-links"> <li><a href="#inicio">Inicio</a></li> <li><a href="#servicios">Servicios</a></li> <li><a href="#acerca">Acerca de</a></li> <li><a href="#contacto" class="btn-action">Contacto</a></li> </ul> </nav>

2. Estilos CSS3 (Flexbox & Posicionamiento Fijo)

Aplicamos display: flex con justify-content: space-between para separar el logo y el menú hacia los extremos opuestos de la pantalla.

/* 1. Estilos del Contenedor de la Barra */ .navbar { position: fixed; top: 0; left: 0; width: 100%; height: 70px; background-color: #1e293b; display: flex; justify-content: space-between; /* Separa logo a la izq y enlaces a la der */ align-items: center; /* Centra los elementos verticalmente */ padding: 0 2rem; box-sizing: border-box; z-index: 1000; /* Mantiene la barra por encima del contenido */ } /* 2. Estilos del Logo / Marca */ .nav-brand { font-size: 1.25rem; font-weight: bold; color: #38bdf8; text-decoration: none; } /* 3. Estilos de la Lista de Enlaces */ .nav-links { list-style: none; display: flex; /* Pone los ítems en línea horizontal */ gap: 1.5rem; /* Espaciado uniforme entre ítems */ margin: 0; padding: 0; } /* 4. Estilos de los Enlaces */ .nav-links a { color: #94a3b8; text-decoration: none; font-weight: 500; transition: color 0.2s ease; } .nav-links a:hover { color: #ffffff; }

3. Puntos Clave de la Solución

Para lograr la apariencia de barra y la alineación a la derecha sin complicaciones:

  • Ubicación Fija: position: fixed; top: 0; left: 0; width: 100%; garantiza que la barra esté anclada en la parte superior del navegador sin importar cuánto deslices hacia abajo.
  • Compensación del Body: Al usar fixed, el elemento sale del flujo del documento. Es necesario agregar un padding-top al body equivalente al alto de la barra (ej. 80px) para que el contenido no quede oculto por detrás.
  • Alineación Extremo a Extremo: justify-content: space-between envía el primer hijo (logo) al extremo izquierdo y el segundo hijo (.nav-links) al extremo derecho automáticamente.
